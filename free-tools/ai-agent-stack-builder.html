FAQ

What is an AI agent stack?

The set of tools an AI agent runs on: the agent or framework itself, the model, memory and knowledge retrieval (RAG), connectors such as MCP servers, a sandbox to run code safely, and evals or observability to see what it is doing.

Where do the recommendations come from?

From the AgentScout directory of 1,809 link-checked AI agent tools. Your answers filter it, and tools are ordered by AgentScout weekly picks and GitHub stars.

Can I share my stack?

Yes. Copy the link (your choices are saved in it), copy the stack as text, or download a PNG stack card to post.

Does this cost anything?

No. It is free, needs no sign-up and runs in your browser.
