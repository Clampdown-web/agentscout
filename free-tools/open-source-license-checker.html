Open source vs source-available

Open-source licenses (MIT, Apache, BSD, MPL, LGPL, GPL, AGPL) let anyone use, change and share the code, with conditions that range from keeping a notice (permissive) to sharing your changes (copyleft). Source-available licenses (ELv2, BSL, SSPL) publish the code but restrict some uses, most often offering it as a competing hosted service. AgentScout labels these as "Source-available" in the directory.

FAQ

Can I use MIT or Apache 2.0 AI tools in a commercial product?

Yes. Both are permissive: you can use, change and sell software that includes them, as long as you keep the license and copyright notices (and, for Apache 2.0, the NOTICE file and a note of significant changes).

What is the catch with AGPL?

If you change AGPL software and let people use it over a network, for example as a web app, you must offer them the source code of your changed version.

Is source-available the same as open source?

No. Licenses like the Elastic License 2.0, Business Source License and SSPL publish the code but restrict some uses, typically running it as a competing hosted service.

Is this legal advice?

No. It is a plain-English summary of common license terms. Read the actual license and ask a lawyer when it matters.
