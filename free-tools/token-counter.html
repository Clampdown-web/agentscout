How accurate is this?

This is an estimate. It splits text the way modern byte-pair tokenizers roughly do (short common words are one token, long words, symbols and numbers split into several), but it is not OpenAI's, Anthropic's, Google's or xAI's real tokenizer. For plain English it usually lands within about 10–15% of real counts. Code, non-English text and unusual symbols vary more.

Different models count the same text differently. Anthropic says Claude 4.7 and later models use a newer tokenizer that makes about 30% more tokens for the same text, so the counter also shows that figure. For exact counts, use each provider's token-counting API or the usage numbers in an API response.

FAQ

What is a token?

A token is a chunk of text a language model reads or writes, often a short word or part of a longer word. In English, one token is about 4 characters or three-quarters of a word on average.

Is this the exact token count?

No. It is an approximation that runs in your browser. Real counts depend on each model's tokenizer; use the provider's token-counting API when you need exact numbers.

Is my text uploaded anywhere?

No. Counting happens in your browser with JavaScript. Nothing is sent to AgentScout or to any AI provider.

Why count tokens?

API prices, context-window limits and rate limits are all measured in tokens, so a token count tells you whether a prompt fits and what it will cost.
