FAQ

What is AGENTS.md?

AGENTS.md is a plain Markdown file at the root of a repository that tells AI coding agents how to work on the project: what it is, how to build and test it, and the rules to follow. OpenAI Codex reads it, and a growing list of other agents support it (see agents.md).

What is the difference between CLAUDE.md, GEMINI.md and AGENTS.md?

They do the same job for different agents: Claude Code reads CLAUDE.md, Gemini CLI reads GEMINI.md, and Codex and many others read AGENTS.md. The content can be identical, which is why this generator writes them all from one form.

Should I use .cursorrules or .cursor/rules?

.cursor/rules/*.mdc project rules are Cursor's current format; a single .cursorrules file in the project root is the older way and is still recognised by some setups. Check Cursor's docs for your version.

Where does copilot-instructions.md go?

Save it as .github/copilot-instructions.md in your repository so GitHub Copilot uses it as repository custom instructions.

Is anything uploaded?

No. The files are built in your browser and downloaded straight to your device.
