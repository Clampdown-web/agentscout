How it works

An agent re-sends its whole conversation on every step, so input grows: step k sends the system prompt and tools, the starting context, and every earlier tool result and model reply. The estimator adds those up step by step. The cached share applies to input that was already sent on an earlier step (prompt caching), billed at the cached rate; the first step is always full price. Retries add extra steps at the average step cost.

Prices are the same verified list the AI API cost calculator uses, checked on 2026-10-21 from each provider's official pricing page (standard tier, short-context rates). This tool does not list context-window sizes: check the provider page to make sure your final-step context fits the model.

FAQ

Why is an agent task so much more expensive than one chat request?

Each step re-sends the full conversation so far, including every tool result, so input tokens grow with every step. A 10-step task can use many times the tokens of a single prompt.

How does prompt caching change the cost?

Input already sent on an earlier step can often be served from the provider's prompt cache at a lower cached rate. Set the cached share to how much of that repeated input you expect to hit the cache; 0% means no caching.

Are reasoning tokens included?

Only if you add them. Thinking tokens are billed as output, so raise the output-per-step figure if your model reasons before acting.

Where do the prices come from?

The same list as the AgentScout cost calculator, copied from the official OpenAI, Anthropic, Google and xAI pricing pages on 2026-10-21. Confirm on the provider page before you budget.
