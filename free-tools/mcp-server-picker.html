FAQ

What is an MCP server?

A Model Context Protocol server is a small program that gives an AI app like Claude Desktop, Cursor or VS Code access to a tool or data source, such as GitHub, a database or your files, through one standard interface.

How are matches found?

By keyword across the name, description and tags of every MCP and infrastructure tool in the AgentScout directory, with servers named after the app first, then AgentScout picks and GitHub stars. Read each server's page to confirm it does what you need.

How do I install the servers I pick?

Follow the install steps in each server's own docs, then paste the details into the MCP config builder to get config for Claude Desktop, Cursor, VS Code or Claude Code.

Are MCP servers safe?

Only as safe as the code and the permissions you give them. Prefer official or well-maintained servers, give the least access needed, and never paste real secrets into shared files.
