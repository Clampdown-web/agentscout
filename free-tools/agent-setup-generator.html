AI agent setup generator

Describe your agent once and get starter config files and system prompts for Claude Code, Codex, Cursor, CrewAI, LangChain and the OpenAI Agents SDK.

Free, no sign-up. Runs entirely in your browser: nothing you type is sent to AgentScout or any AI provider.

These are starting points. Check each project's docs for the latest options. Framework pages on AgentScout: Claude Code · OpenAI Codex CLI · Cursor · CrewAI · OpenAI Agents SDK.

What each file is for

  • CLAUDE.md is read by Claude Code at the start of every session in that folder; .mcp.json adds project-scoped MCP servers.
  • AGENTS.md is the instructions file OpenAI Codex CLI (and a growing list of other coding agents) read from your repo.
  • .cursor/rules/*.mdc are Cursor project rules; alwaysApply: true includes the rule in every chat.
  • agents.yaml and tasks.yaml live in src/<project>/config/ of a CrewAI project.
  • The LangChain and OpenAI Agents SDK snippets are runnable Python starters; add your API key as an environment variable.

FAQ

Which frameworks does the generator support?

Claude Code (CLAUDE.md and .mcp.json), OpenAI Codex CLI (AGENTS.md), Cursor project rules, CrewAI YAML config, LangChain's create_agent in Python, the OpenAI Agents SDK in Python, and a plain system prompt for any model.

Do I need an API key?

Not to use the generator. To run the generated Python or CrewAI code you need a key for the model provider you choose, set as an environment variable.

Is anything sent to a server?

No. Files are generated in your browser, and the download button saves them straight to your device.

Are these files production-ready?

They are starter scaffolds. Review them, add real tool code and check each framework's documentation for the latest options.
