FAQ

What is llms.txt?

llms.txt is a proposed standard (llmstxt.org) for a Markdown file at the root of a website that gives AI assistants a short summary and a curated list of the most useful pages, so they don't have to crawl everything.

What format does this generator follow?

An H1 with the site name, an optional blockquote summary, optional details, then H2 sections that contain Markdown link lists, with an optional note after each link. A section called Optional holds links that can be skipped when context is short.

Does AgentScout have one?

Yes: agentscouthq.com/llms.txt lists the directory's categories and machine-readable catalog.

Is anything uploaded?

No. The file is built in your browser and downloaded directly.
