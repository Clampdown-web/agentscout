MCP config builder

Add your MCP servers once and get config you can paste into Claude Desktop, Cursor, VS Code and Claude Code. See also the MCP & infra category.

Free, no sign-up. Runs entirely in your browser: nothing you type is sent to AgentScout or any AI provider.

One server per line. Local (stdio) servers: name | command and arguments | KEY=value KEY2=value. Remote servers: name | https://url.

Claude Desktop: claude_desktop_config.json

Cursor: .cursor/mcp.json (project) or ~/.cursor/mcp.json

VS Code: .vscode/mcp.json

Claude Code: terminal commands

Claude Desktop connects to remote servers through the mcp-remote bridge here; newer versions can also add remote servers under Settings → Connectors. Never paste real secrets into shared files.

FAQ

Where does the Claude Desktop config file live?

On macOS it is ~/Library/Application Support/Claude/claude_desktop_config.json and on Windows %APPDATA%\Claude\claude_desktop_config.json. You can also open it from Claude Desktop's Settings → Developer → Edit Config. Restart Claude Desktop after saving.

What is the difference between the Cursor and VS Code formats?

Cursor's mcp.json uses a top-level mcpServers object, like Claude Desktop. VS Code's .vscode/mcp.json uses a top-level servers object and a type field (stdio or http) for each server.

Does this tool install or run anything?

No. It only formats text in your browser. You still need Node.js (for npx servers) or whatever runtime each server needs, and you should only add servers you trust.
