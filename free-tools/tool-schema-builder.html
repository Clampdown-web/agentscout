    FAQ

    Why does each provider need a different format?

    They all use JSON Schema for the parameters, but wrap it differently: OpenAI's Responses API takes type, name, description and parameters at the top level; Chat Completions nests them under function; Anthropic calls the schema input_schema; Gemini lists functions under functionDeclarations.

    What does OpenAI strict mode change?

    With strict set to true, the model's arguments are guaranteed to match your schema. OpenAI requires every property to be listed as required and additionalProperties to be false; use a nullable type if a field is truly optional.

    Can I use nested objects?

    This builder makes flat parameter lists with empty object and string-array placeholders. Edit the output by hand for deeper nesting.

    Is anything sent to an AI provider?

    No. The schema is generated in your browser.
