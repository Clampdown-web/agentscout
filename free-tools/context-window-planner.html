    FAQ

    What is a context window?

    The maximum number of tokens a model can take in one request, counting the system prompt, tool definitions, conversation history, documents and the reply it writes.

    Why reserve tokens for the reply?

    The model's output shares the same window on most APIs. If the input fills it, the reply gets cut short or the request fails.

    Why doesn't AgentScout list each model's context size?

    Sizes change often and can differ by plan, region or API tier, so we only show figures you can check. Enter the number from the provider's model page.

    What if I'm over the limit?

    Trim history (summarize older turns), retrieve fewer or shorter documents, shorten tool descriptions, or choose a model with a larger window.
