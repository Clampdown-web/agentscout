AI agent news: November 2026

50 stories about AI agents, coding agents and MCP. Open a story for its summary, related tools and the source link.

Friday, November 27, 2026

  1. Switzerland says AI agents broke into four of five targets

    The Next Web reports that Switzerland's National Cyber Security Centre has five confirmed cases of cyberattacks carried out with AI agents, and that attackers got into systems in four of them. Director Florian Schütz told SRF on Thursday that three cases targeted critical-infrastructure operators and two of those succeeded, with no major outages. The centre's Tuesday notice had said every known case succeeded. It wants critical updates on internet-facing systems within 24 hours, and multi-factor authentication or passkeys on services such as webmail and VPNs.

    The Next Web

  2. Papa John's order is the UK's first cardless AI agent payment

    The Guardian reports that an order of nine Papa John's mini pizzas is the first UK purchase in which an AI agent paid a retailer without a card. The Financial Conduct Authority sandbox trial used Lloyds Bank and TrueLayer. The agent had a spend cap per transaction and per month, and no account security details were shared. TrueLayer chief executive Francesco Simoneschi said the customer described the occasion, confirmed the order, and existing buyer-protection rules still apply if the agent orders the wrong thing.

    The Guardian

  3. Black Friday tests shopping agents, and most shoppers will not let them pay

    Fortune reports that a Morning Consult poll for Visa found 54 percent of adults have used AI for at least one shopping task, while 23 percent trust generative AI to handle a payment. In a Visa trial, 22 personal agents shopped for a TV, a laptop, and a hair appliance, and only 57 percent of 15 trips each ended in a suitable purchase or suggestion. An American Express survey found 52 percent would let an agent buy low-cost essentials, and 15 percent would let it buy big-ticket electronics.

    Fortune

Thursday, November 26, 2026

  1. Mail opens an MCP server for email, cloud files, and calendar

    VK's Mail opened an MCP server on 27 November 2026 so an AI agent can work in Mail, Cloud, and Calendar for every user. In mail it can find messages and attachments, summarize a thread, and draft or send mail. In cloud storage it can upload, download, and sort files. In the calendar it can find a free time, create an event from a message, and add a call link. The server only sees what that user can already see, and the person signs in and chooses what to allow.

    VK

  2. UK retailers ask who pays if a shopping agent gets the order wrong

    The Guardian reports that Meta's Muse, which launched in the UK on Tuesday, is working with Marks & Spencer, Sainsbury's, JD Sports, and Currys. A YouGov poll found a third of people planning to shop Black Friday intend to get help from AI, up from 19 percent last year, while KPMG found 12 percent plan to use an AI tool specifically to find deals. Muse must ask before it buys or sends email. Retailers told the paper they will not hand over checkout until it is clear who is liable when an agent gets an order wrong.

    The Guardian

  3. Linux 7.5 is set to gain in-tree skills for coding agents

    Phoronix reports that NVIDIA's Sasha Levin, who co-maintains the Linux long-term kernels, plans to send an agents/skills directory to Linus Torvalds for the Linux 7.5 merge window in late December. He asked for the branch to be dropped from linux-next because it is ready for mainline. The first skills cover Fixes tags, stable tags, finding other copies of a bug, commit messages, and KUnit tests.

    Phoronix

  4. Enhancv opens a resume MCP server inside Claude and ChatGPT

    Enhancv launched a remote MCP server on 26 November 2026 that lets Claude, ChatGPT, Cursor, and VS Code edit the resume stored in a person's Enhancv account. Changes show up in the editor to keep or undo, and the connector is told to ask when a bullet needs a number the person has not given. It cannot delete resumes or reach billing. Reading and job search work on the free plan. Editing, tailoring, cover letters, and PDF downloads need Enhancv Pro.

    EIN Presswire

  5. Meta declined a UK watchdog's offer to test Muse before launch

    WIRED reports that Meta turned down a Financial Conduct Authority suggestion to test Muse together in the regulator's sandbox before the UK rollout. Colin Payne, the FCA's head of innovation, said the agency wants to see how the agent handles payments and whether it acts for the customer. Meta said it has engaged with the relevant regulators. The Competition and Markets Authority said it will act if it has concerns about UK consumers.

    WIRED

Wednesday, November 25, 2026

  1. Gap uses Cognition's Devin to keep holiday shopping online

    Gap Inc. said on 25 November 2026 that engineers use Cognition's Devin agent on its ecommerce sites. A daily site scan looks for shopper friction and system faults, then drafts a tested code fix for a person to review and publish. Gap says that work has helped recover millions in sales that downtime would have lost, and that people still approve every change.

    Gap Inc.

  2. Human Security sees AI agent traffic heading for a 150x Cyber Week

    Adweek reports that Human Security expects AI agent traffic during Cyber Week, 26 to 30 November, to reach about 150 times last year's level, with checkout-page requests near 160 times. Meta's Muse accounts for about 70 percent of the agent traffic Human sees and 57 percent of checkout requests. The figures count page and search actions on sites Human protects, not completed orders.

    Adweek

  3. Amazon and Meta reportedly in talks to lift blockade on AI agent Muse

    TechCrunch reports that Amazon and Meta have held talks about letting Muse shop on Amazon, according to Fortune. The open questions are how search results would appear and how advertising would work, and any deal would need both chief executives to approve it. Two months ago, Muse shoppers could not check out on Amazon. Neither company had commented.

    TechCrunch

  4. Duco opens an MCP server for post-trade reconciliation agents

    Duco made its MCP server generally available on 25 November 2026. Agents on any MCP client can search reconciliation breaks, label them, and match or clear exceptions under the user's existing permissions. Every action is written to Duco's audit log, and the server is available to Duco clients.

    Duco

  5. Alta opens an MCP server so sales agents can prospect in chat

    Alta opened Alta MCP in Claude, ChatGPT, and Codex on 25 November 2026. A rep can describe an audience, get verified contacts, and draft a multichannel campaign in the same chat. Campaigns stay drafts until a person launches them, and sending or resuming a campaign asks for confirmation first.

    Alta

Tuesday, November 24, 2026

  1. Magister opens a marketing MCP server across 85 tools

    Magister Marketing launched an MCP server on 25 November 2026 that connects Claude, ChatGPT, Codex, Cursor, and other MCP clients to 85 marketing tools. It can read analytics and ad accounts and draft posts, but anything that publishes, sends, or spends waits for a person to approve it. Connect is $29 a month and the Agent plan is $99 a month, after a free trial.

    EIN Presswire

  2. Google Workspace opens MCP servers and a CLI for governed AI agents

    Google made Workspace MCP servers and a Workspace CLI generally available, giving agents a managed way into Gmail, Drive, Docs, Sheets, and other Workspace apps. A new addendum tells agents to use those doors instead of REST APIs, with technical enforcement starting 1 February 2027. Admins can require confirmations, read audit logs, and revoke access.

    Google

  3. Even the best AI agents struggle with everyday life

    TechCrunch covers ShellBench, a test of 100 everyday tasks built from real agent requests in messy personal files. The leading models finished only about 60 percent of attempts, and 15.7 percent of all runs missed a safety check. The top scorer passed all three repeats of the same task less than half the time.

    TechCrunch

  4. Walmart teams up with Meta to bring Black Friday deals to AI agent Muse

    TechCrunch reports Walmart is partnering with Meta so Black Friday deals show up inside Muse, Meta's personal AI agent.

    TechCrunch

  5. Maple raises $5.3M for a private desktop agent and a cloud agent that stays on

    TechCrunch reports Maple closed a $5.3 million seed round led by Epic Ventures. Maple Work is a desktop agent that can use local files, apps, and the browser, with chats decrypted only inside a hardware enclave the company says it cannot read. The round is meant to fund a cloud agent that keeps working after the computer is off.

    TechCrunch

  6. Anthropic opens Skills over MCP and long-running tasks in Claude

    Anthropic put Skills over MCP in public beta, so apps connected to Claude can ship step-by-step guides that load only when a task needs them. Tasks, which keep long jobs running in the background, and Elicitation, which stops to ask the user, are now generally available in Claude and Claude Code. Shopify, GitHub, and Supabase are among the first users.

    The Next Web

  7. JFrog says an AI agent published Hugging Face malware and leaked its own keys

    JFrog Security Research says an autonomous agent it calls ARTEX uploaded fake Hugging Face models that steal cloud credentials and commit them back to a public repo. The payload ran on the operator's own machine and exposed the agent's keys. Hugging Face disabled all 13 repos in the campaign on 24 November after JFrog reported them.

    JFrog

  8. Mesh launches an MCP server so coding agents can build payments flows

    Mesh launched Mesh MCP, a hosted server that lets a coding agent assemble a payments integration from Mesh's live documentation and API spec. Each request is checked against that spec before it is sent. The server is read-only, does not move funds, and connects to Claude Code, Cursor, Codex, and other MCP clients.

    PR Newswire

  9. UK ICO says it will act if consumer AI agents ship without user controls

    The UK Information Commissioner's Office said it will step in when organisations rush out consumer AI agents without privacy safeguards and real user controls. It wants privacy built in from the start, and says guidance informed by its call for evidence is due in spring 2027. The post does not name a product or announce a fine.

    ICO

    The Verge
