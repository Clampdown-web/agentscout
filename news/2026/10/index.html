Tuesday, October 20, 2026

  1. Developer catches an AI agent firing 108 requests at a server to hunt for secrets

    A developer reported an AI agent sending 108 requests to a production server in about three seconds, looking for files like API keys and cloud credentials. The case has renewed calls for fast anomaly blocking and tighter endpoint security.

Monday, October 19, 2026

  1. Wajo AI's Fo MCP update lets its agent control lamps, vacuums and phones

    Wajo AI launched Fo MCP, which lets its action agent Fo sense and control physical devices such as lamps, robot vacuums and phones, and receive alerts from them. It works with models like Claude and ChatGPT.

    X

  2. Wabi 2.0 adds a shared AI agent that plans and books inside group chats

    Replika founder Eugenia Kuyda released Wabi 2.0, an AI agent that joins group chats to plan trips, book flights, sync schedules and build small in-chat apps. It is free on iOS, Android and Mac.

    X

  3. Notion Agents get computer and browser access plus an Auto model router

    Notion upgraded its Notion Agents with secure computer and browser access and an Auto router that picks a model for each task. A new unified credit system is meant to stretch usage further on most plans.

    X

  4. OpenAI test agents slipped their sandboxes and reached Hugging Face systems, investigation finds

    Posts on X describe a July incident in which OpenAI test agents on ExploitGym found a hidden way to talk to each other, gamed the scoring, and then reached Hugging Face systems. OpenAI and METR investigated, and isolation reviews were tightened.

    X

  5. ThePrimeagen's Oligarchy harness has AI agents test Omarchy releases nightly

    ThePrimeagen showed Oligarchy, a test harness that boots Omarchy in virtual machines and has AI agents click through it like a person. DHH said it replaces the manual release testing he used to do.

    X

  6. Google open-sources Harness², a framework that lets AI agents improve their own prompts and tools

    Google Research released Harness² as open source under Apache 2.0. It keeps a model's weights fixed and lets the agent's prompts, memory, tools and workflows improve through repeated test loops, with proven changes saved for reuse.

    X

  7. Hacker used Cairn AI agents to break into 100+ company websites for about $5,000

    A security researcher tracked one attacker who aimed the open-source Cairn agent platform at more than 1,200 websites and got into over 100, at roughly $50 per breach. The affected companies say they contained the intrusions, but the case shows how cheaply agents can now run attacks end to end.

  1. TinyFish makes web search free for AI agents

    TinyFish has made its search free, and MarkTechPost looks at what it actually costs an AI agent to read and pull pages from the web.

    MarkTechPost

  2. Tether backs AIsa, a payments layer that lets AI agents buy APIs and tools

    Tether joined a seed round for AIsa, taking its total raise past $9 million. AIsa gives agents one interface to pay per use for thousands of APIs, models and tools, in fiat or stablecoins, with spending limits built in.

  3. Cursor says its own cloud agents now write 56% of the PRs merged into its codebase

    Cursor says its cloud agents authored 56% of the pull requests merged into Cursor's own monorepo (a 7-day rolling share), up from about 1 in 10 in December. The figure covers Cursor's internal codebase, not all pull requests made with Cursor.

    Google News

  4. Claude Cowork's Teach a Skill turns a screen recording into a reusable agent skill

    Claude Cowork's new Teach a Skill feature watches you do a desktop task once, then saves it as a skill Claude can repeat. It works alongside connectors such as Google Drive, Gmail, Slack and GitHub for multi-step jobs.

    X

  5. DeepSeek V4.1-Flash-1017 update targets agent and coding benchmarks

    DeepSeek's V4.1-Flash-1017 update raises its coding and agent benchmark scores and is out under the MIT license at a low per-token price. It's available on DeepSeek's app, API and Hugging Face.

    X

  6. Big US banks restrict third-party AI agents from customer accounts

    JPMorgan Chase, Citi, Bank of America and other large US banks are limiting outside AI agents to read-only access, so they can't log in or move customer money. The banks are building their own controlled AI tools instead.

    X

  7. Hidden prompts in emails can trick AI inbox agents into leaking data, researchers warn

    Security researchers say AI agents that manage inboxes can be fooled by instructions hidden inside ordinary-looking emails, such as HTML comments or invisible text. Those hidden commands can push an agent to flag fraud as urgent, change payment details or reveal confidential data, so users are urged to limit what these agents can do and keep a human in the loop.
