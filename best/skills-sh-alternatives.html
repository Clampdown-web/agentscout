skills.sh alternatives (2026)

skills.sh is a agent infra tool: Vercel Labs' open-source CLI (npx skills) and directory for finding, installing and sharing agent skills across Claude Code, Codex, Cursor, OpenCode and 75+ other coding agents. Pricing, as the maker states it: Open source (MIT). Its GitHub repo has 35,459 stars. We found 16 tools in the directory that do overlapping work (writing code, coding in the terminal); 12 of them are open source and 2 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with skills.sh, then by GitHub stars.

  1. CLI-Anything (Open source): Open-source project from HKUDS that generates agent-native command-line interfaces for existing software, codebases and web APIs, with CLI-Hub, a registry of community CLIs that coding agents can install and drive. Consider it because it also covers codebase context and code search and MCP gateways and registries; it has more GitHub stars (54,399 vs 35,459).
  2. opencodex (Open source): A local provider proxy that lets OpenAI Codex (CLI, app and SDK) and Claude Code run on other model providers such as Claude, Gemini, Grok, DeepSeek or local Ollama models. Consider it because it also covers MCP gateways and registries and agent frameworks and SDKs.
  3. Magpie (Open source): Free, open-source menu bar app and local gateway that lets any coding agent (Claude Code, Codex, Gemini CLI, OpenCode and 60+ more) use any model provider or subscription, with failover when a quota runs out. Consider it because it also covers MCP gateways and registries and local and self-hosted.
  4. Open Terminal (Open source): Self-hosted terminal service from the Open WebUI team that gives AI agents an API to run commands, manage files and execute code. Consider it because it also covers local and self-hosted.
  5. Vectoree (Usage-based): Vectoree gives coding agents a backend behind one project key: an OpenAI-compatible model gateway across providers, an MCP tool hub, auth, Postgres and storage, driven by a skill and CLI, pay-as-you-go with no monthly fee. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers SQL and databases and RAG and documents.
  6. Google Workspace CLI (Open source): Official Google Workspace command-line tool for Drive, Gmail, Calendar, Docs and more, usable by agents. Consider it because it also covers email.
  7. Open Connector (Open source): Open-source auth gateway connecting SaaS apps to AI agents via SDK, CLI and MCP. Consider it because it also covers identity, auth and secrets and MCP gateways and registries.
  8. Mirage (Open source): Virtual terminal environment for AI agents. Consider it because it does the same job with a different approach (open source).
  9. NVIDIA Open Agent Safety Platform (Open source): Reference stack pairing OpenShell with NVIDIA Sentry on BlueField-4 DPUs for hardware-level agent monitoring. Consider it because it also covers guardrails and policies and tracing and observability.
  10. XCrawl (Freemium): XCrawl is a web scraping, crawling and SERP API that returns clean JSON, Markdown or screenshots in one request, with agent skills for plugging it into AI agents; free trial with no card. Consider it because it also covers scraping and crawling.
