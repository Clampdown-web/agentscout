skills.sh alternatives (2026)

skills.sh is a MCP & infra tool: Vercel Labs' open-source CLI (npx skills) and directory for finding, installing and sharing agent skills across Claude Code, Codex, Cursor, OpenCode and 75+ other coding agents. Pricing, as the maker states it: Open source (MIT). Its GitHub repo has 35,459 stars. We found 277 tools in the directory that do overlapping work (writing code, coding in the terminal, connecting tools with MCP); 149 of them are open source and 28 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with skills.sh, then by GitHub stars.

REA (Open source): MCP server and CLI that lets coding agents reverse engineer native binaries, Electron and JavaScript apps, .NET assemblies and live websites, using Ghidra, Hopper or IDA under the hood. Consider it because it also covers MCP servers; it has more GitHub stars (301,645 vs 35,459).
  2. CLI-Anything (Open source): Open-source project from HKUDS that generates agent-native command-line interfaces for existing software, codebases and web APIs, with CLI-Hub, a registry of community CLIs that coding agents can install and drive. Consider it because it also covers codebase context and code search and MCP gateways and registries; it has more GitHub stars (54,399 vs 35,459).
  3. Magpie (Open source): Free, open-source menu bar app and local gateway that lets any coding agent (Claude Code, Codex, Gemini CLI, OpenCode and 60+ more) use any model provider or subscription, with failover when a quota runs out. Consider it because it also covers MCP gateways and registries and local and self-hosted.
  4. Open Terminal (Open source): Self-hosted terminal service from the Open WebUI team that gives AI agents an API to run commands, manage files and execute code. Consider it because it also covers local and self-hosted.
  5. Sentry MCP (Source-available + cloud): Sentry's MCP server and CLI that give coding agents access to Sentry issues, errors and traces for debugging. Consider it because it also covers tracing and observability and MCP servers.
  6. GitKraken MCP (See site): GitKraken's MCP server, via the GitKraken CLI, for managing repos, pull requests and issues across GitHub, GitLab and Bitbucket. Consider it because it also covers code review and MCP servers.
  7. CircleCI MCP (Freemium): CircleCI's MCP servers (hosted and CLI) for diagnosing build failures, inspecting runs and managing CI pipelines from coding agents. Consider it because it also covers MCP servers.
  8. Vectoree (Usage-based): Vectoree gives coding agents a backend behind one project key: an OpenAI-compatible model gateway across providers, an MCP tool hub, auth, Postgres and storage, driven by a skill and CLI, pay-as-you-go with no monthly fee. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers SQL and databases and RAG and documents.
  9. Google Workspace CLI (Open source): Official Google Workspace command-line tool for Drive, Gmail, Calendar, Docs and more, usable by agents. Consider it because it also covers email.
  10. MCP Inspector (Open source): Official developer tool for testing and debugging MCP servers through a web UI, CLI or terminal UI. Consider it because it also covers MCP servers.
