LangGraph alternatives (2026)

LangGraph is a frameworks tool: Framework for stateful, graph-based agent workflows. Pricing, as the maker states it: Open source. Its GitHub repo has 43,868 stars. We found 136 tools in the directory that do overlapping work (automating workflows, building AI agents, memory for agents); 130 of them are open source and 2 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with LangGraph, then by GitHub stars.

  1. tRPC-Agent-Go (Open source): Go framework for production agent systems with graph workflows, tools, memory, A2A, AG-UI, MCP, evaluation and OpenTelemetry. Consider it because it also covers memory and evals and benchmarks.
  2. Ruflo (Open source): Open-source multi-agent meta-harness for Claude Code, Codex, and MCP clients; Oct 13 release adds Mods (mission workflows) and a single control plane with human approval. Consider it because it also covers running many agents in parallel and multi-agent orchestration; it has more GitHub stars (79,153 vs 43,868).
  3. OpenAI Agents SDK (Python) (Open source): OpenAI's Python SDK for building multi-agent workflows; v0.23.0/0.23.1 released Oct 1-2. Consider it because it also covers multi-agent orchestration.
  4. Mastra (Open source): TypeScript framework for agents, workflows and RAG. Consider it because it also covers RAG and documents.
  5. Go Micro (Open source): Go framework for distributed systems where services double as tools for AI agents, with RPC, discovery, messaging and agent workflows. Consider it because it does the same job with a different approach (open source).
  6. Microsoft Agent Framework (Open source): Microsoft's framework for building and orchestrating agents and multi-agent workflows in Python and .NET. Consider it because it also covers multi-agent orchestration.
  7. PocketFlow (Open source): Minimalist 100-line LLM framework for building agents and workflows. Consider it because it does the same job with a different approach (open source).
  8. Marvin (Open source): Python library from Prefect for building AI agents and structured LLM workflows. Consider it because it does the same job with a different approach (open source).
  9. eve (Open source): Vercel's open-source agent framework, pitched as Next.js for agents: a file-system-based way to define an agent's tools, prompts and workflows and run it in production. Consider it because it also covers vocal tuning and vocal plugins.
  10. EvoAgentX (Open source): Framework for building, evaluating and automatically evolving LLM agents and agentic workflows. Consider it because it also covers evals and benchmarks.
