  1. tRPC-Agent-Go (Open source): Go framework for production agent systems with graph workflows, tools, memory, A2A, AG-UI, MCP, evaluation and OpenTelemetry. Consider it because it also covers memory and evals and benchmarks.
  2. Ruflo (Open source): Open-source multi-agent meta-harness for Claude Code, Codex, and MCP clients; Oct 13 release adds Mods (mission workflows) and a single control plane with human approval. Consider it because it also covers running many agents in parallel and multi-agent orchestration; it has more GitHub stars (74,609 vs 43,237).
  3. OpenAI Agents SDK (Python) (Open source): OpenAI's Python SDK for building multi-agent workflows; v0.23.0/0.23.1 released Oct 1-2. Consider it because it also covers multi-agent orchestration.
  4. Go Micro (Open source): Go framework for distributed systems where services double as tools for AI agents, with RPC, discovery, messaging and agent workflows. Consider it because it does the same job with a different approach (open source).
  5. Microsoft Agent Framework (Open source): Microsoft's framework for building and orchestrating agents and multi-agent workflows in Python and .NET. Consider it because it also covers multi-agent orchestration.
  6. PocketFlow (Open source): Minimalist 100-line LLM framework for building agents and workflows. Consider it because it does the same job with a different approach (open source).
  7. Marvin (Open source): Python library from Prefect for building AI agents and structured LLM workflows. Consider it because it does the same job with a different approach (open source).
  8. EvoAgentX (Open source): Framework for building, evaluating and automatically evolving LLM agents and agentic workflows. Consider it because it also covers evals and benchmarks.
  9. Workflow SDK (Open source): Vercel's TypeScript SDK for building durable, reliable and observable apps and AI agents. Consider it because it also covers tracing and observability.
  10. Mastra (Open source): TypeScript framework for agents, workflows and RAG. Consider it because it also covers RAG and documents.
