AnythingLLM is a personal agents tool: Local-first desktop and server app for chatting with your documents, running agents and connecting any LLM. Pricing, as the maker states it: Open source + cloud. Its GitHub repo has 67,747 stars. We found 111 tools in the directory that do overlapping work (controlling a computer, personal assistance, working with documents); 60 of them are open source and 28 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with AnythingLLM, then by GitHub stars.

Updated November 9, 2026

  1. 5ire (Source-available): Cross-platform desktop AI assistant and MCP client with a local knowledge base and support for major model providers. Consider it because it does the same job with a different approach (source-available).
  2. Ekko Studio (Open source): Ekko Studio (formerly Hermes Studio / Hermes Web UI) is a local-first desktop app and self-hosted web console for multi-agent chat, coding and visual workflows, supporting Hermes Agent, Ekko Agent and 14 coding-agent integrations including Claude Code and Codex, with group chat, voice, files and human approval gates. Consider it because it is aimed at developers who want to build on it; it also covers voice and phone agents and workflow automation.
  3. DeepChat (Open source): Open-source, local-first AI agent desktop client with MCP, skills, ACP support and remote control from messaging apps. Consider it because it also covers rules, skills and config.
  4. LobsterAI (Open source): NetEase Youdao's desktop agent for data analysis, slides, documents and web research. Consider it because it also covers research and reports.
  5. Orkas (Open source): Local-first multi-agent desktop app where a commander model coordinates specialist agents and your installed coding CLIs. Consider it because it also covers multi-agent orchestration.
  6. AnyModelBot (Open source): AnyModelBot is an open-source, local-first personal AI agent app for Windows, macOS and Linux where each bot has its own persona, model, workspace and memory, reachable in the app or chat apps, and it can work files, commands and your desktop with any model on pay-as-you-go billing. Consider it because it also covers memory.
  7. JustHireMe (Open source): Local-first desktop workbench that finds job listings, ranks your fit and generates tailored application materials. Consider it because it does the same job with a different approach (open source).
  8. Jarvis (Source-available): Private, local-first desktop AI assistant with voice and text chat, personal memory, dictation and MCP tools. Consider it because it also covers memory and voice and phone agents.
  9. Akeru Bot (Open source): Open-source alternative to Grok Bot for named AI teammates: local-first desktop, web and mobile clients where each bot has its own tools, instructions and memory. MIT-licensed independent fork of T3 Code. Consider it because it is aimed at developers who want to build on it; it also covers memory and mobile and remote control.
  10. Eigent (Open source): Open-source cowork desktop app that runs multi-agent workflows locally. Consider it because it also covers workflow automation and multi-agent orchestration.
