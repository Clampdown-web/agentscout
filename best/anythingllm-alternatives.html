AnythingLLM alternatives (2026)

AnythingLLM is a personal agents tool: Local-first desktop and server app for chatting with your documents, running agents and connecting any LLM. Pricing, as the maker states it: Open source + cloud. Its GitHub repo has 67,210 stars. We found 62 tools in the directory that do overlapping work (running agents locally, working with documents, controlling a computer); 39 of them are open source and 9 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with AnythingLLM, then by GitHub stars.

  1. 5ire (Source-available): Cross-platform desktop AI assistant and MCP client with a local knowledge base and support for major model providers. Consider it because it does the same job with a different approach (source-available).
  2. DeepChat (Open source): Open-source, local-first AI agent desktop client with MCP, skills, ACP support and remote control from messaging apps. Consider it because it also covers rules, skills and config.
  3. LobsterAI (Open source): NetEase Youdao's desktop agent for data analysis, slides, documents and web research. Consider it because it also covers research and reports.
  4. JustHireMe (Open source): Local-first desktop workbench that finds job listings, ranks your fit and generates tailored application materials. Consider it because it does the same job with a different approach (open source).
  5. Orkas (Open source): Local-first multi-agent desktop app where a commander model coordinates specialist agents and your installed coding CLIs. Consider it because it also covers multi-agent orchestration.
  6. Jarvis (Source-available): Private, local-first desktop AI assistant with voice and text chat, personal memory, dictation and MCP tools. Consider it because it also covers memory and voice and phone agents.
  7. Eigent (Open source): Open-source cowork desktop app that runs multi-agent workflows locally. Consider it because it also covers workflow automation and multi-agent orchestration.
  8. Skales (See site): Personal AI agent for desktop and mobile that codes, automates the desktop and browser and runs scheduled tasks with local or cloud models. Consider it because it also covers browser automation and mobile and remote control.
  9. Screenpipe (Source-available + cloud): Records your screen and audio locally so AI agents can search and act on your computer history. Consider it because it is aimed at developers who want to build on it.
  10. AionUi (Open source): Open-source desktop cowork app that gives a GUI to CLI agents like Claude Code, Codex, OpenCode and others. Consider it because it also covers terminal and CLI agents.
