Ready-made AI agents for business work: operations, finance, support, sales and back-office tasks. Below are the top 20 of 60 matching tools in the AgentScout directory, ranked.

Updated November 11, 2026

How we ranked: Most tools here are commercial products without public GitHub repos, so we rank by the maturity stated on each listing: Mature first, then Active, then newer launches. Within each group, tools with more tracked GitHub stars come first, then alphabetical order. This is not a quality score. No paid placements.

    business agentsOpen source★ 108,842 GitHub stars

    Self-hosted app for running a team of AI agents like a small company, with org charts, goals, budgets and approval gates across Claude Code, Codex, OpenClaw and other harnesses.

    Pricing (as stated): Open source · Mature

    Pricing (as stated): Open source + cloud · Mature

    Pricing (as stated): Open source + cloud · Mature
