  1. Workflow SDK (Open source): Vercel's TypeScript SDK for building durable, reliable and observable apps and AI agents. Consider it because it also covers workflow automation and agent frameworks and SDKs.
  2. Agents CLI (Open source): Google's CLI and skills that teach coding assistants to build, evaluate and deploy agents on Google Cloud and the Gemini platform. Consider it because it also covers evals and benchmarks and terminal and CLI agents.
  3. Apache Maka (Open source): Incubating Apache agent harness and workspace that records everything it does and publishes benchmarked run results. Consider it because it also covers evals and benchmarks and agent frameworks and SDKs.
  4. fast-agent (Open source): Framework to build, run and evaluate agents with strong MCP, ACP and A2A support. Consider it because it also covers evals and benchmarks and agent frameworks and SDKs.
  5. Antigravity SDK (Open source): Google's Python SDK for building stateful AI agents powered by Antigravity and Gemini, abstracting the agent loop and runtime. Consider it because it also covers agent frameworks and SDKs.
  6. EvoAgentX (Open source): Framework for building, evaluating and automatically evolving LLM agents and agentic workflows. Consider it because it also covers evals and benchmarks and workflow automation.
  7. Unreal Agent (Open source): Unreal Agent is an async-first agent harness from Unreal Labs, a team researching how to make agentic workflows efficient. The library handles inputs with stable IDs and deduplication, append-only sessions that can be forked, and a coordinator that manages each model turn and translates tool calls into operations. It ships with a cloud agent runner, a terminal UI and benchmark runners, under the MIT license. Consider it because it also covers voice and phone agents and research and reports.
  8. tRPC-Agent-Go (Open source): Go framework for production agent systems with graph workflows, tools, memory, A2A, AG-UI, MCP, evaluation and OpenTelemetry. Consider it because it also covers memory and evals and benchmarks.
  9. Sage (Open source): Sage is an open-source (MIT) RSI agent harness, where RSI stands for Recursive Self-Improvement: it improves agents using feedback from their tasks. Starting from a goal or a curated usage history, it runs the agent, has a separate evaluator grade the results, tunes the agent and keeps every version with its evidence, so you decide which one to adopt. It comes as a Desktop app, a multi-user Server with Agent Studio, and the SAgents Python runtime, with support for Skills, MCP, multi-agent setups and sandboxed runs with approvals. Consider it because it also covers computer and desktop control and sandboxes and secure execution.
  10. ECC (Open source + cloud): The agent harness performance optimization system. Skills, instincts, memory, security, and research-first development for Claude Code, Codex, Opencode, Cursor and beyond Consider it because it also covers memory and research and reports; it has more GitHub stars (293,059 vs 89,781).
