Cognee alternatives (2026)

Cognee is a memory & RAG tool: Open-source memory platform that builds knowledge graphs so agents keep long-term memory. Pricing, as the maker states it: Open source + cloud.   1. GGraphiti (Open source): Builds real-time, temporal knowledge graphs that serve as memory for AI agents. Consider it because it does the same job with a different approach (open source).
  2. ZZep (See site): Context layer that unifies business data, documents and conversations into memory so agents complete tasks correctly. Consider it because it also covers RAG and documents.
  3. CClaude-Mem (Open source): Gives coding agents memory across sessions by capturing what they do, compressing it and feeding the relevant context back in later. Consider it because it has more GitHub stars (101,230 vs 32,405).
  4. MMem0 (Open source + cloud): Memory layer for AI agents. Consider it because it has more GitHub stars (67,147 vs 32,405).
  5. MMemPalace (Open source): Local-first AI memory system that stores conversations verbatim with a pluggable backend and serves recall to agents without API calls. Consider it because it also covers voice and phone agents and local and self-hosted; it has more GitHub stars (59,622 vs 32,405).
  6. HHindsight (Open source + cloud): Agent memory system that stores experiences and learns from them so agents improve over time. Consider it because it has more GitHub stars (50,483 vs 32,405).
  7. OOpenViking (Open source): Context database for AI agents that keeps memory, knowledge and skills in one inspectable virtual filesystem agents can navigate. Consider it because it also covers SQL and databases and rules, skills and config; it has more GitHub stars (40,217 vs 32,405).
  8. SSupermemory (Open source + cloud): Memory and context engine for agents with an API, app and MCP server, which can also run fully locally. Consider it because it also covers MCP servers and local and self-hosted.
  9. AAgentMemory (Open source): Persistent memory layer for AI coding agents. Consider it because it does the same job with a different approach (open source).
  10. CChroma (Open source + cloud): Open-source search and vector database widely used for agent memory and RAG. Consider it because it also covers SQL and databases and RAG and documents.
