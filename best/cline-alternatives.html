  1. Zed (Open source): High-performance, multiplayer code editor from the creators of Atom and Tree-sitter, with built-in AI agent editing for macOS, Linux and Windows. Consider it because it is ready to use without building anything; it also covers editing and rough cuts; it has more GitHub stars (91,879 vs 70,289).
  2. OpenHands (Open source + cloud): Open-source platform for autonomous coding agents. Consider it because it has more GitHub stars (90,845 vs 70,289).
  3. Oh My Pi (Open source): Terminal coding agent with IDE features wired in, from Stencil Labs. Consider it because it also covers terminal and CLI agents.
  4. Cursor (Freemium): AI code editor with an agent mode and background agents. Consider it because it is ready to use without building anything; it also covers editing and rough cuts.
  5. Kilo Code (Open source + cloud): Open-source AI coding agent for VS Code, JetBrains, the CLI and the cloud that works with 500+ models at no markup. Consider it because it also covers terminal and CLI agents.
  6. Superset (Source-available): Agentic IDE for orchestrating many coding agents in parallel. Consider it because it also covers running many agents in parallel and multi-agent orchestration.
  7. Qodo (Freemium): AI code review and testing agents that work in the IDE, the terminal and pull requests to catch issues before merge. Consider it because it also covers code review and testing and QA.
  8. Open SWE (Open source): LangChain's asynchronous coding agent that takes work from GitHub issues, Slack or Linear, implements it in an isolated sandbox and opens a pull request. Consider it because it also covers code review and agents in chat apps.
  9. mini-SWE-agent (Open source): Tiny 100-line agent that solves GitHub issues or helps on the command line, from the SWE-agent team. Consider it because it also covers terminal and CLI agents.
  10. 21st Magic MCP (Open source): MCP server from 21st.dev that lets Cursor, Claude Code and Windsurf search and generate React and Tailwind UI components inside the editor. Consider it because it also covers MCP servers and editing and rough cuts.
