rtk alternatives (2026)

rtk is a coding tool: A CLI proxy that sits between coding agents and your shell and trims noisy command output before it reaches the model, cutting token use on everyday commands like tests, builds and git. Free and open source, with an RTK Pro tier for teams. Pricing, as the maker states it: Free and open source (Apache-2.0); RTK Pro adds team features.. Its GitHub repo has 84,727 stars.   1. Tokscale (Open source): Tracks token usage across AI coding agents from your terminal. Consider it because it does the same job with a different approach (open source).
  2. Jevgrep (Open source): CLI that finds relevant repo files and excerpts from natural-language questions for coding agents; claims ~40% cheaper agent runs. Consider it because it does the same job with a different approach (open source).
  3. opencode (Open source): Open-source terminal coding agent that works with many model providers. Consider it because it has more GitHub stars (222,192 vs 84,727).
  4. Claude Code (Paid): Anthropic's terminal coding agent that edits code, runs commands and handles git. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers editing and rough cuts; it has more GitHub stars (153,533 vs 84,727).
  5. CC Switch (Open source): Desktop manager for Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw and other coding agents that switches API providers in one click and manages MCP servers, skills and prompts. Consider it because it is ready to use without building anything; it also covers computer and desktop control and MCP servers; it has more GitHub stars (149,277 vs 84,727).
  6. OpenAI Codex CLI (Open source): OpenAI's open-source coding agent for the terminal; also runs in the cloud. Consider it because it has more GitHub stars (131,122 vs 84,727).
  7. Pi (Open source): Minimal, extensible open-source terminal coding agent and agent toolkit from Earendil, with a multi-provider LLM API, TypeScript SDK, RPC mode and installable extensions, skills and themes. Consider it because it also covers agent frameworks and SDKs and rules, skills and config; it has more GitHub stars (118,193 vs 84,727).
  8. Gemini CLI (Open source): Google's open-source terminal agent powered by Gemini. Consider it because it has more GitHub stars (108,564 vs 84,727).
  9. Understand-Anything (Open source): Turns any codebase, knowledge base or docs folder into an interactive knowledge graph you can explore and question, working inside Claude Code, Codex, Cursor, Copilot and Gemini CLI. Consider it because it also covers codebase context and code search and RAG and documents; it has more GitHub stars (88,504 vs 84,727).
  10. Open Interpreter (Open source): Terminal coding agent forked from OpenAI's Codex and tuned for low-cost and open-weight models, with switchable harness modes that imitate tools like Claude Code. Consider it because it also covers agent frameworks and SDKs.
