Updated / sources checked November 11, 2026.

ComfyUI is a video generation tool: Node-based open-source engine for image and video generation workflows. Run models like Wan, LTX and Hunyuan locally or in Comfy Cloud, with an agent that builds workflows. Pricing, as the maker states it: Desktop app free and open source (GPL-3.0); Comfy Cloud Standard $20/mo ($16 yearly), Creator $35/mo, Pro $100/mo, Team $700/mo. Its GitHub repo has 144,113 stars. We found 92 tools in the directory that do overlapping work (automating workflows, making videos, images and design); 13 of them are open source and 42 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with ComfyUI, then by GitHub stars.

Updated November 10, 2026

  1. Higgsfield (Paid): Create images, videos and voice from prompts or references using many models, with camera-move presets and an AI agent that automates workflows. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers voice and phone agents.
  2. Luma Dream Machine (Paid): Luma AI's video and image generation platform, built on its Ray models, with creative agents that handle end-to-end workflows. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers testing and QA.
  3. OpenCreator (Open source): OpenCreator, formerly KrillinAI, is an Apache-2.0 workspace for creators that runs locally and brings reusable skills and agents together for scripts, video, images, voice, translation and editing, building on its original strength of translating and dubbing videos into more than 120 languages, with a desktop app. Consider it because it is aimed at developers who want to build on it; it also covers voice and phone agents and computer and desktop control.
  4. BeefTV (Open source): BeefTV is an open-source, local-first desktop workspace for making AI video. On a free-form canvas you connect footage, images, generation models and agents into one flow, so you can go from an idea to finished clips without hopping between tools. It runs on macOS, Windows and Linux. Consider it because it also covers computer and desktop control and editing and rough cuts.
  5. explainroo (Open source): Lets your AI coding agent make narrated explainer videos: it writes the script, builds the visuals and renders the voice and video on your own computer, with no API key needed. Free and open source. Consider it because it is aimed at developers who want to build on it; it also covers voice and phone agents.
  6. Adobe Firefly (Paid): Adobe's generative app for images, video and audio, with 30+ models including Adobe's commercially safe ones and a creative agent. Consider it because it is a managed commercial product, if you'd rather not run it yourself.
  7. Vidu (Freemium): AI video generator from text, images and references, with fast workflows for social clips, ads and stories. Consider it because it also covers marketing and social media and editing and rough cuts.
  8. Hypit (Open source): An open-source agent workflow that takes a viral short video and rebuilds it as an editable template, letting you swap the presenter, script, voice and B-roll to produce many new variants with your own API keys. Consider it because it also covers trading agents and voice and phone agents.
  9. Wan 2.2 (Open source): Alibaba's open, large-scale video generation models for text to video and image to video. Consider it because it is aimed at developers who want to build on it.
  10. CogVideoX (Open source): Open text-to-video and image-to-video models from Zhipu AI (Z.ai) and Tsinghua. Consider it because it is aimed at developers who want to build on it.
