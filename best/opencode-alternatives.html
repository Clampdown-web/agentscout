opencode is a coding tool: OpenCode is an MIT-licensed open-source AI coding agent for the terminal, with a beta desktop app, that works with many model providers instead of locking you to one. Install it with a one-line script, npm, Homebrew, pacman, mise or Nix, then let it read your repository, edit files and run commands from a keyboard-driven TUI. Pricing, as the maker states it: Free and open source (MIT); bring your own model provider.. Its GitHub repo has 223,180 stars. We found 287 tools in the directory that do overlapping work (writing code, coding in the terminal, controlling a computer); 237 of them are open source and 26 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with opencode, then by GitHub stars.

Updated November 10, 2026

  1. OpenAI Codex CLI (Open source): Codex CLI is OpenAI's Apache-2.0 coding agent that runs locally in your terminal, reading your repository, editing files and running commands, with standalone installers for macOS, Linux and Windows plus npm and Homebrew. The same agent is available as IDE extensions for VS Code, Cursor and Windsurf, a desktop app via codex app, and the cloud-based Codex Web in ChatGPT. Consider it because it also covers local and self-hosted and IDE and editor agents.
  2. OmniRush (Free): OmniRush is a desktop coding agent for Windows, macOS and Linux, with a terminal CLI as well. It works through the files of your own projects, reading code, making edits and running commands, and gives free access to frontier models from a model picker, with GPT 6 Astra as the default. Builds for each platform are published on its releases page. Consider it because it is ready to use without building anything.
  3. mu (Open source): mu is an open-source coding agent with a judgment kernel: a small, fast judge model makes the many routine decisions in each turn so the main model only gets the context it needs. It ships as a command-line tool and a desktop app and aims to keep coding sessions focused and cheap. Consider it because it does the same job with a different approach (open source).
  4. Apexo Code (Open source): Apexo Code is an open-source agent project that helps builders handle apexo: An open-source, general-purpose coding agent for terminal (TUI), web, and desktop. Consider it because it does the same job with a different approach (open source).
  5. Orca (Open source): Orca is an MIT-licensed desktop app for running a fleet of coding agents such as Claude Code and Codex in parallel on your own subscriptions, each in its own git worktree, with diffs, a built-in browser and a CLI in one place. You can drive an agent in a chat view or its raw terminal and switch between them without losing context, hand a big task to one agent that splits it across worker agents, and keep agents running on a remote Orca server, any SSH host or a cloud VM after you close your laptop; there are mobile apps too. Consider it because it also covers code review and running many agents in parallel.
  6. Gemini CLI (Open source): Gemini CLI is Google's Apache-2.0 open-source terminal agent that brings Gemini models into your shell to read code, edit files and run commands. As of June 18, 2026 it is aimed at Gemini Code Assist Standard/Enterprise and Code Assist for GitHub users; free individual access and Google AI Pro/Ultra plans moved to Antigravity CLI, and the project says it is not tuned for the Gemini 4 series. Consider it because it also covers planning and task tracking.
  7. bb (Open source): bb is an MIT-licensed agentic IDE that can control, customise and automate itself, which you drive from its desktop app, web app, CLI or HTTP API; work runs in threads you can watch live, steer at any point or hand to another agent. The macOS Apple Silicon app is the main build, with alpha Linux and Windows versions and an npx option. Consider it because it also covers IDE and editor agents.
  8. Waku (Open source): Waku is a native desktop app that gathers your local coding agents in one place. It shows sessions from Amp, Claude Code, Codex, Cursor, OpenCode, Grok and Pi on a single timeline that stays entirely on your machine, so you can follow and switch between agent runs without juggling terminals. Consider it because it is ready to use without building anything; it also covers local and self-hosted.
  9. Orke (Free): BOMTOBE's free desktop workspace for Claude Code, Codex and other coding agents: terminal sessions, an in-app browser the agent can use, a Git review window and scheduled AI employees. Consider it because it is ready to use without building anything; it also covers browser automation.
  10. CC Switch (Open source): Desktop manager for Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw and other coding agents that switches API providers in one click and manages MCP servers, skills and prompts. Consider it because it is ready to use without building anything; it also covers MCP servers and rules, skills and config.
