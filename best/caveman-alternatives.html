Caveman is a coding tool: Caveman is an Apache-2.0 skill and proxy for coding agents that cuts tokens by making the agent answer in clipped "caveman" prose and read less context, while keeping code exact; it reports about a third fewer input tokens in Claude Code sessions and offers an Auto mode and a hosted Caveman Cloud. Pricing, as the maker states it: Open source + cloud. Its GitHub repo has 118,539 stars. We found 287 tools in the directory that do overlapping work (writing code); 237 of them are open source and 26 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Caveman, then by GitHub stars.

Updated November 10, 2026

  1. rtk (Open source + cloud): A CLI proxy that sits between coding agents and your shell and trims noisy command output before it reaches the model, cutting token use on everyday commands like tests, builds and git. Free and open source, with an RTK Pro tier for teams. Consider it because it also covers token usage and cost tracking and terminal and CLI agents.
  2. Paritok (Open source + cloud): Paritok is a compression gateway that sits between a coding agent and its LLM. Using its own open-source 4B code-aware model, it shrinks tool output, files and conversation history on the fly without losing what the agent needs, which cuts token bills and lets agent sessions run longer before they hit context limits. Consider it because it does the same job with a different approach (open source + cloud).
  3. Casbin Gateway (Open source): Casbin Gateway is an open-source agent project that helps builders handle see what every AI coding agent on your machine is doing. Consider it because it does the same job with a different approach (open source).
  4. opencode (Open source): OpenCode is an MIT-licensed open-source AI coding agent for the terminal, with a beta desktop app, that works with many model providers instead of locking you to one. Install it with a one-line script, npm, Homebrew, pacman, mise or Nix, then let it read your repository, edit files and run commands from a keyboard-driven TUI. Consider it because it also covers computer and desktop control and terminal and CLI agents; it has more GitHub stars (223,180 vs 118,539).
  5. Ponytail (Open source): Ponytail is an MIT-licensed skill for Claude Code and other coding agents that makes them write like a terse senior engineer: only the code a task needs, without cutting validation, error handling, security or accessibility; its published benchmark on 39 tasks reports roughly half the code, time and tokens while more risky logic ships with tests. Consider it because it also covers evals and benchmarks; it has more GitHub stars (187,364 vs 118,539).
  6. Claude Code (Paid): Claude Code is Anthropic's agentic coding tool that lives in your terminal, understands your codebase and carries out routine tasks, explains complex code and handles git workflows through natural-language commands. It also runs in IDEs and on GitHub when you tag @claude, and installs via a native script, Homebrew or WinGet (the npm install is deprecated). Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers codebase context and code search and workflow automation; it has more GitHub stars (153,919 vs 118,539).
  7. CC Switch (Open source): Desktop manager for Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw and other coding agents that switches API providers in one click and manages MCP servers, skills and prompts. Consider it because it is ready to use without building anything; it also covers computer and desktop control and MCP servers; it has more GitHub stars (150,320 vs 118,539).
  8. UI UX Pro Max (Open source): UI UX Pro Max is an open-source agent skill that gives coding agents design intelligence for web and mobile UI, with a design-system generator that reasons over your product type and outputs matching styles, colour palettes, font pairings, layout patterns and UX rules for many frameworks. Consider it because it also covers agent frameworks and SDKs and images and design; it has more GitHub stars (147,219 vs 118,539).
  9. Graphify (Open source): Graphify is an Apache-2.0 /graphify skill for Claude Code, Cursor, Codex and Gemini CLI that maps a whole project, including code, docs, SQL schemas, configs and PDFs, into a knowledge graph the agent can query instead of grepping through files. Code is parsed locally with tree-sitter, so the map is deterministic, needs no LLM or vector store, and nothing leaves your machine, and every edge in the graph says why it exists. A separate paid Graphify Cloud adds always-on team memory with a 14-day trial. Consider it because it also covers codebase context and code search and memory; it has more GitHub stars (139,123 vs 118,539).
  10. OpenAI Codex CLI (Open source): Codex CLI is OpenAI's Apache-2.0 coding agent that runs locally in your terminal, reading your repository, editing files and running commands, with standalone installers for macOS, Linux and Windows plus npm and Homebrew. The same agent is available as IDE extensions for VS Code, Cursor and Windsurf, a desktop app via codex app, and the cloud-based Codex Web in ChatGPT. Consider it because it also covers computer and desktop control and local and self-hosted; it has more GitHub stars (131,661 vs 118,539).
