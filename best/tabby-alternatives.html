Tabby alternatives (2026)

Tabby is a coding tool: Self-hosted AI coding assistant that offers an on-premises alternative to GitHub Copilot with no database or cloud service required. Pricing, as the maker states it: Open source + cloud. Its GitHub repo has 33,913 stars. We found 146 tools in the directory that do overlapping work (writing code, data analysis); 106 of them are open source and 11 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Tabby, then by GitHub stars.

  1. CCodeGraphContext (Open source): MCP server and CLI that index local code into a graph database so AI assistants can query code relationships. Consider it because it also covers MCP servers and terminal and CLI agents.
  2. GGraphify (Open source): Turns a codebase plus its docs, SQL schemas, configs and PDFs into a knowledge graph that coding agents can query. Consider it because it also covers codebase context and code search and RAG and documents; it has more GitHub stars (127,237 vs 33,913).
  3. OOrca (Open source): Agent development environment for running a fleet of parallel coding agents on your own subscriptions and reviewing their work. Consider it because it also covers running many agents in parallel; it has more GitHub stars (94,443 vs 33,913).
  4. Ccode-review-graph (Open source): Local code knowledge graph built with Tree-sitter that serves compact review context over MCP, so coding agents read only the files a change touches. Consider it because it also covers codebase context and code search.
  5. CCoder (Open source + cloud): Self-hosted cloud development environments for developers and their coding agents. Consider it because it does the same job with a different approach (open source + cloud).
  6. RRepowise (Open source): Codebase intelligence tool that indexes code, call graph, git history and docs locally and answers questions for you and your coding agent over MCP. Consider it because it also covers codebase context and code search and voice and phone agents.
  7. MMission Control (Open source): Self-hosted control plane for dispatching tasks to agents, reviewing runs and tracking spend. Consider it because it also covers running many agents in parallel and token usage and cost tracking.
  8. KKiro Crew (Open source): Kiro's open-source, persistent development workspace that runs unattended and recurring coding tasks locally or on your own hardware. Consider it because it also covers multi-agent orchestration.
  9. Ggptme (Open source): Terminal agent with local tools that writes code, runs commands, browses the web and uses vision. Consider it because it also covers terminal and CLI agents.
  10. ZZeron (Open source): Native control plane for running and monitoring Claude Code, Codex, Cursor, Devin and other coding agents locally. Consider it because it is ready to use without building anything; it also covers running many agents in parallel and tracing and observability.
