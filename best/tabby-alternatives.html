Tabby is a coding tool: Self-hosted AI coding assistant that offers an on-premises alternative to GitHub Copilot with no database or cloud service required. Pricing, as the maker states it: Open source + cloud. Its GitHub repo has 33,913 stars. We found 199 tools in the directory that do overlapping work (writing code, data analysis); 147 of them are open source and 26 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Tabby, then by GitHub stars.

Updated October 24, 2026

  1. CodeGraphContext (Open source): MCP server and CLI that index local code into a graph database so AI assistants can query code relationships. Consider it because it also covers MCP servers and terminal and CLI agents.
  2. AOCI-CODE (Open source): AOCI-CODE keeps a persistent, Git-versioned map of your whole codebase and database schema that your coding agent writes and a local MCP server governs. Agents in Codex, Claude Code, Cursor or OpenCode read the map once and know what each file is for, what it depends on and what must not break, instead of re-reading the repo on every task. It can index an existing codebase of up to about half a million lines and report how well it knows each area before taking over development. Consider it because it also covers codebase context and code search and MCP servers.
  3. superagnt (Paid): superagnt is a hosted MCP server and REST API that gives AI agents one key for the tools they lack: Instagram, TikTok, LinkedIn, YouTube, Reddit and X data, web scraping to clean markdown or JSON, email finding and lead enrichment, plus a real Postgres database, memory, schedules, queues and an inbox. Credits are charged only on successful calls, and it plugs into Claude, Cursor, Codex and other agents. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers memory and voice and phone agents.
  4. Graphify (Open source): Turns a codebase plus its docs, SQL schemas, configs and PDFs into a knowledge graph that coding agents can query. Consider it because it also covers codebase context and code search and RAG and documents; it has more GitHub stars (127,237 vs 33,913).
  5. Orca (Open source): Agent development environment for running a fleet of parallel coding agents on your own subscriptions and reviewing their work. Consider it because it also covers running many agents in parallel; it has more GitHub stars (94,443 vs 33,913).
  6. code-review-graph (Open source): Local code knowledge graph built with Tree-sitter that serves compact review context over MCP, so coding agents read only the files a change touches. Consider it because it also covers codebase context and code search.
  7. Coder (Open source + cloud): Self-hosted cloud development environments for developers and their coding agents. Consider it because it does the same job with a different approach (open source + cloud).
  8. Repowise (Open source): Codebase intelligence tool that indexes code, call graph, git history and docs locally and answers questions for you and your coding agent over MCP. Consider it because it also covers codebase context and code search and voice and phone agents.
  9. Mission Control (Open source): Self-hosted control plane for dispatching tasks to agents, reviewing runs and tracking spend. Consider it because it also covers running many agents in parallel and token usage and cost tracking.
  10. Kiro Crew (Open source): Kiro's open-source, persistent development workspace that runs unattended and recurring coding tasks locally or on your own hardware. Consider it because it also covers multi-agent orchestration.
