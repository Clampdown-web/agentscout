XiaoZhi ESP32 alternatives (2026)

XiaoZhi ESP32 is a voice tool: Open-source voice chatbot firmware for ESP32 devices that talks through LLMs like Qwen and DeepSeek and controls hardware and services via MCP. Pricing, as the maker states it: Open source. Its GitHub repo has 31,392 stars. We found 24 tools in the directory that do overlapping work (connecting tools with MCP, building voice agents); 13 of them are open source and 2 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with XiaoZhi ESP32, then by GitHub stars.

  1. Dograh (Open source + cloud): Self-hostable voice agent platform with a visual call-flow builder, bring-your-own speech and LLM providers and MCP control, pitched as an open alternative to Vapi and Retell. Consider it because it also covers images and design.
  2. Pipecat (Open source): Open-source framework for voice and multimodal conversational agents. Consider it because it also covers agent frameworks and SDKs.
  3. TEN Framework (Source-available): Open-source framework for real-time multimodal voice agents, including the TEN Agent demo. Consider it because it also covers agent frameworks and SDKs.
  4. Vision Agents (Open source): Stream's open framework for building real-time voice and video agents with any model. Consider it because it also covers agent frameworks and SDKs and video.
  5. vocode (Open source + cloud): Open-source library for building voice-based LLM agents for phone calls and apps. Consider it because it also covers agent frameworks and SDKs.
  6. Qwen Audio Agent (Open source): Real-time voice runtime from the Qwen Audio team that keeps agents talking while they think and work on tasks. Consider it because it does the same job with a different approach (open source).
  7. ElevenLabs UI (Open source): Component library on shadcn/ui with orbs, waveforms and voice-agent components for building audio and agentic apps. Consider it because it also covers agent frameworks and SDKs.
  8. ElatoAI (Open source): Realtime voice AI for ESP32 devices and toys with 100+ speech and LLM model options. Consider it because it does the same job with a different approach (open source).
  9. VoiceMode (Open source): Adds natural voice conversations to Claude Code and other assistants. Consider it because it does the same job with a different approach (open source).
  10. TryVoice (Open source): Hands-free voice runtime for coding agents with wake word, push-to-talk and streaming replies. Consider it because it does the same job with a different approach (open source).
