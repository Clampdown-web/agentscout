DeepTutor alternatives (2026)

DeepTutor is a personal agents tool: Open-source personalized AI tutoring agent from HKU that turns your materials into guided explanations, practice and long-term learning support. Pricing, as the maker states it: Open source. Its GitHub repo has 41,594 stars. We found 62 tools in the directory that do overlapping work (customer support, memory for agents, personal assistance); 39 of them are open source and 9 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with DeepTutor, then by GitHub stars.

  1. Nanobot (Open source): Ultra-lightweight, self-hosted personal agent framework in Python with a web UI, tools, memory and MCP support. Consider it because it is aimed at developers who want to build on it; it also covers agent frameworks and SDKs and local and self-hosted; it has more GitHub stars (49,096 vs 41,594).
  2. Rowboat (Open source): AI coworker with memory that works alongside you and your team. Consider it because it does the same job with a different approach (open source).
  3. Osaurus (Open source): Native macOS harness for AI agents with any model, memory and autonomous execution. Consider it because it also covers agent frameworks and SDKs.
  4. Mercury Agent (Open source): Self-hosted personal AI agent with a written personality, local memory, permission-gated tools and token budgets, reachable via CLI or Telegram. Consider it because it also covers agents in chat apps and guardrails and policies.
  5. Jarvis (Source-available): Private, local-first desktop AI assistant with voice and text chat, personal memory, dictation and MCP tools. Consider it because it also covers voice and phone agents and computer and desktop control.
  6. AirJelly (Freemium): Always-on desktop assistant that watches your workflow, remembers context and acts proactively. Consider it because it also covers computer and desktop control and workflow automation.
  7. LibreChat (Open source): Self-hosted, multi-user AI chat platform with agents, MCP, skills, code interpreter and support for OpenAI, Anthropic, Gemini, AWS, Azure and many more providers. Consider it because it also covers local and self-hosted and rules, skills and config; it has more GitHub stars (45,910 vs 41,594).
  8. DeepChat (Open source): Open-source, local-first AI agent desktop client with MCP, skills, ACP support and remote control from messaging apps. Consider it because it also covers computer and desktop control and local and self-hosted.
  9. 5ire (Source-available): Cross-platform desktop AI assistant and MCP client with a local knowledge base and support for major model providers. Consider it because it also covers RAG and documents and computer and desktop control.
  10. OpenClaw (Open source): Open-source personal agent you run yourself and reach over chat apps. Consider it because it is aimed at developers who want to build on it; it also covers personal assistants; it has more GitHub stars (391,938 vs 41,594).
