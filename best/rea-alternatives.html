REA alternatives (2026)

REA is a MCP & infra tool: MCP server and CLI that lets coding agents reverse engineer native binaries, Electron and JavaScript apps, .NET assemblies and live websites, using Ghidra, Hopper or IDA under the hood. Pricing, as the maker states it: Open source. Its GitHub repo has 301,645 stars. We found 285 tools in the directory that do overlapping work (writing code, coding in the terminal, automating workflows); 151 of them are open source and 30 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with REA, then by GitHub stars.

  1. Desktop Commander MCP (Open source): MCP server that gives Claude and other clients terminal control, process management, file search and diff-based file editing on your computer. Consider it because it is ready to use without building anything; it also covers code review and computer and desktop control.
  2. Sentry MCP (Source-available + cloud): Sentry's MCP server and CLI that give coding agents access to Sentry issues, errors and traces for debugging. Consider it because it also covers tracing and observability.
  3. Cloud Run MCP (Open source): Google Cloud's MCP server and Gemini CLI extension that lets AI agents deploy apps to Cloud Run. Consider it because it does the same job with a different approach (open source).
  4. GitKraken MCP (See site): GitKraken's MCP server, via the GitKraken CLI, for managing repos, pull requests and issues across GitHub, GitLab and Bitbucket. Consider it because it also covers code review.
  5. remotify-mcp (Open source): remotify-mcp is a free, open-source (Apache-2.0) local stdio MCP server (npx remotify-mcp) that gives Claude Code, Cursor, Codex, OpenCode, Gemini CLI and other MCP hosts a remote_exec tool for running shell commands on a remote computer through an HTTP relay. The remote machine needs only curl and bash (no SSH port or installed agent), and each command can wait for human approval or run automatically. Consider it because it also covers local and self-hosted.
  6. CircleCI MCP (Freemium): CircleCI's MCP servers (hosted and CLI) for diagnosing build failures, inspecting runs and managing CI pipelines from coding agents. Consider it because it does the same job with a different approach (freemium).
  7. MCP Inspector (Open source): Official developer tool for testing and debugging MCP servers through a web UI, CLI or terminal UI. Consider it because it does the same job with a different approach (open source).
  8. MCPorter (Open source): TypeScript runtime and CLI for discovering and calling MCP servers from scripts, terminals and agents, or packaging them as standalone CLIs. Consider it because it does the same job with a different approach (open source).
  9. Google Workspace MCP (Open source): MCP server and CLI that gives AI assistants natural-language control of Gmail, Calendar, Drive, Docs, Sheets, Slides, Forms, Tasks and Chat. Consider it because it also covers email.
  10. SEAL (Freemium): SEAL is an MCP server (npx sealnet-mcp) that lets AI agents send and request files and secrets with end-to-end encryption. After pairing, the default delivery route sends the file to the user's SEAL inbox and returns a handle to the model. Also has a browser app, CLI and SDK; free up to 1 GB per seal. Consider it because it also covers testing and QA and email.
