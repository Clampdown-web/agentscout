Next AI Draw.io alternatives (2026)

Next AI Draw.io is a productivity tool: Create and edit draw.io diagrams by chatting with AI, as a web app, desktop app or MCP server. Pricing, as the maker states it: Open source. Its GitHub repo has 36,406 stars. We found 13 tools in the directory that do overlapping work (controlling a computer, connecting tools with MCP, images and design); 9 of them are open source and 3 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Next AI Draw.io, then by GitHub stars.

  1. draw.io MCP (Open source): The official draw.io MCP server, so Claude, ChatGPT, Cursor and other assistants can create and edit flowcharts, architecture diagrams and other draw.io diagrams right in the chat. Free and needs no sign-in. Consider it because it does the same job with a different approach (open source).
  2. OpenKnowledge (Open source): OpenKnowledge is a free, local-first markdown editor and knowledge base built for working alongside AI agents. It looks and feels like a Notion-style WYSIWYG editor, with callouts, tabs, Mermaid diagrams and media blocks, but every page stays a plain markdown file on your disk. Coding agents such as Claude Code, Codex, Cursor, Gemini CLI and dozens of others can read and write the same files through its integrations, so specs, team wikis and LLM wikis stay in one place that both people and agents keep up to date. It ships as a desktop app plus a web UI and CLI. Consider it because it also covers RAG and documents and local and self-hosted.
  3. Kition (Open source): Kition is an open-source desktop office workspace with an AI agent built in. It combines documents, data tables and a whiteboard for design work in one app, and its tool-using agent can research the web, write and translate, organise records and produce editable brand assets, with visual workflows to chain the steps together. Consider it because it also covers RAG and documents and research and reports.
  4. Craft Agents (Open source): Desktop app from the makers of Craft for working with agents in a document-first way; the agent sets up APIs and MCP servers for you and sessions can be shared. Consider it because it also covers RAG and documents.
  5. ArchiLabs (Paid): AI teammate for architects that creates and edits native models and drawings in Revit and AutoCAD from a task, PDF or screen recording. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers RAG and documents.
  6. ExcaliClaw (Freemium): Hand-drawn diagram workspace your agent can draw in via MCP (Claude, Cursor, VS Code). Consider it because it also covers IDE and editor agents.
  7. Skill Recorder (Open source): Microsoft desktop app that records you doing a task once and turns the recording into a reusable skill or automation for Copilot agents. Consider it because it does the same job with a different approach (open source).
  8. Genspark (Freemium): All-in-one AI workspace whose agents research and produce slides, docs, sheets, images, video and code for you. Consider it because it also covers research and reports and video.
  9. PPT Master (Open source): AI tool that turns documents or topics into native, editable PowerPoint decks with real shapes, charts, transitions and narration from speaker notes. Consider it because it also covers RAG and documents and ADR, dubbing and voices; it has more GitHub stars (67,862 vs 36,406).
  10. GenOffice (Open source): Free, open-source office suite with docs, sheets and slides editors and a built-in AI agent. Consider it because it also covers IDE and editor agents.
