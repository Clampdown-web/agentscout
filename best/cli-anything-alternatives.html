    CLI-Anything alternatives (2026)

    CLI-Anything is a agent infra tool: Open-source project from HKUDS that generates agent-native command-line interfaces for existing software, codebases and web APIs, with CLI-Hub, a registry of community CLIs that coding agents can install and drive. Pricing, as the maker states it: Open source (Apache-2.0). Its GitHub repo has 54,399 stars. We found 28 tools in the directory that do overlapping work (writing code, coding in the terminal); 23 of them are open source and 2 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with CLI-Anything, then by GitHub stars.

    1. opencodex (Open source): A local provider proxy that lets OpenAI Codex (CLI, app and SDK) and Claude Code run on other model providers such as Claude, Gemini, Grok, DeepSeek or local Ollama models. Consider it because it also covers agent frameworks and SDKs and local and self-hosted.
    2. Magpie (Open source): Free, open-source menu bar app and local gateway that lets any coding agent (Claude Code, Codex, Gemini CLI, OpenCode and 60+ more) use any model provider or subscription, with failover when a quota runs out. Consider it because it also covers local and self-hosted.
    3. Vectoree (Usage-based): Vectoree gives coding agents a backend behind one project key: an OpenAI-compatible model gateway across providers, an MCP tool hub, auth, Postgres and storage, driven by a skill and CLI, pay-as-you-go with no monthly fee. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers SQL and databases and RAG and documents.
    4. Open Connector (Open source): Open-source auth gateway connecting SaaS apps to AI agents via SDK, CLI and MCP. Consider it because it also covers identity, auth and secrets and agent frameworks and SDKs.
    5. skills.sh (Open source): Vercel Labs' open-source CLI (npx skills) and directory for finding, installing and sharing agent skills across Claude Code, Codex, Cursor, OpenCode and 75+ other coding agents. Consider it because it also covers rules, skills and config.
    6. Open Terminal (Open source): Self-hosted terminal service from the Open WebUI team that gives AI agents an API to run commands, manage files and execute code. Consider it because it also covers local and self-hosted.
    7. Google Workspace CLI (Open source): Official Google Workspace command-line tool for Drive, Gmail, Calendar, Docs and more, usable by agents. Consider it because it also covers email.
    8. Mirage (Open source): Virtual terminal environment for AI agents. Consider it because it does the same job with a different approach (open source).
    9. NVIDIA Open Agent Safety Platform (Open source): Reference stack pairing OpenShell with NVIDIA Sentry on BlueField-4 DPUs for hardware-level agent monitoring. Consider it because it also covers guardrails and policies and tracing and observability.
    10. OmniRoute (Open source): Self-hosted AI gateway that puts hundreds of model providers behind one endpoint for Claude Code, Codex, Cursor and others, with quota-aware fallback and MCP/A2A support. Consider it because it also covers local and self-hosted; it has more GitHub stars (77,863 vs 54,399).
