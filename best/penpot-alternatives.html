Penpot is a graphic design & branding tool: Penpot is an open-source (MPL-2.0) design and prototyping platform for product teams that runs in the browser or self-hosted on your own servers. It works on open standards such as SVG, CSS, HTML and JSON, supports real-time collaboration, components, design tokens and flex/grid layouts that map to code, and has an official MCP server so AI agents like Claude can read design files and create or edit elements. Penpot Cloud has a free tier. Pricing, as the maker states it: Free and open source (MPL-2.0); cloud Unlimited $7/editor/mo (capped at $175), Enterprise $25/member/mo. Its GitHub repo has 61,870 stars. We found 42 tools in the directory that do overlapping work (browsing the web, connecting tools with MCP, images and design); 8 of them are open source and 29 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Penpot, then by GitHub stars.

  1. UseIt Studio (Freemium): UseIt Studio is an AI design agent for things you can hold. You describe what you want in a sentence, it asks the questions a designer would, and you refine any detail by pointing at it. Instead of a flat mockup you get a real, editable design file ready to print, cut and fold, with true dimensions, bleed and dielines, for pins, stickers, gift boxes, pop-up cards, packaging and brand kits. It runs in the browser, and a Windows desktop helper lets you call it up anywhere. Consider it because it also covers voice and phone agents and computer and desktop control.
  2. OpenPencil (Open source): Open-source vector design tool where teams of AI agents turn prompts into UI designs on a live canvas, with a built-in MCP server. Consider it because it also covers RAG and documents.
  3. Figma Make (Freemium): Prompt-to-prototype and app builder inside Figma that works from your designs and components. Consider it because it also covers no-code app building.
  4. Doory (Open source): Doory is a free, open-source design platform in the browser for making social posts, slides, posters and logos, a self-hostable alternative to Canva. You can start designing right away without an account, using templates, text, shapes and images on a drag-and-drop canvas. Consider it because it also covers no-code app building.
  5. Open Design Agent Kit (Open source): Open Design Agent Kit is an MIT-licensed extension that brings Open Design's design skills, brand design systems and remixable examples into the coding agent you already use, including GitHub Copilot Chat, Claude Code, Codex, Cursor and other MCP clients. You ask in chat for a pitch deck, poster, social post, landing page, dashboard or mobile prototype, and your agent's own model builds the files in your repo, guided by a library meant to keep the result from looking AI-generated. It needs no desktop app, daemon, extra account or API key. Consider it because it is aimed at developers who want to build on it; it also covers computer and desktop control and tracing and observability.
  6. Doop (Open source + cloud): An open-source multiplayer design canvas with a design MCP server, so you and agents like Claude Code and Codex can design side by side on the same live canvas. Self-host or use Doop Cloud, free during beta. Consider it because it is aimed at developers who want to build on it; it also covers running many agents in parallel.
  7. Agenvas (Open source): Agenvas is an open-source (MIT), self-hosted infinite creative canvas where text, images, video, audio and AI agents work together on connected cards. Deployed with a single Docker Compose command, it connects to your own OpenAI-compatible endpoints, ComfyUI workflows and RunningHub apps, and gates agent media proposals behind human approval before generation runs. Consider it because it also covers workflow automation and video.
  8. Adobe Express (Freemium): Quick design, social and video app with Firefly generation and a conversational AI Assistant that edits for you. Consider it because it also covers video.
  9. Banani (Freemium): Generates UI designs from text prompts and lets you edit them on a canvas. Consider it because it does the same job with a different approach (freemium).
  10. Picsart (Freemium): Photo and design editor with AI agents that make social content and edits from a voice or text request. Consider it because it also covers voice and phone agents and IDE and editor agents.
