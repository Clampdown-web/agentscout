    Penpot alternatives (2026)

    Penpot is a graphic design & branding tool: Open-source design and prototyping tool with an official MCP server so AI agents can read and edit design files. Pricing, as the maker states it: Free and open source (MPL-2.0); cloud Unlimited $7/editor/mo (capped at $175), Enterprise $25/member/mo. Its GitHub repo has 61,335 stars. We found 33 tools in the directory that do overlapping work (connecting tools with MCP, images and design, open-source image generation); 2 of them are open source and 26 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Penpot, then by GitHub stars.

    1. OpenPencil (Open source): Open-source vector design tool where teams of AI agents turn prompts into UI designs on a live canvas, with a built-in MCP server. Consider it because it also covers RAG and documents.
    2. Figma Make (Freemium): Prompt-to-prototype and app builder inside Figma that works from your designs and components. Consider it because it also covers no-code app building.
    3. Doop (Open source + cloud): An open-source multiplayer design canvas with a design MCP server, so you and agents like Claude Code and Codex can design side by side on the same live canvas. Self-host or use Doop Cloud, free during beta. Consider it because it is aimed at developers who want to build on it; it also covers running many agents in parallel.
    4. Adobe Express (Freemium): Quick design, social and video app with Firefly generation and a conversational AI Assistant that edits for you. Consider it because it also covers video.
    5. Banani (Freemium): Generates UI designs from text prompts and lets you edit them on a canvas. Consider it because it does the same job with a different approach (freemium).
    6. Picsart (Freemium): Photo and design editor with AI agents that make social content and edits from a voice or text request. Consider it because it also covers voice and phone agents and IDE and editor agents.
    7. UseIt Studio (Freemium): UseIt Studio is an AI design agent for things you can hold. You describe what you want in a sentence, it asks the questions a designer would, and you refine any detail by pointing at it. Instead of a flat mockup you get a real, editable design file ready to print, cut and fold, with true dimensions, bleed and dielines, for pins, stickers, gift boxes, pop-up cards, packaging and brand kits. It runs in the browser, and a Windows desktop helper lets you call it up anywhere. Consider it because it also covers voice and phone agents and browser automation.
    8. Visily (Freemium): AI wireframing and UI design tool for non-designers, with an MCP server. Consider it because it does the same job with a different approach (freemium).
    9. Google Stitch (Free): Google Labs tool that turns a prompt or sketch into UI designs and front-end code. Consider it because it does the same job with a different approach (free).
    10. Napkin AI (Freemium): Turns text into editable diagrams, infographics and visuals. Consider it because it does the same job with a different approach (freemium).
