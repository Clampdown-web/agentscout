Agentic Awesome Skills is a coding tool: Agentic Awesome Skills, formerly Antigravity Awesome Skills, is a library of more than 2,900 installable SKILL.md playbooks for Claude Code, Codex, Cursor, Gemini CLI and other coding agents, with AAS Core, a tool that lets Codex or Claude search the full local catalog, record the skills it picks and preview a plan before changing your project; the code is MIT and imported skills keep their own licences. Pricing, as the maker states it: Open source. Its GitHub repo has 49,467 stars. We found 292 tools in the directory that do overlapping work (writing code, coding in the terminal, building AI agents); 239 of them are open source and 28 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Agentic Awesome Skills, then by GitHub stars.

Updated November 11, 2026

  1. Desktop CC GUI (Open source): Desktop CC GUI (ccgui) is an MIT-licensed desktop app for macOS, Windows and Linux that puts command-line coding agents, including Claude Code, Codex CLI, Kimi CLI, Grok CLI, OpenCode, Qoder and DeepSeek Harness, behind one graphical interface, with streaming output, visible thinking and tool calls, token usage and Git commits; it is built with Tauri, React and Rust and keeps settings locally. Consider it because it also covers token usage and cost tracking and voice and phone agents.
  2. Pi (Open source): Minimal, extensible open-source terminal coding agent and agent toolkit from Earendil, with a multi-provider LLM API, TypeScript SDK, RPC mode and installable extensions, skills and themes. Consider it because it has more GitHub stars (118,955 vs 49,467).
  3. Pydantic Deep Agents (Open source): Self-hosted terminal AI assistant and Python framework on Pydantic AI, with tool calling, sandboxed execution, multi-agent teams and checkpoints. Consider it because it also covers sandboxes and secure execution and multi-agent orchestration.
  4. Nexting (Paid): Nexting is a remote control for the coding agents on your own Mac or Windows PC: view live Claude Code, Codex, Grok or Cursor sessions, send tasks and drive them from the iPhone app or a $129 wearable PIN, with an open-source devices SDK and an optional $29/month Plus plan. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it is ready to use without building anything; it also covers voice and phone agents and mobile and remote control.
  5. Zero (Open source): An open-source terminal coding agent written in Go that works with 30+ model providers, supports MCP, skills and subagents, and keeps all sessions on your own disk. Consider it because it also covers multi-agent orchestration.
  6. HTML Anything (Open source): An agentic HTML editor from the Open Design team. Your local coding-agent CLI (Claude Code, Cursor, Codex, Gemini and others) writes HTML decks, posters, reports and prototypes from 75 skills, shows them in a sandboxed preview, and exports in one click. No API key is needed. Consider it because it also covers sandboxes and secure execution and IDE and editor agents.
  7. Open Interpreter (Open source): Terminal coding agent forked from OpenAI's Codex and tuned for low-cost and open-weight models, with switchable harness modes that imitate tools like Claude Code. Consider it because it has more GitHub stars (68,731 vs 49,467).
  8. GSD Core (Open source): GSD Core is a spec-driven development and context-engineering framework that runs Claude Code, Codex, Cursor, Copilot and other coding agents through a discuss, plan, execute, verify and ship loop, doing heavy research and execution in fresh-context subagents to avoid context rot. Consider it because it also covers research and reports and multi-agent orchestration.
  9. Munder Difflin (Open source): Free, open-source harness that runs Claude Code, Codex, Gemini CLI and other terminal agents together like an office. Consider it because it does the same job with a different approach (open source).
  10. Agmsg (Open source + cloud): Cross-vendor messaging for CLI AI coding agents — let Claude Code, Codex, Gemini & Copilot talk to each other in one team. Bash + SQLite, no daemon, no framework Consider it because it does the same job with a different approach (open source + cloud).
