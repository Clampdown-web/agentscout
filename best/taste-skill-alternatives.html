Taste Skill is a coding tool: Taste Skill is an MIT Agent Skill that pushes coding agents to build polished company websites instead of generic landing pages, enforcing one design system, plain copy, real photos and brand icons, restrained motion, and a browser-based checker and finish gate that verify the rules before a page is done. Pricing, as the maker states it: Open source. Its GitHub repo has 112,355 stars. We found 301 tools in the directory that do overlapping work (writing code, browsing the web, research); 247 of them are open source and 28 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Taste Skill, then by GitHub stars.

Updated November 13, 2026

  1. Erd Editor (Open source + cloud): Design database schemas as ERDs in your browser, VS Code, JetBrains IDEs or Obsidian. Import SQL, DBML and GraphQL, export DDL and code, and let coding agents edit live over MCP Consider it because it also covers SQL and databases and IDE and editor agents.
  2. Anti Slop (Open source): Rules for an AI coding agent to filter out generic AI-generated UI designs, text, and code Consider it because it does the same job with a different approach (open source).
  3. shadcn/lint (Open source): Linter for Tailwind design systems from shadcn that turns your design rules into checks coding agents can run and fix against. Consider it because it does the same job with a different approach (open source).
  4. stack-diagram (Open source): stack-diagram is an MIT-licensed agent skill that turns one sentence describing your stack into an architecture diagram with the official logos of each service, for example Next.js and Hono on Vercel with Postgres on Neon, Clerk and Stripe. It installs with npx skills add for Claude Code, Codex, Cursor and other skill-aware agents, or as a zip in the Claude apps. Consider it because it also covers SQL and databases.
  5. HTML Anything (Open source): An agentic HTML editor from the Open Design team. Your local coding-agent CLI (Claude Code, Cursor, Codex, Gemini and others) writes HTML decks, posters, reports and prototypes from 75 skills, shows them in a sandboxed preview, and exports in one click. No API key is needed. Consider it because it also covers sandboxes and secure execution and local and self-hosted.
  6. UI UX Pro Max (Open source): UI UX Pro Max is an open-source agent skill that gives coding agents design intelligence for web and mobile UI, with a design-system generator that reasons over your product type and outputs matching styles, colour palettes, font pairings, layout patterns and UX rules for many frameworks. Consider it because it also covers agent frameworks and SDKs and mobile and remote control; it has more GitHub stars (147,219 vs 112,355).
  7. Beautiful Rust (Open source): Three Agent Skills plus a drop-in clippy config that teach coding agents to write, review and port idiomatic Rust. rust-best-practices loads whenever an agent writes Rust and steers it toward robust, maintainable code; rust-review produces a prioritised report where each finding cites the rule it breaks and shows the fix; rust-port moves C, C++, Python, Go or JavaScript to Rust by porting the original tests first so behaviour can be proven equal. Distilled from the Google Rust Style Guide, Rust API Guidelines, Effective Rust, Rust Design Patterns and Microsoft's Pragmatic Rust Guidelines; works with Claude Code, Codex, Copilot, Cursor and Gemini CLI. MIT. Consider it because it also covers terminal and CLI agents.
  8. Orca (Open source): Orca is an MIT-licensed desktop app for running a fleet of coding agents such as Claude Code and Codex in parallel on your own subscriptions, each in its own git worktree, with diffs, a built-in browser and a CLI in one place. You can drive an agent in a chat view or its raw terminal and switch between them without losing context, hand a big task to one agent that splits it across worker agents, and keep agents running on a remote Orca server, any SSH host or a cloud VM after you close your laptop; there are mobile apps too. Consider it because it also covers code review and running many agents in parallel.
  9. Archify (Open source): Archify is an Apache-2.0 agent skill for Cursor, Claude Code, Codex CLI and OpenCode that turns an idea, plan or whole codebase into an interactive HTML diagram you can explore, follow source links through and share, from repository maps to learning paths and travel plans. Consider it because it also covers codebase context and code search and planning and task tracking.
  10. Cline (Open source): Cline is an Apache-2.0 open-source coding agent that runs as a VS Code extension, a JetBrains plugin, a macOS and Windows desktop app, a CLI (npm i -g cline, interactive or headless for CI) and an SDK for building your own agents. It creates and edits files, runs commands, browses the web and uses MCP tools with human-in-the-loop approval for each step, and works with the model provider of your choice. Consider it because it also covers computer and desktop control and agent frameworks and SDKs.
