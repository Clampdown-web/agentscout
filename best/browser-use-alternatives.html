Updated November 9, 2026

  1. AutoCua (Open source): AutoCua is an open-source computer use agent that drives real desktop apps with mouse and keyboard on Windows, macOS and Linux, and also works in Chrome, Firefox and other browsers, in a real terminal and on an iPhone, iPad or iOS Simulator. It is built as a multi-agent harness you install with pip, so one agent can carry a task across the desktop, the web, the shell and a phone. Consider it because it also covers voice and phone agents and computer and desktop control.
  2. OpenCLI (Open source): Turns websites into CLI commands and lets agents use your logged-in browser. Consider it because it does the same job with a different approach (open source).
  3. Moli (Open source): Lightweight Rust headless browser for AI agents that fetches pages, searches and extracts content, usable via CLI, CDP or WebDriver. Consider it because it also covers scraping and crawling.
  4. BrowserOS (Open source): Open-source agentic browser that runs AI agents locally. Consider it because it is ready to use without building anything.
  5. Playwriter (Open source): Chrome extension and CLI or MCP that lets agents control your own logged-in browser by running Playwright snippets. Consider it because it does the same job with a different approach (open source).
  6. Kernel (Usage-based): Cloud browsers for AI agents: launch headless or live-view Chrome sessions in milliseconds with stealth mode, persistent profiles and replays, controlled through an API, CLI or MCP server. Free tier plus usage pricing. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers MCP servers.
  7. Libretto (Open source): An open-source CLI, debugging agents and browser tools for building and maintaining reliable web integrations, helping coding agents inspect real pages and write automations that keep working. Consider it because it does the same job with a different approach (open source).
  8. Interceptor (Open source): Browser automation and computer use for AI agents. One CLI and MCP server for your signed-in browser, native macOS apps, and real iPhones Consider it because it also covers voice and phone agents and computer and desktop control.
  9. MagenticLite (Open source): MagenticLite is the next generation of Magentic-UI from Microsoft AI Frontiers. It works across the browser and local files and checks in before critical actions. The 0.1 release is on the magentic-ui-0.1 branch. Consider it because it does the same job with a different approach (open source).
  10. Webcmd (Open source): Browser layer for AI agents that learns how each website works as agents use it and saves that as local memory to make later runs faster and cheaper. Consider it because it also covers memory and token usage and cost tracking.
