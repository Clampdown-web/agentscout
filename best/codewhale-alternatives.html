  1. opencode (Open source): Open-source terminal coding agent that works with many model providers. Consider it because it has more GitHub stars (223,180 vs 41,152).
  2. Claude Code (Paid): Anthropic's terminal coding agent that edits code, runs commands and handles git. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers editing and rough cuts; it has more GitHub stars (153,919 vs 41,152).
  3. CC Switch (Open source): Desktop manager for Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw and other coding agents that switches API providers in one click and manages MCP servers, skills and prompts. Consider it because it is ready to use without building anything; it also covers computer and desktop control and MCP servers; it has more GitHub stars (150,320 vs 41,152).
  4. OpenAI Codex CLI (Open source): OpenAI's open-source coding agent for the terminal; also runs in the cloud. Consider it because it has more GitHub stars (131,661 vs 41,152).
  5. Pi (Open source): Minimal, extensible open-source terminal coding agent and agent toolkit from Earendil, with a multi-provider LLM API, TypeScript SDK, RPC mode and installable extensions, skills and themes. Consider it because it also covers agent frameworks and SDKs and rules, skills and config; it has more GitHub stars (118,955 vs 41,152).
  6. Gemini CLI (Open source): Google's open-source terminal agent powered by Gemini. Consider it because it has more GitHub stars (108,626 vs 41,152).
  7. Understand-Anything (Open source): Turns any codebase, knowledge base or docs folder into an interactive knowledge graph you can explore and question, working inside Claude Code, Codex, Cursor, Copilot and Gemini CLI. Consider it because it also covers codebase context and code search and RAG and documents; it has more GitHub stars (88,992 vs 41,152).
  8. rtk (Open source + cloud): A CLI proxy that sits between coding agents and your shell and trims noisy command output before it reaches the model, cutting token use on everyday commands like tests, builds and git. Free and open source, with an RTK Pro tier for teams. Consider it because it also covers token usage and cost tracking and MCP gateways and registries; it has more GitHub stars (85,050 vs 41,152).
  9. Open Interpreter (Open source): Terminal coding agent forked from OpenAI's Codex and tuned for low-cost and open-weight models, with switchable harness modes that imitate tools like Claude Code. Consider it because it also covers agent frameworks and SDKs; it has more GitHub stars (68,731 vs 41,152).
  10. Warp (Open source + cloud): Agentic development environment built from the terminal, now open source, for running coding agents and cloud software factories. Consider it because it has more GitHub stars (65,787 vs 41,152).
