  1. Cline (Open source): Autonomous coding agent inside VS Code with step-by-step approvals. Consider it because it also covers IDE and editor agents.
  2. Open SWE (Open source): LangChain's asynchronous coding agent that takes work from GitHub issues, Slack or Linear, implements it in an isolated sandbox and opens a pull request. Consider it because it also covers code review and agents in chat apps.
  3. mini-SWE-agent (Open source): Tiny 100-line agent that solves GitHub issues or helps on the command line, from the SWE-agent team. Consider it because it also covers terminal and CLI agents.
  4. Cloudroom (Open source + cloud): Cloudroom runs Claude Code, Codex, Pi and other coding agents in the cloud, each in its own isolated sandbox on its own Git branch, using your own model logins; the Rust core is open source to self-host, and a desktop app manages local and cloud agents. Consider it because it also covers computer and desktop control and sandboxes and secure execution.
  5. Roomote (Freemium): Cloud coding agent from the Roo Code team that runs your real dev environment, verifies its work, reviews code with a second model and hands back PRs with live previews; works from Slack, Teams, GitHub and Linear, self-hosted or on its cloud. Consider it because it also covers code review and agents in chat apps.
  6. BackAnt Kairos (Free): Backant's Kairos, an autonomous developer that runs Claude Code against your repository. Consider it because it does the same job with a different approach (free).
  7. Conductor (Freemium): Runs multiple coding agents such as Claude Code, Codex, Cursor, and OpenCode in parallel across local Git worktrees or isolated cloud sandboxes, with Mac and iOS apps to review and merge their work. Consider it because it also covers running many agents in parallel and multi-agent orchestration.
  8. Devin (Freemium): Cognition's autonomous software engineer that takes tickets and opens PRs. Consider it because it does the same job with a different approach (freemium). OpenHands vs Devin →
  9. Jules (Freemium): Google's asynchronous coding agent that works on your GitHub repo in a cloud VM and comes back with a tested pull request. Consider it because it also covers code review.
  10. opencode (Open source): Open-source terminal coding agent that works with many model providers. Consider it because it also covers terminal and CLI agents; it has more GitHub stars (223,180 vs 92,255).
