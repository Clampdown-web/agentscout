OpenHands is a coding tool: OpenHands is an MIT-licensed platform for autonomous coding agents whose Agent Canvas acts as a self-hosted control center: start conversations and automations such as Slack reports or splitting GitHub issues into tasks, and run the OpenHands agent or ACP-compatible agents like Claude Code, Codex, Gemini CLI and OpenCode on local, Docker, VM or company backends, with optional OpenHands Cloud and Enterprise. Pricing, as the maker states it: Free and open source to self-host; OpenHands Cloud and Enterprise are paid.. Its GitHub repo has 92,255 stars. We found 301 tools in the directory that do overlapping work (writing code, coding in the terminal, automating workflows); 247 of them are open source and 28 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with OpenHands, then by GitHub stars.

Updated November 12, 2026

  1. HAPI (Open source): HAPI is an AGPL-3.0, local-first app that wraps official coding-agent sessions such as Claude Code, Codex, Cursor Agent, OpenCode, Copilot and Kimi and lets you control them remotely from native iOS and Android apps, a web app or a Telegram Mini App, so you can approve requests with one tap, run terminal commands from your phone, dictate by voice and switch between desk and phone without restarting the session. Consider it because it also covers voice and phone agents and mobile and remote control.
  2. Goose (Open source): goose is an Apache-2.0, general-purpose AI agent that runs on your own machine as a desktop app (macOS, Linux, Windows), a CLI and an embeddable API, built in Rust. It installs, runs, edits and tests code, and also handles research, writing, automation and data analysis. It works with 15+ model providers including Anthropic, OpenAI, Google, Ollama, OpenRouter, Azure and Bedrock, can reuse existing Claude, ChatGPT or Gemini subscriptions through ACP, and connects to 70+ MCP extensions. goose is part of the Agentic AI Foundation at the Linux Foundation. Consider it because it also covers research and reports and computer and desktop control.
  3. Sheprd (Open source): Sheprd is an Apache-2.0 native workspace for terminals and AI coding agents on macOS, Linux and Windows, built in Rust with GPUI. It organises repositories, Git worktrees, tabs and splits, lets you chat with agents, review their changes and track pull requests and usage across local, SSH and cloud machines, and adds browser previews, automations and phone remote control on top of a Herdr terminal daemon. Consider it because it also covers code review and running many agents in parallel.
  4. Roomote (Freemium): Cloud coding agent from the Roo Code team that runs your real dev environment, verifies its work, reviews code with a second model and hands back PRs with live previews; works from Slack, Teams, GitHub and Linear, self-hosted or on its cloud. Consider it because it also covers code review.
  5. HTML Anything (Open source): An agentic HTML editor from the Open Design team. Your local coding-agent CLI (Claude Code, Cursor, Codex, Gemini and others) writes HTML decks, posters, reports and prototypes from 75 skills, shows them in a sandboxed preview, and exports in one click. No API key is needed. Consider it because it also covers sandboxes and secure execution and IDE and editor agents.
  6. Graphify (Open source): Graphify is an Apache-2.0 /graphify skill for Claude Code, Cursor, Codex and Gemini CLI that maps a whole project, including code, docs, SQL schemas, configs and PDFs, into a knowledge graph the agent can query instead of grepping through files. Code is parsed locally with tree-sitter, so the map is deterministic, needs no LLM or vector store, and nothing leaves your machine, and every edge in the graph says why it exists. A separate paid Graphify Cloud adds always-on team memory with a 14-day trial. Consider it because it also covers codebase context and code search and memory; it has more GitHub stars (139,123 vs 92,255).
  7. OpenAI Codex CLI (Open source): Codex CLI is OpenAI's Apache-2.0 coding agent that runs locally in your terminal, reading your repository, editing files and running commands, with standalone installers for macOS, Linux and Windows plus npm and Homebrew. The same agent is available as IDE extensions for VS Code, Cursor and Windsurf, a desktop app via codex app, and the cloud-based Codex Web in ChatGPT. Consider it because it also covers computer and desktop control and IDE and editor agents; it has more GitHub stars (131,661 vs 92,255).
  8. Orca (Open source): Orca is an MIT-licensed desktop app for running a fleet of coding agents such as Claude Code and Codex in parallel on your own subscriptions, each in its own git worktree, with diffs, a built-in browser and a CLI in one place. You can drive an agent in a chat view or its raw terminal and switch between them without losing context, hand a big task to one agent that splits it across worker agents, and keep agents running on a remote Orca server, any SSH host or a cloud VM after you close your laptop; there are mobile apps too. Consider it because it also covers code review and running many agents in parallel; it has more GitHub stars (110,696 vs 92,255).
  9. Aider (Open source): Aider is an Apache-2.0 AI pair programmer in your terminal: you start a new project or work in an existing repo, and it edits files across 100+ languages using a map of your whole codebase, then commits each change to git with a sensible message. It works with Claude, DeepSeek, OpenAI models and almost any other LLM, including local models, and also supports voice input, images and web pages as context and linting and testing after each edit. Consider it because it also covers codebase context and code search and voice and phone agents.
  10. Agentic Awesome Skills (Open source): Agentic Awesome Skills, formerly Antigravity Awesome Skills, is a library of more than 2,900 installable SKILL.md playbooks for Claude Code, Codex, Cursor, Gemini CLI and other coding agents, with AAS Core, a tool that lets Codex or Claude search the full local catalog, record the skills it picks and preview a plan before changing your project; the code is MIT and imported skills keep their own licences. Consider it because it also covers planning and task tracking and agent frameworks and SDKs.
