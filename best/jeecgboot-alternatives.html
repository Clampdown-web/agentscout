Updated November 11, 2026

  1. MEX (Open source): MEX gives engineers and their coding agents shared project memory stored as Markdown in a .mex folder that travels with Git, with a local hub for people, CLI and skills for Claude Code and Codex, an MCP server and checked statechart explanations. Consider it because it also covers memory and MCP servers.
  2. OpenViking (Open source): Context database for AI agents that keeps memory, knowledge and skills in one inspectable virtual filesystem agents can navigate. Consider it because it also covers memory and SQL and databases.
  3. memU (Open source): Lightweight memory system that gives Codex, Claude Code, Cursor and other agents a shared memory across sessions and devices and distills reusable skills. Consider it because it also covers memory.
  4. Yuxi (Open source): ： RAG、 、 、MCP/Skills、 。Yuxi = Cloud Agents + Knowledge RAG, Self-hosted knowledge agent platform for RAG, knowledge graphs and multi-agent workflows Consider it because it also covers codebase context and code search and RAG and documents.
  5. Magic Context (Open source): Magic Context is an MIT-licensed memory layer for coding agents, part of CortexKit, that keeps one long-running session per project: it captures what happens, consolidates it into durable memory and recalls the relevant context later, so the agent remembers past decisions instead of starting each task from scratch; it includes a dashboard and configuration docs. Consider it because it also covers memory and tracing and observability.
  6. MarkItDown (Open source): MarkItDown is Microsoft's MIT-licensed Python tool that converts PDFs, Word, PowerPoint and Excel files, images, audio, HTML, CSV, JSON, ZIP archives and more into clean Markdown that LLMs and agents can read, keeping headings, lists, tables and links. You can call it from the command line or Python, add optional plugins such as Azure Document Intelligence for harder documents, and expose it to Claude Desktop and other agents through the companion markitdown-mcp server. Consider it because it also covers RAG and documents and voice and phone agents; it has more GitHub stars (192,990 vs 48,343).
  7. Headroom (Open source): Headroom is an Apache-2.0 library, proxy and MCP server that compresses what an AI agent reads, including tool outputs, logs, files, RAG chunks and chat history, before it reaches the model, so you send fewer input tokens for the same answers. The project's own measurements show 21 to 57 percent fewer input tokens across four agent scenarios and over 90 percent on repeated JSON arrays and log lines, with little saving on prose. Compression runs locally, and it is on PyPI and npm as headroom-ai. Consider it because it also covers RAG and documents and MCP gateways and registries; it has more GitHub stars (78,329 vs 48,343).
  8. Supermemory (Open source + cloud): Memory and context engine for agents with an API, app and MCP server, which can also run fully locally. Consider it because it also covers memory and MCP servers.
  9. xerj (Open source): A local-first search engine and MCP server for agents: one Rust binary indexes code, docs, logs, CSV/JSONL and PDFs for full-text, vector and hybrid search plus agent memory, behind an Elasticsearch-compatible API. Consider it because it also covers memory and RAG and documents.
  10. LongMemory (Open source): Local-first memory engine for agents that keeps durable, time-aware memories in SQLite and serves them to Claude, Copilot, Codex and others over MCP, CLI or HTTP. Consider it because it also covers memory and local and self-hosted.
