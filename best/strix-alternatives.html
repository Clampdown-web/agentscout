Strix alternatives (2026)

Strix is a coding tool: Open-source AI agents that run penetration tests on your app to find and help fix security vulnerabilities. Pricing, as the maker states it: Open source + cloud. Its GitHub repo has 69,022 stars. We found 117 tools in the directory that do overlapping work (agent security and safety, testing apps, open-source agents); 95 of them are open source and 9 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Strix, then by GitHub stars.

  1. PentestAgent (Open source): Agent framework for black-box security testing and bug bounty work. Consider it because it also covers agent frameworks and SDKs.
  2. PentAGI (Open source): Autonomous multi-agent system for running penetration testing tasks. Consider it because it also covers multi-agent orchestration.
  3. Mantis (Open source): Google's toolkit for AI coding agents to autonomously find, reproduce and patch software vulnerabilities in isolated environments. Consider it because it also covers sandboxes and secure execution and agent frameworks and SDKs.
  4. Goose (Open source): Extensible open-source AI agent that installs, runs, edits and tests code on your machine with any LLM and MCP extensions. Consider it because it does the same job with a different approach (open source).
  5. opencode (Open source): Open-source terminal coding agent that works with many model providers. Consider it because it also covers terminal and CLI agents; it has more GitHub stars (213,329 vs 69,022).
  6. OpenAI Codex CLI (Open source): OpenAI's open-source coding agent for the terminal; also runs in the cloud. Consider it because it also covers terminal and CLI agents; it has more GitHub stars (129,112 vs 69,022).
  7. Gemini CLI (Open source): Google's open-source terminal agent powered by Gemini. Consider it because it also covers terminal and CLI agents; it has more GitHub stars (107,334 vs 69,022).
  8. Qwen Code (Open source): Open-source terminal coding agent from the Qwen team. Consider it because it also covers terminal and CLI agents.
  9. Qodo (Freemium): AI code review and testing agents that work in the IDE, the terminal and pull requests to catch issues before merge. Consider it because it also covers code review and testing and QA.
  10. MobileBuildMCP (Open source): Sentry's MCP server and CLI that gives coding agents build, test and run tools for iOS and macOS projects. Consider it because it also covers MCP servers and terminal and CLI agents.
