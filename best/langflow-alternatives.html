    Langflow alternatives (2026)

    Langflow is a no-code builders tool: Visual drag-and-drop builder for AI agents and workflows that you can run locally, deploy as an API or expose as an MCP server. Pricing, as the maker states it: Open source + cloud. Its GitHub repo has 155,757 stars. We found 34 tools in the directory that do overlapping work (writing code, automating workflows, building apps without code); 12 of them are open source and 9 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Langflow, then by GitHub stars.

BetterClaw (Freemium): Build and deploy AI agents without code on 28+ model providers or local LLMs, with 120+ app connectors, any MCP server and unlimited skills, running in Telegram, Slack, Discord and Gmail. Consider it because it is ready to use without building anything; it also covers agents in chat apps and email.
    2. Activepieces (Open source + cloud): Open-source automation platform with AI agents and hundreds of pieces usable as MCP servers. Consider it because it does the same job with a different approach (open source + cloud).
    3. FastGPT (Source-available + cloud): AI agent building platform with knowledge-base RAG, data processing and a visual workflow editor for deploying question-answering and automation apps. Consider it because it is ready to use without building anything; it also covers RAG and documents and IDE and editor agents.
    4. Sim Studio (Open source + cloud): Workspace for visually building, deploying and monitoring AI agents and workflows. Consider it because it also covers tracing and observability.
    5. Baserow (Open source + cloud): No-code platform for databases, apps, automations and AI agents, an Airtable alternative available as cloud or self-hosted. Consider it because it is ready to use without building anything; it also covers SQL and databases.
    6. PySpur (Open source): Visual playground for building and iterating on agent workflows. Consider it because it does the same job with a different approach (open source).
    7. BuildShip (Paid): Visual AI workflow builder for automating backends, building tools for AI agents and spinning up APIs. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it is ready to use without building anything.
    8. Giselle (Open source + cloud): Open-source AI agent studio for building agentic workflows with a visual builder. Consider it because it does the same job with a different approach (open source + cloud).
    9. Make (Freemium): Visual automation platform with AI agents. Consider it because it is ready to use without building anything.
    10. Dify (Source-available + cloud): Open-source platform for building LLM apps and agents visually. Consider it because it is ready to use without building anything; it has more GitHub stars (158,410 vs 155,757). Langflow vs Dify →
