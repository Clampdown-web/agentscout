Langflow alternatives (2026)

Langflow is a no-code builders tool: Visual drag-and-drop builder for AI agents and workflows that you can run locally, deploy as an API or expose as an MCP server. Pricing, as the maker states it: Open source + cloud. Its GitHub repo has 155,757 stars. We found 30 tools in the directory that do overlapping work (writing code, automating workflows, building voice agents); 11 of them are open source and 7 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Langflow, then by GitHub stars.

Consider it because it is ready to use without building anything; it also covers RAG and documents and IDE and editor agents.
  3. SSim Studio (Open source + cloud): Workspace for visually building, deploying and monitoring AI agents and workflows. Consider it because it also covers tracing and observability.
  4. BBaserow (Open source + cloud): No-code platform for databases, apps, automations and AI agents, an Airtable alternative available as cloud or self-hosted. Consider it because it is ready to use without building anything; it also covers SQL and databases.
  5. PPySpur (Open source): Visual playground for building and iterating on agent workflows. Consider it because it does the same job with a different approach (open source).

  7. GGiselle (Open source + cloud): Open-source AI agent studio for building agentic workflows with a visual builder. Consider it because it does the same job with a different approach (open source + cloud).
  8. MMake (Freemium): Visual automation platform with AI agents. Consider it because it is ready to use without building anything.
