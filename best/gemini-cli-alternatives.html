Updated / sources checked November 12, 2026.

Gemini CLI is a coding tool: Gemini CLI is Google's Apache-2.0 open-source terminal agent that brings Gemini models into your shell to read code, edit files and run commands. As of June 18, 2026 it is aimed at Gemini Code Assist Standard/Enterprise and Code Assist for GitHub users; free individual access and Google AI Pro/Ultra plans moved to Antigravity CLI, and the project says it is not tuned for the Gemini 4 series. Pricing, as the maker states it: Open source; access through Gemini Code Assist Standard/Enterprise licences.. Its GitHub repo has 108,626 stars. We found 296 tools in the directory that do overlapping work (writing code, coding in the terminal, open-source agents); 242 of them are open source and 28 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Gemini CLI, then by GitHub stars.

Updated November 10, 2026

  1. opencode (Open source): OpenCode is an MIT-licensed open-source AI coding agent for the terminal, with a beta desktop app, that works with many model providers instead of locking you to one. Install it with a one-line script, npm, Homebrew, pacman, mise or Nix, then let it read your repository, edit files and run commands from a keyboard-driven TUI. Consider it because it also covers computer and desktop control; it has more GitHub stars (223,180 vs 108,626).
  2. OpenAI Codex CLI (Open source): Codex CLI is OpenAI's Apache-2.0 coding agent that runs locally in your terminal, reading your repository, editing files and running commands, with standalone installers for macOS, Linux and Windows plus npm and Homebrew. The same agent is available as IDE extensions for VS Code, Cursor and Windsurf, a desktop app via codex app, and the cloud-based Codex Web in ChatGPT. Consider it because it also covers computer and desktop control and local and self-hosted; it has more GitHub stars (131,661 vs 108,626).
  3. Archify (Open source): Archify is an Apache-2.0 agent skill for Cursor, Claude Code, Codex CLI and OpenCode that turns an idea, plan or whole codebase into an interactive HTML diagram you can explore, follow source links through and share, from repository maps to learning paths and travel plans. Consider it because it also covers codebase context and code search and images and design.
  4. Goose (Open source): goose is an Apache-2.0, general-purpose AI agent that runs on your own machine as a desktop app (macOS, Linux, Windows), a CLI and an embeddable API, built in Rust. It installs, runs, edits and tests code, and also handles research, writing, automation and data analysis. It works with 15+ model providers including Anthropic, OpenAI, Google, Ollama, OpenRouter, Azure and Bedrock, can reuse existing Claude, ChatGPT or Gemini subscriptions through ACP, and connects to 70+ MCP extensions. goose is part of the Agentic AI Foundation at the Linux Foundation. Consider it because it also covers research and reports and computer and desktop control.
  5. Agentic Awesome Skills (Open source): Agentic Awesome Skills, formerly Antigravity Awesome Skills, is a library of more than 2,900 installable SKILL.md playbooks for Claude Code, Codex, Cursor, Gemini CLI and other coding agents, with AAS Core, a tool that lets Codex or Claude search the full local catalog, record the skills it picks and preview a plan before changing your project; the code is MIT and imported skills keep their own licences. Consider it because it also covers agent frameworks and SDKs and local and self-hosted.
  6. ThinkRail (Open source): JetBrains' lightweight agentic IDE that pairs you with the pi coding agent, with isolated git-worktree workspaces, editor tabs, terminals and diffs. Consider it because it also covers code review and running many agents in parallel.
  7. OmniRush (Free): OmniRush is a desktop coding agent for Windows, macOS and Linux, with a terminal CLI as well. It works through the files of your own projects, reading code, making edits and running commands, and gives free access to frontier models from a model picker, with GPT 6 Astra as the default. Builds for each platform are published on its releases page. Consider it because it is ready to use without building anything; it also covers computer and desktop control.
  8. FuXi (Free): A terminal AI coding agent that edits code, runs commands and works across 30+ model families, with parallel multi-provider inference and cost-aware model routing. Consider it because it also covers running many agents in parallel.
  9. ripwire (Open source): Zero-dependency CLI and MCP server that gives coding agents a ranked call graph, blast radius and tests-to-run before and after edits. Consider it because it also covers voice and phone agents and MCP servers.
  10. Mirror CLI (See site): Reflection AI's terminal coding agent that reads code, edits files and runs commands in isolated git worktrees, using the open-weight Beam model by default. Consider it because it also covers running many agents in parallel and sandboxes and secure execution.
