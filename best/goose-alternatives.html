Goose alternatives (2026)

Goose is a coding tool: Extensible open-source AI agent that installs, runs, edits and tests code on your machine with any LLM and MCP extensions. Pricing, as the maker states it: Open source. Its GitHub repo has 55,347 stars. We found 146 tools in the directory that do overlapping work (writing code, connecting tools with MCP, testing apps); 106 of them are open source and 11 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Goose, then by GitHub stars.

  1. Rripwire (Open source): Zero-dependency CLI and MCP server that gives coding agents a ranked call graph, blast radius and tests-to-run before and after edits. Consider it because it also covers voice and phone agents and MCP servers.
  2. 221st Magic MCP (Open source): MCP server from 21st.dev that lets Cursor, Claude Code and Windsurf search and generate React and Tailwind UI components inside the editor. Consider it because it also covers MCP servers and IDE and editor agents.
  3. CClaude Code (Paid): Anthropic's terminal coding agent that edits code, runs commands and handles git. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers terminal and CLI agents; it has more GitHub stars (150,707 vs 55,347).
  4. ZZed (Open source): High-performance, multiplayer code editor from the creators of Atom and Tree-sitter, with built-in AI agent editing for macOS, Linux and Windows. Consider it because it is ready to use without building anything; it also covers IDE and editor agents; it has more GitHub stars (91,879 vs 55,347).
  5. CCursor (Freemium): AI code editor with an agent mode and background agents. Consider it because it is ready to use without building anything; it also covers IDE and editor agents.
  6. MMobileBuildMCP (Open source): Sentry's MCP server and CLI that gives coding agents build, test and run tools for iOS and macOS projects. Consider it because it also covers MCP servers and terminal and CLI agents.
  7. CCode-Graph-RAG (Open source): Graph-based RAG for monorepos that lets agents query and edit multi-language code. Consider it because it also covers codebase context and code search and RAG and documents.
  8. HHercules (Open source): Open-source testing agent that turns plain Gherkin steps into end-to-end UI, API, accessibility and security tests. Consider it because it also covers testing and QA.
  9. FFrontman (Open source): Browser-based AI coding agent: click an element in your running app, describe the change, and it edits the source with hot reload. Consider it because it is ready to use without building anything; it also covers browser automation.
  10. MMirror CLI (See site): Reflection AI's terminal coding agent that reads code, edits files and runs commands in isolated git worktrees, using the open-weight Beam model by default. Consider it because it also covers running many agents in parallel and sandboxes and secure execution.
