AI agents, desktop coding assistants and local LLM runtimes that can run on your own machine or offline without sending data to a third-party cloud. Below are the top 25 of 123 matching tools in the AgentScout directory, ranked.

Updated November 10, 2026

How we ranked: Ranked by GitHub stars as recorded on each AgentScout listing (link checks 2026-11-12). Tools without a tracked public repo come after, in alphabetical order. Stars measure developer popularity, not quality or fit for your job, so read each listing before you choose. No paid placements.

  1. 1. Ollama

    models & local runtimesOpen source★ 185,335 GitHub stars

    Ollama is an MIT-licensed tool for running open models such as Kimi, GLM, MiniMax, DeepSeek, gpt-oss, Qwen and Gemma locally or in Ollama's cloud, with apps for macOS, Windows and Linux plus an official Docker image. It can launch or connect those models to coding agents including Claude Code, Codex, Copilot CLI, DeepSeek Harness, Droid and OpenCode (`ollama launch claude`), and official Python and JavaScript libraries are available; v0.40.16 shipped Nov 9, 2026.

    Pricing (as stated): Free and open source (MIT); Ollama also offers a cloud option at ollama.com (no price listed in this update). · Mature

  2. 2. OpenAI Codex CLI

    codingOpen source★ 131,661 GitHub stars

    Codex CLI is OpenAI's Apache-2.0 coding agent that runs locally in your terminal, reading your repository, editing files and running commands, with standalone installers for macOS, Linux and Windows plus npm and Homebrew. The same agent is available as IDE extensions for VS Code, Cursor and Windsurf, a desktop app via codex app, and the cloud-based Codex Web in ChatGPT.

    Pricing (as stated): Open source CLI; usage through a ChatGPT plan or OpenAI API key. · Mature

  3. 3. Headroom

    memory & RAGOpen source★ 78,329 GitHub stars

    Headroom is an Apache-2.0 library, proxy and MCP server that compresses what an AI agent reads, including tool outputs, logs, files, RAG chunks and chat history, before it reaches the model, so you send fewer input tokens for the same answers. The project's own measurements show 21 to 57 percent fewer input tokens across four agent scenarios and over 90 percent on repeated JSON arrays and log lines, with little saving on prose. Compression runs locally, and it is on PyPI and npm as headroom-ai.

    Pricing (as stated): Free and open source (Apache-2.0); a paid Headroom for Teams plan is offered. · Mature

  4. 4. AnythingLLM

    personal agentsOpen source + cloud★ 67,747 GitHub stars

    Local-first desktop and server app for chatting with your documents, running agents and connecting any LLM.

    Pricing (as stated): Open source + cloud · Mature

  5. 5. MemPalace

    memory & RAGOpen source★ 60,133 GitHub stars

    MemPalace is an MIT-licensed, local-first memory system for AI agents that stores conversation history as verbatim text (it does not summarize or paraphrase) and retrieves it with semantic search. People and projects are organised as wings, topics as rooms and original content in drawers so searches can be scoped, and the retrieval backend is pluggable (ChromaDB by default) with no API calls required. Official docs are at mempalaceofficial.com; v3.11.0 shipped Oct 14, 2026.

    Pricing (as stated): Free and open source (MIT). · Mature

  6. 6. PrivateGPT

    frameworksOpen source★ 57,620 GitHub stars

    PrivateGPT is an Apache-2.0 API layer that turns local models into private AI applications: it speaks a Claude-style messages API and adds file ingestion, retrieval with citations and agentic RAG, built-in tools (web search, web fetch, code execution), custom tools, MCP connectors and structured access such as text-to-SQL. It does not run models itself; it connects to any OpenAI-compatible inference server (Ollama, llama.cpp, vLLM and others) and ships a workbench UI at /ui for testing.

    Pricing (as stated): Free and open source (Apache-2.0). The same team also offers the commercial on-premise Zylon platform (no price listed in this update). · Mature

  7. 7. Goose

    codingOpen source★ 55,956 GitHub stars

    goose is an Apache-2.0, general-purpose AI agent that runs on your own machine as a desktop app (macOS, Linux, Windows), a CLI and an embeddable API, built in Rust. It installs, runs, edits and tests code, and also handles research, writing, automation and data analysis. It works with 15+ model providers including Anthropic, OpenAI, Google, Ollama, OpenRouter, Azure and Bedrock, can reuse existing Claude, ChatGPT or Gemini subscriptions through ACP, and connects to 70+ MCP extensions. goose is part of the Agentic AI Foundation at the Linux Foundation.

    Pricing (as stated): Open source · Mature

  8. 8. LocalAI

    models & local runtimesOpen source★ 50,071 GitHub stars

    LocalAI is an MIT-licensed, self-hosted AI engine that runs LLMs, vision, voice, image and video models on your own hardware, including CPU-only machines, behind drop-in OpenAI-, Anthropic- and ElevenLabs-compatible APIs. Each backend (llama.cpp, vLLM, whisper.cpp, stable-diffusion, MLX and others) is pulled only when a model needs it, it runs on NVIDIA, AMD, Intel, Apple Silicon or Vulkan, and it adds multi-user API keys, quotas and saved agents that can use tools, MCP servers, skills and files.

    Pricing (as stated): Open source · Mature
