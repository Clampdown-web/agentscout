LobeHub alternatives (2026)

LobeHub is a personal agents tool: Open-source agent workspace that organizes a team of AI agents for round-the-clock work, with scheduling, reporting and self-hosting or a cloud version. Pricing, as the maker states it: Source-available + cloud. Its GitHub repo has 83,475 stars. We found 92 tools in the directory that do overlapping work (writing code, personal assistance, open-source agents); 53 of them are open source and 17 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with LobeHub, then by GitHub stars.

Updated October 23, 2026

Quick answer: the top picks on this list, ranked by GitHub stars and listing maturity, are Pinvou Agent, Dodaios and OpenClaw, out of 11 tools listed below. At a glance: 9 open-source, 9 free or freemium and 7 local or self-hosted across 11 link-checked tools (last verified Oct 23, 2026).

  1. Pinvou Agent (Open source): Open-source desktop AI agent workspace for work, design and coding tasks that end in finished deliverables. Consider it because it is open source, so you can self-host and inspect it; it also covers computer and desktop control and images and design.
  2. Dodaios (Open source): Open-source desktop agent OS for Windows, macOS and Linux (formerly Personal Jarvis): talk to it and it runs your coding CLIs side by side, your browser and your apps, with offline Whisper speech, a local wiki memory and support for Ollama, Claude or ChatGPT subscriptions. Consider it because it is open source, so you can self-host and inspect it; it also covers running many agents in parallel and memory.
  3. OpenClaw (Open source): Open-source personal agent you run yourself and reach over chat apps. Consider it because it is open source, so you can self-host and inspect it; it is aimed at developers who want to build on it; it also covers personal assistants.
  4. Career Ops (Open source): Open-source job search agent that scans job boards and scores each posting against your CV before you apply. Consider it because it is open source, so you can self-host and inspect it.
  5. CowAgent (Open source): Open-source personal assistant and agent harness that plans tasks, runs tools and skills and connects to chat apps. Consider it because it is open source, so you can self-host and inspect it; it is aimed at developers who want to build on it; it also covers planning and task tracking and agent frameworks and SDKs.
  6. LibreChat (Open source): Self-hosted, multi-user AI chat platform with agents, MCP, skills, code interpreter and support for OpenAI, Anthropic, Gemini, AWS, Azure and many more providers. Consider it because it is open source, so you can self-host and inspect it; it also covers local and self-hosted and rules, skills and config.
  7. agenticSeek (Open source): Fully local autonomous agent that browses, codes and plans without paid APIs. Consider it because it is open source, so you can self-host and inspect it; it is aimed at developers who want to build on it; it also covers planning and task tracking and local and self-hosted.
  8. Leon (Open source): Open-source personal assistant that runs on your own server. Consider it because it is open source, so you can self-host and inspect it; it is aimed at developers who want to build on it; it also covers local and self-hosted and personal assistants.
  9. Jev (Open source): Jev is an open-source chat assistant for Android, Windows and macOS that reads the conversation on your screen, judges what the other person wants and whether a message looks risky, and drafts candidate replies for you. It fills in the reply box, but you always decide whether to send, so it helps with tricky messages without acting on its own. Consider it because it is open source, so you can self-host and inspect it; it also covers computer and desktop control and mobile and remote control.
  10. Kun (Source-available): Local-first agent workspace for coding, writing, design, research and automation. Consider it because it also covers research and reports and local and self-hosted.
