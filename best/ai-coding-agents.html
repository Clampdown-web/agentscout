AI coding agents, AI editors and CLI coding tools that write, edit and review code for you. Below are the top 20 of 293 matching tools in the AgentScout directory, ranked.

Updated November 10, 2026

How we ranked: Ranked by GitHub stars as recorded on each AgentScout listing (link checks 2026-11-11). Tools without a tracked public repo come after, in alphabetical order. Stars measure developer popularity, not quality or fit for your job, so read each listing before you choose. No paid placements.

  1. 1. opencode

    codingOpen source★ 223,180 GitHub stars

    OpenCode is an MIT-licensed open-source AI coding agent for the terminal, with a beta desktop app, that works with many model providers instead of locking you to one. Install it with a one-line script, npm, Homebrew, pacman, mise or Nix, then let it read your repository, edit files and run commands from a keyboard-driven TUI.

    Pricing (as stated): Free and open source (MIT); bring your own model provider. · Active

  2. 2. Ponytail

    codingOpen source★ 187,364 GitHub stars

    Ponytail is an MIT-licensed skill for Claude Code and other coding agents that makes them write like a terse senior engineer: only the code a task needs, without cutting validation, error handling, security or accessibility; its published benchmark on 39 tasks reports roughly half the code, time and tokens while more risky logic ships with tests.

    Pricing (as stated): Open source · Mature

  3. 3. Claude Code

    codingPaid★ 153,919 GitHub stars

    Claude Code is Anthropic's agentic coding tool that lives in your terminal, understands your codebase and carries out routine tasks, explains complex code and handles git workflows through natural-language commands. It also runs in IDEs and on GitHub when you tag @claude, and installs via a native script, Homebrew or WinGet (the npm install is deprecated).

    Pricing (as stated): Requires a paid Claude plan or Anthropic API usage. · Mature

  4. 4. CC Switch

    codingOpen source★ 150,320 GitHub stars

    Desktop manager for Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw and other coding agents that switches API providers in one click and manages MCP servers, skills and prompts.

    Pricing (as stated): Open source · Mature

  5. 5. UI UX Pro Max

    codingOpen source★ 147,219 GitHub stars

    UI UX Pro Max is an open-source agent skill that gives coding agents design intelligence for web and mobile UI, with a design-system generator that reasons over your product type and outputs matching styles, colour palettes, font pairings, layout patterns and UX rules for many frameworks.

    Pricing (as stated): Open source · Mature

  6. 6. Graphify

    codingOpen source★ 139,123 GitHub stars

    Graphify is an Apache-2.0 /graphify skill for Claude Code, Cursor, Codex and Gemini CLI that maps a whole project, including code, docs, SQL schemas, configs and PDFs, into a knowledge graph the agent can query instead of grepping through files. Code is parsed locally with tree-sitter, so the map is deterministic, needs no LLM or vector store, and nothing leaves your machine, and every edge in the graph says why it exists. A separate paid Graphify Cloud adds always-on team memory with a 14-day trial.

    Pricing (as stated): Free and open source (Apache-2.0); optional paid Graphify Cloud with a 14-day free trial. · Mature

  7. 7. OpenAI Codex CLI

    codingOpen source★ 131,661 GitHub stars

    Codex CLI is OpenAI's Apache-2.0 coding agent that runs locally in your terminal, reading your repository, editing files and running commands, with standalone installers for macOS, Linux and Windows plus npm and Homebrew. The same agent is available as IDE extensions for VS Code, Cursor and Windsurf, a desktop app via codex app, and the cloud-based Codex Web in ChatGPT.

    Pricing (as stated): Open source CLI; usage through a ChatGPT plan or OpenAI API key. · Mature

  8. 8. Pi

    codingOpen source★ 118,955 GitHub stars

    Minimal, extensible open-source terminal coding agent and agent toolkit from Earendil, with a multi-provider LLM API, TypeScript SDK, RPC mode and installable extensions, skills and themes.

    Pricing (as stated): Open source (MIT); bring your own model provider or subscription · Mature

  9. 9. Caveman

    codingOpen source + cloud★ 118,539 GitHub stars

    Caveman is an Apache-2.0 skill and proxy for coding agents that cuts tokens by making the agent answer in clipped "caveman" prose and read less context, while keeping code exact; it reports about a third fewer input tokens in Claude Code sessions and offers an Auto mode and a hosted Caveman Cloud.

    Pricing (as stated): Open source + cloud · Mature

  10. 10. Agent Skills (Addy Osmani)

    codingOpen source★ 114,397 GitHub stars

    Agent Skills by Addy Osmani packages senior-engineer workflows and quality gates as skills for AI coding agents, with nine slash commands such as /spec, /plan, /build, /test, /review and /ship that walk an agent from idea to production with tests and review at each step.

    Pricing (as stated): Open source · Mature

  11. 11. Taste Skill

    codingOpen source★ 112,355 GitHub stars

    Taste Skill is an MIT Agent Skill that pushes coding agents to build polished company websites instead of generic landing pages, enforcing one design system, plain copy, real photos and brand icons, restrained motion, and a browser-based checker and finish gate that verify the rules before a page is done.

    Pricing (as stated): Open source · Mature

  12. 12. Orca

    codingOpen source★ 110,696 GitHub stars

    Orca is an MIT-licensed desktop app for running a fleet of coding agents such as Claude Code and Codex in parallel on your own subscriptions, each in its own git worktree, with diffs, a built-in browser and a CLI in one place. You can drive an agent in a chat view or its raw terminal and switch between them without losing context, hand a big task to one agent that splits it across worker agents, and keep agents running on a remote Orca server, any SSH host or a cloud VM after you close your laptop; there are mobile apps too.

    Pricing (as stated): Free and open source (MIT); you use your own Claude, Codex or other agent subscriptions. · Mature

  13. 13. Gemini CLI

    codingOpen source★ 108,626 GitHub stars

    Gemini CLI is Google's Apache-2.0 open-source terminal agent that brings Gemini models into your shell to read code, edit files and run commands. As of June 18, 2026 it is aimed at Gemini Code Assist Standard/Enterprise and Code Assist for GitHub users; free individual access and Google AI Pro/Ultra plans moved to Antigravity CLI, and the project says it is not tuned for the Gemini 4 series.

    Pricing (as stated): Open source; access through Gemini Code Assist Standard/Enterprise licences. · Mature

  14. 14. Impeccable

    codingOpen source★ 106,611 GitHub stars

    Impeccable gives coding agents a design vocabulary: install it into a project and steer with commands such as polish and bolder, review with critique and audit, and catch typical AI-generated design clichés before they ship; works with Claude Code, Cursor, Codex CLI, Copilot, Gemini CLI and more.

    Pricing (as stated): Open source · Mature

  15. 15. Archify

    codingOpen source★ 94,965 GitHub stars

    Archify is an Apache-2.0 agent skill for Cursor, Claude Code, Codex CLI and OpenCode that turns an idea, plan or whole codebase into an interactive HTML diagram you can explore, follow source links through and share, from repository maps to learning paths and travel plans.

    Pricing (as stated): Open source · Mature

  16. 16. Zed

    codingOpen source★ 92,411 GitHub stars

    High-performance, multiplayer code editor from the creators of Atom and Tree-sitter, with built-in AI agent editing for macOS, Linux and Windows.

    Pricing (as stated): Open source · Mature

  17. 17. OpenHands

    codingOpen source + cloud★ 92,255 GitHub stars

    OpenHands is an MIT-licensed platform for autonomous coding agents whose Agent Canvas acts as a self-hosted control center: start conversations and automations such as Slack reports or splitting GitHub issues into tasks, and run the OpenHands agent or ACP-compatible agents like Claude Code, Codex, Gemini CLI and OpenCode on local, Docker, VM or company backends, with optional OpenHands Cloud and Enterprise.

    Pricing (as stated): Free and open source to self-host; OpenHands Cloud and Enterprise are paid. · Mature

  18. 18. Understand-Anything

    codingOpen source★ 88,992 GitHub stars

    Turns any codebase, knowledge base or docs folder into an interactive knowledge graph you can explore and question, working inside Claude Code, Codex, Cursor, Copilot and Gemini CLI.

    Pricing (as stated): Open source · Mature

  19. 19. rtk

    codingOpen source + cloud★ 85,050 GitHub stars

    A CLI proxy that sits between coding agents and your shell and trims noisy command output before it reaches the model, cutting token use on everyday commands like tests, builds and git. Free and open source, with an RTK Pro tier for teams.

    Pricing (as stated): Free and open source (Apache-2.0); RTK Pro adds team features. · Mature

  20. 20. Cline

    codingOpen source★ 71,064 GitHub stars

    Autonomous coding agent inside VS Code with step-by-step approvals.

    Pricing (as stated): Open source · Mature
