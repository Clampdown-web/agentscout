  2. Eigent (Open source): Open-source cowork desktop app that runs multi-agent workflows locally. Consider it because it also covers computer and desktop control and workflow automation.
  3. Jarvis (Source-available): Private, local-first desktop AI assistant with voice and text chat, personal memory, dictation and MCP tools. Consider it because it also covers memory and voice and phone agents.
  4. Open WebUI (Source-available): Self-hosted, offline-capable AI platform with a chat interface for Ollama and OpenAI-compatible models, plus tools, pipelines and agent features. Consider it because it has more GitHub stars (156,022 vs 35,761).
  5. AnythingLLM (Open source + cloud): Local-first desktop and server app for chatting with your documents, running agents and connecting any LLM. Consider it because it also covers RAG and documents and computer and desktop control; it has more GitHub stars (67,210 vs 35,761).
  6. Nanobot (Open source): Ultra-lightweight, self-hosted personal agent framework in Python with a web UI, tools, memory and MCP support. Consider it because it is aimed at developers who want to build on it; it also covers memory and agent frameworks and SDKs; it has more GitHub stars (49,096 vs 35,761).
  7. LibreChat (Open source): Self-hosted, multi-user AI chat platform with agents, MCP, skills, code interpreter and support for OpenAI, Anthropic, Gemini, AWS, Azure and many more providers. Consider it because it also covers rules, skills and config; it has more GitHub stars (45,910 vs 35,761).
  8. agenticSeek (Open source): Fully local autonomous agent that browses, codes and plans without paid APIs. Consider it because it is aimed at developers who want to build on it; it also covers planning and task tracking.
  9. Leon (Open source): Open-source personal assistant that runs on your own server. Consider it because it is aimed at developers who want to build on it; it also covers personal assistants.
  10. Octop (Open source): Self-hosted, multi-user AI assistant with multiple agents. Consider it because it also covers running many agents in parallel.
