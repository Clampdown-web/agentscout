Ready-to-use AI agent apps that are open source, so you can run them on your own computer or server instead of only in someone else's cloud. Below are the top 20 of 148 matching tools in the AgentScout directory, ranked.

Updated November 10, 2026

How we ranked: Ranked by GitHub stars as recorded on each AgentScout listing (link checks 2026-11-13). Tools without a tracked public repo come after, in alphabetical order. Stars measure developer popularity, not quality or fit for your job, so read each listing before you choose. No paid placements.

  1. 1. CC Switch

    codingOpen source★ 150,320 GitHub stars

    Desktop manager for Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw and other coding agents that switches API providers in one click and manages MCP servers, skills and prompts.

    Pricing (as stated): Open source · Mature

  2. 2. ComfyUI

    video generationOpen source + cloud★ 144,113 GitHub stars

    Node-based open-source engine for image and video generation workflows. Run models like Wan, LTX and Hunyuan locally or in Comfy Cloud, with an agent that builds workflows.

    Pricing (as stated): Desktop app free and open source (GPL-3.0); Comfy Cloud Standard $20/mo ($16 yearly), Creator $35/mo, Pro $100/mo, Team $700/mo · Active

  3. 3. Immich

    photography & photo editingOpen source★ 117,678 GitHub stars

    Self-hosted photo and video library with AI face recognition and smart search, a private alternative to Google Photos.

    Pricing (as stated): Free and open source (AGPL-3.0), self-hosted · Active

  4. 4. Zed

    codingOpen source★ 92,411 GitHub stars

    High-performance, multiplayer code editor from the creators of Atom and Tree-sitter, with built-in AI agent editing for macOS, Linux and Windows.

    Pricing (as stated): Open source · Mature

  5. 5. Career Ops

    personal agentsOpen source★ 78,796 GitHub stars

    Career-Ops is an MIT-licensed job-search agent that runs on your machine inside Claude Code, Codex, OpenCode or another AI CLI. You paste a job or let it scan job boards; it checks whether the posting is still open, scores the fit from 1 to 5 against your CV, tailors an ATS-friendly resume and cover letter, drafts application answers, preps you for interviews and tracks every application. It fills in the forms but you press Submit yourself.

    Pricing (as stated): Free and open source (MIT); you use your own AI CLI subscription. · Mature

  6. 6. PPT Master

    productivityOpen source★ 71,178 GitHub stars

    PPT Master is an MIT-licensed tool that turns documents or topics into native, editable PowerPoint decks with real shapes, transitions and animations, data-backed charts and tables, audio narration from speaker notes, and support for your own .pptx templates. It can read PDFs, Word files and web pages, structure the narrative and write a .pptx you can keep editing in PowerPoint; v6.9.0 shipped Nov 8, 2026.

    Pricing (as stated): Free and open source (MIT). · Mature

  7. 7. AnythingLLM

    personal agentsOpen source + cloud★ 67,747 GitHub stars

    Local-first desktop and server app for chatting with your documents, running agents and connecting any LLM.

    Pricing (as stated): Open source + cloud · Mature

  8. 8. TrendRadar

    researchOpen source★ 63,563 GitHub stars

    TrendRadar is a GPL-3.0 trending-news assistant that you can deploy in minutes with Docker, locally or on Cloudflare; it gathers hot lists and RSS feeds from many platforms, filters them by your keywords or with AI, adds AI analysis and translation, and pushes alerts to WeChat Work, Feishu, Telegram, Slack, ntfy, Bark or email, with an MCP server so AI clients can query the news. Its main docs are in Chinese.

    Pricing (as stated): Open source · Mature

  9. 9. Penpot

    graphic design & brandingOpen source★ 61,870 GitHub stars

    Open-source design and prototyping tool with an official MCP server so AI agents can read and edit design files.

    Pricing (as stated): Free and open source (MPL-2.0); cloud Unlimited $7/editor/mo (capped at $175), Enterprise $25/member/mo · Active

  10. 10. Cherry Studio

    personal agentsOpen source★ 53,099 GitHub stars

    Cherry Studio is an AGPL-3.0 desktop AI workstation for Windows, macOS and Linux that lets you chat with many cloud and local model providers side by side, run agents, build knowledge bases, generate images and automate everyday tasks from one app. It ships hundreds of ready-made assistants, supports MCP tools, and now has iOS and Android companion apps; a commercial licence is offered for teams that cannot use AGPL.

    Pricing (as stated): Open source · Mature

  11. 11. Upscayl

    photography & photo editingOpen source★ 51,327 GitHub stars

    Free open-source desktop app for upscaling images on your own computer.

    Pricing (as stated): Free and open source (AGPL-3.0) desktop app; Upscayl Cloud free trial (10 credits), Pro $24.99/mo · Active

  12. 12. DeepTutor

    education & tutoringOpen source★ 51,307 GitHub stars

    DeepTutor is an Apache-2.0 lifelong personalized tutoring agent from HKU DS that turns your study materials into guided explanations, practice, mastery tracking and long-term learning support. It offers a desktop app, a CLI for agent-native use, narrated video lessons, notebooks, Anki and calendar exports, and a skills community; v1.7.2 shipped Nov 6, 2026 with complete desktop downloads, selected-text speech, NVIDIA NIM embeddings and a Korean interface preview.

    Pricing (as stated): Free and open source (Apache-2.0). · Mature

  13. 13. LibreChat

    personal agentsOpen source★ 46,482 GitHub stars

    LibreChat is an MIT-licensed, self-hosted multi-user AI chat platform that puts OpenAI, Anthropic, Google Gemini, AWS Bedrock, Azure, Mistral, OpenRouter and other providers behind one ChatGPT-style interface. It includes agents with MCP tools and skills, a code interpreter, artifacts, message search, presets and secure multi-user auth; v0.8.8 added a beta Agent Management API with OpenAPI docs, per-agent workspaces and Ask/Allow/Deny approval controls for file writes and commands.

    Pricing (as stated): Open source · Mature

  14. 14. Jan

    models & local runtimesOpen source★ 45,169 GitHub stars

    Open-source ChatGPT alternative that downloads and runs LLMs fully offline on your computer, with optional connections to cloud models.

    Pricing (as stated): Open source · Mature

  15. 15. PhotoPrism

    photography & photo editingOpen source★ 40,377 GitHub stars

    Self-hosted AI photo library that auto-tags, recognizes faces and finds places.

    Pricing (as stated): Community edition free (AGPL-3.0, self-hosted); Essentials €2/mo, Plus from €6/mo; managed hosting via PikaPods from $6.50/mo · Active

  16. 16. MindsHub

    productivityOpen source + cloud★ 39,831 GitHub stars

    MindsDB's agent workspace for research, analysis, documents and coding, with a model router, a scoped vault for connected data and swappable open-source agent harnesses.

    Pricing (as stated): Open source + cloud · Mature

  17. 17. Vane

    researchOpen source★ 37,844 GitHub stars

    Open-source AI answering engine that searches the web and replies with sources, self-hostable.

    Pricing (as stated): Open source · Mature

  18. 18. QwenPaw

    personal agentsOpen source★ 36,995 GitHub stars

    Personal AI assistant you can install locally or in the cloud, connected to multiple chat channels.

    Pricing (as stated): Open source · Mature

  19. 19. Next AI Draw.io

    productivityOpen source★ 36,504 GitHub stars

    Create and edit draw.io diagrams by chatting with AI, as a web app, desktop app or MCP server.

    Pricing (as stated): Open source · Mature

  20. 20. AionUi

    personal agentsOpen source★ 33,920 GitHub stars

    Open-source desktop cowork app that gives a GUI to CLI agents like Claude Code, Codex, OpenCode and others.

    Pricing (as stated): Open source · Mature
