Trending open-source AI agents

The 25 listed open-source projects that gained the most GitHub stars between Oct 20 and Oct 27, 2026, from our daily snapshots of each repo.

    codingOpen source+8,458 stars

    Agent development environment for running a fleet of parallel coding agents on your own subscriptions and reviewing their work.

  3. #3 DeepSeek Harness

    frameworksOpen source+7,722 stars

    DeepSeek's open-source agent harness with a local web UI, built so that every tool, model and scheduled task is a swappable plugin; still a developer preview.

  4. #4 Graphify

    codingOpen source+6,934 stars

    Turns a codebase plus its docs, SQL schemas, configs and PDFs into a knowledge graph that coding agents can query.

  5. #5 Magpie

    agent infraOpen source+5,490 stars

    Free, open-source menu bar app and local gateway that lets any coding agent (Claude Code, Codex, Gemini CLI, OpenCode and 60+ more) use any model provider or subscription, with failover when a quota runs out.

  6. #6 HyperFrames

    film & TV productionOpen source+5,379 stars

    HeyGen's open-source framework that renders HTML, CSS and animations into deterministic MP4 videos, usable from a CLI or by coding agents through skills.

  7. #7 xerj

    memory & RAGOpen source+5,178 stars

    A local-first search engine and MCP server for agents: one Rust binary indexes code, docs, logs, CSV/JSONL and PDFs for full-text, vector and hybrid search plus agent memory, behind an Elasticsearch-compatible API.

  8. #8 PPT Master

    productivityOpen source+5,058 stars

  13. #13 DeepTutor

  14. #14 SolidCraft

    3D & concept artOpen source+2,995 stars

  15. #15 ComfyUI

    video generationOpen source + cloud+2,992 stars

    agent infraOpen source+2,867 stars
