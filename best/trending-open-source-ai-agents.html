The 25 listed open-source projects that gained the most GitHub stars between Oct 30 and Nov 8, 2026, from our daily snapshots of each repo.

Updated October 28, 2026

  1. #1 REA

    MCP serversOpen source+32,619 stars

    MCP server and CLI that lets coding agents reverse engineer native binaries, Electron and JavaScript apps, .NET assemblies and live websites, using Ghidra, Hopper or IDA under the hood.

  2. #2 Dsh Our Free Model

    frameworksOpen source+13,924 stars

    dsh ， 、 API Key， DeepSeek V4.1 Flash、Kimi K3 —— ， 。 All you do is install this plugin in dsh: no login, no sign-up, no API key — the frontier models are just there, DeepSeek V4.1 Flash and Kimi K3.

  3. #3 OpenMausBot

    personal agentsOpen source+9,969 stars

    Open-source chat app for running your own team of AI bots, each with a virtual machine it can use, on the model you choose.

  4. #4 DeepSeek Harness

    frameworksOpen source+9,878 stars

    DeepSeek's open-source agent harness with a local web UI, built so that every tool, model and scheduled task is a swappable plugin; still a developer preview.

  5. #5 Claude-Mem

    memory & RAGOpen source+9,377 stars

    Gives coding agents memory across sessions by capturing what they do, compressing it and feeding the relevant context back in later.

  6. #6 Scrapling

    browser/computer useOpen source+9,313 stars

    Python web-scraping framework with fast HTTP requests, stealth browsers, adaptive parsing and concurrent crawling, plus an MCP server for agents.

  7. #7 Orca

    codingOpen source+8,399 stars

    Agent development environment for running a fleet of parallel coding agents on your own subscriptions and reviewing their work.

  8. #8 Elephant-Goldfish Model

    codingOpen source+8,222 stars

    Elephant-Goldfish Model is an open-source method and plugin from Google for spec-driven development with AI coding agents. A deep-context agent drafts the design, then fresh zero-context subagents stress-test that spec for gaps and wrong assumptions before any code is written, which catches problems that a single long-running agent tends to miss.

  9. #9 ECC

    frameworksOpen source + cloud+6,474 stars

    The agent harness performance optimization system. Skills, instincts, memory, security, and research-first development for Claude Code, Codex, Opencode, Cursor and beyond

  10. #10 Magpie

    agent infraOpen source+6,196 stars

    Free, open-source menu bar app and local gateway that lets any coding agent (Claude Code, Codex, Gemini CLI, OpenCode and 60+ more) use any model provider or subscription, with failover when a quota runs out.

  11. #11 DeepTutor

    education & tutoringOpen source+5,541 stars

    Open-source personalized AI tutoring agent from HKU that turns your materials into guided explanations, practice and long-term learning support.

  12. #12 OpenMontage

    film & TV productionOpen source+5,387 stars

    Open-source agentic video production system with ready pipelines and tools that agents use to edit and assemble videos.

  13. #13 Graphify

    codingOpen source+5,224 stars

    Turns a codebase plus its docs, SQL schemas, configs and PDFs into a knowledge graph that coding agents can query.

  14. #14 HyperFrames

    film & TV productionOpen source+5,156 stars

    HeyGen's open-source framework that renders HTML, CSS and animations into deterministic MP4 videos, usable from a CLI or by coding agents through skills.

  15. #15 Orkas

    personal agentsOpen source+4,220 stars

    Local-first multi-agent desktop app where a commander model coordinates specialist agents and your installed coding CLIs.

  16. #16 Lightpanda

    browser/computer useOpen source + cloud+3,708 stars

    Headless browser written from scratch in Zig for AI agents and automation, built for speed and low memory rather than forked from Chromium.

  17. #17 PPT Master

    productivityOpen source+3,686 stars

    AI tool that turns documents or topics into native, editable PowerPoint decks with real shapes, charts, transitions and narration from speaker notes.

  18. #18 Agent-Reach

    researchOpen source+3,622 stars

    Lets an AI agent read and search sites like X, Reddit, YouTube and GitHub through one toolkit, without paid APIs.

  19. #19 Paperclip

    business agentsOpen source+3,409 stars

    Self-hosted app for running a team of AI agents like a small company, with org charts, goals, budgets and approval gates across Claude Code, Codex, OpenClaw and other harnesses.

  20. #20 Hermes Agent (Nous Research)

    frameworksOpen source+2,960 stars

    Open-source agent harness; v0.21.7 stable shipped Oct 12, v0.22.0 RCs Oct 13-14.

  21. #21 OmniRoute

    agent infraOpen source+2,893 stars

    Self-hosted AI gateway that puts hundreds of model providers behind one endpoint for Claude Code, Codex, Cursor and others, with quota-aware fallback and MCP/A2A support.

  22. #22 Concat

    film & TV productionOpen source+2,889 stars

    Concat is a free, open-source video editor meant as a CapCut replacement that runs entirely on your own machine. It covers auto-captions, text-to-speech voices, background removal, keyframes, titles, effects, filters and transitions with multi-track editing up to 4K, with no watermark, account or subscription. It runs on Windows, macOS, Linux, Android and iOS, and it can be scripted through a documented JSON-RPC and gRPC API, so scripts and AI agents can drive edits.

  23. #23 Video Shotcraft

    frameworksOpen source+2,838 stars

    AI video skill for Claude Code & Codex — cinematic product videos with Remotion: 152 shot recipe cards, 209 motion previews, a production-ready template

  24. #24 Firecrawl

    researchOpen source + cloud+2,788 stars

    Turns websites into clean, LLM-ready data for agents.

  25. #25 SolidCraft

    3D & concept artOpen source+2,744 stars

    Parametric 3D CAD app written in Rust for desktop and web, with a built-in MCP server so AI agents can sketch and build models.
