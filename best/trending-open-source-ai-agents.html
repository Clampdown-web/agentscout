The 25 listed open-source projects that gained the most GitHub stars between Oct 23 and Oct 30, 2026, from our daily snapshots of each repo.

Updated November 10, 2026

  1. #1 REA

    MCP serversOpen source+40,127 stars

    MCP server and CLI that lets coding agents reverse engineer native binaries, Electron and JavaScript apps, .NET assemblies and live websites, using Ghidra, Hopper or IDA under the hood.

  2. #2 DeepTutor

    education & tutoringOpen source+9,056 stars

    DeepTutor is an Apache-2.0 lifelong personalized tutoring agent from HKU DS that turns your study materials into guided explanations, practice, mastery tracking and long-term learning support. It offers a desktop app, a CLI for agent-native use, narrated video lessons, notebooks, Anki and calendar exports, and a skills community; v1.7.2 shipped Nov 6, 2026 with complete desktop downloads, selected-text speech, NVIDIA NIM embeddings and a Korean interface preview.

  3. #3 DeepSeek Harness

    frameworksOpen source+7,410 stars

    DeepSeek's open-source agent harness with a local web UI, built so that every tool, model and scheduled task is a swappable plugin; still a developer preview.

  4. #4 Orca

    codingOpen source+7,347 stars

    Orca is an MIT-licensed desktop app for running a fleet of coding agents such as Claude Code and Codex in parallel on your own subscriptions, each in its own git worktree, with diffs, a built-in browser and a CLI in one place. You can drive an agent in a chat view or its raw terminal and switch between them without losing context, hand a big task to one agent that splits it across worker agents, and keep agents running on a remote Orca server, any SSH host or a cloud VM after you close your laptop; there are mobile apps too.

  5. #5 Magpie

    agent infraOpen source+5,989 stars

    Free, open-source menu bar app and local gateway that lets any coding agent (Claude Code, Codex, Gemini CLI, OpenCode and 60+ more) use any model provider or subscription, with failover when a quota runs out.

  6. #6 Graphify

    codingOpen source+5,557 stars

    Graphify is an Apache-2.0 /graphify skill for Claude Code, Cursor, Codex and Gemini CLI that maps a whole project, including code, docs, SQL schemas, configs and PDFs, into a knowledge graph the agent can query instead of grepping through files. Code is parsed locally with tree-sitter, so the map is deterministic, needs no LLM or vector store, and nothing leaves your machine, and every edge in the graph says why it exists. A separate paid Graphify Cloud adds always-on team memory with a 14-day trial.

  7. #7 Agent-Reach

    researchOpen source+5,400 stars

    Agent Reach is an MIT-licensed CLI that gives an AI agent read and search access to sites it usually cannot reach well, including X, Reddit, YouTube, GitHub, Bilibili and XiaoHongShu, through one tool and without paid platform APIs. It is meant to be installed alongside agents such as Claude Code or OpenClaw so they can pull posts, threads, transcripts and repository data straight into a task; the project and its docs are mainly in Chinese.

  8. #8 HyperFrames

    film & TV productionOpen source+5,398 stars

    HyperFrames is HeyGen's Apache-2.0 framework for turning HTML, CSS, media and seekable animations into deterministic MP4 videos, so a coding agent can write a web page and render it as a video. You can use it from the CLI, from Claude Code, Codex or Cursor after installing its skills with one command, or in the free HyperFrames Studio desktop app, whose Pro plan adds HeyGen's video, image, voice and music models.

  9. #9 Cindy

    personal agentsOpen source+5,396 stars

    Open-source, ready-to-run AI agent that combines Claude Code, Codex and tools into one agent working on your local files and apps.

  10. #10 ThinkRail

    codingOpen source+5,359 stars

    JetBrains' lightweight agentic IDE that pairs you with the pi coding agent, with isolated git-worktree workspaces, editor tabs, terminals and diffs.

  11. #11 PPT Master

    productivityOpen source+4,691 stars

    PPT Master is an MIT-licensed tool that turns documents or topics into native, editable PowerPoint decks with real shapes, transitions and animations, data-backed charts and tables, audio narration from speaker notes, and support for your own .pptx templates. It can read PDFs, Word files and web pages, structure the narrative and write a .pptx you can keep editing in PowerPoint; v6.9.0 shipped Nov 8, 2026.

  12. #12 xerj

    memory & RAGOpen source+4,356 stars

    A local-first search engine and MCP server for agents: one Rust binary indexes code, docs, logs, CSV/JSONL and PDFs for full-text, vector and hybrid search plus agent memory, behind an Elasticsearch-compatible API.

  13. #13 Claude-Mem

    memory & RAGOpen source+2,958 stars

    Claude-Mem is an Apache-2.0 memory plugin for coding agents that records what the agent does during a session, compresses those observations with AI, and feeds the relevant context back into later sessions, so the agent does not start from zero each time. It works with Claude Code, Codex, Gemini CLI, Copilot, OpenCode, OpenClaw, Hermes and others, stores memory locally, and includes search tools for looking back through past work.

  14. #14 opencode

    codingOpen source+2,748 stars

    OpenCode is an MIT-licensed open-source AI coding agent for the terminal, with a beta desktop app, that works with many model providers instead of locking you to one. Install it with a one-line script, npm, Homebrew, pacman, mise or Nix, then let it read your repository, edit files and run commands from a keyboard-driven TUI.

  15. #15 Orkas

    personal agentsOpen source+2,732 stars

    Local-first multi-agent desktop app where a commander model coordinates specialist agents and your installed coding CLIs.

  16. #16 SolidCraft

    3D & concept artOpen source+2,676 stars

    Parametric 3D CAD app written in Rust for desktop and web, with a built-in MCP server so AI agents can sketch and build models.

  17. #17 OmniRoute

    agent infraOpen source+2,599 stars

    OmniRoute is an MIT-licensed self-hosted AI gateway that puts hundreds of model providers behind one endpoint for Claude Code, Codex, Cursor, OpenCode, Cline and Copilot, with quota-aware automatic fallback and MCP/A2A support. You bring your own provider accounts; it catalogs third-party free tiers and shows the live totals on its dashboard rather than granting tokens itself, and it can compress prompts to cut token use. v3.8.53 shipped Nov 6, 2026.

  18. #18 OpenMausBot

    personal agentsOpen source+2,508 stars

    Open-source chat app for running your own team of AI bots, each with a virtual machine it can use, on the model you choose.

  19. #19 NVIDIA OpenShell

    sandboxes & code executionOpen source+2,464 stars

    OpenShell is NVIDIA's Apache-2.0 safe, private runtime for fleets of autonomous AI agents: each agent runs in an isolated sandbox where declarative YAML policies control which files, networks, packages, APIs and credentials it can touch. The project is moving to the CNCF (ai-openshell); the 0.1.x line, at v0.1.8 on Nov 10, 2026, brought a stable release cadence, new isolation primitives, an expanded extension surface and new APIs.

  20. #20 Firecrawl

    researchOpen source + cloud+2,440 stars

    Turns websites into clean, LLM-ready data for agents.

  21. #21 Paperclip

    business agentsOpen source+2,439 stars

    Self-hosted app for running a team of AI agents like a small company, with org charts, goals, budgets and approval gates across Claude Code, Codex, OpenClaw and other harnesses.

  22. #22 CC Switch

    codingOpen source+2,376 stars

    Desktop manager for Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw and other coding agents that switches API providers in one click and manages MCP servers, skills and prompts.

  23. #23 Hermes Agent (Nous Research)

    frameworksOpen source+2,308 stars

    Hermes Agent is Nous Research's MIT-licensed, self-improving agent with a built-in learning loop: it writes skills from completed tasks, refines them in use, keeps agent-curated memory and searches its own past conversations. It runs on anything from a $5 VPS to serverless infrastructure, offers a full terminal UI, and one gateway serves Telegram, Discord, Slack, WhatsApp, Signal and the CLI, with any model via Nous Portal, OpenRouter, OpenAI or your own endpoint.

  24. #24 OpenMontage

    film & TV productionOpen source+2,125 stars

    OpenMontage is an AGPL-3.0 agentic video production system that turns an AI coding assistant such as Claude Code, Cursor or Codex into a video studio: you describe the video in plain language and the agent runs research, scripting, asset generation, editing and final composition through ready-made pipelines. Besides image-based videos it can cut real motion edits from free stock footage and open archives, and the repo ships a review guide and an agent guide. Paid image and video generation providers are optional.

  25. #25 Career Ops

    personal agentsOpen source+2,071 stars

    Career-Ops is an MIT-licensed job-search agent that runs on your machine inside Claude Code, Codex, OpenCode or another AI CLI. You paste a job or let it scan job boards; it checks whether the posting is still open, scores the fit from 1 to 5 against your CV, tailors an ATS-friendly resume and cover letter, drafts application answers, preps you for interviews and tracks every application. It fills in the forms but you press Submit yourself.
