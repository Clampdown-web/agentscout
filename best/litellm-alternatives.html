LiteLLM alternatives (2026)

LiteLLM is a agent infra tool: Open-source AI gateway and Python SDK that calls 100+ LLM providers in the OpenAI format, with cost tracking, guardrails, load balancing and logging. Pricing, as the maker states it: Open source + cloud. Its GitHub repo has 62,146 stars. We found 39 tools in the directory that do overlapping work (building AI agents, building voice agents, building MCP servers); 26 of them are open source and 5 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with LiteLLM, then by GitHub stars.

  1. NVIDIA Open Agent Safety Platform (Open source): Reference stack pairing OpenShell with NVIDIA Sentry on BlueField-4 DPUs for hardware-level agent monitoring. Consider it because it also covers terminal and CLI agents.
  2. opencodex (Open source): A local provider proxy that lets OpenAI Codex (CLI, app and SDK) and Claude Code run on other model providers such as Claude, Gemini, Grok, DeepSeek or local Ollama models. Consider it because it also covers local and self-hosted and terminal and CLI agents.
  3. Portkey AI Gateway (Freemium): Fast open-source AI gateway that routes requests to hundreds of LLMs through one API with fallbacks, load balancing and built-in guardrails. Consider it because it does the same job with a different approach (freemium).
  4. Manifest (Open source + cloud): Open-source LLM gateway that routes each request from agents and apps to the right model across API keys, subscriptions and local models, with spend tracking. Consider it because it also covers local and self-hosted.
  5. Monid (Open source + cloud): Gateway that gives an agent one base URL and one key to call thousands of paid tools, from web scraping and enrichment to image and voice generation, billed per call. Consider it because it also covers scraping and crawling and images and design.
  6. Open Connector (Open source): Open-source auth gateway connecting SaaS apps to AI agents via SDK, CLI and MCP. Consider it because it also covers identity, auth and secrets and terminal and CLI agents.
  7. Kong Gateway (Open source + cloud): Cloud-native API, LLM and MCP gateway that adds routing, auth, multi-LLM support, semantic security and MCP traffic analytics through plugins. Consider it because it also covers identity, auth and secrets.
  8. Inngest (Freemium): Inngest is a durable workflow orchestration platform for running stateful step functions and AI workflows on serverless, servers or the edge. You write functions in TypeScript, Python or Go with automatic retries, queues, throttling and human-in-the-loop waits, and its AgentKit and AI inference steps let you build durable, long-running AI agents with tracing and evals. The server is source-available (SSPL, converting to Apache 2.0 later) and can be self-hosted, or you can use Inngest Cloud. Consider it because it also covers evals and benchmarks and workflow automation.
  9. Arcade (Open source + cloud): Actions runtime for enterprise agents with thousands of prebuilt authenticated tools, plus an open-source framework for building your own MCP servers. Consider it because it also covers identity, auth and secrets and MCP servers.
  10. Agent Barn (Open source + cloud): Agent Barn is an open-source (Apache-2.0) control plane for running a fleet of AI agents on your own Kubernetes: create, configure, run and monitor agents across Slack, Microsoft Teams and Telegram from one place. Consider it because it also covers running many agents in parallel and agents in chat apps.
