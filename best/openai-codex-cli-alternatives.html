OpenAI Codex CLI is a coding tool: Codex CLI is OpenAI's Apache-2.0 coding agent that runs locally in your terminal, reading your repository, editing files and running commands, with standalone installers for macOS, Linux and Windows plus npm and Homebrew. The same agent is available as IDE extensions for VS Code, Cursor and Windsurf, a desktop app via codex app, and the cloud-based Codex Web in ChatGPT. Pricing, as the maker states it: Open source CLI; usage through a ChatGPT plan or OpenAI API key.. Its GitHub repo has 131,661 stars. We found 292 tools in the directory that do overlapping work (writing code, coding in the terminal, controlling a computer); 239 of them are open source and 28 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with OpenAI Codex CLI, then by GitHub stars.

Updated November 11, 2026

  1. HTML Anything (Open source): An agentic HTML editor from the Open Design team. Your local coding-agent CLI (Claude Code, Cursor, Codex, Gemini and others) writes HTML decks, posters, reports and prototypes from 75 skills, shows them in a sandboxed preview, and exports in one click. No API key is needed. Consider it because it also covers sandboxes and secure execution and VFX and compositing.
  2. opencode (Open source): OpenCode is an MIT-licensed open-source AI coding agent for the terminal, with a beta desktop app, that works with many model providers instead of locking you to one. Install it with a one-line script, npm, Homebrew, pacman, mise or Nix, then let it read your repository, edit files and run commands from a keyboard-driven TUI. Consider it because it has more GitHub stars (223,180 vs 131,661).
  3. Orca (Open source): Orca is an MIT-licensed desktop app for running a fleet of coding agents such as Claude Code and Codex in parallel on your own subscriptions, each in its own git worktree, with diffs, a built-in browser and a CLI in one place. You can drive an agent in a chat view or its raw terminal and switch between them without losing context, hand a big task to one agent that splits it across worker agents, and keep agents running on a remote Orca server, any SSH host or a cloud VM after you close your laptop; there are mobile apps too. Consider it because it also covers code review and running many agents in parallel.
  4. bb (Open source): bb is an MIT-licensed agentic IDE that can control, customise and automate itself, which you drive from its desktop app, web app, CLI or HTTP API; work runs in threads you can watch live, steer at any point or hand to another agent. The macOS Apple Silicon app is the main build, with alpha Linux and Windows versions and an npx option. Consider it because it does the same job with a different approach (open source).
  5. Desktop CC GUI (Open source): Desktop CC GUI (ccgui) is an MIT-licensed desktop app for macOS, Windows and Linux that puts command-line coding agents, including Claude Code, Codex CLI, Kimi CLI, Grok CLI, OpenCode, Qoder and DeepSeek Harness, behind one graphical interface, with streaming output, visible thinking and tool calls, token usage and Git commits; it is built with Tauri, React and Rust and keeps settings locally. Consider it because it also covers token usage and cost tracking and voice and phone agents.
  6. OmniRush (Free): OmniRush is a desktop coding agent for Windows, macOS and Linux, with a terminal CLI as well. It works through the files of your own projects, reading code, making edits and running commands, and gives free access to frontier models from a model picker, with GPT 6 Astra as the default. Builds for each platform are published on its releases page. Consider it because it is ready to use without building anything.
  7. Waku (Open source): Waku is a native desktop app that gathers your local coding agents in one place. It shows sessions from Amp, Claude Code, Codex, Cursor, OpenCode, Grok and Pi on a single timeline that stays entirely on your machine, so you can follow and switch between agent runs without juggling terminals. Consider it because it is ready to use without building anything.
  8. ThinkRail (Open source): JetBrains' lightweight agentic IDE that pairs you with the pi coding agent, with isolated git-worktree workspaces, editor tabs, terminals and diffs. Consider it because it also covers code review and running many agents in parallel.
  9. Wake (Open source): Wake is a desktop app that collects every coding-agent conversation on your computer into one searchable place. It reads the local history kept by Claude Code, Codex, Cursor, Copilot CLI, Gemini CLI, Antigravity, Devin and other agents, groups sessions by agent and project, and lets you find a past conversation in seconds and resume it in your terminal. It is read-only and nothing leaves your machine. Built in Rust, it runs on macOS, with Linux and Windows in beta. Consider it because it does the same job with a different approach (open source).
  10. Amp (Usage-based): Agentic coding tool for the terminal and editor. Consider it because it is a managed commercial product, if you'd rather not run it yourself.
