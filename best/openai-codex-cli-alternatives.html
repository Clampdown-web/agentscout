  1. opencode (Open source): Open-source terminal coding agent that works with many model providers. Consider it because it has more GitHub stars (221,359 vs 130,852).
  2. Pi (Open source): Minimal, extensible open-source terminal coding agent and agent toolkit from Earendil, with a multi-provider LLM API, TypeScript SDK, RPC mode and installable extensions, skills and themes. Consider it because it also covers agent frameworks and SDKs and rules, skills and config.
  3. Gemini CLI (Open source): Google's open-source terminal agent powered by Gemini. Consider it because it does the same job with a different approach (open source).
  4. Qwen Code (Open source): Open-source terminal coding agent from the Qwen team. Consider it because it does the same job with a different approach (open source).
  5. Kilo Code (Open source + cloud): Open-source AI coding agent for VS Code, JetBrains, the CLI and the cloud that works with 500+ models at no markup. Consider it because it also covers IDE and editor agents.
  6. Grok CLI (Open source): Open-source coding agent for the Grok API. Consider it because it does the same job with a different approach (open source).
  7. Zero (Open source): An open-source terminal coding agent written in Go that works with 30+ model providers, supports MCP, skills and subagents, and keeps all sessions on your own disk. Consider it because it also covers multi-agent orchestration and local and self-hosted.
  8. PiG (Open source): PiG is a faithful Go port of Pi, the open-source terminal coding agent, first developed at Hewlett Packard Enterprise. It keeps Pi's behaviour and extension model while shipping as a single fast Go binary, so you can run the same minimal, hackable coding agent without a Node.js runtime. Consider it because it does the same job with a different approach (open source).
  9. mu (Open source): mu is an open-source coding agent with a judgment kernel: a small, fast judge model makes the many routine decisions in each turn so the main model only gets the context it needs. It ships as a command-line tool and a desktop app and aims to keep coding sessions focused and cheap. Consider it because it also covers computer and desktop control.
  10. Claude Code (Paid): Anthropic's terminal coding agent that edits code, runs commands and handles git. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers editing and rough cuts; it has more GitHub stars (153,337 vs 130,852).
