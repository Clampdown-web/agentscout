OpenAI Codex CLI alternatives (2026)

OpenAI Codex CLI is a coding tool: OpenAI's open-source coding agent for the terminal; also runs in the cloud. Pricing, as the maker states it: Open source; uses ChatGPT plan or API. Its GitHub repo has 129,112 stars. We found 117 tools in the directory that do overlapping work (coding in the terminal, writing code, open-source agents); 95 of them are open source and 9 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with OpenAI Codex CLI, then by GitHub stars.

  1. opencode (Open source): Open-source terminal coding agent that works with many model providers. Consider it because it has more GitHub stars (213,329 vs 129,112).
  2. Gemini CLI (Open source): Google's open-source terminal agent powered by Gemini. Consider it because it does the same job with a different approach (open source).
  3. Qwen Code (Open source): Open-source terminal coding agent from the Qwen team. Consider it because it does the same job with a different approach (open source).
  4. Grok CLI (Open source): Open-source coding agent for the Grok API. Consider it because it does the same job with a different approach (open source).
  5. Claude Code (Paid): Anthropic's terminal coding agent that edits code, runs commands and handles git. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it has more GitHub stars (150,707 vs 129,112). OpenAI Codex CLI vs Claude Code →
  6. CC Switch (Open source): Desktop manager for Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw and other coding agents that switches API providers in one click and manages MCP servers, skills and prompts. Consider it because it is ready to use without building anything; it also covers computer and desktop control and MCP servers; it has more GitHub stars (145,685 vs 129,112).
  7. Open Interpreter (Open source): Terminal coding agent forked from OpenAI's Codex and tuned for low-cost and open-weight models, with switchable harness modes that imitate tools like Claude Code. Consider it because it also covers agent frameworks and SDKs.
  8. Codewhale (Open source): Rust agent engine and terminal coding client with model choice, tool approvals and review flows. Consider it because it does the same job with a different approach (open source).
  9. Oh My Pi (Open source): Terminal coding agent with IDE features wired in, from Stencil Labs. Consider it because it also covers IDE and editor agents.
  10. Repomix (Open source): CLI and web tool that packs an entire repository into a single AI-friendly file (with an MCP server) so coding agents and LLMs get full codebase context. Consider it because it also covers codebase context and code search and MCP servers.
