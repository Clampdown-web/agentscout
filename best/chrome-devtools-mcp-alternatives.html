Chrome DevTools MCP alternatives (2026)

Chrome DevTools MCP is a browser/computer use tool: Official MCP server that lets coding agents control and inspect a live Chrome browser through DevTools for debugging and performance work. Pricing, as the maker states it: Open source. Its GitHub repo has 53,681 stars. We found 58 tools in the directory that do overlapping work (writing code, browsing the web, connecting tools with MCP); 41 of them are open source and 6 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Chrome DevTools MCP, then by GitHub stars.

  1. Anchor Action Index (Freemium): Shared memory of web workflows for Anchor's cloud browsers: computer-use agents replay proven paths as deterministic code and the model only steps in where a page has changed, exposed as tools on Anchor's MCP server and REST API. Consider it because it also covers memory and computer and desktop control.
  2. Playwright MCP (Open source): Microsoft's MCP server giving agents browser control via Playwright. Consider it because it does the same job with a different approach (open source).
  3. Ui.Vision RPA (Open source): Browser and desktop automation extension with OCR and image recognition, plus an MCP server so AI agents can create and run macros. Consider it because it is ready to use without building anything; it also covers computer and desktop control and images and design.
  4. Mobile MCP (Open source): MCP server that lets agents automate iOS and Android apps on simulators, emulators and real devices through one platform-agnostic interface. Consider it because it also covers mobile and remote control.
  5. Windows-MCP (Open source): Lightweight MCP server for computer use on Windows that lets agents navigate files, control apps and interact with the UI. Consider it because it also covers computer and desktop control.
  6. Peekaboo (Open source): macOS CLI, menu-bar app and MCP server for screen capture, accessibility inspection and native UI automation by AI agents. Consider it because it also covers computer and desktop control and terminal and CLI agents.
  7. webclaw (Open source + cloud): Rust web extraction tool that turns sites into clean Markdown or JSON for agents, as a CLI, MCP server and REST API, with a hosted API. Consider it because it also covers scraping and crawling and terminal and CLI agents.
  8. Firefox DevTools MCP (See site): Mozilla's MCP server that lets AI agents browse with Firefox and inspect pages with its developer tools over WebDriver BiDi. Consider it because it does the same job with a different approach (see site).
  9. Stagehand (Open source): Browser automation framework mixing code with natural-language actions. Consider it because it also covers agent frameworks and SDKs.
  10. Playwriter (Open source): Chrome extension and CLI or MCP that lets agents control your own logged-in browser by running Playwright snippets. Consider it because it also covers terminal and CLI agents.
