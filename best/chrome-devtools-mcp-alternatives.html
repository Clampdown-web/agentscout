Chrome DevTools MCP alternatives (2026)

Chrome DevTools MCP is a browser/computer use tool: Official MCP server that lets coding agents control and inspect a live Chrome browser through DevTools for debugging and performance work. Pricing, as the maker states it: Open source. Its GitHub repo has 54,105 stars. We found 81 tools in the directory that do overlapping work (writing code, browsing the web, connecting tools with MCP); 55 of them are open source and 16 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Chrome DevTools MCP, then by GitHub stars.

  1. Anchor Action Index (Freemium): Shared memory of web workflows for Anchor's cloud browsers: computer-use agents replay proven paths as deterministic code and the model only steps in where a page has changed, exposed as tools on Anchor's MCP server and REST API. Consider it because it also covers memory and computer and desktop control.
  2. Scrapling (Open source): Python web-scraping framework with fast HTTP requests, stealth browsers, adaptive parsing and concurrent crawling, plus an MCP server for agents. Consider it because it also covers scraping and crawling and agent frameworks and SDKs; it has more GitHub stars (89,611 vs 54,105).
  3. Playwright MCP (Open source): Microsoft's MCP server giving agents browser control via Playwright. Consider it because it does the same job with a different approach (open source).
  4. Ui.Vision RPA (Open source): Browser and desktop automation extension with OCR and image recognition, plus an MCP server so AI agents can create and run macros. Consider it because it is ready to use without building anything; it also covers computer and desktop control and images and design.
  5. Terminator (Open source): Desktop automation library and MCP server that lets AI assistants control any Windows app through the accessibility tree, like Playwright for the desktop. Consider it because it also covers computer and desktop control and agent frameworks and SDKs.
  6. Kernel (Usage-based): Cloud browsers for AI agents: launch headless or live-view Chrome sessions in milliseconds with stealth mode, persistent profiles and replays, controlled through an API, CLI or MCP server. Free tier plus usage pricing. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers terminal and CLI agents.
  7. axuse (Open source): axuse gives AI agents browser and computer use through a single MCP server that plugs into Claude Code, Codex, OpenCode and other MCP hosts. Instead of a screenshot loop it reads the DOM, the accessibility tree and Chrome DevTools, which makes actions faster and uses far fewer tokens, and it has zero dependencies, with desktop control on Windows, macOS (opt-in) and Linux. Consider it because it also covers computer and desktop control.
  8. PhoneUse (Usage-based): PhoneUse gives AI agents phones of their own to operate. Agents get cloud Android phones that boot in seconds and scale to hundreds, or real retail iPhones and Androids in a San Francisco rack, tapped by a robot stylus, for apps that detect emulators, with real carrier numbers for SMS and 2FA codes. One MCP server with tools such as acquire, read screen, tap, type, swipe, open app and read SMS plugs into Claude, Cursor, Codex or Windsurf, and there is a Python SDK and REST API. On-demand cloud phones are billed per minute, with flat monthly prices for dedicated and real phones. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers voice and phone agents and computer and desktop control.
  9. Pudding (Free): Pudding is a desktop AI workspace from Teatak for macOS and Windows 11 that connects your own model API keys or local Ollama models with a built-in browser, file and command tools, a Studio for Markdown documents and typed tables, scheduled tasks, parallel subtask delegation and MCP plugins. Every tool call is shown in the conversation with per-project permission controls (Ask, Auto or Full access). Consider it because it is ready to use without building anything; it also covers running many agents in parallel and RAG and documents.
  10. Stagehand (Open source): Browser automation framework mixing code with natural-language actions. Consider it because it also covers agent frameworks and SDKs and mixing.
