  1. Serena (Open source): MCP toolkit that gives coding agents semantic code retrieval and editing, like IDE features. Consider it because it is open source, so you can self-host and inspect it; it also covers IDE and editor agents and editing and rough cuts.
  2. Grounded Docs MCP (Open source): Self-hosted MCP server that indexes up-to-date documentation from websites, GitHub, npm and PyPI so coding agents query the right version. Consider it because it is open source, so you can self-host and inspect it; it also covers local and self-hosted.
  3. FastMCP (Open source): Pythonic framework for building MCP servers and clients quickly. Consider it because it is open source, so you can self-host and inspect it.
  4. MCP TypeScript SDK (Open source): Official TypeScript SDK for building MCP servers and clients. Consider it because it is open source, so you can self-host and inspect it.
  5. mcp-use (Open source): Full-stack MCP framework for building MCP servers, MCP apps and agents that connect to them. Consider it because it is open source, so you can self-host and inspect it.
  6. Zotero MCP (Open source): MCP server that connects your Zotero research library to Claude and other assistants. Consider it because it is open source, so you can self-host and inspect it; it also covers research and reports.
  7. MCP-UI (Open source): SDK that lets MCP servers send interactive web components such as forms, charts and buttons that chat hosts render inside the conversation. Consider it because it is open source, so you can self-host and inspect it.
  8. MCP C# SDK (Open source): Official C# SDK for building MCP servers and clients, maintained with Microsoft. Consider it because it is open source, so you can self-host and inspect it.
  9. MCP Java SDK (Open source): Official Java SDK for MCP servers and clients. Consider it because it is open source, so you can self-host and inspect it.
  10. MCP Apps (Open source): Official spec and SDK for MCP Apps, the standard for interactive UIs like charts and forms that MCP servers render inside chat clients. Consider it because it is open source, so you can self-host and inspect it.
