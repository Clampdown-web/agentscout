Context7 alternatives (2026)

Context7 is a MCP & infra tool: MCP server and platform that feeds coding agents up-to-date, version-specific library documentation. Pricing, as the maker states it: Freemium. Its GitHub repo has 63,157 stars. We found 267 tools in the directory that do overlapping work (writing code, building AI agents, working with documents); 149 of them are open source and 23 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Context7, then by GitHub stars.

  1. Grounded Docs MCP (Open source): Self-hosted MCP server that indexes up-to-date documentation from websites, GitHub, npm and PyPI so coding agents query the right version. Consider it because it is open source, so you can self-host and inspect it; it also covers local and self-hosted.
  2. Microsoft Learn MCP (Source-available): Official Microsoft Learn MCP server giving agents up-to-date Microsoft documentation. Consider it because it does the same job with a different approach (source-available).
  3. Redpanda Docs MCP (See site): Redpanda's MCP server for answering questions from Redpanda documentation and API references. Consider it because it does the same job with a different approach (see site).
  4. Serena (Open source): MCP toolkit that gives coding agents semantic code retrieval and editing, like IDE features. Consider it because it is open source, so you can self-host and inspect it; it also covers IDE and editor agents.
  5. FastMCP (Open source): Pythonic framework for building MCP servers and clients quickly. Consider it because it is open source, so you can self-host and inspect it.
  6. MCP TypeScript SDK (Open source): Official TypeScript SDK for building MCP servers and clients. Consider it because it is open source, so you can self-host and inspect it.
  7. mcp-use (Open source): Full-stack MCP framework for building MCP servers, MCP apps and agents that connect to them. Consider it because it is open source, so you can self-host and inspect it.
  8. Zotero MCP (Open source): MCP server that connects your Zotero research library to Claude and other assistants. Consider it because it is open source, so you can self-host and inspect it; it also covers research and reports.
  9. MCP C# SDK (Open source): Official C# SDK for building MCP servers and clients, maintained with Microsoft. Consider it because it is open source, so you can self-host and inspect it.
  10. MCP Java SDK (Open source): Official Java SDK for MCP servers and clients. Consider it because it is open source, so you can self-host and inspect it.
