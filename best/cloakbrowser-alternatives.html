CloakBrowser alternatives (2026)

CloakBrowser is a browser/computer use tool: Chromium build with source-level fingerprint patches, used as a drop-in Playwright or Puppeteer replacement for agent browsing. Pricing, as the maker states it: Open source. Its GitHub repo has 32,280 stars. We found 64 tools in the directory that do overlapping work (browsing the web); 44 of them are open source and 7 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with CloakBrowser, then by GitHub stars.

  1. Browser Use (Open source + cloud): Library that lets AI agents control a web browser. Consider it because it also covers agent frameworks and SDKs; it has more GitHub stars (117,912 vs 32,280).
  2. Scrapling (Open source): Python web-scraping framework with fast HTTP requests, stealth browsers, adaptive parsing and concurrent crawling, plus an MCP server for agents. Consider it because it also covers scraping and crawling and MCP servers; it has more GitHub stars (88,372 vs 32,280).
  3. Chrome DevTools MCP (Open source): Official MCP server that lets coding agents control and inspect a live Chrome browser through DevTools for debugging and performance work. Consider it because it also covers MCP servers; it has more GitHub stars (53,681 vs 32,280).
  4. UI-TARS-desktop (Open source): ByteDance's open-source multimodal agent stack, including a desktop app and Agent TARS for controlling computers and browsers. Consider it because it also covers computer and desktop control; it has more GitHub stars (39,297 vs 32,280).
  5. Playwright MCP (Open source): Microsoft's MCP server giving agents browser control via Playwright. Consider it because it also covers MCP servers; it has more GitHub stars (38,115 vs 32,280).
  6. Lightpanda (Open source + cloud): Headless browser written from scratch in Zig for AI agents and automation, built for speed and low memory rather than forked from Chromium. Consider it because it also covers memory; it has more GitHub stars (36,657 vs 32,280).
  7. OpenCLI (Open source): Turns websites into CLI commands and lets agents use your logged-in browser. Consider it because it also covers terminal and CLI agents.
  8. Stagehand (Open source): Browser automation framework mixing code with natural-language actions. Consider it because it also covers agent frameworks and SDKs.
  9. Moli (Open source): Lightweight Rust headless browser for AI agents that fetches pages, searches and extracts content, usable via CLI, CDP or WebDriver. Consider it because it also covers scraping and crawling and terminal and CLI agents.
  10. Browser Harness (Open source): Agent skill from the Browser Use team that lets Claude Code, Codex or Cursor drive your own logged-in Chrome to click, type, read pages and download files. Consider it because it also covers agent frameworks and SDKs.
