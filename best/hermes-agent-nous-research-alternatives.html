Hermes Agent (Nous Research) alternatives (2026)

Hermes Agent (Nous Research) is a frameworks tool: Open-source agent harness; v0.21.7 stable shipped Oct 12, v0.22.0 RCs Oct 13-14. Pricing, as the maker states it: Open source. Its GitHub repo has 256,929 stars. We found 136 tools in the directory that do overlapping work (building AI agents, research, open-source agents); 130 of them are open source and 2 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Hermes Agent (Nous Research), then by GitHub stars.

  1. Unreal Agent (Open source): Unreal Agent is an async-first agent harness from Unreal Labs, a team researching how to make agentic workflows efficient. The library handles inputs with stable IDs and deduplication, append-only sessions that can be forked, and a coordinator that manages each model turn and translates tool calls into operations. It ships with a cloud agent runner, a terminal UI and benchmark runners, under the MIT license. Consider it because it also covers voice and phone agents and evals and benchmarks.
  2. FrontierAgent (Open source): Open-source agent runtime and terminal app for long-horizon research and file work, with single-agent ReAct and parallel agent-team modes. Consider it because it also covers running many agents in parallel and terminal and CLI agents.
  3. DeepSeek Harness (Open source): DeepSeek's open-source agent harness with a local web UI, built so that every tool, model and scheduled task is a swappable plugin; still a developer preview. Consider it because it also covers local and self-hosted; it has more GitHub stars (261,062 vs 256,929).
  4. Ruflo (Open source): Open-source multi-agent meta-harness for Claude Code, Codex, and MCP clients; Oct 13 release adds Mods (mission workflows) and a single control plane with human approval. Consider it because it also covers running many agents in parallel and workflow automation.
  5. AstrBot (Open source): Open-source agent chatbot platform and framework that connects LLMs, plugins and tools to mainstream messaging apps for assistants, support bots and knowledge bases. Consider it because it also covers RAG and documents.
  6. OpenHuman (Open source): Lightweight open-source agent harness designed to run many agents cheaply on small servers. Consider it because it also covers running many agents in parallel and images and design.
  7. AIOS (See site): Research AI agent operating system that handles scheduling, context switching, memory, storage and tool management for LLM-based agents. Consider it because it also covers memory and mobile and remote control.
  8. TrueForge (Open source): Open-source agent harness runtime that turns an LLM into a working agent. Consider it because it does the same job with a different approach (open source).
  9. Raven (Open source): Host agent that plans complex jobs as task graphs and coordinates built-in and third-party agents for research, coding, design and on-call work. Consider it because it also covers SRE and incident response and planning and task tracking.
  10. AWorld (Open source): Agent harness from inclusionAI for building expert agents that search, reproduce and improve on ideas with their own tools and memory. Consider it because it also covers memory.
