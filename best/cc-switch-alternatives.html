CC Switch alternatives (2026)

CC Switch is a coding tool: Desktop manager for Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw and other coding agents that switches API providers in one click and manages MCP servers, skills and prompts. Pricing, as the maker states it: Open source. Its GitHub repo has 145,685 stars. We found 190 tools in the directory that do overlapping work (writing code, coding in the terminal, connecting tools with MCP); 140 of them are open source and 24 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with CC Switch, then by GitHub stars.

  1. Repomix (Open source): CLI and web tool that packs an entire repository into a single AI-friendly file (with an MCP server) so coding agents and LLMs get full codebase context. Consider it because it is aimed at developers who want to build on it; it also covers codebase context and code search.
  2. MobileBuildMCP (Open source): Sentry's MCP server and CLI that gives coding agents build, test and run tools for iOS and macOS projects. Consider it because it is aimed at developers who want to build on it; it also covers mobile and remote control.
  3. CodeGraphContext (Open source): MCP server and CLI that index local code into a graph database so AI assistants can query code relationships. Consider it because it is aimed at developers who want to build on it; it also covers SQL and databases and local and self-hosted.
  4. Container Use (Open source): Dagger's MCP server and CLI that gives each coding agent its own containerized environment so several can work in parallel safely. Consider it because it is aimed at developers who want to build on it; it also covers running many agents in parallel.
  5. ripwire (Open source): Zero-dependency CLI and MCP server that gives coding agents a ranked call graph, blast radius and tests-to-run before and after edits. Consider it because it is aimed at developers who want to build on it; it also covers voice and phone agents and editing and rough cuts.
  6. Gemini MCP Tool (Source-available): MCP server that lets Claude and other assistants call the Gemini CLI to analyze large files and codebases with its big context window. Consider it because it is aimed at developers who want to build on it; it also covers codebase context and code search and voice and phone agents.
  7. Zero (Open source): An open-source terminal coding agent written in Go that works with 30+ model providers, supports MCP, skills and subagents, and keeps all sessions on your own disk. Consider it because it is aimed at developers who want to build on it; it also covers multi-agent orchestration and local and self-hosted.
  8. Pi (Open source): Minimal, extensible open-source terminal coding agent and agent toolkit from Earendil, with a multi-provider LLM API, TypeScript SDK, RPC mode and installable extensions, skills and themes. Consider it because it is aimed at developers who want to build on it; it also covers agent frameworks and SDKs.
  9. opcode (Open source): A desktop app for Claude Code that lets you manage sessions, build custom agents, track usage and browse project history from a GUI instead of the terminal. Consider it because it is aimed at developers who want to build on it.
  10. ZCode (Open source): ZCode is Z.ai's open-source AI coding workspace and official harness for GLM-5.3, with a desktop app, web interface and terminal agent that run multiple agents on long goals, plus control from WeChat, Feishu or Telegram. Consider it because it is aimed at developers who want to build on it; it also covers running many agents in parallel and agents in chat apps.
