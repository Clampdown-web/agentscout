Updated / sources checked November 10, 2026.

CC Switch is a coding tool: Desktop manager for Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw and other coding agents that switches API providers in one click and manages MCP servers, skills and prompts. Pricing, as the maker states it: Open source. Its GitHub repo has 150,320 stars. We found 273 tools in the directory that do overlapping work (writing code, coding in the terminal, connecting tools with MCP); 224 of them are open source and 26 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with CC Switch, then by GitHub stars.

Updated November 9, 2026

  1. Claude Code Templates (Open source): Claude Code Templates is an open catalog and CLI of more than 1,980 Claude Code components (skills, subagents, slash commands, hooks, MCP servers and settings) at aitmpl.com, where you preview each file and combine components into one npx install that merges with your existing configuration. Consider it because it is aimed at developers who want to build on it; it also covers multi-agent orchestration.
  2. Repomix (Open source): CLI and web tool that packs an entire repository into a single AI-friendly file (with an MCP server) so coding agents and LLMs get full codebase context. Consider it because it is aimed at developers who want to build on it; it also covers codebase context and code search.
  3. MobileBuildMCP (Open source): Sentry's MCP server and CLI that gives coding agents build, test and run tools for iOS and macOS projects. Consider it because it is aimed at developers who want to build on it; it also covers mobile and remote control.
  4. Fallow (Open source): Codebase intelligence for TypeScript and JavaScript in a single Rust binary. It reports health, complexity hotspots, duplication, circular dependencies, architecture boundaries and unused code, and ships as a CLI, a GitHub Action, an LSP, an MCP server and a VS Code extension. Consider it because it is aimed at developers who want to build on it; it also covers codebase context and code search and IDE and editor agents.
  5. CodeGraphContext (Open source): MCP server and CLI that index local code into a graph database so AI assistants can query code relationships. Consider it because it is aimed at developers who want to build on it; it also covers SQL and databases and local and self-hosted.
  6. Container Use (Open source): Dagger's MCP server and CLI that gives each coding agent its own containerized environment so several can work in parallel safely. Consider it because it is aimed at developers who want to build on it; it also covers running many agents in parallel.
  7. ripwire (Open source): Zero-dependency CLI and MCP server that gives coding agents a ranked call graph, blast radius and tests-to-run before and after edits. Consider it because it is aimed at developers who want to build on it; it also covers voice and phone agents and editing and rough cuts.
  8. Gemini MCP Tool (Source-available): MCP server that lets Claude and other assistants call the Gemini CLI to analyze large files and codebases with its big context window. Consider it because it is aimed at developers who want to build on it; it also covers codebase context and code search and voice and phone agents.
  9. Zero (Open source): An open-source terminal coding agent written in Go that works with 30+ model providers, supports MCP, skills and subagents, and keeps all sessions on your own disk. Consider it because it is aimed at developers who want to build on it; it also covers multi-agent orchestration and local and self-hosted.
  10. Concord (Open source + cloud): Concord lets coding agents message each other and work together in a shared workspace. Agents running in different tools or on different machines can hand off tasks, ask each other questions and review each other's code in real time through its MCP server, so a team of agents can coordinate without you copying messages between terminals. Consider it because it is aimed at developers who want to build on it; it also covers running many agents in parallel.
