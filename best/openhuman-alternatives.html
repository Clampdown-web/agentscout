Consider it because it also covers workflow automation and multi-agent orchestration; it has more GitHub stars (79,669 vs 42,368).
  2. AgentScope (Open source): Framework for building and running transparent multi-agent applications with visual debugging. Consider it because it also covers multi-agent orchestration.
  3. DeepSeek Harness (Open source): DeepSeek's open-source agent harness with a local web UI, built so that every tool, model and scheduled task is a swappable plugin; still a developer preview. Consider it because it also covers local and self-hosted; it has more GitHub stars (263,334 vs 42,368).
  4. Hermes Agent (Nous Research) (Open source): Open-source agent harness; v0.21.7 stable shipped Oct 12, v0.22.0 RCs Oct 13-14. Consider it because it also covers research and reports; it has more GitHub stars (257,588 vs 42,368).
  5. AstrBot (Open source): Open-source agent chatbot platform and framework that connects LLMs, plugins and tools to mainstream messaging apps for assistants, support bots and knowledge bases. Consider it because it also covers RAG and documents; it has more GitHub stars (44,074 vs 42,368).
  6. TrueForge (Open source): Open-source agent harness runtime that turns an LLM into a working agent. Consider it because it does the same job with a different approach (open source).
  7. FrontierAgent (Open source): Open-source agent runtime and terminal app for long-horizon research and file work, with single-agent ReAct and parallel agent-team modes. Consider it because it also covers research and reports and terminal and CLI agents.
  8. Cheshire Cat (Open source): Open-source AI agent microservice designed to be easy to understand and extend, with plugins and memory. Consider it because it also covers memory.
  9. ECC (Open source + cloud): The agent harness performance optimization system. Skills, instincts, memory, security, and research-first development for Claude Code, Codex, Opencode, Cursor and beyond Consider it because it also covers memory and research and reports; it has more GitHub stars (291,617 vs 42,368).
  10. MetaGPT (Open source): Multi-agent framework that assigns roles like product manager and engineer to LLM agents to build software. Consider it because it also covers multi-agent orchestration; it has more GitHub stars (71,035 vs 42,368).
