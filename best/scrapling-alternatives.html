Scrapling is a browser/computer use tool: Python web-scraping framework with fast HTTP requests, stealth browsers, adaptive parsing and concurrent crawling, plus an MCP server for agents. Pricing, as the maker states it: Open source. Its GitHub repo has 89,984 stars.   1. Terminator (Open source): Desktop automation library and MCP server that lets AI assistants control any Windows app through the accessibility tree, like Playwright for the desktop. Consider it because it also covers computer and desktop control.
  2. ScrapeGraphAI (Open source + cloud): Python library that uses LLMs and graph logic to build scraping pipelines: describe the data you want and it extracts it from websites or documents. Consider it because it also covers RAG and documents.
  3. PhoneUse (Usage-based): PhoneUse gives AI agents phones of their own to operate. Agents get cloud Android phones that boot in seconds and scale to hundreds, or real retail iPhones and Androids in a San Francisco rack, tapped by a robot stylus, for apps that detect emulators, with real carrier numbers for SMS and 2FA codes. One MCP server with tools such as acquire, read screen, tap, type, swipe, open app and read SMS plugs into Claude, Cursor, Codex or Windsurf, and there is a Python SDK and REST API. On-demand cloud phones are billed per minute, with flat monthly prices for dedicated and real phones. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers voice and phone agents and computer and desktop control.
  4. Chrome DevTools MCP (Open source): Official MCP server that lets coding agents control and inspect a live Chrome browser through DevTools for debugging and performance work. Consider it because it does the same job with a different approach (open source).
  5. Playwright MCP (Open source): Microsoft's MCP server giving agents browser control via Playwright. Consider it because it does the same job with a different approach (open source).
  6. Stagehand (Open source): Browser automation framework mixing code with natural-language actions. Consider it because it also covers mixing.
  7. Moli (Open source): Lightweight Rust headless browser for AI agents that fetches pages, searches and extracts content, usable via CLI, CDP or WebDriver. Consider it because it also covers terminal and CLI agents.
  8. webclaw (Open source + cloud): Rust web extraction tool that turns sites into clean Markdown or JSON for agents, as a CLI, MCP server and REST API, with a hosted API. Consider it because it also covers terminal and CLI agents.
  9. Ui.Vision RPA (Open source): Browser and desktop automation extension with OCR and image recognition, plus an MCP server so AI agents can create and run macros. Consider it because it is ready to use without building anything; it also covers computer and desktop control and images and design.
  10. Notte (Source-available + cloud): Browser infrastructure for AI agents: stealth cloud browsers with CAPTCHA solving and proxies, a Playwright-based framework and serverless automations. Consider it because it does the same job with a different approach (source-available + cloud).
