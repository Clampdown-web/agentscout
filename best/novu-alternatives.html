Updated / sources checked October 31, 2026.

Novu is an agent infra tool: Open-source communication infrastructure that gives products and AI agents one API to reach users over in-app inbox, email, SMS, push, Slack, Teams and chat. Pricing, as the maker states it: See site. Its GitHub repo has 40,164 stars. We found 282 tools in the directory that do overlapping work (writing and managing email, connecting tools with MCP); 149 of them are open source and 30 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Novu, then by GitHub stars.

Updated October 25, 2026

  1. Bird MCP (See site): Bird's MCP server for sending and receiving email, SMS, WhatsApp and voice messages from AI agents through one API. Consider it because it also covers voice and phone agents and MCP servers.
  2. Google Workspace CLI (Open source): Official Google Workspace command-line tool for Drive, Gmail, Calendar, Docs and more, usable by agents. Consider it because it is open source, so you can self-host and inspect it; it also covers terminal and CLI agents.
  3. Google Workspace MCP (Open source): MCP server and CLI that gives AI assistants natural-language control of Gmail, Calendar, Drive, Docs, Sheets, Slides, Forms, Tasks and Chat. Consider it because it is open source, so you can self-host and inspect it; it also covers MCP servers and terminal and CLI agents.
  4. Atomic Mail (See site): Email API that gives AI agents their own inboxes, built on JMAP with MCP and agent skill support. Consider it because it does the same job with a different approach (see site).
  5. Sentio (Open source): Sentio, from Truespar, is a self-hosted email inbox API for AI agents: a Rust SMTP server that gives each agent a real address, delivers inbound mail as authenticated webhooks and lets agents reply in-thread over REST, with multi-tenant isolation. Consider it because it is open source, so you can self-host and inspect it; it also covers identity, auth and secrets and local and self-hosted.
  6. SendPulse MCP (See site): SendPulse's MCP server for driving its email, CRM, chatbot, SMTP and course automation from AI agents. Consider it because it also covers sales and lead generation and MCP servers.
  7. Hello Retail MCP (See site): Hello Retail's MCP server for setting up and tuning e-commerce search, recommendations, email and product agents. Consider it because it also covers MCP servers and vocal tuning and vocal plugins.
  8. Kajabi MCP (See site): Kajabi's MCP server for managing products, pages, contacts, offers, emails and analytics from any MCP client. Consider it because it also covers MCP servers.
  9. MailVeri MCP (Open source + cloud): Open-source MCP server that lets AI agents and coding assistants verify single emails and bulk email lists through the MailVeri API, with SMTP, catch-all, disposable and role-account detection. Consider it because it is open source, so you can self-host and inspect it; it also covers MCP servers.
  10. OneSignal MCP (See site): OneSignal's official hosted MCP server for managing users, segments, templates, push and email messages and analytics from AI clients. Consider it because it also covers MCP servers.
