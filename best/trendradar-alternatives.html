TrendRadar is a research tool: TrendRadar is a GPL-3.0 trending-news assistant that you can deploy in minutes with Docker, locally or on Cloudflare; it gathers hot lists and RSS feeds from many platforms, filters them by your keywords or with AI, adds AI analysis and translation, and pushes alerts to WeChat Work, Feishu, Telegram, Slack, ntfy, Bark or email, with an MCP server so AI clients can query the news. Its main docs are in Chinese. Pricing, as the maker states it: Open source. Its GitHub repo has 63,563 stars. We found 66 tools in the directory that do overlapping work (writing and managing email, research, connecting tools with MCP); 46 of them are open source and 15 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with TrendRadar, then by GitHub stars.

  1. GPT Researcher (Open source): GPT Researcher is an Apache-2.0 open deep-research agent that investigates any topic on the web or in your local documents and writes a detailed, cited report. Planner and execution agents split the task into research questions and run them in parallel, context filtering keeps only useful sources, recursive deep research goes both broad and deep, and a multi-agent mode carries work from planning to publication. It works with most LLM providers and runs as a Python package, Docker app, web UI or MCP server. Consider it because it is aimed at developers who want to build on it; it also covers running many agents in parallel and planning and task tracking.
  2. OpenCity Record (Freemium): OpenCity Record makes US city council and planning meetings searchable in plain language: what was decided, who voted and what is coming up, drawn from meeting transcripts, agendas and ordinances across hundreds of cities. Connect it to Claude, ChatGPT or Cursor through its remote MCP server and ask questions about your local government, with every answer citing the meeting it came from. Consider it because it also covers planning and task tracking and subtitles and transcripts.
  3. PDFMathTranslate (Open source): PDFMathTranslate (pdf2zh) translates scientific PDFs while keeping the original layout: formulas, charts, tables of contents and annotations stay in place and it outputs bilingual or translated-only files. It works with Google, DeepL, OpenAI, Ollama and other translation services, adds experimental OCR and an ultrafast mode for native-text PDFs, and runs as a CLI, a desktop or web GUI, Docker, an MCP server or a Zotero plugin. AGPL-3.0; an EMNLP 2025 demo paper. Consider it because it also covers RAG and documents and computer and desktop control.
  4. AIPOCH Open-Science (Open source): A local-first, model-agnostic desktop research workbench. You work with an agent on papers and data through skills, MCP tools, and Python/R execution, then export traceable .science packages for reproducible results. It runs on macOS, Windows and Linux. Consider it because it is aimed at developers who want to build on it; it also covers research and reports and computer and desktop control.
  5. Deep Research (u14) (Open source): Deep research app that works with any LLM and exposes an API and MCP server. Consider it because it also covers research and reports.
  6. Paper2Agent (Open source): Multi-agent system that turns a research paper and its code into a working MCP server and agent skills you can query and run. Consider it because it is aimed at developers who want to build on it; it also covers research and reports and multi-agent orchestration.
  7. Paper Search MCP (Open source): MCP server and CLI that searches and downloads academic papers from arXiv, PubMed, bioRxiv, Semantic Scholar and other sources for research agents. Consider it because it is aimed at developers who want to build on it; it also covers research and reports and terminal and CLI agents.
  8. new-term-radar (Open source): new-term-radar is an MIT Python tool, also packaged as an MCP server and agent skill, that catches names of new AI models, products and repos the day they appear on X, Hugging Face, GitHub and company sitemaps, before keyword tools list them. It is aimed at SEO and content people who want to write about a term before search demand peaks. Consider it because it is aimed at developers who want to build on it; it also covers marketing and social media.
  9. OpenOSINT (Open source + cloud): An open-source OSINT engine with about 20 passive investigation tools usable from a CLI, a web UI or an MCP server for AI assistants, with hosted monitoring and due-diligence plans. Consider it because it is aimed at developers who want to build on it; it also covers planning and task tracking and tracing and observability.
  10. Frank AI Researcher (Freemium): Frank AI Researcher is a hosted MCP server for AI-moderated voice interviews with a team's own customers. An MCP client can draft a study, publish an interviewer link and read transcripts. Frank does not recruit participants, and the project README says MCP is included on every plan, including Free. On 24 Nov 2026 the pricing page listed a free plan with 60 voice minutes a month and no card. Paid yearly totals were Starter $590 (120 voice minutes), Growth $1,990 (450 voice minutes) and Business $3,750 (950 voice minutes), with the monthly toggle showing $59, $199 and $375. The endpoint is https://api.hifrank.ai/mcp. Consider it because it is aimed at developers who want to build on it; it also covers planning and task tracking and voice and phone agents.
