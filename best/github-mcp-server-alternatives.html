GitHub MCP Server alternatives (2026)

GitHub MCP Server is a MCP & infra tool: GitHub's official MCP server for letting agents work with repositories, issues, pull requests and Actions. Pricing, as the maker states it: Open source. Its GitHub repo has 33,663 stars. We found 279 tools in the directory that do overlapping work (writing code, reviewing pull requests, connecting tools with MCP); 158 of them are open source and 24 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with GitHub MCP Server, then by GitHub stars.

  1. GitKraken MCP (See site): GitKraken's MCP server, via the GitKraken CLI, for managing repos, pull requests and issues across GitHub, GitLab and Bitbucket. Consider it because it also covers terminal and CLI agents.
  2. Desktop Commander MCP (Open source): MCP server that gives Claude and other clients terminal control, process management, file search and diff-based file editing on your computer. Consider it because it is ready to use without building anything; it also covers computer and desktop control and terminal and CLI agents.
  3. REA (Open source): MCP server and CLI that lets coding agents reverse engineer native binaries, Electron and JavaScript apps, .NET assemblies and live websites, using Ghidra, Hopper or IDA under the hood. Consider it because it also covers terminal and CLI agents; it has more GitHub stars (301,645 vs 33,663).
  4. Context7 (Freemium): MCP server and platform that feeds coding agents up-to-date, version-specific library documentation. Consider it because it also covers RAG and documents and agent frameworks and SDKs; it has more GitHub stars (63,157 vs 33,663).
  5. Codebase Memory MCP (Open source): MCP server that indexes codebases into a persistent knowledge graph so coding agents can look up structure quickly. Consider it because it also covers codebase context and code search and memory; it has more GitHub stars (46,717 vs 33,663).
  6. Framelink Figma MCP (Open source): MCP server that gives Cursor and other coding agents Figma layout data so they can implement designs accurately in one shot. Consider it because it also covers images and design.
  7. GitMCP (Open source): Free remote MCP server that gives agents up-to-date docs and code for any GitHub project. Consider it because it does the same job with a different approach (open source).
  8. Observal (Open source): Self-hosted registry and insight engine for sharing coding-agent skills, MCP servers and agents across a team. Consider it because it also covers MCP gateways and registries and local and self-hosted.
  9. jCodeMunch MCP (Source-available): MCP server for symbol-level code exploration that cuts token use. Consider it because it also covers token usage and cost tracking.
  10. Figma Console MCP (Open source): Design-system-focused MCP server that reads and writes Figma and checks design-code parity and accessibility. Consider it because it also covers images and design.
