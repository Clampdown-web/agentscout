Codebase Memory MCP alternatives (2026)

Codebase Memory MCP is a MCP & infra tool: MCP server that indexes codebases into a persistent knowledge graph so coding agents can look up structure quickly. Pricing, as the maker states it: Open source. Its GitHub repo has 46,717 stars.   2. Locize MCP (See site): Locize's MCP server with translation-management tools for keys, translation memory, glossary, styleguides and versions. Consider it because it does the same job with a different approach (see site).
  3. Zeroboot (Open source + cloud): VM sandboxes for running agent code that start in under a millisecond by forking a warm snapshot with copy-on-write memory. Consider it because it also covers sandboxes and secure execution.

REA (Open source): MCP server and CLI that lets coding agents reverse engineer native binaries, Electron and JavaScript apps, .NET assemblies and live websites, using Ghidra, Hopper or IDA under the hood. Consider it because it also covers terminal and CLI agents; it has more GitHub stars (301,645 vs 46,717).
  5. Context7 (Freemium): MCP server and platform that feeds coding agents up-to-date, version-specific library documentation. Consider it because it also covers RAG and documents and agent frameworks and SDKs; it has more GitHub stars (63,157 vs 46,717).
  6. CLI-Anything (Open source): Open-source project from HKUDS that generates agent-native command-line interfaces for existing software, codebases and web APIs, with CLI-Hub, a registry of community CLIs that coding agents can install and drive. Consider it because it also covers MCP gateways and registries and terminal and CLI agents; it has more GitHub stars (54,399 vs 46,717).
  7. GitHub MCP Server (Open source): GitHub's official MCP server for letting agents work with repositories, issues, pull requests and Actions. Consider it because it also covers code review.
  8. Framelink Figma MCP (Open source): MCP server that gives Cursor and other coding agents Figma layout data so they can implement designs accurately in one shot. Consider it because it also covers images and design.
  9. GitMCP (Open source): Free remote MCP server that gives agents up-to-date docs and code for any GitHub project. Consider it because it does the same job with a different approach (open source).
  10. Observal (Open source): Self-hosted registry and insight engine for sharing coding-agent skills, MCP servers and agents across a team. Consider it because it also covers MCP gateways and registries and local and self-hosted.
