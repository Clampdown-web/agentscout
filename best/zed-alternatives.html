    1. Cursor (Freemium): AI code editor with an agent mode and background agents. Consider it because it does the same job with a different approach (freemium).
    2. 21st Magic MCP (Freemium): MCP server from 21st.dev that lets Cursor, Claude Code and Windsurf search and generate React and Tailwind UI components inside the editor. Consider it because it is aimed at developers who want to build on it; it also covers MCP servers.
    3. ThinkRail (Open source): JetBrains' lightweight agentic IDE that pairs you with the pi coding agent, with isolated git-worktree workspaces, editor tabs, terminals and diffs. Consider it because it is aimed at developers who want to build on it; it also covers code review and running many agents in parallel.
    4. Amp (Usage-based): Agentic coding tool for the terminal and editor. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it is aimed at developers who want to build on it; it also covers terminal and CLI agents.
    5. TRAE (Paid): AI coding IDE and agent that works alongside you in your editor to write, edit and run code. Consider it because it is a managed commercial product, if you'd rather not run it yourself.
    6. Claude Code (Paid): Anthropic's terminal coding agent that edits code, runs commands and handles git. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it is aimed at developers who want to build on it; it also covers terminal and CLI agents.
    7. Cline (Open source): Autonomous coding agent inside VS Code with step-by-step approvals. Consider it because it is aimed at developers who want to build on it; it also covers autonomous and cloud coding agents.
    8. Goose (Open source): Extensible open-source AI agent that installs, runs, edits and tests code on your machine with any LLM and MCP extensions. Consider it because it is aimed at developers who want to build on it.
    9. Oh My Pi (Open source): Terminal coding agent with IDE features wired in, from Stencil Labs. Consider it because it is aimed at developers who want to build on it; it also covers terminal and CLI agents.
    10. Kilo Code (Open source + cloud): Open-source AI coding agent for VS Code, JetBrains, the CLI and the cloud that works with 500+ models at no markup. Consider it because it is aimed at developers who want to build on it; it also covers terminal and CLI agents.
