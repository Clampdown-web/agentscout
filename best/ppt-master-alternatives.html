PPT Master alternatives (2026)

PPT Master is a productivity tool: AI tool that turns documents or topics into native, editable PowerPoint decks with real shapes, charts, transitions and narration from speaker notes. Pricing, as the maker states it: Open source. Its GitHub repo has 63,293 stars. We found 14 tools in the directory that do overlapping work (data analysis, working with documents, spreadsheets, slides and docs); 9 of them are open source and 3 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with PPT Master, then by GitHub stars.

Updated October 24, 2026

Quick answer: the top picks on this list, ranked by GitHub stars and listing maturity, are OpenKnowledge, Kition and ArchiLabs, out of 11 tools listed below. At a glance: 9 open-source, 10 free or freemium and 1 local or self-hosted across 11 link-checked tools (last verified Oct 24, 2026).

  1. OpenKnowledge (Open source): OpenKnowledge is a free, local-first markdown editor and knowledge base built for working alongside AI agents. It looks and feels like a Notion-style WYSIWYG editor, with callouts, tabs, Mermaid diagrams and media blocks, but every page stays a plain markdown file on your disk. Coding agents such as Claude Code, Codex, Cursor, Gemini CLI and dozens of others can read and write the same files through its integrations, so specs, team wikis and LLM wikis stay in one place that both people and agents keep up to date. It ships as a desktop app plus a web UI and CLI. Consider it because it also covers computer and desktop control and local and self-hosted.
  2. Kition (Open source): Kition is an open-source desktop office workspace with an AI agent built in. It combines documents, data tables and a whiteboard for design work in one app, and its tool-using agent can research the web, write and translate, organise records and produce editable brand assets, with visual workflows to chain the steps together. Consider it because it also covers research and reports and computer and desktop control.
  3. ArchiLabs (Paid): AI teammate for architects that creates and edits native models and drawings in Revit and AutoCAD from a task, PDF or screen recording. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers computer and desktop control.
  4. MindsHub (Open source + cloud): MindsDB's agent workspace for research, analysis, documents and coding, with a model router, a scoped vault for connected data and swappable open-source agent harnesses. Consider it because it also covers research and reports and agent frameworks and SDKs.
  5. GenOffice (Open source): Free, open-source office suite with docs, sheets and slides editors and a built-in AI agent. Consider it because it also covers IDE and editor agents.
  6. Craft Agents (Open source): Desktop app from the makers of Craft for working with agents in a document-first way; the agent sets up APIs and MCP servers for you and sessions can be shared. Consider it because it also covers computer and desktop control and MCP servers.
  7. draw.io MCP (Open source): The official draw.io MCP server, so Claude, ChatGPT, Cursor and other assistants can create and edit flowcharts, architecture diagrams and other draw.io diagrams right in the chat. Free and needs no sign-in. Consider it because it also covers MCP servers and images and design.
  8. Agente Smart Documents (Freemium): Agente Smart Documents turns a finished Word document into a reusable template your AI agent can fill. You upload an example, it builds the template, then ChatGPT or Codex, Claude, Grok Bot, Hermes or the web workspace asks only for the details that are missing and hands back a filled .docx with the original layout kept, for you to review before sending. A few documents are free each month, then a flat monthly fee per office. Consider it because it does the same job with a different approach (freemium).
  9. Next AI Draw.io (Open source): Create and edit draw.io diagrams by chatting with AI, as a web app, desktop app or MCP server. Consider it because it also covers computer and desktop control and MCP servers.
  10. Teable (Open source + cloud): AI spreadsheet and database for business with built-in agents. Consider it because it also covers SQL and databases.
