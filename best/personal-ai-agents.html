Personal AI agents and assistants that work for you directly: chat apps, desktop assistants and always-on helpers. Below are the top 20 of 121 matching tools in the AgentScout directory, ranked.

Updated November 10, 2026

How we ranked: Ranked by GitHub stars as recorded on each AgentScout listing (link checks 2026-11-13). Tools without a tracked public repo come after, in alphabetical order. Stars measure developer popularity, not quality or fit for your job, so read each listing before you choose. No paid placements.

  1. 1. OpenClaw

    personal agentsOpen source★ 393,429 GitHub stars

    OpenClaw is an MIT-licensed personal AI assistant that runs on your own computer and answers in the chat apps you already use, including Discord, iMessage, Slack, Teams, Telegram and WhatsApp, with native apps for macOS, iOS, Android, Windows and Linux. State, memory and credentials stay on your hardware, models and harnesses such as Claude, Codex or local models are swappable plugins, and one gateway can run a personal or shared multiplayer assistant. It is stewarded by the non-profit OpenClaw Foundation with no paid tier or hosted service.

    Pricing (as stated): Free and open source (MIT); you pay only for the model providers you connect. · Active

  2. 2. Open WebUI

    personal agentsSource-available★ 157,244 GitHub stars

    Self-hosted, offline-capable AI platform with a chat interface for Ollama and OpenAI-compatible models, plus tools, pipelines and agent features.

    Pricing (as stated): Source-available · Mature

  3. 3. LobeHub

    personal agentsSource-available + cloud★ 83,604 GitHub stars

    Open-source agent workspace that organizes a team of AI agents for round-the-clock work, with scheduling, reporting and self-hosting or a cloud version.

    Pricing (as stated): Source-available + cloud · Mature

  4. 4. Career Ops

    personal agentsOpen source★ 78,796 GitHub stars

    Career-Ops is an MIT-licensed job-search agent that runs on your machine inside Claude Code, Codex, OpenCode or another AI CLI. You paste a job or let it scan job boards; it checks whether the posting is still open, scores the fit from 1 to 5 against your CV, tailors an ATS-friendly resume and cover letter, drafts application answers, preps you for interviews and tracks every application. It fills in the forms but you press Submit yourself.

    Pricing (as stated): Free and open source (MIT); you use your own AI CLI subscription. · Mature

  5. 5. AnythingLLM

    personal agentsOpen source + cloud★ 67,747 GitHub stars

    Local-first desktop and server app for chatting with your documents, running agents and connecting any LLM.

    Pricing (as stated): Open source + cloud · Mature

  6. 6. Cherry Studio

    personal agentsOpen source★ 53,099 GitHub stars

    Cherry Studio is an AGPL-3.0 desktop AI workstation for Windows, macOS and Linux that lets you chat with many cloud and local model providers side by side, run agents, build knowledge bases, generate images and automate everyday tasks from one app. It ships hundreds of ready-made assistants, supports MCP tools, and now has iOS and Android companion apps; a commercial licence is offered for teams that cannot use AGPL.

    Pricing (as stated): Open source · Mature

  9. 9. LibreChat

It includes agents with MCP tools and skills, a code interpreter, artifacts, message search, presets and secure multi-user auth; v0.8.8 added a beta Agent Management API with OpenAPI docs, per-agent workspaces and Ask/Allow/Deny approval controls for file writes and commands.

    Pricing (as stated): Open source · Mature
