MCP reference servers alternatives (2026)

MCP reference servers is a MCP & infra tool: Official collection of reference MCP servers. Pricing, as the maker states it: Open source. Its GitHub repo has 91,237 stars. We found 267 tools in the directory that do overlapping work (connecting tools with MCP, building MCP servers); 148 of them are open source and 24 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with MCP reference servers, then by GitHub stars.

  1. REA (Open source): MCP server and CLI that lets coding agents reverse engineer native binaries, Electron and JavaScript apps, .NET assemblies and live websites, using Ghidra, Hopper or IDA under the hood. Consider it because it also covers terminal and CLI agents; it has more GitHub stars (301,645 vs 91,237).
  2. Context7 (Freemium): MCP server and platform that feeds coding agents up-to-date, version-specific library documentation. Consider it because it also covers RAG and documents and agent frameworks and SDKs.
  3. Codebase Memory MCP (Open source): MCP server that indexes codebases into a persistent knowledge graph so coding agents can look up structure quickly. Consider it because it also covers codebase context and code search and memory.
  4. GitHub MCP Server (Open source): GitHub's official MCP server for letting agents work with repositories, issues, pull requests and Actions. Consider it because it also covers code review.
  5. FastMCP (Open source): Pythonic framework for building MCP servers and clients quickly. Consider it because it also covers agent frameworks and SDKs.
  6. n8n-MCP (Open source): MCP server that lets Claude, Cursor and other agents build n8n workflows for you. Consider it because it also covers workflow automation.
  7. MCP Toolbox for Databases (Open source): Open-source MCP server from Google for connecting agents to databases. Consider it because it also covers SQL and databases.
  8. Framelink Figma MCP (Open source): MCP server that gives Cursor and other coding agents Figma layout data so they can implement designs accurately in one shot. Consider it because it also covers images and design.
  9. MCP TypeScript SDK (Open source): Official TypeScript SDK for building MCP servers and clients. Consider it because it also covers agent frameworks and SDKs.
  10. IDA Pro MCP (Open source): MCP server connecting IDA Pro to language models for AI-assisted reverse engineering. Consider it because it does the same job with a different approach (open source).
