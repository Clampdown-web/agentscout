MCP reference servers is a MCP servers tool: The Model Context Protocol servers repository holds the small set of reference MCP servers maintained by the MCP steering group, showing protocol features and SDK usage for builders writing their own servers. The project warns they are educational examples rather than production-ready, and points to the official MCP Registry for discovering published servers. Pricing, as the maker states it: Free and open source.. Its GitHub repo has 91,693 stars. We found 1064 tools in the directory that do overlapping work (writing code, building AI agents, connecting tools with MCP); 789 of them are open source and 107 list a free or freemium plan. Updated November 10, 2026

  1. Ruby Sdk (See site): Ruby Sdk is an MCP server that gives agents a way to handle for the Model Context Protocol servers and clients. Consider it because it does the same job with a different approach (see site).
  2. Wenbu (Free): Wenbu is a hosted Streamable HTTP MCP server (wenbu 1.5.0 at wenbu.app/mcp, listed in the official MCP Registry as app.wenbu/mcp) and web app for traditional Chinese cultural systems and reflection. Connect Claude, Cursor or any MCP client with no API key required to call seven tools—calculate_bazi, cast_iching, draw_tarot, calculate_ziwei, search_library, read_library and get_daily_card—or run the MIT-licensed server locally. Consider it because it is ready to use without building anything; it also covers voice and phone agents and local and self-hosted.
  3. Context7 (Freemium): MCP server and platform that feeds coding agents up-to-date, version-specific library documentation. Consider it because it also covers RAG and documents.
  4. FastMCP (Open source): Pythonic framework for building MCP servers and clients quickly. Consider it because it does the same job with a different approach (open source).
  5. MCP Python SDK (Open source): Official Python SDK for building Model Context Protocol servers and clients. Consider it because it does the same job with a different approach (open source).
  6. MCP TypeScript SDK (Open source): Official TypeScript SDK for building MCP servers and clients. Consider it because it does the same job with a different approach (open source).
  7. mcp-use (Open source): Full-stack MCP framework for building MCP servers, MCP apps and agents that connect to them. Consider it because it does the same job with a different approach (open source).
  8. MCP Go SDK (Open source): Official Go SDK for building Model Context Protocol servers and clients, maintained with Google. Consider it because it does the same job with a different approach (open source).
  9. MCP C# SDK (Open source): Official C# SDK for building MCP servers and clients, maintained with Microsoft. Consider it because it does the same job with a different approach (open source).
  10. MCP Rust SDK (Open source): Official Rust SDK for the Model Context Protocol. Consider it because it does the same job with a different approach (open source).
