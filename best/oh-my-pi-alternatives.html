    1. Kilo Code (Open source + cloud): Open-source AI coding agent for VS Code, JetBrains, the CLI and the cloud that works with 500+ models at no markup. Consider it because it does the same job with a different approach (open source + cloud).
    2. Qodo (Freemium): AI code review and testing agents that work in the IDE, the terminal and pull requests to catch issues before merge. Consider it because it also covers code review and testing and QA.
    3. AutoDev (Open source): Multi-agent development platform built on Kotlin Multiplatform for research, coding, review and data queries across IntelliJ, VS Code, CLI and more. Consider it because it also covers research and reports and multi-agent orchestration.
    4. ThinkRail (Open source): JetBrains' lightweight agentic IDE that pairs you with the pi coding agent, with isolated git-worktree workspaces, editor tabs, terminals and diffs. Consider it because it also covers code review and running many agents in parallel.
    5. Amp (Usage-based): Agentic coding tool for the terminal and editor. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers editing and rough cuts.
    6. Factory (Paid): Agent-native software development platform whose Droids write code, run tests and handle deployments from the IDE, terminal or Slack. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers agents in chat apps.
    7. opencode (Open source): Open-source terminal coding agent that works with many model providers. Consider it because it has more GitHub stars (213,329 vs 35,686).
    8. Claude Code (Paid): Anthropic's terminal coding agent that edits code, runs commands and handles git. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it also covers editing and rough cuts; it has more GitHub stars (150,707 vs 35,686).
    9. CC Switch (Open source): Desktop manager for Claude Code, Codex, Gemini CLI, OpenCode, OpenClaw and other coding agents that switches API providers in one click and manages MCP servers, skills and prompts. Consider it because it is ready to use without building anything; it also covers computer and desktop control and MCP servers; it has more GitHub stars (145,685 vs 35,686).
    10. OpenAI Codex CLI (Open source): OpenAI's open-source coding agent for the terminal; also runs in the cloud. Consider it because it has more GitHub stars (129,112 vs 35,686).
