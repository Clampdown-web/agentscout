RAGFlow alternatives (2026)

Pricing, as the maker states it: Open source + cloud. Its GitHub repo has 92,958 stars.   1. MarkItDown (Open source): Microsoft's Python tool and MCP server that converts PDFs, Office documents, images, audio and web pages to Markdown for LLM and agent pipelines. Consider it because it also covers MCP servers and images and design; it has more GitHub stars (192,483 vs 92,958).
  2. PageIndex (Open source + cloud): Document index for reasoning-based, vectorless RAG that lets agents navigate long documents like a table of contents. Consider it because it does the same job with a different approach (open source + cloud).
  3. Chroma (Open source + cloud): Open-source search and vector database widely used for agent memory and RAG. Consider it because it also covers memory and SQL and databases.
  4. xerj (Open source): A local-first search engine and MCP server for agents: one Rust binary indexes code, docs, logs, CSV/JSONL and PDFs for full-text, vector and hybrid search plus agent memory, behind an Elasticsearch-compatible API. Consider it because it also covers memory and search APIs.
  5. llmware (Open source): Framework for building private, local RAG and agent applications with small specialized models on AI PCs, edge and self-hosted setups. Consider it because it also covers agent frameworks and SDKs and local and self-hosted.
  6. LanceDB (Open source + cloud): Open-source multimodal vector database for search, RAG and agent memory. Consider it because it also covers memory and SQL and databases.
  7. Activeloop (Open source + cloud): Deep Lake, a multimodal database for AI that stores vectors, images, text and video so agents and RAG apps can search and retrieve them. Consider it because it also covers SQL and databases and video.
  8. Zep (Freemium): Context layer that unifies business data, documents and conversations into memory so agents complete tasks correctly. Consider it because it also covers codebase context and code search and memory.
  9. 53AIHub (Open source + cloud): 53AI Hub is an open-source AI portal and knowledge base for managing enterprise knowledge, AI agents, prompts, and AI tools, seamlessly integrating with Coze, Dify, FastGPT, RAGFlow.
