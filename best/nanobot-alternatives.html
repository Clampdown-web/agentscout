    Nanobot alternatives (2026)

    Nanobot is a personal agents tool: Ultra-lightweight, self-hosted personal agent framework in Python with a web UI, tools, memory and MCP support. Pricing, as the maker states it: Open source. Its GitHub repo has 49,096 stars. We found 85 tools in the directory that do overlapping work (building AI agents, personal assistance, connecting tools with MCP); 48 of them are open source and 15 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Nanobot, then by GitHub stars.

    1. TecAdRise Bot (Open source): TecAdRise Bot is a free, MIT-licensed Windows desktop app (Electron and Cursor SDK) for running a local team of AI agents, each with its own model, memory, skills, MCP servers, workspace and schedule. Consider it because it also covers computer and desktop control and MCP servers.
    2. Osaurus (Open source): Native macOS harness for AI agents with any model, memory and autonomous execution. Consider it because it is ready to use without building anything.
    3. Jarvis (Source-available): Private, local-first desktop AI assistant with voice and text chat, personal memory, dictation and MCP tools. Consider it because it is ready to use without building anything; it also covers voice and phone agents and computer and desktop control.
    4. CowAgent (Open source): Open-source personal assistant and agent harness that plans tasks, runs tools and skills and connects to chat apps. Consider it because it also covers planning and task tracking and rules, skills and config.
    5. Mercury Agent (Open source): Self-hosted personal AI agent with a written personality, local memory, permission-gated tools and token budgets, reachable via CLI or Telegram. Consider it because it is ready to use without building anything; it also covers agents in chat apps and guardrails and policies.
    6. Memmy (Open source): A local-first personal AI agent with a self-evolving long-term memory that its desktop app, CLI and your other AI agents can all share. Consider it because it is ready to use without building anything; it also covers computer and desktop control and terminal and CLI agents.
    7. CORE (See site): Always-on personal AI that builds a memory graph from your email, meetings and tools, then plans and runs tasks like opening a pull request. Consider it because it is ready to use without building anything; it also covers code review and planning and task tracking.
    8. Dodaios (Open source): Open-source desktop agent OS for Windows, macOS and Linux (formerly Personal Jarvis): talk to it and it runs your coding CLIs side by side, your browser and your apps, with offline Whisper speech, a local wiki memory and support for Ollama, Claude or ChatGPT subscriptions. Consider it because it is ready to use without building anything; it also covers running many agents in parallel and voice and phone agents.
    9. AirJelly (Freemium): Always-on desktop assistant that watches your workflow, remembers context and acts proactively. Consider it because it is ready to use without building anything; it also covers computer and desktop control and workflow automation.
    10. LVLZ (Paid): LVLZ is a personal AI agent you run by messaging it like a person, on iMessage or WhatsApp, as a text, voice note or call. It runs errands on real websites in a cloud browser, such as bookings, forms and shopping, turns messages into tasks and projects, fills a CRM from your conversations, and runs routines like a morning brief or a price watch. Everything it does lands in a web workspace, its memory can be read, edited and exported, and it asks before paying, contacting someone new or deleting anything, with cards and passwords kept in an encrypted vault. Consider it because it is a managed commercial product, if you'd rather not run it yourself; it is ready to use without building anything; it also covers voice and phone agents and agents in chat apps.
