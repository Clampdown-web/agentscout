Nanobot alternatives (2026)

Nanobot is a personal agents tool: Ultra-lightweight, self-hosted personal agent framework in Python with a web UI, tools, memory and MCP support. Pricing, as the maker states it: Open source. Its GitHub repo has 49,343 stars. We found 93 tools in the directory that do overlapping work (building AI agents, personal assistance, connecting tools with MCP); 52 of them are open source and 18 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Nanobot, then by GitHub stars.

  1. TecAdRise Bot (Open source): TecAdRise Bot is a free, MIT-licensed Windows desktop app (Electron and Cursor SDK) for running a local team of AI agents, each with its own model, memory, skills, MCP servers, workspace and schedule. Consider it because it also covers computer and desktop control and MCP servers.
  2. Osaurus (Open source): Native macOS harness for AI agents with any model, memory and autonomous execution. Consider it because it is ready to use without building anything.
  3. Jarvis (Source-available): Private, local-first desktop AI assistant with voice and text chat, personal memory, dictation and MCP tools. Consider it because it is ready to use without building anything; it also covers voice and phone agents and computer and desktop control.
  4. Guaca (Open source): Desktop workspace inspired by Grok Bot where AI agents collaborate, write code and use tools; runs locally or on your own server, with shared conversations, persistent memory and MCP plugins. AGPL-3.0. Consider it because it also covers computer and desktop control.
  5. Teebots (Free): Teebots is a free desktop app that keeps a small team of AI bots on your own computer. Each bot can use a different model through your own API key, with requests going straight to the provider, and keeps its own private memory alongside a shared group memory. Put several bots in one group chat and @mention one to hand it a task, or let them pass steps to each other. Bots can work with files in their own folder, run commands, use skills including MCP and browse in their own browser, but they stop and wait for your approval before submitting or paying for anything. Scheduled daily or weekly jobs keep running from the menu bar. Chats, memory, files and logins stay local. Available for Mac (Apple silicon) now, with Windows and Linux coming soon. Consider it because it is ready to use without building anything; it also covers browser automation and computer and desktop control.
  6. CowAgent (Open source): Open-source personal assistant and agent harness that plans tasks, runs tools and skills and connects to chat apps. Consider it because it also covers planning and task tracking and rules, skills and config.
  7. Mercury Agent (Open source): Self-hosted personal AI agent with a written personality, local memory, permission-gated tools and token budgets, reachable via CLI or Telegram. Consider it because it is ready to use without building anything; it also covers agents in chat apps and guardrails and policies.
  8. Memmy (Open source): A local-first personal AI agent with a self-evolving long-term memory that its desktop app, CLI and your other AI agents can all share. Consider it because it is ready to use without building anything; it also covers computer and desktop control and terminal and CLI agents.
  9. CORE (See site): Always-on personal AI that builds a memory graph from your email, meetings and tools, then plans and runs tasks like opening a pull request. Consider it because it is ready to use without building anything; it also covers code review and planning and task tracking.
  10. Dodaios (Open source): Open-source desktop agent OS for Windows, macOS and Linux (formerly Personal Jarvis): talk to it and it runs your coding CLIs side by side, your browser and your apps, with offline Whisper speech, a local wiki memory and support for Ollama, Claude or ChatGPT subscriptions. Consider it because it is ready to use without building anything; it also covers running many agents in parallel and voice and phone agents.
