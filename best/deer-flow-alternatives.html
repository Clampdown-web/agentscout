Deer Flow alternatives (2026)

Deer Flow is a research tool: ByteDance's open-source long-horizon agent harness that researches, codes and creates using sandboxes, memory and sub-agents. Pricing, as the maker states it: Open source. Its GitHub repo has 83,959 stars. We found 42 tools in the directory that do overlapping work (writing code, building AI agents, research); 25 of them are open source and 6 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with Deer Flow, then by GitHub stars.

  1. EvoScientist (Open source): Self-evolving AI scientist system that autonomously explores research ideas, runs experiments and improves with growing skills and memory. Consider it because it also covers rules, skills and config.
  2. Hyperresearch (Open source + cloud): Deep research harness that turns Claude Code or Codex into a research agent building a persistent, searchable wiki, with a hosted API and MCP. Consider it because it does the same job with a different approach (open source + cloud).
  3. LLM for Zotero (Open source): Zotero plugin that adds a research agent to your library so you can ask questions about papers, compare sources and save notes without leaving the reader. Consider it because it is ready to use without building anything.
  4. MiroFlow (Open source): Research agent framework with web UI supporting MiroThinker and other models. Consider it because it does the same job with a different approach (open source).
  5. Feynman (Open source): Open-source research agent that searches, reads papers and writes cited reports. Consider it because it does the same job with a different approach (open source).
  6. Agent-Reach (Open source): Lets an AI agent read and search sites like X, Reddit, YouTube and GitHub through one toolkit, without paid APIs. Consider it because it has more GitHub stars (98,176 vs 83,959).
  7. GPT Researcher (Open source): Autonomous agent that researches the web and writes cited reports. Consider it because it does the same job with a different approach (open source).
  8. DeepAnalyze (Open source): Agentic LLM from Renmin University that autonomously runs data science pipelines and produces analyst-grade research reports. Consider it because it does the same job with a different approach (open source).
  9. OpenScience (Open source): Research agent workbench that reads the literature, writes and runs code and experiments and logs every step, with skills and connectors for databases like PubMed, UniProt and arXiv. Consider it because it is ready to use without building anything; it also covers SQL and databases and rules, skills and config.
  10. Paper2Agent (Open source): Multi-agent system that turns a research paper and its code into a working MCP server and agent skills you can query and run. Consider it because it also covers MCP servers and multi-agent orchestration.
