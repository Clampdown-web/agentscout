MemPalace alternatives (2026)

MemPalace is a memory & RAG tool: Local-first AI memory system that stores conversations verbatim with a pluggable backend and serves recall to agents without API calls. Pricing, as the maker states it: Open source. Its GitHub repo has 59,622 stars. We found 38 tools in the directory that do overlapping work (building voice agents, memory for agents, running agents locally); 34 of them are open source and 0 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with MemPalace, then by GitHub stars.

  1. Supermemory (Open source + cloud): Memory and context engine for agents with an API, app and MCP server, which can also run fully locally. Consider it because it also covers MCP servers.
  2. EverOS (Open source): Local-first, portable memory layer for AI agents stored as Markdown. Consider it because it does the same job with a different approach (open source).
  3. Basic Memory (Open source + cloud): Persistent memory for Claude, Codex and Cursor stored as local Markdown knowledge, available open source or as a hosted cloud workspace. Consider it because it is ready to use without building anything.
  4. Claude-Mem (Open source): Gives coding agents memory across sessions by capturing what they do, compressing it and feeding the relevant context back in later. Consider it because it has more GitHub stars (101,230 vs 59,622).
  5. Headroom (Open source): Library, proxy and MCP server that compresses tool outputs, logs, files and RAG chunks locally before they reach the LLM, cutting tokens for coding agents. Consider it because it also covers RAG and documents and MCP gateways and registries; it has more GitHub stars (75,629 vs 59,622).
  6. Mem0 (Open source + cloud): Memory layer for AI agents. Consider it because it has more GitHub stars (67,147 vs 59,622).
  7. Hindsight (Open source + cloud): Agent memory system that stores experiences and learns from them so agents improve over time. Consider it because it does the same job with a different approach (open source + cloud).
  8. OpenViking (Open source): Context database for AI agents that keeps memory, knowledge and skills in one inspectable virtual filesystem agents can navigate. Consider it because it also covers SQL and databases and rules, skills and config.
  9. Cognee (Open source + cloud): Open-source memory platform that builds knowledge graphs so agents keep long-term memory. Consider it because it also covers codebase context and code search.
  10. Graphiti (Open source): Builds real-time, temporal knowledge graphs that serve as memory for AI agents. Consider it because it also covers codebase context and code search.
