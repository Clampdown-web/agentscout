OpenViking alternatives (2026)

OpenViking is a memory & RAG tool: Context database for AI agents that keeps memory, knowledge and skills in one inspectable virtual filesystem agents can navigate. Pricing, as the maker states it: Open source. Its GitHub repo has 40,217 stars. We found 37 tools in the directory that do overlapping work (memory for agents); 33 of them are open source and 0 list a free or freemium plan. Below are the 10 closest, ranked by how many tasks and sub-tasks they share with OpenViking, then by GitHub stars.

  1. Chroma (Open source + cloud): Open-source search and vector database widely used for agent memory and RAG. Consider it because it also covers RAG and documents.
  2. memU (Open source): Lightweight memory system that gives Codex, Claude Code, Cursor and other agents a shared memory across sessions and devices and distills reusable skills. Consider it because it does the same job with a different approach (open source).
  3. LanceDB (Open source + cloud): Open-source multimodal vector database for search, RAG and agent memory. Consider it because it also covers RAG and documents.
  4. Acontext (Open source): Memory layer that stores agent experience as reusable skills. Consider it because it does the same job with a different approach (open source).
  5. Claude-Mem (Open source): Gives coding agents memory across sessions by capturing what they do, compressing it and feeding the relevant context back in later. Consider it because it has more GitHub stars (101,230 vs 40,217).
  6. Mem0 (Open source + cloud): Memory layer for AI agents. Consider it because it has more GitHub stars (67,147 vs 40,217).
  7. MemPalace (Open source): Local-first AI memory system that stores conversations verbatim with a pluggable backend and serves recall to agents without API calls. Consider it because it also covers voice and phone agents and local and self-hosted; it has more GitHub stars (59,622 vs 40,217).
  8. Hindsight (Open source + cloud): Agent memory system that stores experiences and learns from them so agents improve over time. Consider it because it has more GitHub stars (50,483 vs 40,217).
  9. Cognee (Open source + cloud): Open-source memory platform that builds knowledge graphs so agents keep long-term memory. Consider it because it also covers codebase context and code search.
  10. Graphiti (Open source): Builds real-time, temporal knowledge graphs that serve as memory for AI agents. Consider it because it also covers codebase context and code search.
