Our recommendation

Choose LangGraph if you want to model your agent as a stateful graph with explicit steps and control flow.

Choose AutoGen if your design is built around several agents talking to each other in multi-agent conversations.

FAQ

What is the difference between LangGraph and AutoGen?

LangGraph: Framework for stateful, graph-based agent workflows. AutoGen: Microsoft's framework for multi-agent conversations, now archived and no longer maintained; Microsoft points new users to Microsoft Agent Framework.

Is LangGraph or AutoGen open source?

LangGraph: Yes. AutoGen: Yes. Pricing as each maker states it: LangGraph, Open source; AutoGen, Open source.

Should I choose LangGraph or AutoGen?

Choose LangGraph if you want to model your agent as a stateful graph with explicit steps and control flow. Choose AutoGen if your design is built around several agents talking to each other in multi-agent conversations.
