Vercel

by VercelCursor

The Vercel plugin helps you build and deploy web apps and agents on Vercel from inside Cursor. It bundles 3 specialist subagents, 33 skills, hooks, deploy and env commands, and Vercel's MCP server.

Add on cursor.com ↗

Subagents (3), skills (33), commands (5), MCP (1)

  • Subagents: ai-architect, deployment-expert and performance-optimizer.
  • Skills include ai-sdk, ai-gateway, auth, bootstrap and access-protected-vercel-deployment. 28 more: see the original listing.
  • Commands: deploy (preview by default, or prod), env, status, bootstrap and conventions.
  • Hooks: SessionStart, PostToolUse and SessionEnd.
  • MCP: the vercel MCP server.
  • Add it from the Cursor marketplace (you need to be signed in to Cursor) or run /add-plugin vercel in Cursor.
  • You need a Vercel account.
  • The deploy command can push to production when you pass “prod”.
  • Connects to Vercel's official MCP server with OAuth; its config note says it's read-only in the first release (search docs, list projects and deployments, inspect logs). (from the source code, not the listing)
  • Listed on the Cursor marketplace by Vercel.
  • Repository: vercel/vercel-plugin on GitHub.
  • License: Apache-2.0 (the repository's LICENSE file).
