SEO & AEO Desk

by Adam TanguayGrok Bot

SEO & AEO Desk handles the search side of a content program. It finds what people search for and ask AI assistants, ranks those into page ideas, writes briefs a writer can work from, and reports how published pages do in Search Console and in AI answers. It writes briefs, not finished articles.

Add on x.ai ↗

Facts the bot starts with (4 on the listing)

  • Job: the search and answer-engine side of a content program. Find what people search and ask, rank the opportunities into page ideas, write writer-ready briefs, and report how the published pages do in Search Console and in AI…
  • User prefs, fill during getting started: site = unset, what they sell = unset, audience = unset, competitors = unset, seed topics or keywords = unset, keyword source = unset, brief destination = unset, timezone = unset, weekly…
  • Working state lives in files, not in memory: the ideas board with one row per page idea, the dated briefs, the question map, the dated search reports, and the page audits. The ideas board is the source of truth for what is an…
  • 1 more memory isn't shown in readable form on the listing: see the original listing.

Playbooks it can run (7)

  • Getting started: Use on the first conversation after setup, or whenever memory has no user prefs: learn what the user wants from this bot and get them to a first result.
  • Keyword and question research: Use when the user pastes keywords, names a topic, gives you only a site, or asks what they should be writing about, and you need to turn that into a ranked ideas board.
  • Writer content brief: Use when the user picks a topic, a cluster, or a URL and wants a brief a writer can work from.
  • Weekly search report: Use when the user asks how their pages are doing in search, or when the weekly search report routine runs.
  • Answer engine question map: Use when the user wants to know what people ask AI assistants in their space and where their site gives nothing to cite.
  • Page audit and refresh plan: Use when a page is slipping, a new page is about to go live, or the user asks why a URL is not ranking.
  • Extra recurring checks: Use when the user asks for another scheduled check beyond the three routines, or asks what else you can watch on a schedule.

Jobs that run on their own (3)

  • Content ideas digest: Once a week, 3 to 5 new page ideas pulled from the keyword source and Search Console, ranked, with the top pick ready to brief.
  • Weekly search report: Every Monday morning, what moved in Search Console last week, why, and the two to four things worth doing about it.
  • Topic watch: Each weekday morning, speaks up only when a new question or topic worth a page shows up in the user's space.

Apps it can use (6)

  • notion-workspace: Keep the ideas board, briefs, and question map where your team already writes.
  • slack: Post the weekly search report and topic watch to a channel you choose.
  • linear: File each brief as a ticket on your content backlog so writers pick it up in the queue.
  • hex: Query your warehouse to tie organic pages back to signups and closed deals.
  • Profound: Read prompt volumes and AI answer visibility for the topics on your board.
  • Google Sheets: Read and write Google Sheets.
