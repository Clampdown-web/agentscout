Free AI agent tools

Free tools built by AgentScout, plus 1867 free and open-source AI agent tools from our directory, grouped by category.

What this is

This page has two different kinds of free. The first is AgentScout's own set of 18 calculators and generators. They run in your browser: no account, no API key, and nothing from the form is stored on our server. The second is the directory slice below: 1867 listings in 40 categories whose maker-stated pricing says open source, open weights, open standard, free, a free tier, or freemium.

The directory half is not a promise that the product costs zero to run. The line on the card is the maker's wording. The mix of those listings is 1147 open source, 8 source-available, 647 free or freemium, 60 paid, usage-based or enterprise, 5 pricing on the maker's site.

Who it is for

Use the browser tools when you want a config file, a token estimate, a prompt, or a stack sketch and you do not want to sign up. Use the directory half when you want a real agent product or library that the maker says you can start without a paid plan.

Pros and cons

Pros

  • The 18 AgentScout tools are on this site, so you can see exactly what they compute. The MCP config builder, cost estimator, and rules-file generator are typical starting points.
  • The directory half names REA, OpenClaw, ECC, DeepSeek Harness among the most-starred matches, so you can see popular open projects without leaving the page.
  • Discontinued and archived listings are left out of this hub, which keeps dead projects from looking like current free options.

Cons

  • Open source still needs a machine, and often a model API key. Freemium still has a paid tier. The card says which of those the maker claimed.
  • 4 of these listings have an empty or See site price label even though another field matched the free filter. Read the card before you assume a number.
  • A browser calculator estimates. It is not an invoice from OpenAI, Anthropic, Google, or xAI, and the model prices inside it can change.

How to use it

  1. If you need a file or a number, stay in the AgentScout tools grid. Open one tool, fill the form, and copy the result. Refreshing the page clears it.
  2. If you need a product, jump to a category section below. The count next to the heading is how many free-matching listings are in that category.
  3. Open the listing, then the official site. Confirm the free tier still exists. Stars on the row are from the listing, not a quality score.
  4. For a client-specific MCP config, the MCP config builder writes Claude Desktop, Cursor, and VS Code JSON. You still paste it into the client yourself.

FAQ

Are the tools at the top the same as the long list?

No. The top grid is software on this website (18 calculators and generators). The long list is other people's tools whose listings say free or open source (1867 across 40 categories).

Does open source mean I will not pay anything?

It means the maker says the code is open source, sometimes alongside a paid cloud. You can still pay for a model API, a GPU, or their hosted plan. The pricing phrase on the row is the one to read.

What should I open first?

For a config, the MCP config builder. For a bill, the AI API cost calculator or the agent run cost estimator. For a product, pick the category that matches the job and open two listings before you install.
