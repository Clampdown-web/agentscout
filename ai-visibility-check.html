What the check covers

The score is 100 points, split across the questions a buyer or maker would actually type:

  • Category discovery (30): three category prompts, 10 points each if recommended, 6 if cited, 3 if mentioned, 0 if absent.
  • Problem and how-to queries (28): four problem prompts, 7 points each if recommended, 4 if cited, 2 if mentioned, 0 if absent.
  • Comparison queries (16): two comparison prompts, 8 points each if recommended, 5 if cited, 2 if mentioned, 0 if absent.
  • Brand search (10): 10 if official pages lead or are recommended, 6 if the official site is cited but a third party leads, 3 if only mentioned, 0 if the official site is absent.
  • Third-party citations (16): 4 points for each distinct third-party page that was a source of a non-brand answer and that names the subject, up to four pages. The subject’s own pages do not count.

Each prompt is scored on one rung: recommended, cited, mentioned, or absent. The same rung is recorded for the rivals named in the check. Pages the answers cite are opened, and the report says which of those pages already name the site.
