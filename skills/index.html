    Agent Skills with install commands

    Agent skills are folders of instructions and scripts (a SKILL.md plus files) that coding agents load when a task needs them. Here are 9 skills from the AgentScout directory, each with the install command copied from its official README on Oct 22, 2026. Anthropic's own example skills install in Claude Code with /plugin marketplace add anthropics/skills (README).

    skills.sh

    Vercel Labs' open-source CLI (npx skills) and directory for finding, installing and sharing agent skills across Claude Code, Codex, Cursor, OpenCode and 75+ other coding agents.

    Install with: Any agent via the skills CLI (Claude Code, Codex, Cursor, OpenCode and more)

    npx skills add vercel-labs/agent-skills

    Command from the official README.

    Playwright Skill

    Playwright automation skill for coding agents.

    Install with: skills CLI, installed globally

    npx skills add lackeyjb/playwright-skill --skill playwright-skill --global --yes

    Command from the official README.

    Agents CLI

    Google's CLI and skills that teach coding assistants to build, evaluate and deploy agents on Google Cloud and the Gemini platform.

    Install with: skills CLI

    npx skills add google/agents-cli

    Command from the official README.

    HyperFrames

    HeyGen's open-source framework that renders HTML, CSS and animations into deterministic MP4 videos, usable from a CLI or by coding agents through skills.

    Install with: skills CLI

    npx skills add heygen-com/hyperframes

    Command from the official README.

    Binance Agent OS

    Binance developer platform connecting AI agents to trading, market data, Agentic Wallet, x402 payments and on-chain services via MCP, APIs and skills.

    Install with: skills CLI

    npx skills add https://github.com/binance/binance-skills-hub

    Command from the official README.

    Ultralytics Agents

    Visual canvas in Ultralytics Platform that chains YOLO models, vision-language models, conditions and actions like Slack alerts, plus official agent skills that let coding agents train, tune and export YOLO models.

    Install with: Claude Code (terminal)

    claude plugin marketplace add ultralytics/skills
    claude plugin install yolo@ultralytics

    Command from the official README.

    NVIDIA TAO Agent Skills

    NVIDIA's vision-model post-training toolkit, now packaged as agent skills so Claude Code or Codex can fine-tune, optimize and export vision foundation models from plain-English prompts.

    Install with: Claude Code (inside a session)

    /plugin marketplace add NVIDIA-TAO/tao-skill-bank@7.3.0
    /plugin install tao-skills@tao-skill-bank

    Command from the official README.

    onetake

    onetake is an agent skill for Claude Code and similar agents that makes product launch films, teasers and feature demos as one continuous camera move, where each beat grows out of the previous one instead of cutting between slides. The agent writes the motion as code and renders it with ffmpeg, and the skill checks continuity at every transition. The free edition on GitHub is for noncommercial use; onetake Pro adds a camera operator that follows each beat, source files for every example film, starter templates and a commercial licence.

    Install with: Claude Code (copy into your skills folder)

    git clone https://github.com/feitangyuan/onetake.git ~/.claude/skills/onetake

    Command from the official README.

    Antalpha Wallet Guard

    Open-source agent skill that scans EVM wallets for dangerous approvals, malicious addresses, risky tokens and NFTs, rug pulls and phishing sites, powered by GoPlus data.

    Install with: ClawHub

    clawhub install antalpha-wallet-guard

    Command from the official README.
