Best tools for building voice agents (2026)

Platforms for agents that talk: phone lines, voice assistants and real-time speech in and out. We list 104 tools for building voice agents below, each with a link-checked page, pricing as the maker states it and alternatives.

104 tools: 40 open source, 4 source-available, 19 free or freemium, 37 paid, usage-based or enterprise, 4 pricing on the maker's site.

Gufo

Newmodels & local runtimesOpen source

Gufo is an open-source inference engine built for AMD Strix Halo machines that runs text, vision and speech models locally, with tuned kernels and published benchmarks for each supported model. It serves models through an API so local agents can use them, and image and video generation support is in progress.

Added Oct 25, 2026

Whirl

Newpersonal agentsOpen source

Whirl is an open-source AI chat app that lets you talk to every major model in one place, remembers what matters about you across conversations, and builds living documents and visualizations as you go. You can bring your own tools, so the assistant can do more than answer, and pick up any thread exactly where you left it.

Newsales & marketingPaid

The Blaze MCP server connects Blaze, the AI marketing platform for small businesses, to Claude and Codex. From a chat you can plan, create and schedule social posts, carousels, videos, blogs and newsletters in your brand's voice, then keep them on your Blaze content calendar.

Added Oct 25, 2026

Wenbu

NewMCP serversFree

Wenbu is a hosted Streamable HTTP MCP server (wenbu 1.5.0 at wenbu.app/mcp, listed in the official MCP Registry as app.wenbu/mcp) and web app for traditional Chinese cultural systems and reflection. Connect Claude, Cursor or any MCP client with no API key required to call seven tools—calculate_bazi, cast_iching, draw_tarot, calculate_ziwei, search_library, read_library and get_daily_card—or run the MIT-licensed server locally.

Added Oct 25, 2026

NewvoiceOpen source

TapQ is an always-on voice layer for the coding and work agents you already run. You talk to Claude Code, Codex and others through your earbuds, interrupt them, steer the work and hear spoken updates, so you can supervise agents hands-free while away from the keyboard.

Added Oct 23, 2026

Financial Cents MCP

NewMCP serversPaid

The Financial Cents MCP server connects an accounting, bookkeeping or tax firm's Financial Cents practice-management account to Claude, ChatGPT, Gemini, Cursor and other MCP clients. Staff can ask about overdue work, unpaid invoices or missing client tax documents in plain English and have the assistant log time or create tasks, with each connection bound to one firm, your own permissions applied, writes confirmed in the client and deletes not offered at all. It is a hosted server signed in with OAuth and comes with the Scale plan.

Added Oct 23, 2026

Tulimoa Memory

Newmemory & RAGUsage-based

Tulimoa Memory is a hosted, shared memory store for AI agents and agent swarms. Agents write what they learn into it during the day; overnight a separate model sorts those notes into a knowledge graph with associative recall, and each agent starts the morning with a short briefing so it reads less and knows more. It is billed per call, with starting credit to try it.

Added Oct 23, 2026

Voxtral 3

NewvoiceUsage-based

Voxtral 3 is Mistral AI's voice agent stack: speech-to-text in 50+ languages with speaker labels and end-of-turn detection, expressive text-to-speech in 35+ languages, and a voice agent SDK built on LiveKit that handles listening, tool calls and speaking in one stream over SIP or WebRTC. You can use it through Mistral's API with EU, US or global endpoints, or deploy it yourself, and it is priced per minute of audio or per character.

Added Oct 22, 2026

Newagent infraOpen source + cloud

Its flows include AI agent steps that call an LLM with your scripts as tools, support nested agents and MCP, and run on a fast self-hostable workflow engine. It positions itself as an open-source alternative to Retool and Temporal.

Added Oct 22, 2026

Cayu

NewframeworksOpen source

Cayu is an open-source Python framework for building and running domain-specific, long-horizon agents on a durable runtime. Sessions survive restarts and redeploys from SQLite or Postgres stores, tool policies can require human approval before side effects, spend caps are checked before each model call, and timers, background tasks, subagents and forks cover longer multi-agent work. It is Apache 2.0 licensed.

Mercury 3

Newmodels & local runtimesUsage-based

Mercury 3 is Inception's diffusion language model, which writes many tokens in parallel rather than one at a time, reaching over 1,000 tokens per second on NVIDIA GPUs with a 1M-token context, tool calling and structured outputs. It has an OpenAI-compatible API and is also offered on OpenRouter, Baseten and Vercel, which makes it a fit for voice bots, support agents and browser agents where response speed matters. Pricing is per million input and output tokens.

The Fish Speech models behind it are published on GitHub and Hugging Face.
