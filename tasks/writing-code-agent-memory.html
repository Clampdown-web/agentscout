Memory tools for coding agents

Memory layers that let agents remember users, past sessions and facts over time. Of the 916 tools on our writing code page, 47 fit this narrower job. By pricing: 35 open source, 1 source-available, 2 free or freemium, 1 paid, usage-based or enterprise, 8 pricing on the maker's site. The most-starred open repos here are ECC (293,059 stars), Graphify (139,123 stars), Claude-Mem (105,394 stars). Most come from the coding (14), MCP servers (12), memory & RAG (10) categories.

Graphify

codingOpen source

Graphify is an Apache-2.0 /graphify skill for Claude Code, Cursor, Codex and Gemini CLI that maps a whole project, including code, docs, SQL schemas, configs and PDFs, into a knowledge graph the agent can query instead of grepping through files. Code is parsed locally with tree-sitter, so the map is deterministic, needs no LLM or vector store, and nothing leaves your machine, and every edge in the graph says why it exists. A separate paid Graphify Cloud adds always-on team memory with a 14-day trial.

Added Oct 16, 2026

Claude-Mem

memory & RAGOpen source

Claude-Mem is an Apache-2.0 memory plugin for coding agents that records what the agent does during a session, compresses those observations with AI, and feeds the relevant context back into later sessions, so the agent does not start from zero each time. It works with Claude Code, Codex, Gemini CLI, Copilot, OpenCode, OpenClaw, Hermes and others, stores memory locally, and includes search tools for looking back through past work.

Added Oct 16, 2026

Deer Flow

researchOpen source

DeerFlow 2.0 is ByteDance's MIT-licensed super-agent harness for long tasks that can take minutes to hours, such as research reports, coding jobs and content creation. It coordinates sub-agents, long-term memory, sandboxed code execution, tools and extensible skills, and can take requests through a message gateway; version 2.0 is a ground-up rewrite, with the original Deep Research framework kept on a separate branch.
