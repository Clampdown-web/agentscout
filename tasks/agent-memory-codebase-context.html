Codebase context and code search tools for agent memory

Context layers and code search that help agents understand large codebases with fewer tokens. Of the 272 tools on our memory for agents page, 12 fit this narrower job. By pricing: 8 open source, 1 source-available, 1 free or freemium, 1 paid, usage-based or enterprise, 1 pricing on the maker's site. The most-starred open repos here are Graphify (139,123 stars), Codebase Memory MCP (47,830 stars), Cognee (32,918 stars). Most come from the memory & RAG (6), coding (3), MCP servers (3) categories.

Updated November 11, 2026

Graphify

codingOpen source

Graphify is an Apache-2.0 /graphify skill for Claude Code, Cursor, Codex and Gemini CLI that maps a whole project, including code, docs, SQL schemas, configs and PDFs, into a knowledge graph the agent can query instead of grepping through files. Code is parsed locally with tree-sitter, so the map is deterministic, needs no LLM or vector store, and nothing leaves your machine, and every edge in the graph says why it exists. A separate paid Graphify Cloud adds always-on team memory with a 14-day trial.

Tulimoa Memory

memory & RAGUsage-based

Tulimoa Memory is a hosted, shared memory store for AI agents and agent swarms. Agents write what they learn into it during the day; overnight a separate model sorts those notes into a knowledge graph with associative recall, and each agent starts the morning with a short briefing so it reads less and knows more. It is billed per call, with starting credit to try it.
