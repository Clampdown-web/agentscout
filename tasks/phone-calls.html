Best AI agents for handling phone calls (2026)

Voice agents that answer and place phone calls, book appointments and route callers. We list 33 tools for handling phone calls below, each with a link-checked page, pricing as the maker states it and alternatives.

33 tools: 8 open source, 1 source-available, 8 free or freemium, 16 paid, usage-based or enterprise.

Newpersonal agentsFreemium

My Green Robot is a consumer AI phone and email agent for Rhode Island homeowners that finds Google-rated local lawn care and landscaping companies, calls and emails up to three shops per request to ask your questions and book free on-site estimates, and brings back written quotes to compare side by side without phone tag.

DIRI AI

Newsales & marketingFreemium

DIRI AI is a voice role-play trainer for salespeople. You pick a situation, such as a price objection, an intro meeting, a cold call or a client who wants to leave, set the difficulty, and talk out loud with an AI customer that reacts to what you actually say rather than a fixed script. After each call you get an instant report with a transcript, the key moments highlighted and specific stronger wording to try next time, plus a history of your practice. Managers can use it to help new hires ramp up before real calls.

Newmemory & RAGOpen source

MemoraX Code is a shared memory layer for coding agents such as Codex, Claude Code, OpenCode, Cursor, Trae and DeepSeek Harness. It recalls prior engineering knowledge, captures lessons from finished work, keeps repository knowledge and architecture history up to date, and carries your procedures and preferences into new sessions, bringing back only the memory relevant to the task at hand. It needs Node.js 20 or later and is MIT licensed.

Reticle

NewcodingSource-available + cloud

Verification layer for AI coding agents: a dev-only SDK inside your web or desktop app lets the agent drive real flows and read network calls, app state and console, then returns a pass, fail or cannot-tell verdict with the file and line to fix; saved flows replay without an AI model and can gate CI.

Added Oct 21, 2026

Tov

NewcodingOpen source

Tov is an experimental programming language designed to be written by coding agents. It uses TypeScript syntax minus a few traps (no any, null or loose equality, separate int and float types, and failing calls marked with try), so agents already know how to write it, and its compiler returns machine-readable fixes the agent can apply after every edit. Programs compile to small, fast native binaries, with published benchmarks against Rust, Bun and Node. Agents can learn it from the site's llms.txt.

TypeSafe Jev

Newagent infraUsage-based

Jev is TypeSafe's System One decision model, built for the small decisions inside software and agents. You send a state and typed questions (choice, score and more) and get typed answers with probabilities back instead of free-form text, so code can branch on them directly to route, classify, score or rank options. Agents can use it to settle narrow calls cheaply and save the larger LLM for open-ended work. Available through TypeSafe's API, Python and JavaScript SDKs, an agent skill, and OpenRouter.

Wren x402 Doctor

NewcryptoFreemium

Wren x402 Doctor helps sellers of x402 pay-per-call endpoints, the payment standard AI agents use to pay for APIs in USDC, get listed in the Coinbase CDP Bazaar and stay listed. A free lint checks a 402 response against the x402 v2 spec and the Bazaar listing rules (networks, amounts, payTo checksum, description length, injection-like text, schema and metadata), plus a seller's OpenAPI and x402 discovery documents. Paid endpoints include a Bazaar health check ($0.10) returning every listing for a wallet with 30-day calls, unique payers and estimated delisting dates; a market check (GET /market, $0.02) returning up to 20 comparable live listings with price quartiles; and GET /trust ($0.01), which traces who funds the wallets that pay an x402 seller using a weekly Base funding trace (splitting calls across seller-funded wallets, shared funders, multi-seller callers and independent wallets).
