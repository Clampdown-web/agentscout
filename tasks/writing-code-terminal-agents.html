Terminal and CLI agents for coding agents

Agents that run in your terminal: they read files, run commands and propose changes. Of the 916 tools on our writing code page, 152 fit this narrower job. By pricing: 129 open source, 3 source-available, 12 free or freemium, 5 paid, usage-based or enterprise, 3 pricing on the maker's site. The most-starred open repos here are REA (410,375 stars), opencode (223,180 stars), Ollama (185,335 stars). Most come from the coding (98), MCP servers (11), agent infra (8) categories.
