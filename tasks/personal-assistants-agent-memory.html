Memory tools for personal AI assistants

Memory layers that let agents remember users, past sessions and facts over time. Of the 125 tools on our personal assistance page, 26 fit this narrower job. By pricing: 16 open source, 1 source-available, 5 free or freemium, 1 paid, usage-based or enterprise, 3 pricing on the maker's site. The most-starred open repos here are OpenClaw (393,429 stars), Graphify (139,123 stars), Nanobot (49,674 stars). Most come from the personal agents (23), coding (1), business agents (1) categories.

Updated November 11, 2026

OpenClaw

personal agentsOpen source

OpenClaw is an MIT-licensed personal AI assistant that runs on your own computer and answers in the chat apps you already use, including Discord, iMessage, Slack, Teams, Telegram and WhatsApp, with native apps for macOS, iOS, Android, Windows and Linux. State, memory and credentials stay on your hardware, models and harnesses such as Claude, Codex or local models are swappable plugins, and one gateway can run a personal or shared multiplayer assistant. It is stewarded by the non-profit OpenClaw Foundation with no paid tier or hosted service.

Added Oct 14, 2026

Graphify

codingOpen source

Graphify is an Apache-2.0 /graphify skill for Claude Code, Cursor, Codex and Gemini CLI that maps a whole project, including code, docs, SQL schemas, configs and PDFs, into a knowledge graph the agent can query instead of grepping through files. Code is parsed locally with tree-sitter, so the map is deterministic, needs no LLM or vector store, and nothing leaves your machine, and every edge in the graph says why it exists. A separate paid Graphify Cloud adds always-on team memory with a 14-day trial.

Teebots

personal agentsFree

Teebots is a free desktop app that keeps a small team of AI bots on your own computer. Each bot can use a different model through your own API key, with requests going straight to the provider, and keeps its own private memory alongside a shared group memory. Put several bots in one group chat and @mention one to hand it a task, or let them pass steps to each other. Bots can work with files in their own folder, run commands, use skills including MCP and browse in their own browser, but they stop and wait for your approval before submitting or paying for anything. Scheduled daily or weekly jobs keep running from the menu bar. Chats, memory, files and logins stay local. Available for Mac (Apple silicon) now, with Windows and Linux coming soon.
