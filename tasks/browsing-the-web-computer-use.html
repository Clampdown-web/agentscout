Computer and desktop control tools for web browsing agents

Agents that see the screen and use the mouse and keyboard, so they can work in desktop apps as well as the browser. Of the 118 tools on our browsing the web page, 30 fit this narrower job. By pricing: 20 open source, 7 free or freemium, 2 paid, usage-based or enterprise, 1 pricing on the maker's site. The most-starred open repos here are UI-TARS-desktop (39,397 stars), Cua (31,070 stars), Midscene.js (15,410 stars). Most come from the browser/computer use (24), personal agents (3), productivity (1) categories.

Cumora

productivityOpen source

Cumora is a team chat app where AI agents are members of the workspace rather than a chat box you prompt. Each agent gets a persona, its own private memory and files, a status, and a schedule on which it wakes up, reads the room and decides whether to message someone, post an idea or pull a small group together. Agents can message each other, and you can read those side conversations. People join by email or link, agents can be grouped into teams and given projects, and the same live workspace runs on desktop, in the browser and on a phone. It is free during an invite-only preview.

PhoneUse

Newbrowser/computer useUsage-based

PhoneUse gives AI agents phones of their own to operate. Agents get cloud Android phones that boot in seconds and scale to hundreds, or real retail iPhones and Androids in a San Francisco rack, tapped by a robot stylus, for apps that detect emulators, with real carrier numbers for SMS and 2FA codes. One MCP server with tools such as acquire, read screen, tap, type, swipe, open app and read SMS plugs into Claude, Cursor, Codex or Windsurf, and there is a Python SDK and REST API. On-demand cloud phones are billed per minute, with flat monthly prices for dedicated and real phones.

Teebots

Newpersonal agentsFree

Teebots is a free desktop app that keeps a small team of AI bots on your own computer. Each bot can use a different model through your own API key, with requests going straight to the provider, and keeps its own private memory alongside a shared group memory. Put several bots in one group chat and @mention one to hand it a task, or let them pass steps to each other. Bots can work with files in their own folder, run commands, use skills including MCP and browse in their own browser, but they stop and wait for your approval before submitting or paying for anything. Scheduled daily or weekly jobs keep running from the menu bar. Chats, memory, files and logins stay local. Available for Mac (Apple silicon) now, with Windows and Linux coming soon.
