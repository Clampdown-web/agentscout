Computer and desktop control tools for web browsing agents

Agents that see the screen and use the mouse and keyboard, so they can work in desktop apps as well as the browser. Of the 205 tools on our browsing the web page, 50 fit this narrower job. By pricing: 36 open source, 8 free or freemium, 2 paid, usage-based or enterprise, 4 pricing on the maker's site. Orca

codingOpen source

Orca is an MIT-licensed desktop app for running a fleet of coding agents such as Claude Code and Codex in parallel on your own subscriptions, each in its own git worktree, with diffs, a built-in browser and a CLI in one place. You can drive an agent in a chat view or its raw terminal and switch between them without losing context, hand a big task to one agent that splits it across worker agents, and keep agents running on a remote Orca server, any SSH host or a cloud VM after you close your laptop; there are mobile apps too.

Agent Desktop

browser/computer useOpen source

Vercel Labs' open-source computer-use layer that lets AI agents read and operate desktop apps on macOS, Windows and Linux through the OS accessibility tree instead of guessing from screenshots. A snapshot returns JSON with a stable ref for every clickable element; the agent acts on a ref and snapshots again to verify, which keeps actions safe to retry, saves tokens by scoping to one app region and lets several agents work in parallel. Rust CLI plus C library, installed with npm install -g agent-desktop. Apache-2.0.
