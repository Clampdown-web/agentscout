Sandboxes and secure execution tools for coding agents

Isolated sandboxes where agents can run code and tools away from your machine and data. Of the 916 tools on our writing code page, 46 fit this narrower job. By pricing: 37 open source, 1 source-available, 3 free or freemium, 1 paid, usage-based or enterprise, 4 pricing on the maker's site. The most-starred open repos here are Deer Flow (84,715 stars), Context Mode (32,905 stars), NVIDIA OpenShell (20,733 stars). Most come from the sandboxes & code execution (26), coding (11), MCP servers (3) categories.

Deer Flow

researchOpen source

DeerFlow 2.0 is ByteDance's MIT-licensed super-agent harness for long tasks that can take minutes to hours, such as research reports, coding jobs and content creation. It coordinates sub-agents, long-term memory, sandboxed code execution, tools and extensible skills, and can take requests through a message gateway; version 2.0 is a ground-up rewrite, with the original Deep Research framework kept on a separate branch.

Sandstorm (formerly forkd)

sandboxes & code executionOpen source
