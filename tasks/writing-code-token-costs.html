Token usage and cost tracking tools for coding agents

Trackers for token usage and spend across coding agents. Of the 916 tools on our writing code page, 18 fit this narrower job. By pricing: 14 open source, 1 source-available, 2 free or freemium, 1 paid, usage-based or enterprise. The most-starred open repos here are rtk (85,050 stars), CodexBar (23,105 stars), Codeburn (11,620 stars). Most come from the coding (12), agent infra (2), evals & observability (1) categories.

Updated November 11, 2026

rtk

codingOpen source + cloud

A CLI proxy that sits between coding agents and your shell and trims noisy command output before it reaches the model, cutting token use on everyday commands like tests, builds and git. Free and open source, with an RTK Pro tier for teams.

Added Oct 20, 2026

CodexBar

NewcodingOpen source

CodexBar is an MIT-licensed macOS menu bar app, with a Linux desktop version, that keeps the usage limits of AI coding providers such as Codex and Claude Code in view, showing session, weekly and monthly windows with countdowns to each reset, credit balances, spend and live provider incident badges, so you can tell whether there is room to start a long agent task; it reuses existing local sign-ins rather than asking for a new login.

Added Nov 10, 2026

Codeburn

evals & observabilityOpen source + cloud

Free, local tool to track AI coding token usage and cost across 37 tools and agents (Claude Code, Cursor, Codex, Gemini and more), by model, project, and task. npx codeburn

Added Oct 28, 2026

Trail Code

codingOpen source

Context layer that makes Claude Code, Cursor, Codex and other coding agents faster and cheaper on large codebases.

Added Oct 16, 2026

Mission Control

codingOpen source

Self-hosted control plane for dispatching tasks to agents, reviewing runs and tracking spend.

Added Oct 16, 2026

Tokscale

codingOpen source

Tracks token usage across AI coding agents from your terminal.

Added Oct 16, 2026

Weave Router

agent infraOpen source

An open-source LLM router for Claude Code, Codex and other coding agents that sends each request to the cheapest model that still meets your quality bar, cutting model spend.

Added Oct 20, 2026

Desktop CC GUI

NewcodingOpen source

Desktop CC GUI (ccgui) is an MIT-licensed desktop app for macOS, Windows and Linux that puts command-line coding agents, including Claude Code, Codex CLI, Kimi CLI, Grok CLI, OpenCode, Qoder and DeepSeek Harness, behind one graphical interface, with streaming output, visible thinking and tool calls, token usage and Git commits; it is built with Tauri, React and Rust and keeps settings locally.

Added Nov 11, 2026

vAPI Network

NewcryptoOpen source

vapi-network is an Apache-2.0, non-custodial TypeScript client from vAPI Network for finding and paying x402 APIs in USDC on Base from a terminal, an MCP client or your own code; keys stay encrypted on your device, a spend policy is checked before each payment is signed, payments go straight to the provider with no vAPI fee, and each call leaves a local receipt. It is not related to the voice company Vapi.ai.

Added Nov 10, 2026

abtop

codingOpen source

htop-style monitor for Claude Code and Codex sessions and token use.

Added Oct 16, 2026

Jevgrep

codingOpen source

CLI that finds relevant repo files and excerpts from natural-language questions for coding agents; claims ~40% cheaper agent runs.

Added Oct 14, 2026

jCodeMunch MCP

MCP serversSource-available + cloud

MCP server for symbol-level code exploration that cuts token use.

HiRoute

agent infraOpen source

HiRoute, from the Higress team, is an open-source local model router for long-running agents like Codex and Claude Code: it hands routine stages to cheaper models, saves your strongest model for hard steps and keeps a record of each decision.

Added Oct 20, 2026

Mixdog

NewcodingOpen source

Mixdog is an open-source agent project that helps builders handle desktop coding agent where a lead model plans and cheaper models handle.

Added Nov 10, 2026

CCC

codingFree

CCC (Claude Command Center) is a free, source-available local dashboard for macOS, Linux and Windows that puts every Claude Code, Codex, Cursor and five other coding-agent sessions on one visual board, highlights which session needs your input, tracks token usage and lets sessions continue on $0 models when rate limits hit.

Added Oct 24, 2026

AutoRouter

NewcodingFreemium

AutoRouter is a Mac app, in beta, that sits under Codex, Claude Code and other coding harnesses and routes each turn to a suitable model, sending routine file reads and renames to cheaper models so your Claude and ChatGPT subscriptions last longer. Routing across your own subscriptions is free; Pro at $50 a month adds every provider and $20 of monthly API credit.

Added Nov 11, 2026

Empyre

business agentsPaid

Empyre turns a plain-language business brief into a running software company: eight AI agents (CEO, CTO, CMO, CFO and more) build it, deploy it to its own HTTPS address and keep operating it, shipping code, marketing and support with spend approval; plans $49, $149 and $299 a month.

Added Oct 19, 2026

Token Tracker

NewcodingOpen source

Token Tracker is a free, open-source, local-first dashboard that monitors AI token usage and cost across Claude Code, Codex, Cursor, Gemini and 27 CLIs.
