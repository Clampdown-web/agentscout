    Best AI agents for images and design (2026)

    AI agents for visual work: design agents that build graphics and brand assets from a brief, image generators you can direct by chat, diagram makers, and MCP servers that let agents work in Figma, Canva and Penpot. We list 45 tools for images and design below, each with a link-checked page, pricing as the maker states it and alternatives.

    Updated October 21, 2026

    45 tools: 16 open source, 19 free or freemium, 9 paid, usage-based or enterprise, 1 pricing on the maker's site.

    This page lists AI agents and MCP servers that create or edit visuals for you. For every art, design, 3D and photo tool, see Image generation, Graphic design & branding, 3D & concept art and Photography & photo editing.

    PR Lens

    NewcodingOpen source

    PR Lens helps people review code that agents wrote. For each pull request it draws animated architecture and data-flow diagrams inside the PR, showing which parts of the app were added, changed or removed, what else depends on the change and how a request now moves through the system. It also flags likely bugs, security holes and design problems in the same review comment, with a ready prompt to hand each fix to your coding agent or an autofix. The open-source core runs locally and installs as an agent skill.

    Added Oct 21, 2026

    WaveSpeed MCP

    NewMCP serversUsage-based

    WaveSpeed MCP is WaveSpeedAI's official MCP server and CLI, which lets an AI agent run any model in WaveSpeed's live catalog of over a thousand image, video, audio and 3D generation models from one connection. Agents can pick a model, submit a generation job and get the result back without switching tools. It is available as a hosted remote server or a local install, and usage is billed per generation at WaveSpeed's API prices.

    Added Oct 21, 2026

    OpenKnowledge

    NewproductivityOpen source

    OpenKnowledge is a free, local-first markdown editor and knowledge base built for working alongside AI agents. It looks and feels like a Notion-style WYSIWYG editor, with callouts, tabs, Mermaid diagrams and media blocks, but every page stays a plain markdown file on your disk. Coding agents such as Claude Code, Codex, Cursor, Gemini CLI and dozens of others can read and write the same files through its integrations, so specs, team wikis and LLM wikis stay in one place that both people and agents keep up to date. It ships as a desktop app plus a web UI and CLI.

    Added Oct 21, 2026
