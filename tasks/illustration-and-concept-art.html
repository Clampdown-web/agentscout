img2threejs

New3D & concept artOpen source

img2threejs is an open-source agent workflow that looks at a reference image and rebuilds the object in it as a procedural Three.js model written purely in code. Each model goes through quality gates before it is accepted, comes out ready to animate, and is built in a token-efficient way, so a coding agent can turn photos or concept art into live 3D scenes without any mesh files.

Added Oct 24, 2026

Images Upscale

Newphotography & photo editingFreemium

Images Upscale is a browser-based AI image upscaler that uses cloud Real-ESRGAN models to enlarge JPG, PNG and WebP files 2x or 4x with modes tuned for photos, anime and illustrations, product shots and screenshots. It supports multi-image and ZIP batch uploads, watermark-free downloads, and companion tools for background removal, unblurring and alt-text generation.
