Crolytics

Newsales & marketingPaid

Crolytics is a managed, governed AI workspace for B2B marketing and go-to-market teams, hosted on Google Cloud. Its agents connect to your CMS, GA4, Search Console and knowledge base through custom MCP connectors, answer analytics questions in plain language, track how AI assistants cite your brand (GEO/AEO), and draft or update website pages behind human approval gates, with per-person permissions and a tamper-evident audit log. Teams use it from the Crolytics chat or inside their own Claude or ChatGPT account.

Financial Cents MCP

NewMCP serversPaid

The Financial Cents MCP server connects an accounting, bookkeeping or tax firm's Financial Cents practice-management account to Claude, ChatGPT, Gemini, Cursor and other MCP clients. Staff can ask about overdue work, unpaid invoices or missing client tax documents in plain English and have the assistant log time or create tasks, with each connection bound to one firm, your own permissions applied, writes confirmed in the client and deletes not offered at all. It is a hosted server signed in with OAuth and comes with the Scale plan.

OpenAPPA

Newsecurity & governanceOpen source

OpenAPPA is a deterministic guardrail that sits between an AI agent and its tools and tracks how data flows across tool calls, instead of asking a second model to judge each call. Policies decide whether untrusted or sensitive data may reach a given action, which blocks data exfiltration caused by prompt injection or hallucination while letting agents finish their tasks. It plugs into Claude Code, Pi, OpenCode, kAgent and Archestra, comes with reusable policy "batteries", validation, observability and reporting, and is backed by a NeurIPS workshop paper with published benchmarks. It is in preview as an open RFC.

Added Oct 21, 2026

HOL Guard

Newsecurity & governanceOpen source + cloud

HOL Guard is a free, open-source (Apache-2.0), local-first security layer for AI coding agents such as Claude Code, Codex, Cursor and GitHub Copilot CLI. On supported integrations it checks risky shell commands, reads of secret-bearing files, package installs and new or changed MCP tools before they run, lets you allow, ask or block each action, and keeps a local record for review. It installs with pipx (hol-guard) and works offline; optional Guard Cloud adds synced approvals, team policy and dashboards.
