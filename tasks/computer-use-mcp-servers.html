axuse

Newbrowser/computer useOpen source

axuse gives AI agents browser and computer use through a single MCP server that plugs into Claude Code, Codex, OpenCode and other MCP hosts. Instead of a screenshot loop it reads the DOM, the accessibility tree and Chrome DevTools, which makes actions faster and uses far fewer tokens, and it has zero dependencies, with desktop control on Windows, macOS (opt-in) and Linux.
