Memory tools for building AI agents

Memory layers that let agents remember users, past sessions and facts over time. Of the 652 tools on our building AI agents page, 43 fit this narrower job. By pricing: 35 open source, 1 free or freemium, 7 pricing on the maker's site. The most-starred open repos here are Hermes Agent (Nous Research) (258,708 stars), OpenClaw (393,429 stars), ECC (293,059 stars). Most come from the frameworks (24), memory & RAG (7), personal agents (4) categories.

Updated November 11, 2026

Hermes Agent (Nous Research)

frameworksOpen source

Hermes Agent is Nous Research's MIT-licensed, self-improving agent with a built-in learning loop: it writes skills from completed tasks, refines them in use, keeps agent-curated memory and searches its own past conversations. It runs on anything from a $5 VPS to serverless infrastructure, offers a full terminal UI, and one gateway serves Telegram, Discord, Slack, WhatsApp, Signal and the CLI, with any model via Nous Portal, OpenRouter, OpenAI or your own endpoint.

Added Oct 14, 2026

OpenClaw

personal agentsOpen source

OpenClaw is an MIT-licensed personal AI assistant that runs on your own computer and answers in the chat apps you already use, including Discord, iMessage, Slack, Teams, Telegram and WhatsApp, with native apps for macOS, iOS, Android, Windows and Linux. State, memory and credentials stay on your hardware, models and harnesses such as Claude, Codex or local models are swappable plugins, and one gateway can run a personal or shared multiplayer assistant. It is stewarded by the non-profit OpenClaw Foundation with no paid tier or hosted service.
