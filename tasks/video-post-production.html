FableCut

Newfilm & TV productionOpen source

FableCut is a Premiere-style video editor that runs entirely in the browser and exposes the whole timeline as one JSON document, covering media, clips, tracks, effects, keyframes and transitions. You can edit by hand or let an AI agent such as Claude Code or Claude Desktop cut the video over MCP or REST while the timeline updates live. It has no npm dependencies, starts with one node command and is MIT licensed.

Vidmoat is a hosted AI video editor you direct in chat. It runs on Windows, macOS, Linux, Android and iOS, and it can be scripted through a documented JSON-RPC and gRPC API, so scripts and AI agents can drive edits.
