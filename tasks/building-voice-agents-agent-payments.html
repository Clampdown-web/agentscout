Agent payment tools for voice agents

Payment rails that let agents pay for APIs and services on their own, including x402 and stablecoin payments. Of the 333 tools on our building voice agents page, 9 fit this narrower job. By pricing: 6 open source, 1 paid, usage-based or enterprise, 2 pricing on the maker's site. The most-starred open repos here are Bindu (10,022 stars), vAPI Network (3,876 stars), PayPal MCP (13 stars). Most come from the MCP servers (4), agent infra (1), crypto (1) categories.

Updated November 10, 2026

Bindu

agent infraOpen source

Identity, communication and payments layer that lets AI agents talk to and pay each other.

Added Oct 16, 2026

vAPI Network

NewcryptoOpen source

vapi-network is an Apache-2.0, non-custodial TypeScript client from vAPI Network for finding and paying x402 APIs in USDC on Base from a terminal, an MCP client or your own code; keys stay encrypted on your device, a spend policy is checked before each payment is signed, payments go straight to the provider with no vAPI fee, and each call leaves a local receipt. It is not related to the voice company Vapi.ai.

Added Nov 10, 2026

finance & accountingOpen source

PayPal's MCP server for invoices, orders, payments and other PayPal operations from agents.

Added Nov 10, 2026

HitPay MCP Server

NewMCP serversOpen source

HitPay MCP Server is an MCP server that gives agents a way to handle hitPay MCP: sales, payouts, balances; create payment links and invoices.

Daiku

browser/computer useSee site

Add-on that gives Claude, ChatGPT, Codex and other AI apps their own cloud Chrome logged in to your sites, working in many tabs at once while your laptop is shut, with every send or payment approved on your phone.

Added Oct 27, 2026

Final POS

NewMCP serversOpen source

Final POS is an MCP server agents call to build custom POS apps with any AI agent: checkout flows, kiosks, payment.

Added Nov 10, 2026

PayGuard (YourAITools)

Newsecurity & governanceUsage-based

PayGuard, from YourAITools, is an x402 pay-per-call API that lets an agent check a crypto wallet address against the US Treasury OFAC SDN sanctions list before it pays, returning matches, programs and the list date for $0.001 USDC a check (or $0.01 for 50) on Base, Polygon, Arbitrum or Solana, with no API key or signup; it is informational screening, not legal advice.
