AI RAG and document tools

Retrieval tools that let agents search documents, PDFs and knowledge bases and answer from them (RAG). Of the 281 tools on our working with documents page, 208 fit this narrower job. By pricing: 82 open source, 2 source-available, 26 free or freemium, 6 paid, usage-based or enterprise, 92 pricing on the maker's site. The most-starred open repos here are MarkItDown (192,990 stars), Graphify (139,123 stars), RAGFlow (93,182 stars). Most come from the MCP servers (115), memory & RAG (24), frameworks (13) categories.

Updated November 11, 2026

MarkItDown

memory & RAGOpen source

MarkItDown is Microsoft's MIT-licensed Python tool that converts PDFs, Word, PowerPoint and Excel files, images, audio, HTML, CSV, JSON, ZIP archives and more into clean Markdown that LLMs and agents can read, keeping headings, lists, tables and links. You can call it from the command line or Python, add optional plugins such as Azure Document Intelligence for harder documents, and expose it to Claude Desktop and other agents through the companion markitdown-mcp server.

Added Oct 18, 2026

Graphify

codingOpen source

Graphify is an Apache-2.0 /graphify skill for Claude Code, Cursor, Codex and Gemini CLI that maps a whole project, including code, docs, SQL schemas, configs and PDFs, into a knowledge graph the agent can query instead of grepping through files. Code is parsed locally with tree-sitter, so the map is deterministic, needs no LLM or vector store, and nothing leaves your machine, and every edge in the graph says why it exists. A separate paid Graphify Cloud adds always-on team memory with a 14-day trial.

It reached v1.0 on November 6, 2026, and can be deployed locally with Docker or used through RAGFlow Cloud.

FAQ

What are the best AI tools for working with documents focused on RAG and documents?

We list 208. The first three by GitHub stars and featured status are MarkItDown: MarkItDown is Microsoft's MIT-licensed Python tool that converts PDFs, Word, PowerPoint and Excel files, images, audio, HTML, CSV, JSON, ZIP archives and more into clean Markdown that LLMs and agents can read, keeping headings, lists, tables and links. You can call it from the command line or Python, add optional plugins such as Azure Document Intelligence for harder documents, and expose it to Claude Desktop and other agents through the companion markitdown-mcp server.; Graphify: Graphify is an Apache-2.0 /graphify skill for Claude Code, Cursor, Codex and Gemini CLI that maps a whole project, including code, docs, SQL schemas, configs and PDFs, into a knowledge graph the agent can query instead of grepping through files. Code is parsed locally with tree-sitter, so the map is deterministic, needs no LLM or vector store, and nothing leaves your machine, and every edge in the graph says why it exists. A separate paid Graphify Cloud adds always-on team memory with a 14-day trial.; RAGFlow: RAGFlow is an Apache-2.0 retrieval-augmented generation engine that combines deep document parsing with agent capabilities, a converged context engine and pre-built agent templates to build grounded question answering over complex files. It reached v1.0 on November 6, 2026, and can be deployed locally with Docker or used through RAGFlow Cloud.
