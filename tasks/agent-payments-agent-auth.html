Identity, auth and secrets tools for agent payments

Identity and credential tools that let agents sign in without seeing raw secrets. Of the 148 tools on our agent payments page, 14 fit this narrower job. By pricing: 4 open source, 6 free or freemium, 2 paid, usage-based or enterprise, 2 pricing on the maker's site. The most-starred open repos here are Bindu (10,022 stars), Sphere SDK (5,387 stars), MonoCode (3,489 stars). Most come from the crypto (3), security & governance (3), agent infra (2) categories.

Updated November 27, 2026

Bindu

agent infraOpen source

Identity, communication and payments layer that lets AI agents talk to and pay each other.

Added Oct 16, 2026

Sphere SDK

cryptoOpen source⚠ Moves funds

TypeScript SDK that gives autonomous agents an identity and wallet on the Unicity network to find, negotiate and settle payments with other agents.

Added Oct 18, 2026

MonoCode

codingOpen source

MonoCode is a desktop app that puts the coding agents you already pay for behind one interface. It drives Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity, Pi, Hermes Agent, Devin and others, using the subscriptions and logins already on your machine, so you never buy tokens through it. Each tab is an agent session and one composer sends work to whichever agent you pick, so several sessions can run side by side. It runs on macOS, Windows and Linux, with an iOS app in public beta.

Added Oct 21, 2026

browse

Newbrowser/computer useOpen source

browse is an MIT-licensed MCP server and Chromium extension that lets an agent use the browser you already have, including its tabs and logins. The README says agents can open background tabs, read pages, click, type, take screenshots and capture network traffic, then hand a tab back for a login or a payment. It lists Chrome, Edge, Brave, Arc and other Chromium browsers. GitHub anomalyco/browse recorded MIT, 1,087 stars and 82 forks on 25 Nov 2026. The repo has no separate homepage.

Added Nov 25, 2026

Garage402

Newsecurity & governancePaid

Garage402 is Script Master Labs' inspection page for x402 sellers an agent pays. The HTML page on 26 Nov 2026, not a JSON-only response, says a person can run a free check of up to 3 endpoints and see up to 3 red flags. Agents pay per call in USDC on Base: inspect is $0.05, recommend is $0.01, and route is $0.01. The page says each flag comes from a live probe or public Base data. This path is Garage402 only. The same host's root is Authority Engine, a different product whose publish date is 27 Nov 2026, and it is not listed here.

Added Nov 26, 2026

HIVE402

NewMCP serversFreemiumNot yet checked

HIVE402 is Script Master Labs' live directory of x402 endpoints that agents can pay. The homepage on 26 Nov 2026 showed 67,157 paid endpoints, 43,879 of them marked verified payable, 2,187 operators and 6 payment rails, and it said those figures are re-checked from settlement records. A GET to https://hive402.scriptmasterlabs.com/mcp returned HTTP 200 and named the server x402-agent-idea-forge, with tools such as search_catalog and get_listing. The page describes a free Rescue check that reads an endpoint's catalog state, and a 0.005 USDC OMNIGATE fee leg on some paid flows. This listing is only HIVE402. It is not SqueezeOS, Token Verdict, Verdict Protocol or Authority Engine.

Added Nov 26, 2026

HumanMirror Guard

security & governanceFreemium

HumanMirror Guard offers an opt-in, no-wallet agent-action preview, then buyer-authorized Safe Preflight checks for consequential tool calls via x402 on Base (0.010 USDC per call). Free public integration examples for Python, JavaScript and n8n, plus fixed-scope €299 workflow audits and €990 14-day pilots. Advisory checks do not prove settlement or downstream delivery.

Added Nov 4, 2026

KDPBook

NewproductivityFreemium

KDPBook plans, writes, illustrates and typesets a book for Amazon KDP upload. The site says it is not affiliated with Amazon. The pricing page on 27 Nov 2026 listed Free at $0 with 1,000 welcome credits and no card, Starter at $19 a month for 2,500 credits, Author at $39 for 5,500 and Studio at $79 for 12,000. Yearly billing was shown as 20% less. One-time packs were 1,200 credits for $12 and 3,000 for $29. The page's examples at default settings were about 1,013 credits for a 32-page illustrated picture book, 765 for a 50-design coloring book and 1,165 for a 50,000-word novel with a cover. It says a failed step is not charged and paid plans include commercial rights.

Added Nov 27, 2026

Levee

security & governanceFreemium

Levee is an authorization layer for agent payments that gates what autonomous agents can spend and where.

Added Nov 7, 2026

OrionCMD Checks

MCP serversSee siteNeeds auth

Pay-per-call TLS certificate, DNS/email-auth and domain-expiry checks for any domain (x402 USDC).

Proof x401

cryptoUsage-based

Open HTTP protocol and MCP server that let a website ask an AI agent to prove who it is acting for and have the person cryptographically sign the exact transaction terms, using Proof's agent identity wallet.

Self Agent Vault

agent infraFreemium

Payment and login layer for AI agents: agents check out and sign in using mock tokens, while real card numbers and passwords are swapped in out of the agent's view, with spending caps, merchant allowlists and a kill switch.

Gives AI agents verified identity and payment credentials so they can access and pay for services across the web.
