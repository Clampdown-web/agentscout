Best open-source AI agents (2026)

Open-source agents you can run yourself, inspect and extend, from coding agents to personal assistants. We list 55 tools for open-source agents below, each with a link-checked page, pricing as the maker states it and alternatives.

Updated October 25, 2026

55 tools: 54 open source, 1 source-available.

PiG

NewcodingOpen source

PiG is a faithful Go port of Pi, the open-source terminal coding agent, first developed at Hewlett Packard Enterprise. It keeps Pi's behaviour and extension model while shipping as a single fast Go binary, so you can run the same minimal, hackable coding agent without a Node.js runtime.

Added Oct 25, 2026

AutoCua

Newbrowser/computer useOpen source

AutoCua is an open-source computer use agent that drives real desktop apps with mouse and keyboard on Windows, macOS and Linux, and also works in Chrome, Firefox and other browsers, in a real terminal and on an iPhone, iPad or iOS Simulator. It is built as a multi-agent harness you install with pip, so one agent can carry a task across the desktop, the web, the shell and a phone.

Added Oct 25, 2026

Tura

Newagent infraOpen source

Tura is an open-source agent runtime focused on cutting LLM spending. It manages the context an agent sends to the model so tasks use far fewer tokens, while keeping the finished results, execution evidence and benchmark scores auditable, which makes it aimed at teams running agents at scale.

Added Oct 24, 2026

Jev

Newpersonal agentsOpen source

Jev is an open-source chat assistant for Android, Windows and macOS that reads the conversation on your screen, judges what the other person wants and whether a message looks risky, and drafts candidate replies for you. It fills in the reply box, but you always decide whether to send, so it helps with tricky messages without acting on its own.

Added Oct 23, 2026

Rome OS

NewframeworksOpen source

Rome is an open-source agent OS for recursive agents that compounds what they learn. Agents build their own tools, keep context and reuse capabilities across tasks instead of starting fresh each time, so a long-running assistant grows more capable the more it works.

Added Oct 23, 2026

mu

NewcodingOpen source

mu is an open-source coding agent with a judgment kernel: a small, fast judge model makes the many routine decisions in each turn so the main model only gets the context it needs. It ships as a command-line tool and a desktop app and aims to keep coding sessions focused and cheap.

Added Oct 23, 2026
