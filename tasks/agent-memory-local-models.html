    Local and self-hosted tools for agent memory

    Agents and assistants that can run on your own machine or server, keeping data local. Of the 113 tools on our memory for agents page, 24 fit this narrower job. By pricing: 21 open source, 1 source-available, 2 free or freemium. The most-starred open repos here are Headroom (75,629 stars), MemPalace (59,622 stars), Nanobot (49,096 stars). Most come from the memory & RAG (11), personal agents (9), agent infra (1) categories.

    Inngest

    Newagent infraFreemium

    Inngest is a durable workflow orchestration platform for running stateful step functions and AI workflows on serverless, servers or the edge. You write functions in TypeScript, Python or Go with automatic retries, queues, throttling and human-in-the-loop waits, and its AgentKit and AI inference steps let you build durable, long-running AI agents with tracing and evals. The server is source-available (SSPL, converting to Apache 2.0 later) and can be self-hosted, or you can use Inngest Cloud.

    Added Oct 22, 2026

    OpenKnowledge

    NewproductivityOpen source

    OpenKnowledge is a free, local-first markdown editor and knowledge base built for working alongside AI agents. It looks and feels like a Notion-style WYSIWYG editor, with callouts, tabs, Mermaid diagrams and media blocks, but every page stays a plain markdown file on your disk. Coding agents such as Claude Code, Codex, Cursor, Gemini CLI and dozens of others can read and write the same files through its integrations, so specs, team wikis and LLM wikis stay in one place that both people and agents keep up to date. It ships as a desktop app plus a web UI and CLI.

    Added Oct 21, 2026

    Teebots

    Newpersonal agentsFree

    Teebots is a free desktop app that keeps a small team of AI bots on your own computer. Each bot can use a different model through your own API key, with requests going straight to the provider, and keeps its own private memory alongside a shared group memory. Put several bots in one group chat and @mention one to hand it a task, or let them pass steps to each other. Bots can work with files in their own folder, run commands, use skills including MCP and browse in their own browser, but they stop and wait for your approval before submitting or paying for anything. Scheduled daily or weekly jobs keep running from the menu bar. Chats, memory, files and logins stay local. Available for Mac (Apple silicon) now, with Windows and Linux coming soon.
