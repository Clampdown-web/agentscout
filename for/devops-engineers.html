On-call engineers and platform people who want an agent in the incident path, a sandbox around generated code, or a deploy target for an agent they already built. Security engineers have a separate role page if the work is pentests and guardrails rather than uptime.

Pros

Cons

  • Six tools per job is a cap. The full task page has the rest. 416 matches collapsed to 28 shown names.

How to use it

  1. Start with the job you have this week: an incident, a deploy, a sandbox, or a security check. Open that section.
