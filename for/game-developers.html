Concept art

Tools for illustrators and concept artists: style-controlled generation, sketch-to-render, painting assistants and private style models. All 22 tools →

  • Invoke Open source
    Open-source layered canvas for Stable Diffusion and FLUX, with inpainting, control layers and node workflows. · ★ 28,921
  • img2threejs Open source
    img2threejs is an open-source agent workflow that looks at a reference image and rebuilds the object in it as a procedural Three.js model written purely in code. Each model goes through quality gates before it is accepted, comes out ready to animate, and is built in a token-efficient way, so a coding agent can turn photos or concept art into live 3D scenes without any mesh files. · ★ 19,844
  • Krita AI Diffusion Open source
    Generative fill, inpainting and live painting inside the free Krita app, built so the artist stays in control. · ★ 10,807
  • HunyuanWorld Open source
    Tencent's open model that turns text or an image into an explorable 3D world. · ★ 2,958
  • Artbreeder Freemium
    Collage-to-image and remixing tool for characters, portraits and concept art.
  • Dzine Freemium
    Layer-based AI illustration and design editor with style control, inpainting and image-to-video.

Voice

Platforms for agents that talk: phone lines, voice assistants and real-time speech in and out. All 321 tools →

  • Fish Audio Freemium
    Fish Audio is a voice AI platform for text to speech, voice cloning and speech to text, with a real-time API for voice agents. Its Drama 3 and S2 models take inline emotion and delivery tags such as whispering, laughing or pauses, it can clone a voice from a few seconds of audio, and its library has more than two million community voices for narration, characters, audiobooks and support agents. The Fish Speech models behind it are published on GitHub and Hugging Face. · ★ 33,488
  • XiaoZhi ESP32 Open source
    Open-source voice chatbot firmware for ESP32 devices that talks through LLMs like Qwen and DeepSeek and controls hardware and services via MCP. · ★ 32,282
  • FunASR Open source
