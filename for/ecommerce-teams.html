Agent payments and checkout

Tools that let agents pay, get paid and handle checkout without a human clicking buy. All 39 tools →

  • Bindu Open source
    Identity, communication and payments layer that lets AI agents talk to and pay each other. · ★ 10,022
  • x402 Open standard
    Open HTTP payment standard so agents can pay for APIs per request in stablecoins. · ★ 6,772
  • ClawRouter Open source
    The agent-native LLM router for autonomous agents. Every frontier model behind one wallet, <1ms local routing, USDC payments on Base & Solana via x402 · ★ 6,645
  • Sphere SDK Open source
    TypeScript SDK that gives autonomous agents an identity and wallet on the Unicity network to find, negotiate and settle payments with other agents. · ★ 5,387
  • MonoCode Open source
    MonoCode is a desktop app that puts the coding agents you already pay for behind one interface. It drives Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity, Pi, Hermes Agent, Devin and others, using the subscriptions and logins already on your machine, so you never buy tokens through it. Each tab is an agent session and one composer sends work to whichever agent you pick, so several sessions can run side by side. It runs on macOS, Windows and Linux, with an iOS app in public beta. · ★ 3,489
  • AnyModelBot Open source
    AnyModelBot is an open-source, local-first personal AI agent app for Windows, macOS and Linux where each bot has its own persona, model, workspace and memory, reachable in the app or chat apps, and it can work files, commands and your desktop with any model on pay-as-you-go billing. · ★ 2,741
