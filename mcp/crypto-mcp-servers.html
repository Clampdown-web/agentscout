How to choose

  • Prefer read-only data servers for research and reporting. Servers that sign or send transactions are labelled Moves funds on AgentScout; give those a separate wallet with spend limits.
  • Match the chain: Helius is Solana-only, Etherscan and Blockscout cover EVM chains, and Dune, GoldRush, Bitquery and Moralis span many chains.
  • Most hosted servers need an API key and bill by usage past a free allowance, so check each provider's plan.
  • Only connect servers you trust: an MCP server can read and act on whatever its credentials allow.
