Connect to the AgentScout MCP server

Let your AI assistant search AgentScout directly. The server is free, read-only and needs no sign-up or key. It covers all 1,708 tools, including 239 MCP servers, with pricing as each maker states it.

Quick answer: add https://agentscout-mcp.agentscouthq.workers.dev/mcp as a remote MCP server (Streamable HTTP) in your client.

Server URL

https://agentscout-mcp.agentscouthq.workers.dev/mcp

Add it to your client

Claude Code

claude mcp add --transport http agentscout https://agentscout-mcp.agentscouthq.workers.dev/mcp

Cursor, Windsurf and other clients that use an mcpServers file

{
  "mcpServers": {
    "agentscout": {
      "url": "https://agentscout-mcp.agentscouthq.workers.dev/mcp"
    }
  }
}

VS Code: run MCP: Add Server, choose HTTP and paste the server URL. Claude.ai and Claude Desktop: Settings, Connectors, Add custom connector, then paste the URL.

Limits and data

Read-only: the server can only look things up, it cannot change anything. Up to 60 requests per minute per IP address. Data comes from the same catalog as the site (api/tools.json) and refreshes within about 10 minutes of each site update. Usage is counted anonymously: only the day, the tool used, the type of app and whether it was a public or test request. No IP addresses, search text or arguments are stored (see our privacy policy). Also see the MCP pricing table, MCP link status, the OpenAPI description and llms.txt.
