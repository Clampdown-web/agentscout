Limits and data

Read-only: the server can only look things up, it cannot change anything. Up to 60 requests per minute per IP address. Data comes from the same catalog as the site (api/tools.json) and refreshes within about 10 minutes of each site update. Usage is counted anonymously: only the day, the tool used, the type of app and whether it was a public or test request. No IP addresses, search text or arguments are stored (see our privacy policy). Also see the MCP pricing table, MCP link status (276 of 276 MCP servers responded today (verified Oct 30, 2026)), the OpenAPI description, llms.txt and llms-full.txt.
