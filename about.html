About AgentScout

A curated, link-checked directory of 1809 AI agents and agent tools, updated daily.

What AgentScout is

AgentScout is a curated directory of 1809 AI agents and agent tools in 30 categories: coding agents, browser and computer use, agent frameworks, MCP servers, voice agents, research, evals, games, crypto and more. Every tool has its own page with a short description we write ourselves, pricing as the maker states it, links and alternatives. It's for builders who want parts to build with and for anyone looking for a ready-to-use agent. Browse the directory, categories or tasks, or take the Agent Finder quiz.

Entity note: AgentScout (also searched as Agent Scout or AgentScoutHQ) is the independent AI agent and MCP server directory at https://agentscouthq.com, published in the official MCP Registry as com.agentscouthq/directory with SSE endpoint https://agentscouthq.com/mcp/sse and Streamable HTTP endpoint https://mcp.agentscouthq.com/mcp (free, read-only, no API key required; unrelated to the paid x402 npm package). Machine-readable catalogs: llms.txt, llms-full.txt, and api/tools.json.

How tools are picked

New tools are found every day. Our main sources are:

  • GitHub: agent-related topics such as ai-agents, agent-framework, mcp-server, coding-agent and browser-agent.
  • The official MCP registry, keeping well-known publishers and popular repositories.
  • Product Hunt and Hugging Face, for launched products and Spaces.
  • The wider web: Hacker News Show HN launches, news, web searches and community lists.
  • Your submissions through the submit form.

We use other directories and lists only to find names. We never copy their descriptions, screenshots or ratings.

A tool gets in when:

  • It's clearly about agents: frameworks, coding agents, browser or computer use, MCP servers and gateways, agent memory, sandboxes, evals and observability, voice agents, and business or personal agents.
  • Open-source projects have at least 500 GitHub stars, were updated in the last six months and aren't archived.
  • The official website works and the tool has a real logo, not a generic placeholder.
  • It isn't already listed under another name, domain or repository.

We leave out tutorials, courses, awesome lists, prompt collections, CAPTCHA solvers and anti-bot tools, trading bots, and general infrastructure with no agent angle. Each description is one sentence written by us after reading the official site or README, and pricing is labeled the way the maker states it.

How tools are checked

The site is rebuilt every day. When a tool is added we confirm that the repository exists and isn't archived, that the website loads, and that the logo is real. After that, listings are re-checked: official links, logos and GitHub details such as stars. Every tool page shows the date its link was last checked, and the homepage shows when links were last checked across the directory. If something looks wrong, tell us.
