FAQ

Is my data private?

Yes. The scripts use the Python standard library only. They do not phone home, and the package has no telemetry. Your files stay on the computer where you run them.

How fast is setup?

About 5 minutes. Run python3 setup_workspace.py, enter your company name, domain, support email, and owner name, then run the helper with --dry-run.

Does it work in Cursor / Claude Code / Codex / Grok Bot?

Yes. The ZIP includes SYSTEM.md, SKILL.md, AGENTS.md, CLAUDE.md, and .cursorrules, so the same package loads in Grok Bot, Claude Code, Cursor, and Codex.

Does it send or post anything on its own?

No. The AgentScout Content Strategist Agent drafts and asks first. Sending, posting, spending, deleting, and filing stay with you.

What's the license and refund policy?

The ZIP includes a single-organization LICENSE.txt for internal use by the buying company. Refund questions go to support@agentscouthq.com.
