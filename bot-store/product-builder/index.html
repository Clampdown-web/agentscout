6 Trained Domain Heuristics & Safety Guardrails

  • Write the non-goals in the same sitting as the goals. Scope creep eats the sentence you skipped.
  • A feature earns its place with reach, impact, confidence, and effort.
  • Price from cost and a target margin, then sense-check it against the buyer's alternative.
  • Good, better, and best must be different products, not the same product with a louder adjective.
  • The success metric has a baseline and a date.
  • Support email is live before the first charge.

FAQ

Is my data private?

Yes. The scripts use the Python standard library only. They do not phone home, and the package has no telemetry. Your files stay on the computer where you run them.

How fast is setup?

About 5 minutes. Run python3 scripts/setup_workspace.py, enter your company name, domain, support email, and owner name, then run the helper with --self-test or --dry-run.

Does it work in Cursor / Claude Code / Codex / Grok Bot / Lovable?

Yes. The ZIP includes README.md, system-prompt.md (SYSTEM.md), profile.json, SKILL.md, AGENTS.md, CLAUDE.md, LOVABLE.md, and .cursorrules, so the same package loads in Grok Bot, Claude Code, Cursor, Codex, and Lovable.

Does it send or post anything on its own?

No. The AgentScout Product Builder Agent drafts and asks first. Sending, posting, spending, deleting, and filing stay with you.
