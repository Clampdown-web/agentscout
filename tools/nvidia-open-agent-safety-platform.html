    What is NVIDIA Open Agent Safety Platform?

    The NVIDIA Open Agent Safety Platform is a reference architecture for monitoring AI agents continuously, which NVIDIA announced on its technical blog on September 28, 2026. It combines NVIDIA OpenShell, an open-source secure runtime that runs autonomous agents in sandboxes with kernel-level isolation, with NVIDIA Sentry running on BlueField-4 DPUs.

    Sentry uses NVIDIA DOCA to extend monitoring and enforcement into the hardware. It links agent interactions, policy decisions and tool access into records of agent activity. In Vera Rubin POD systems, the DPU sits on the node's only path to the model, which gives out-of-band visibility and real-time policy enforcement. NVIDIA describes five principles: verifiable policy, out-of-band enforcement, controlling the path to the model, scaling agent authority with how visible its reasoning is, and shared responsibility.

    Sources: developer.nvidia.com/blog/nvidia-open-agent-safety-platform-a-referenc and our directory listing, checked 2026-10-18.

      LayerFS

      LayerFS is a filesystem built for running many coding agents in parallel. Each agent mounts a complete, writable workspace on top of shared committed history, does its work, commits what it changed and goes away, so compute only exists while a command runs. Every tool call becomes a commit on a branch, same-file clashes between agents are refused rather than silently merged, each line records the step that wrote it, and any commit can be forked at no cost for recursive exploration or RL training. Agents on different computers share one serverless store with chunk-level deduplication.
