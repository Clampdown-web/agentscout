About OpenSandbox

OpenSandbox is listed in our MCP & infra category and is aimed at builders. Secure, fast sandbox runtime for AI agents to run code. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

What is OpenSandbox?

OpenSandbox runs AI agents in sandboxes on your own infrastructure. It gives AI applications isolated environments to execute code, run commands, manage files and operate browsers or desktops.

You start locally with Docker and deploy on Kubernetes through one sandbox API; examples need Python 3.10+.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: open-sandbox.ai.

Who is OpenSandbox for?

Developers who need secure, self-hosted code execution for agents.

Key features

  • Isolated code, command and file execution
  • Browser and desktop sandboxes
  • Docker locally, Kubernetes in production
