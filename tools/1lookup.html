About 1Lookup MCP

1Lookup MCP is listed in our MCP servers category and is aimed at builders. 1Lookup MCP is a hosted MCP server at https://app.1lookup.io/api/mcp. Add that URL in Claude or Cursor, sign in, and the agent can validate phone numbers, emails and IP addresses without an API key pasted into the client. It exposes five tools (validate_phone, verify_email, ip_lookup, bulk_verify and get_account) and spends the same credits as the 1Lookup API. 1Lookup lists 76 data products on one credit balance; only these five tools are on the MCP server. Pricing, as the maker states it: Paid plans from $99/month for 20,000 credits to $1,999/month for 1,000,000 credits. Every plan includes a 7-day trial. MCP calls need a paid plan. Core phone, email and IP checks are 1 credit each, with no separate MCP fee. Maturity: Active. We last checked the official link on 2026-11-18.

What is 1Lookup MCP?

1Lookup MCP is the hosted MCP server for 1Lookup, a Momentum Labs data-verification product. The maker, Robby Frank (founder, per 1lookup.io/about), describes it as a way for Claude or Cursor to validate phone numbers, emails and IPs: add one URL, sign in, and do not paste an API key. The endpoint 1Lookup publishes is https://app.1lookup.io/api/mcp. Transport is streamable HTTP. SSE is disabled. Auth is OAuth 2.1 with PKCE (S256 required), dynamic client registration and a browser consent screen. The client receives a scoped token, not the account API key.

The server card and the Claude and Cursor setup pages list five tools. validate_phone confirms a number is real and active and returns line type, carrier, DNC status and a risk level (1 credit). verify_email checks that an address exists and is deliverable, and flags disposable, role-based and risky addresses (1 credit). ip_lookup returns geolocation and connection type, and flags proxy, VPN, Tor and datacenter ranges (1 credit). bulk_verify validates up to 50 phones, emails or IPs of one type in one call and returns a per-item result (1 credit per record). get_account returns the plan, subscription status and remaining credits and spends nothing. 1Lookup's pricing page says the platform has 76 data products on the same credits. Its llms.txt says everything beyond those five tools is on the REST API at https://app.1lookup.io/api/v1, not over MCP.

Tool calls spend the same universal credits as the REST API. There is no separate MCP fee. On the pricing page, monthly plans are Starter at $99 for 20,000 credits (about $4.95 per 1,000 core lookups), Growth at $299 for 85,000 (about $3.52), Professional at $799 for 250,000 (about $3.20) and Enterprise at $1,999 for 1,000,000 (about $2.00). Annual billing takes the equivalent of two months off. Every plan includes a 7-day trial (Starter includes $5 in credits; Growth and above include $20) and nothing is charged on the day you start. A free-plan account receives HTTP 403 UPGRADE_REQUIRED on every tool call. Identical lookups are served from cache for 7 days. The MCP spec lists a rate limit of 1,000 requests per minute, shared with API keys. Access tokens last one hour. Refresh tokens last 30 days and rotate on use.

Sources: 1lookup.io, 1lookup.io/llms.txt, 1lookup.io/products/mcp, 1lookup.io/mcp/claude, 1lookup.io/mcp/cursor, 1lookup.io/mcp/oauth, 1lookup.io/pricing, 1lookup.io/.well-known/mcp/server-card.json, 1lookup.io/about and our directory listing, checked 2026-11-18.

Who is 1Lookup MCP for?

People running outreach, enrichment or signup agents inside Claude or Cursor who want a phone, an email or an IP checked in the same chat, and who would rather approve a browser sign-in than paste an API key into the client.

Pros and cons

Pros

  • The published Claude and Cursor setup is one URL, https://app.1lookup.io/api/mcp, plus a browser approval. The mcp.json entry has no API key.
  • Phone, email and IP checks share the same credits as the REST API. 1Lookup documents no separate MCP fee, and get_account is free.
  • bulk_verify covers up to 50 values of one type in a single call instead of one lookup per value.
  • Identical lookups are cached for 7 days, and the MCP product page says phone and carrier data is refreshed daily.
  • When credits run out, the rate limit hits, or the plan is free, 1Lookup says the tool tells the agent the next step (check get_account, retry, or upgrade) rather than only returning a stack trace.

Cons

  • The MCP server exposes five tools. The pricing page's other products, 76 in total on the same credits, are REST-only at https://app.1lookup.io/api/v1.
  • A free-plan account gets HTTP 403 UPGRADE_REQUIRED on every tool call. Testing the tools depends on the 7-day trial or a paid plan.
  • SSE is disabled. 1Lookup says a client that only speaks the older SSE transport cannot connect, and it names Claude and Cursor as the verified clients.
  • bulk_verify is capped at 50 values and one type per call. The MCP spec lists 1,000 requests per minute, shared with API keys.
  • Access tokens last one hour. Refresh tokens last 30 days and rotate on use, so an idle connection has to sign in again after that window.

Setup

  1. Start a paid plan or the 7-day trial at https://www.1lookup.io/pricing. The Claude setup page says programmatic access is a paid feature: a free-plan account receives HTTP 403 UPGRADE_REQUIRED on every tool call.
  2. Claude, as documented at https://www.1lookup.io/mcp/claude: open Customize, then Connectors, then Add custom connector. Paste https://app.1lookup.io/api/mcp. There is no command, package, API key or environment variable. Sign in in the browser and approve. On Team and Enterprise plans an owner adds it in Organization settings, and members connect afterwards. If you already have an account, open API & MCP in the 1Lookup app and click Connect your AI. That path makes a key and gives you the paste-in link instead of the sign-in window.
  3. Cursor, as documented at https://www.1lookup.io/mcp/cursor: open .cursor/mcp.json for one project, or ~/.cursor/mcp.json for every project. Add one mcpServers entry named 1lookup whose only field is url set to https://app.1lookup.io/api/mcp. Reload Cursor and approve the browser sign-in. The config block is below.
  4. 1Lookup says any client that supports remote MCP over streamable HTTP can use the same URL. SSE is disabled. The in-app Connect your AI wizard also writes steps for ChatGPT, Grok, Claude Code and VS Code. After the tools appear, ask the agent to check a phone, an email or an IP. Each call bills the plan you approved.
