About Streamkap MCP

Streamkap MCP is listed in our MCP servers category and is aimed at builders. Streamkap's official CLI and MCP server let AI agents manage real-time change-data-capture pipelines on Streamkap. An agent can create and edit sources, destinations, pipelines and transforms, check their status and troubleshoot lag, streaming database changes into warehouses and apps without clicking through the console. Pricing, as the maker states it: Free plan $0 (500 MB/month, MCP server included); paid plans priced by data volume. Maturity: Active. We last checked the official link on 2026-10-23.
