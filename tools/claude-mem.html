About Claude-Mem

Claude-Mem is listed in our memory & RAG category and is aimed at builders. Gives coding agents memory across sessions by capturing what they do, compressing it and feeding the relevant context back in later. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

What is Claude-Mem?

Claude-Mem is a persistent memory compression system built for Claude Code. It preserves context across sessions by automatically capturing tool-usage observations, generating semantic summaries and making them available to future sessions.

That lets the agent keep continuity of knowledge about a project after sessions end or reconnect. The installer offers a hosted memory option with a 30-day free trial after a sign-in, and a local observer is available as an opt-in.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: cmem.ai.

Who is Claude-Mem for?

Claude Code users (and other coding-agent users) who are tired of re-explaining a project at the start of every session.
