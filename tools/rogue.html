    Rogue alternatives

    Other evals & observability tools in our directory. See all evals & observability tools →

    AI Beat

    An open-source AI red-teaming suite: PromptBeat attacks models and prompts, and AgentBeat runs black-box security evaluations against HTTP-exposed agents.

    Tracely

    Tracely is open-source, trace-native CI/CD for AI agents: it grades every production trace with evaluators, clusters failures into issues, freezes bad runs into replayable test cases and blocks pull requests that would reintroduce them.

    Zoetrope

    Free, local viewer that turns Claude Code and Codex session transcripts into a live flow graph of every agent and subagent, with tool-call pass/fail status, time-travel replay and full prompt provenance, in the terminal or browser.

    Userpilot Agent Analytics

    Userpilot Agent Analytics shows product teams how users actually get on with the AI agent inside their app. It reads the agent's conversations at scale and reports whether people got what they needed or left frustrated, so teams can see where the agent fails, which requests it can't handle and how agent use ties back to product engagement, alongside Userpilot's existing product analytics.

    SWE-bench

    Benchmark that tests whether language models and coding agents can resolve real GitHub issues, with multimodal and verified variants.

    Openlayer MCP

    Openlayer's MCP server, letting coding agents pull evaluation results, failing tests and monitoring data from Openlayer so they can debug and improve AI systems from the IDE.
