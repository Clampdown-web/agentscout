What is Semble?

Semble is a code search library built for agents. It returns the exact code snippets an agent needs, and its README says it uses about 99% fewer tokens than grep plus file reads, with indexing and search of a full codebase taking under a second for most repos.

Everything runs on CPU with no API keys, GPU or external services. You can use it as an MCP server, as a CLI tool referenced from AGENTS.md, or as a dedicated sub-agent, so coding agents such as Claude Code, Cursor, Codex and OpenCode can query any repo in natural language.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: minish.ai/packages/semble/introduction.
