What is TripoSR?

TripoSR is an open-source model from Tripo AI and Stability AI for fast feed-forward 3D reconstruction from a single image. Built on the Large Reconstruction Model (LRM) approach, it produces a 3D model in under half a second on an NVIDIA A100.

The code, pretrained model and demo are released under the MIT License. You run it with Python and PyTorch (about 6 GB of VRAM for one image by default), can bake a texture instead of vertex colors, and there is a local Gradio app; the technical report compares it favourably with other open-source image-to-3D models.

Sources: the official README and our directory listing, checked 2026-10-21. Official site: github.com/VAST-AI-Research/TripoSR.
