About Label Studio MCP Server

Label Studio MCP Server is listed in our vision category and is aimed at builders. HumanSignal's MCP server that lets AI assistants create Label Studio labeling projects, import tasks, read annotations and add model predictions. Pricing, as the maker states it: Free, open source (Apache-2.0). Maturity: Active. We last checked the official link on 2026-10-17.

What is Label Studio MCP Server?

The Label Studio MCP Server lets AI assistants interact with a Label Studio instance through the label-studio-sdk.

Our listing notes creating labeling projects, importing tasks and reading annotations.
