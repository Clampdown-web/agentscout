About YuE

YuE is listed in our music production category and is aimed at builders. Open song-generation model (YuE2) with lyrics-to-song, zero-shot covers and agentic music editing. Pricing, as the maker states it: Open source (Apache-2.0). Maturity: Active. We last checked the official link on 2026-10-20.

What is YuE?

YuE is an open song-generation project from the Multimodal Art Projection (M-A-P) community; its current version, YuE2, turns lyrics and a style prompt into a complete song with vocals and accompaniment. It first writes an explicit melody-and-chord plan, then renders that plan as audio, so a person or an agent can read, play and change the composition before rendering.

The same model does zero-shot covers of transcribed songs in a new style and agentic editing through a conversation about score, arrangement and lyrics. Its maintainers report it is competitive with Suno v5/v6 on WildSongBench. A yue2-music agent skill teaches agents to generate songs and instrumentals and edit ABC scores, and a free online demo is available.

Sources: the official README and our directory listing, checked 2026-10-20. Official site: map-yue2.github.io.

Who is YuE for?

Musicians, producers and developers who want an open, controllable song generator they can run themselves or drive from an AI agent.

Is YuE free?

YuE's pricing, as the maker states it: Open source (Apache-2.0). Open-source tools are free to use, though you may still pay for model API usage or a hosted plan. Check the official site for current plans.

Is YuE open source?

Yes. YuE is released under the Apache License 2.0, according to its GitHub repository.

What hardware does YuE2 need?

Linux, Python 3.12 and an NVIDIA GPU with BF16 support and 24 GB of VRAM; model files download from Hugging Face on first use.

Where is the original YuE?

Its code, documentation and licence are kept on the repository's YuE-v1 branch.

What are alternatives to YuE?

Similar tools include ACE-Step, Stable Audio, AudioCraft, Soundraw, AIVA and Magenta RealTime.
