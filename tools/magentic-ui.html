About Magentic-UI

Magentic-UI is listed in our browser/computer use category and is aimed at builders. Microsoft Research's experimental human-in-the-loop agent that works across the browser and local files. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

What is Magentic-UI?

Magentic-UI is an agentic application from Microsoft; its next generation, MagenticLite, pairs an on-device-friendly orchestrator model (MagenticBrain) with a browser-use model (Fara).

Our listing describes it as an experimental human-in-the-loop agent working across the browser and local files.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: microsoft.com/en-us/research/blog/magenticlite-magenticbrain-fara1-5-an-agentic-experience-optimized-for-small-models.
