About Qodo

Qodo is listed in our coding category and is aimed at builders. AI code review and testing agents that work in the IDE, the terminal and pull requests to catch issues before merge. Pricing, as the maker states it: Freemium. Maturity: Mature. We last checked the official link on 2026-10-16.

What is Qodo?

Qodo makes AI code review and testing agents that work in the IDE, the terminal and pull requests to catch issues before merge. It integrates with GitHub, GitLab, Bitbucket and Azure DevOps, and offers a free version for open-source projects.

Its open-source PR-Agent project, now community-maintained and described as a legacy project of Qodo, is separate from Qodo's main code-review product.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: qodo.ai.
