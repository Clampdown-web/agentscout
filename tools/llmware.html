About llmware

llmware is listed in our memory & RAG category and is aimed at builders. Framework for building private, local RAG and agent applications with small specialized models on AI PCs, edge and self-hosted setups. Pricing, as the maker states it: Free and open source (Apache-2.0). Maturity: Mature. We last checked the official link on 2026-10-20.

What is llmware?

llmware is an open-source Python framework for building knowledge-based LLM applications that run locally and privately: on AI PCs and laptops, at the edge or self-hosted, across Windows, Mac and Linux. It supports GGUF, OpenVINO, ONNX Runtime (including Qualcomm QNN), Windows Local Foundry and PyTorch, and picks the right inference technology for the target machine.

It has two parts: a model catalog of 300+ quantized models, including 50+ of llmware's own fine-tuned SLIM, Bling, Dragon and Industry-BERT models for enterprise tasks (cloud models from OpenAI, Anthropic and Google are supported too), and a RAG pipeline that parses, chunks, embeds and indexes documents into libraries you can query with text, semantic, hybrid and metadata filters and prompt with sources.

Sources: the official README and our directory listing, checked 2026-10-20. Official site: llmware-ai.github.io/llmware.

Who is llmware for?

Developers building private RAG and agent apps for enterprise documents who want small models that run on a laptop or on-prem hardware instead of a cloud API.
