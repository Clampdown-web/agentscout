    Letta is listed in our frameworks category and is aimed at builders. Framework for stateful agents with long-term memory (formerly MemGPT). Pricing, as the maker states it: Open source + paid cloud. Maturity: Mature. We last checked the official link on 2026-10-14.

    What is Letta?

    Letta (formerly MemGPT) is a framework for building stateful agents with memory that can learn and improve over time. Its current source lives in letta-ai/letta-code, which includes the agent harness, a terminal UI, an App Server, channels and the runtime behind its apps.

    You can run agents locally or self-hosted via the App Server, and use them from a desktop app for macOS, Windows and Linux, chat.letta.com, Slack, Telegram, Discord or the Letta Agent SDK. A paid cloud is also offered.

    Sources: the official README and our directory listing, checked 2026-10-18. Official site: letta.com.

    Who is Letta for?

    Developers who want agents with long-term memory that persist and improve across conversations.
