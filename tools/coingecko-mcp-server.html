    About CoinGecko MCP Server

    CoinGecko MCP Server is listed in our crypto category and is aimed at builders. Official MCP server for crypto prices, market and on-chain data. Pricing, as the maker states it: Free keyless server and Demo API key; paid Pro API plans. Maturity: Active. We last checked the official link on 2026-10-16.

    What is CoinGecko MCP Server?

    CoinGecko's MCP server provides crypto prices, market and on-chain data to agents.

    The listed repo is CoinGecko's TypeScript library for its REST API, which the MCP server builds on.

    Sources: the official README and our directory listing, checked 2026-10-18. Official site: docs.coingecko.com/ai-integration/mcp-server.
