What is Vane?

Vane is a privacy-focused AI answering engine that runs entirely on your own hardware.

It combines web knowledge with local LLMs (Ollama) or cloud providers like OpenAI, Claude and Groq, and answers with cited sources.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: github.com/ItzCrazyKns/Vane.
