About Ruflo

Ruflo is listed in our frameworks category and is aimed at builders. Open-source multi-agent meta-harness for Claude Code, Codex, and MCP clients; Oct 13 release adds Mods (mission workflows) and a single control plane with human approval. Pricing, as the maker states it: Open source (MIT); model costs still apply. Maturity: Active. We last checked the official link on 2026-10-14.

What is Ruflo?

Ruflo is an open-source (MIT) agent meta-harness for Claude Code and Codex. Core provides foundation tools, Console opens an agent cockpit, and Mods add routing and policy enforcement inside Claude Code.

In Claude Code it requires version 2.1.287 or later; for Codex or other MCP clients you set it up with npx and connect to the Ruflo MCP server. Mods run with your account's permissions, and the README recommends reviewing their code before installing. Model costs still apply.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: github.com/ruvnet/ruflo.

Who is Ruflo for?

Claude Code and Codex users who want multi-agent coordination, a visual console and policy controls on top of their existing agent.
