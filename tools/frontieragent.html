What is FrontierAgent?

FrontierAgent, from Apodex, is an open-source agent runtime, terminal app and evaluation suite for long research and file-based tasks. Its frontier-agent terminal UI has two workflows: ReAct, where one agent researches, reads files, writes deliverables and runs commands in a task sandbox, and Agent Team, where a coordinator splits the work across parallel sub-agents and combines their reports.

The same engine runs the benchmarks Apodex uses for its own models, and the framework, tools, workflows and evaluation layer can each be reused on their own. It installs with one command on macOS and Linux with no hard Docker dependency, and works with OpenAI-compatible endpoints including Apodex's API.

Sources: the official README and our directory listing, checked 2026-10-22. Official site: apodex.ai.
