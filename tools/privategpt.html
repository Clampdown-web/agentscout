What is PrivateGPT?

PrivateGPT is an open-source API layer that turns local models into AI applications. It follows the Claude API model and provides the backend building blocks (messages, ingestion, retrieval and tools) so you can build private AI products without depending on cloud APIs.

It does not run models itself: it connects to any OpenAI-compatible inference server. It ships a workbench UI at /ui for testing, and it powers Zylon, an on-premise AI platform for enterprises.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: zylon.ai/private-gpt.

Who is PrivateGPT for?

Developers and companies building private or on-premise AI apps on local models who need RAG, tools and ingestion without rebuilding a backend.

    DeepSeek's open-source agent harness with a local web UI, built so that every tool, model and scheduled task is a swappable plugin; still a developer preview.

    Agent-Native (Builder.io)

    Open-source TypeScript framework for building agents that come with their own app UI; each action is shared by the UI, agent, API, CLI, MCP and A2A.

    Sage

    Sage is an open-source (MIT) RSI agent harness, where RSI stands for Recursive Self-Improvement: it improves agents using feedback from their tasks. Starting from a goal or a curated usage history, it runs the agent, has a separate evaluator grade the results, tunes the agent and keeps every version with its evidence, so you decide which one to adopt. It comes as a Desktop app, a multi-user Server with Agent Studio, and the SAgents Python runtime, with support for Skills, MCP, multi-agent setups and sandboxed runs with approvals.

    Cayu

    Cayu is an open-source Python framework for building and running domain-specific, long-horizon agents on a durable runtime. Sessions survive restarts and redeploys from SQLite or Postgres stores, tool policies can require human approval before side effects, spend caps are checked before each model call, and timers, background tasks, subagents and forks cover longer multi-agent work. It is Apache 2.0 licensed.
