What is HyperFrames?

HyperFrames is an open-source framework for turning HTML, CSS, media and seekable animations into deterministic MP4 videos. Its tagline is "Write HTML. Render video. Built for agents."

You can use it locally through its CLI, from AI coding agents such as Claude Code, Copilot, Cursor, Gemini CLI and OpenCode through plugins and skills, or as the rendering core behind hosted authoring workflows.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: hyperframes.dev.

Who is HyperFrames for?

Developers and AI-agent users who want to generate videos from code or prompts, such as product intros, with repeatable output.
