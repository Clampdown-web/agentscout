What is Strands Agents?

Strands Agents is an open-source SDK for building and running AI agents in Python and TypeScript with a model-driven approach. It runs in your process with no hosted control plane.

One SDK covers lifecycle controls (turn limits, token budgets, cancellation), tools and structured output, MCP, multi-agent patterns, memory and sessions, model portability and streaming.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: github.com/strands-agents/harness-sdk.

Who is Strands Agents for?

Developers who would otherwise write their own agent loop and want the common pieces ready-made.
