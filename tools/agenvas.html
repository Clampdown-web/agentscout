What is Agenvas?

Agenvas is an open-source (MIT), self-hosted multimodal creation canvas where text notes, images, videos, audio clips and AI agents live side by side as connected cards on an infinite workspace. Rather than burying prompts in a linear chat history, you select specific cards on the canvas and connect them to an agent card so the agent sees only the visual and text context you chose.

When an agent proposes generating or editing an image, video or audio clip, Agenvas places a human-in-the-loop approval gate on the proposal card so you can inspect or tweak the prompt before spending model credits. The entire stack—React 19 frontend, Java 21 / Spring Boot / Spring AI backend and PostgreSQL—starts with a single Docker Compose command and plugs into OpenAI-compatible endpoints, local or remote ComfyUI workflows, and RunningHub cloud apps.

Sources: agenvas.com, github.com/grayrepo-byte/Agenvas and our directory listing, checked 2026-11-04.

Who is Agenvas for?

Designers, creative technologists and self-hosters who want an open-source infinite canvas connecting text, image, video and audio generation with ComfyUI, RunningHub and OpenAI-compatible models.

Pros and cons

Pros

  • MIT licensed and self-hosted. The stack (React 19, Java 21, Spring Boot, PostgreSQL) starts with one Docker Compose command.
  • An agent only sees the cards you connect, and a media proposal waits for approval before it spends model credits.
  • You can import a ComfyUI API workflow JSON, map the inputs, and save it as a tool on the canvas.

Cons

  • OpenAI-compatible APIs, ComfyUI, and RunningHub are billed by those providers. Agenvas does not include their usage.
  • You run the Docker stack yourself, including PostgreSQL.
  • The GitHub star count on the listing is small. Popularity is not the reason to pick it.

Setup

  1. Clone the repo and start it with Docker Compose, as the listing describes.
  2. Connect an OpenAI-compatible endpoint, a ComfyUI workflow, or a RunningHub app.
  3. Put text, image, video, or audio on cards and connect only the cards the agent should see.
  4. Approve the proposal card before a generation job runs.
