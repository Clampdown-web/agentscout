About Sparrow

Sparrow is listed in our vision category and is aimed at builders. Open-source tool for structured data extraction from documents and images with ML, LLMs and vision LLMs, plus agentic workflows. Pricing, as the maker states it: Free and open source (GPL-3.0), self-hosted. Maturity: Mature. We last checked the official link on 2026-10-22.

What is Sparrow?

Sparrow, from Katana ML, is an API-first platform for document intelligence: it turns invoices, receipts, bank statements, forms and tables into clean, validated JSON using machine learning, LLMs and vision LLMs, all running on your own infrastructure.

Besides extraction it handles instruction processing such as validation and decisions, and has an agent framework for multi-step workflows monitored through Prefect. Pipelines mix vision and text models, and the same API works on MLX on Apple Silicon, vLLM on NVIDIA, Ollama, Hugging Face or Mistral OCR. A web UI offers drag-and-drop uploads and JSON schema queries.

Sources: the official README and our directory listing, checked 2026-10-22. Official site: sparrow.katanaml.io/process.

Teams that need structured data from business documents without sending them to a third party.
