What is Galileo Agent Leaderboard?

Galileo Agent Leaderboard is an evaluation framework for AI agents across real-world business scenarios.

v1 ranks tool-calling performance; v2 adds synthetic dataset generation and a simulation engine for task completion.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: huggingface.co/spaces/galileo-ai/agent-leaderboard.
