About opencode

OpenCode is an MIT-licensed open-source AI coding agent for the terminal, with a beta desktop app, that works with many model providers instead of locking you to one. Install it with a one-line script, npm, Homebrew, pacman, mise or Nix, then let it read your repository, edit files and run commands from a keyboard-driven TUI. Pricing, as the maker states it: Free and open source (MIT); bring your own model provider.. Maturity: Active. We last checked the official link on 2026-11-09.

What is opencode?

OpenCode is an open-source AI coding agent. It runs in your terminal and is also available as a desktop app (in beta), and it works with many model providers rather than a single vendor.

It ships with two built-in agents you switch between with the Tab key: build, the default full-access agent for development work, and plan, a read-only agent for analysis and code exploration that asks permission before running bash commands. A general subagent handles complex searches and multistep tasks.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: opencode.ai.

Who is opencode for?

Developers who want an open-source terminal coding agent they can point at the model provider of their choice, including people exploring unfamiliar codebases with the read-only plan agent.

    OpenAI Codex CLI

    Codex CLI is OpenAI's Apache-2.0 coding agent that runs locally in your terminal, reading your repository, editing files and running commands, with standalone installers for macOS, Linux and Windows plus npm and Homebrew. The same agent is available as IDE extensions for VS Code, Cursor and Windsurf, a desktop app via codex app, and the cloud-based Codex Web in ChatGPT.

    Gemini CLI

    Gemini CLI is Google's Apache-2.0 open-source terminal agent that brings Gemini models into your shell to read code, edit files and run commands. As of June 18, 2026 it is aimed at Gemini Code Assist Standard/Enterprise and Code Assist for GitHub users; free individual access and Google AI Pro/Ultra plans moved to Antigravity CLI, and the project says it is not tuned for the Gemini 4 series.

    Cline

    Cline is an Apache-2.0 open-source coding agent that runs as a VS Code extension, a JetBrains plugin, a macOS and Windows desktop app, a CLI (npm i -g cline, interactive or headless for CI) and an SDK for building your own agents. It creates and edits files, runs commands, browses the web and uses MCP tools with human-in-the-loop approval for each step, and works with the model provider of your choice.

    Reticle

    Verification layer for AI coding agents: a dev-only SDK inside your web or desktop app lets the agent drive real flows and read network calls, app state and console, then returns a pass, fail or cannot-tell verdict with the file and line to fix; saved flows replay without an AI model and can gate CI.

    mu

    mu is an open-source coding agent with a judgment kernel: a small, fast judge model makes the many routine decisions in each turn so the main model only gets the context it needs. It ships as a command-line tool and a desktop app and aims to keep coding sessions focused and cheap.

    Paritok

    Paritok is a compression gateway that sits between a coding agent and its LLM. Using its own open-source 4B code-aware model, it shrinks tool output, files and conversation history on the fly without losing what the agent needs, which cuts token bills and lets agent sessions run longer before they hit context limits.
