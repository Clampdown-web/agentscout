    What is Browser Harness?

    Browser Harness, from the Browser Use team, lets Claude Code, Codex or Cursor use your real Chrome browser: open pages, click, type, read and download, logged in as you.

    You set it up by pasting one prompt into your coding agent; it talks to Chrome over the DevTools Protocol.

    Sources: the official README and our directory listing, checked 2026-10-18. Official site: github.com/browser-use/browser-harness.
