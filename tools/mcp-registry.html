What is MCP Registry?

The MCP Registry is the official, community-driven registry service for Model Context Protocol servers, run under the modelcontextprotocol project. It gives MCP clients a list of available servers, like an app store, and an API (registry.modelcontextprotocol.io) that clients and sub-registries can build on.

Server authors publish their own entries, and a working group with members from Stacklok, PulseMCP and others maintains it. It launched in preview in September 2025 and its v0.1 API was frozen in October 2025 so integrators could build against a stable contract while work continues towards general availability.

Sources: the official README and our directory listing, checked 2026-10-21. Official site: github.com/modelcontextprotocol/registry.
