What is Easel?

Easel, from Zhejiang University's REAL lab, is an open-source content workspace for social media creators. It connects an OpenClaw agent with account profiles, content skills and real media tools, so the agent actually produces the content instead of only giving advice.

It works in five steps: discover trends and opportunities that suit the account, plan topics, titles, scripts and a calendar, create posts, cards, audio and video, publish to the platforms, and analyze performance to feed back into the account profile. It currently supports Xiaohongshu, Douyin, Kuaishou, Zhihu, Bilibili, WeChat Channels and WeChat Official Accounts, through a web front end or a CLI.

Sources: the official README and our directory listing, checked 2026-10-24. Official site: github.com/ZJU-REAL/Easel.
