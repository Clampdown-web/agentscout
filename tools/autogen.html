About AutoGen

AutoGen is listed in our frameworks category and is aimed at builders. Microsoft's framework for multi-agent conversations, now archived and no longer maintained; Microsoft points new users to Microsoft Agent Framework. Pricing, as the maker states it: Open source. Maturity: Archived (no longer maintained). We last checked the official link on 2026-10-18.

What is AutoGen?

AutoGen is Microsoft's open-source framework for building multi-agent AI applications that can act on their own or alongside people. Its official README now says the project has been archived and is no longer actively maintained. Microsoft no longer provides bug fixes, security fixes, new features or support, and it advises against production use.

Microsoft recommends that new users start with Microsoft Agent Framework, which it calls AutoGen's enterprise-ready successor, and it publishes a migration guide for existing users. AutoGen needs Python 3.10 or later. It ships AgentChat and Core APIs, extensions for model clients and tools such as MCP, and AutoGen Studio, a no-code GUI for prototyping multi-agent workflows.

Sources: github.com/microsoft/autogen and our directory listing, checked 2026-11-04.

Who is AutoGen for?

Researchers and teams maintaining existing AutoGen projects or studying multi-agent patterns. New production work should use Microsoft Agent Framework.

Pros and cons

Pros

  • The repo still documents AgentChat, Core, extensions for model clients and MCP, and AutoGen Studio.
  • Microsoft's README names Microsoft Agent Framework as the successor and points at a migration guide.
  • Python 3.10 or later is the stated requirement if you are only reading or migrating an existing project.

Cons

  • The README says the project is archived and no longer maintained: no bug fixes, security fixes, new features, or support, and it advises against production use.
  • AutoGen Studio is part of that archived tree, not a current hosted product.
  • Starting a new production agent on AutoGen means ignoring the maintainer's own advice.

Setup

  1. For new work, start with Microsoft Agent Framework and the migration guide linked from the AutoGen README.
  2. To study the old APIs, clone github.com/microsoft/autogen and stay on Python 3.10 or newer.
  3. Do not ship AutoGen Studio as if Microsoft were still supporting it.
