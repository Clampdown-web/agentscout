What is Task Master?

Taskmaster is a task management system for AI-driven development. It breaks work into structured tasks with dependencies and is designed to work with AI chat and coding tools, starting with Cursor and Claude.

It runs as a CLI and as an MCP server (with one-click install for Cursor), supports multiple AI providers through your own API keys, and adds commands for research, tags and workstreams, and team collaboration.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: tryhamster.com/research/taskmaster.

Who is Task Master for?

Developers using AI coding agents who want them to plan and work through a structured task list instead of ad-hoc prompts.
