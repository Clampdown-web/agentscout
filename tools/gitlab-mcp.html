About GitLab MCP

GitLab MCP is listed in our MCP & infra category and is aimed at builders. GitLab's official MCP server for letting agents work with projects, issues and merge requests. Pricing, as the maker states it: Freemium. Maturity: Active. We last checked the official link on 2026-10-16.

What is GitLab MCP?

The GitLab MCP server lets you securely connect AI tools such as Claude Desktop, Claude Code and Cursor to your GitLab instance so they can access your GitLab data.

GitLab's docs list it as generally available on the Free, Premium and Ultimate tiers across GitLab.com, Self-Managed and Dedicated (GA since GitLab 19.5), with selectable toolsets.

Sources: the official site and our directory listing, checked 2026-10-18. Official site: docs.gitlab.com/user/gitlab_duo/model_context_protocol/mcp_server.

Who is GitLab MCP for?

Teams on GitLab who want AI assistants to work with projects, issues and merge requests.

Key features

  • Works with GitLab.com, Self-Managed and Dedicated
  • Available on the Free tier
  • Selectable toolsets
