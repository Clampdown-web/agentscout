What is Hermes Agent (Nous Research)?

Hermes Agent is Nous Research's open-source, self-improving AI agent. Its built-in learning loop creates skills from experience, improves them during use, persists knowledge, searches its own past conversations and builds a model of you across sessions.

It can run on a $5 VPS, a GPU cluster or serverless infrastructure, and you can talk to it from Telegram while it works on a cloud VM. It works with any model, including Nous Portal, OpenRouter, OpenAI or your own endpoint, switchable with hermes model, and has a full terminal UI.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: hermes-agent.nousresearch.com.
