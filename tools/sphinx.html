About Sphinx

Sphinx is listed in our coding category and is aimed at builders. Open-source Git hook for agent-assisted coding: before code your agent wrote is pushed to a protected branch, it reads the diff and quizzes you on what the change actually does when things go wrong, and only lets the push through once you answer correctly. Works with Claude Code, Codex, Cursor and OpenCode. What is Sphinx?

Sphinx is an open-source Git hook for agent-assisted development. When you, or your coding agent, push to a branch you protect, Git pauses and Sphinx has a reviewer model that never saw your chat read the diff and ask you what the change does when things go wrong.

Answer wrong and it explains why, then tries a new scenario; answer right and the push continues. Its pitch is that you can outsource the writing but not the understanding. It runs on few tokens using your existing coding agent, OpenRouter or any OpenAI-compatible endpoint, never shows your answers to the coding agent, never opens .env files or keys, and has a logged 'sphinx yolo' escape hatch. It reached the Hacker News front page in October 2026.

Sources: the official README and our directory listing, checked 2026-10-21. Official site: sphinx-six-theta.vercel.app.

Developers who ship code written by Claude Code, Codex, Cursor or other agents and want to be sure they understand it before it reaches production.

    Trail Code

    Context layer that makes Claude Code, Cursor, Codex and other coding agents faster and cheaper on large codebases.

    Emdash

    A free, open-source agentic development environment (YC W26) for running Claude Code, Codex and other coding agents in parallel, each in its own worktree, then reviewing diffs, PRs and CI in one place.

    Codeg

    Multi-agent coding workspace that brings sessions from Claude Code, Codex, OpenCode and other agents into one app so they can work together.

    Cloudroom

    Cloudroom runs Claude Code, Codex, Pi and other coding agents in the cloud, each in its own isolated sandbox on its own Git branch, using your own model logins; the Rust core is open source to self-host, and a desktop app manages local and cloud agents.

    AOCI-CODE

    AOCI-CODE keeps a persistent, Git-versioned map of your whole codebase and database schema that your coding agent writes and a local MCP server governs. Agents in Codex, Claude Code, Cursor or OpenCode read the map once and know what each file is for, what it depends on and what must not break, instead of re-reading the repo on every task. It can index an existing codebase of up to about half a million lines and report how well it knows each area before taking over development.

    Vicoa

    Vicoa is an agent-native IDE for running Claude Code, Codex, Gemini and 40+ other coding agents in parallel, each on its own git worktree, from desktop, web or phone, with notifications when an agent needs you.
