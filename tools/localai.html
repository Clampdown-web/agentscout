What is LocalAI?

LocalAI is an open-source AI engine for running LLM, vision, voice, image and video models on any hardware, no GPU required, with an OpenAI-compatible API.

It has a small core: each backend wraps an engine such as llama.cpp, vLLM, whisper.cpp, stable-diffusion or MLX in its own image, pulled only when a model needs it.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: localai.io.

Who is LocalAI for?

Developers and self-hosters who want to run models, and agents on top of them, on their own hardware.
