About Graphiti

Graphiti is listed in our MCP & infra category and is aimed at builders. Builds real-time, temporal knowledge graphs that serve as memory for AI agents. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

What is Graphiti?

Graphiti, from Zep, is a framework for building and querying temporal context graphs for AI agents. Unlike static knowledge graphs, it tracks how facts change over time.

It serves as real-time memory for agents.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: help.getzep.com/graphiti/getting-started/welcome.

Who is Graphiti for?

Developers building agents that need memory of facts and relationships that change over time.
