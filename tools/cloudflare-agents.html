About Cloudflare Agents

Cloudflare Agents is listed in our frameworks category and is aimed at builders. Cloudflare's SDK for building and deploying stateful AI agents on Workers. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

What is Cloudflare Agents?

Cloudflare Agents is Cloudflare's SDK for persistent, stateful AI agents powered by Durable Objects. Each agent has its own state, storage and lifecycle, with built-in real-time communication, scheduling, AI model calls, MCP and workflows.

Agents hibernate when idle and wake on demand, so you can run very many of them, one per user, session or game room, at no cost while inactive.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: developers.cloudflare.com/agents.

Who is Cloudflare Agents for?

Developers deploying agents on Cloudflare Workers who need per-user state at scale.
