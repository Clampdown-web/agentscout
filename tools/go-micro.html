What is Go Micro?

Go Micro is a Go framework for distributed systems, providing RPC, service discovery, messaging, storage and configuration. Each component is a Go interface with a default implementation you can replace.

It now also treats services as tools for agents: it includes agents (models, conversation history, tools and execution), workflows with retries and checkpoints, and a gateway that exposes services over HTTP and MCP.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: go-micro.dev.

Who is Go Micro for?

Go developers building microservices who want to expose them to AI agents, or add agents and workflows to an existing service architecture.

  • Gateway exposing services over HTTP and MCP
  • Pluggable Go interfaces
