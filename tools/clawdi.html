What is Clawdi?

Clawdi is a home for AI agents with shared context. It runs always-on Hermes or OpenClaw agents in the cloud without a server to maintain, and you chat with them over Telegram, Discord or WhatsApp.

A free, MIT-licensed CLI also connects agents on your own computer, such as Claude Code and Codex, so memories, skills, vaults and connectors are shared across every agent.

Listed in our personal agents category. Official site: clawdi.ai.

Key features

  • Deploy a cloud Hermes or OpenClaw agent in minutes
  • Chat through Telegram, Discord or WhatsApp
  • Shared memories, skills and secret vaults across agents
  • Gmail, Notion, GitHub and hundreds more connectors via one-click OAuth
  • Free MIT-licensed CLI to connect Claude Code, Codex and other local agents
  • Clawdi AI pay-as-you-go models, or bring your own key

Clawdi pricing
