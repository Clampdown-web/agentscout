About StartLux Decision

StartLux Decision is listed in our models & local runtimes category and is aimed at builders. Open decision models (0.8B to 27B) that return a calibrated probability for every option in a single pass, with an inference engine and HTTP server. Pricing, as the maker states it: Open weights 0.8B-27B on Hugging Face; free hosted API. Maturity: Active. We last checked the official link on 2026-10-26.

    LocalAI

    Self-hosted engine with an OpenAI-compatible API for running LLM, vision, voice and image models on your own hardware, including agents.

    Gufo

    Gufo is an open-source inference engine built for AMD Strix Halo machines that runs text, vision and speech models locally, with tuned kernels and published benchmarks for each supported model. It serves models through an API so local agents can use them, and image and video generation support is in progress.

    Strands Decider

    Strands Decider is a small, fast decision model from Strands Labs for agent workflows. Rather than asking a full LLM every time, an agent can use it to choose between options or score something on a scale in a fraction of the time, with calibrated confidence so the workflow knows when to fall back to a bigger model.

    LLMFlyAI

    LLMFlyAI is a one-API gateway for GPT, Claude, Gemini and Grok so apps can switch models behind a single key.

    MiroThinker

    Deep research agent and open models tuned for complex research and forecasting tasks.

    pooled

    Peer-to-peer LLM inference in the browser: pool your laptops, phones and other devices into a room to run large open models for chat and coding agents, with no GPU server.
