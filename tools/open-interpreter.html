About Open Interpreter

Open Interpreter is listed in our coding category and is aimed at builders. Terminal coding agent forked from OpenAI's Codex and tuned for low-cost and open-weight models, with switchable harness modes that imitate tools like Claude Code. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-17.

What is Open Interpreter?

Open Interpreter is a coding agent optimized for low-cost models. It is a fork of OpenAI's Codex that focuses on emulating the agent harness that gets the best performance out of cheaper and open-weight models.

A /harness command switches the active harness, it works in ACP-compatible editors via interpreter acp, and it speaks the same Codex exec protocol, so Codex SDK users can switch with a one-line change. You start a session by typing i or interpreter in your terminal.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: openinterpreter.com.

Who is Open Interpreter for?

Developers who want a terminal coding agent that gets more out of low-cost or open-weight models than general-purpose harnesses do.
