About Stripe Agent Toolkit

Stripe Agent Toolkit is listed in our MCP & infra category and is aimed at builders. Stripe's agent toolkit and MCP server for customers, payments and billing. Pricing, as the maker states it: Open source. Maturity: Active. We last checked the official link on 2026-10-16.

What is Stripe Agent Toolkit?

Stripe's agent toolkit is a one-stop repo for building AI-powered products on Stripe, with SDKs to integrate Stripe with LLMs and agent frameworks.

It includes, for example, @stripe/ai-sdk for Vercel's AI SDK and @stripe/token-meter for billing on token usage. Our listing notes an MCP server for customers, payments and billing.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: docs.stripe.com/agents.

Developers who want agents to work with Stripe payments and billing.
