What is Excel MCP Server?

Excel MCP Server is an open-source MCP server that lets Claude, Cursor, VS Code Copilot, Codex and other clients create, read and edit Excel files, including charts, PivotTables, formulas and tables.

It is built on openpyxl, needs no Microsoft Excel, and runs on Windows, macOS and Linux.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: excelmcpserver.com.

Who is Excel MCP Server for?

People who want AI assistants to build or update spreadsheets.
