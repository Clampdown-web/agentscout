TryVoice is listed in our voice category and is aimed at builders. Hands-free voice runtime for coding agents with wake word, push-to-talk and streaming replies. Pricing, as the maker states it: Open source. Maturity: Early. We last checked the official link on 2026-10-14.

What is TryVoice?

TryVoice is a hands-free voice runtime for AI agents, so you can talk to your coding assistant without touching the keyboard.

It wraps agents like OpenClaw and Claude Code in a voice interface with wake-word activation and push-to-talk.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: github.com/TryAILab/tryvoice-oss.
