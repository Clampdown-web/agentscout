What is Paseo?

Paseo is an open-source agentic development environment for desktop, mobile, web and CLI, with one interface for Claude Code, Codex, Copilot, OpenCode, Pi and other agents.

The desktop app puts agents, editor, terminals, diffs, pull requests and a browser in one window. You can run many agents at once, each in its own worktree, on one or several machines; agents can create worktrees and launch and talk to other agents. The native iOS and Android app is the full app.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: paseo.sh.

Who is Paseo for?

Developers who orchestrate several coding agents and want the same environment on desktop and phone, running on their own machines.

Key features

  • Parallel agents in separate worktrees
  • Agents can launch and message other agents
  • Editor, terminals, diffs, PRs and browser in one window
  • Self-hosted; native iOS and Android apps
