About TEN Framework

TEN Framework is listed in our voice category and is aimed at builders. Open-source framework for real-time multimodal voice agents, including the TEN Agent demo. Pricing, as the maker states it: Source-available. Maturity: Mature. We last checked the official link on 2026-10-16.

What is TEN Framework?

TEN is a source-available framework for real-time multimodal conversational AI.

Its examples include a low-latency, real-time voice assistant over RTC or WebSocket that you can extend with memory and voice activity detection; our listing also notes the TEN Agent demo.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: agent.theten.ai.
