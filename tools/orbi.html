What is Orbi?

Orbi is an open-source software factory for GitHub repositories that turns labelled GitHub Issues into reviewed, merged pull requests and tagged releases. When a maintainer adds the ai-ready label to an Issue, Orbi spins up an isolated git worktree, runs a coding agent (such as Claude Code or Codex) to implement the change and open a pull request, and then launches a separate, independent AI review session with fresh context to verify every acceptance criterion and repair failing checks.

Rather than letting the implementation agent grade its own work, Orbi enforces a six-point merge gate—requiring an explicit reviewer verdict, satisfied acceptance criteria, green CI checks, a clean branch and an exact commit-SHA match between the reviewed revision and the merge target. Teams can self-host Orbi for free with Docker or Node.js 22+ using their own model keys, or use Orbi Cloud with a GitHub App install.

Sources: orbi.build, orbi.build/pricing, github.com/orbi-build/orbi and our directory listing, checked 2026-11-04.

Who is Orbi for?

Engineering teams and solo maintainers on GitHub who want an automated issue-to-PR-to-release pipeline where a separate AI review session checks acceptance criteria and CI before any merge happens.

Pros and cons

Pros

  • Implementation and review are separate sessions. The listing describes a six-point merge gate: reviewer verdict, acceptance criteria, green CI, a clean branch, and an exact commit SHA.
  • Self-hosting is free under AGPL-3.0 or the Sustainable Use License, with your own model keys, via Docker or Node.js 22+.
  • Orbi Cloud includes 3 merged deliveries with no card, then Solo and Pro on the pricing page we cite.

Cons

  • Cloud Solo is $24 a month and Pro is $66 a month, both billed yearly ($290 and $790), for 1 and 5 repos.
  • Work starts from GitHub labels (ai-ready, and ai-release for a tagged release). No label, no run.
  • Self-hosting still needs your own model keys. The app does not include a model.

Setup

  1. Self-host with Docker or Node.js 22+ (SQLite and local git worktrees), or install the Orbi Cloud GitHub App.
  2. Add the ai-ready label to an issue to start an isolated worktree, a pull request, and the separate review session.
  3. Let the six-point gate finish before you expect a merge. Apply ai-release when you want a tagged GitHub Release.
  4. Read the official pricing page linked from the listing before you pick Solo or Pro.
