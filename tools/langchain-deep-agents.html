What is LangChain Deep Agents?

Deep Agents is LangChain's open-source agent harness: an opinionated agent that runs out of the box, with defaults tuned for long-horizon, multi-step work. You can extend, override or replace any piece without forking.

It works with any LLM that supports tool calling, is built on LangGraph for streaming, persistence and checkpointing, and has tracing, evaluation and deployment through LangSmith. Sub-agents with isolated context windows and a pluggable filesystem are built in.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: docs.langchain.com/deepagents.

Developers who want a ready-made harness for long-running agents with sub-agents, while keeping the option to customize everything.
