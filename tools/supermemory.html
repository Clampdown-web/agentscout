About Supermemory

Supermemory is listed in our memory & RAG category and is aimed at builders. Memory and context engine for agents with an API, app and MCP server, which can also run fully locally. Pricing, as the maker states it: Open source + cloud. Maturity: Mature. We last checked the official link on 2026-10-18.

What is Supermemory?

Supermemory is a memory and context engine for AI. It learns from conversations, extracts facts, builds user profiles, handles updates and contradictions, and forgets expired information, so an AI keeps context between conversations.

It combines memory with full RAG, connectors (Google Drive, Gmail, Notion, OneDrive and GitHub) and extractors for PDFs, images, video and code. It can give coding tools such as Claude Code, Cursor, Codex and OpenCode persistent memory, and can be self-hosted.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: supermemory.ai.

Who is Supermemory for?

Developers adding long-term memory and personalization to AI apps or agents, and people who want their coding assistants to remember past work.
