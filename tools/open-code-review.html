What is Open Code Review?

Open Code Review is an AI-powered code review CLI. It began as Alibaba Group's internal AI code review assistant and was later released as open source.

It reads Git diffs and sends changed files to a configurable LLM through an agent that can read full files and search the codebase, then writes structured review comments with line-level precision. An ocr scan command reviews whole files for audits.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: open-codereview.ai.

Who is Open Code Review for?

Engineering teams that want automated, line-level AI code reviews on their own model endpoint, run from the command line or CI.
