    MemOS is listed in our memory & RAG category and is aimed at builders. Memory operating system for LLMs and agents with persistent memory and retrieval. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

    What is MemOS?

    MemOS is a memory operating system for LLMs and AI agents that unifies storing, retrieving and managing memory, giving agents persistent memory and the ability to grow.

    It can connect to DeepSeek Harness, adding automatic recall, background capture, hybrid retrieval and a local Memory Viewer.

    Sources: the official README and our directory listing, checked 2026-10-18. Official site: memos.openmem.net.
