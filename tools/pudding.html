What is Pudding?

Pudding is a desktop AI workspace from Teatak for macOS and Windows 11 where each task has its own conversation, model selection, file and shell tools, and built-in browser tab. Instead of locking you into a subscription, Pudding connects to your own API keys—across Claude, GPT, Gemini, DeepSeek, Qwen, Kimi, GLM and OpenRouter—or runs locally through Ollama with no Teatak account required.

Inside a project, the agent can read and edit local files with inline diff previews, run terminal commands, control its built-in browser or attach to your existing Chrome session, draft Markdown documents and typed data tables in Studio, schedule recurring tasks, delegate parallel subtasks to separate models, and load custom Skills and MCP plugins. Every tool call appears in the conversation and respects per-project permission modes (Ask, Auto or Full access).

Sources: pudding.teatak.com and our directory listing, checked 2026-10-24.

Who is Pudding for?

Developers, researchers and power users on macOS or Windows 11 who want a free bring-your-own-key or local-Ollama desktop workspace combining file editing, browser automation, Studio tables and MCP tools. Note that the Windows release currently omits local desktop GUI control, camera capture and voice dictation.

  • Status: Active desktop app for macOS (Apple Silicon macOS 14+, Intel macOS 15.5+) and Windows 11

Key features

  • Bring-your-own-key support for Claude, OpenAI, Gemini, DeepSeek, Qwen, Kimi, GLM and OpenRouter plus local Ollama models.
  • Built-in browser tab and Chrome extension bridge so tasks can open pages, click elements and extract structured data.
  • Studio workspace for co-editing Markdown documents, typed tables with CSV import/export, and live HTML/JS widgets.
  • Parallel subtask delegation, cron-like scheduled tasks, custom Skills and MCP plugin support with Ask/Auto/Full permission controls.

Is Pudding free?

Yes. Pudding has a free option (Desktop app), according to its pricing page (checked Oct 24, 2026).

How much does Pudding cost?

As of Oct 24, 2026, Pudding's official pricing page lists: Desktop app: Free. Third-party model APIs and external services charge their own usage rates separately.

Is Pudding open source?

Yes. Pudding is released under the Apache-2.0 licence (agent core); desktop app free for personal and commercial use, according to its GitHub repository.

Does Pudding charge a subscription?

No. Pudding is free for personal and commercial use with no Teatak account required, and its agent core is licensed under Apache-2.0. You only pay your chosen model provider if you use paid API keys.

How do macOS and Windows versions of Pudding differ?

Both macOS and Windows 11 support multi-model chat, file and command tools, the built-in browser, Studio, scheduled tasks and MCP plugins. Local computer GUI control, camera capture and voice dictation are currently macOS-only.
