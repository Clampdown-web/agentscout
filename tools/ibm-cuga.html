About IBM CUGA

IBM CUGA is listed in our frameworks category and is aimed at builders. IBM Research's configurable generalist agent (CUGA) for enterprise web and API tasks, with a live demo on Hugging Face Spaces. Pricing, as the maker states it: Open source. Maturity: Active. We last checked the official link on 2026-10-16.

What is IBM CUGA?

IBM CUGA is an enterprise agent harness for sovereign, policy-controlled automation from IBM Research. It turns business requests into actions across your applications, APIs and documents.

You can deploy it in a private cloud or an air-gapped environment, enforce fine-grained execution policies and use open models on infrastructure you control. Our listing notes a live demo on Hugging Face Spaces.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: huggingface.co/spaces/ibm-research/cuga-agent.

Who is IBM CUGA for?

Enterprises that need agents for web and API tasks under strict policy and data-sovereignty requirements.

Key features
