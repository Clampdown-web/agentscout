Maturity: Active. We last checked the official link on 2026-10-19.

    What is Immich?

    Immich is a high-performance, self-hosted photo and video management app, an open-source alternative to cloud photo services. You run the server yourself and use the web app or the iOS and Android apps, which back up your library automatically, including in the background.

    It uses machine learning for facial recognition and clustering and for smart search by objects, faces, metadata and CLIP descriptions, and adds albums and shared albums, partner sharing, a global map, memories, RAW and Live Photo support, multi-user accounts and OAuth sign-in.

    Sources: the official README and our directory listing, checked 2026-10-19. Official site: immich.app.

    Who is Immich for?

    People and families who want a private, self-hosted replacement for Google Photos or iCloud Photos with automatic phone backup and AI search.

    Is Immich free?

    Immich's pricing, as the maker states it: Free and open source (AGPL-3.0), self-hosted. Check the official site for current plans.

    Is Immich open source?

    Yes. Immich is released under the GNU Affero General Public License v3.0, according to its GitHub repository.

    Can I try Immich before installing it?

    Yes. The public demo at demo.immich.app uses the login demo@immich.app with the password demo, and the mobile app can point to the same server URL.

    Does Immich replace a backup?

    No. The project warns users to always follow a 3-2-1 backup plan for their photos and videos.
