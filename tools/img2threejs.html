About img2threejs

img2threejs is listed in our 3D & concept art category and is aimed at builders. img2threejs is an open-source agent workflow that looks at a reference image and rebuilds the object in it as a procedural Three.js model written purely in code. Each model goes through quality gates before it is accepted, comes out ready to animate, and is built in a token-efficient way, so a coding agent can turn photos or concept art into live 3D scenes without any mesh files. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-24.

What is img2threejs?

img2threejs is an Apache-2.0 agent skill that takes one reference image and writes a THREE.Group factory in TypeScript. The README says the object is rebuilt from primitives, procedural shaders and generated geometry, with pivots, sockets and colliders so it can be animated. It runs under Hermes, Claude Code, Codex or OpenCode, and uses whatever image reading or browser tool that host already has.

The pipeline classifies the subject as object, character or hybrid, inventories small details, and walks passes from blockout to optimization. Deterministic Python checks gate the result. The honesty section says a single image cannot show hidden sides or guarantee exact geometry, that unseen faces are mirrored rather than invented with confidence, and that characters are stylized reconstructions, not photoreal likeness. Unity, Unreal, auto-rigging and a web UI are on the roadmap, not the current install.

Sources: github.com/img2threejs/img2threejs, github.com/img2threejs/img2threejs/blob/main/README.md, img2threejs.io and our directory listing, checked 2026-11-09.

Who is img2threejs for?

Developers who want a coding agent to turn one photo or concept image into Three.js code they can read, instead of a mesh file.

Pros and cons

Pros

  • The output is code in the repo, with a hierarchy meant for animation, not a baked mesh you cannot diff.
  • The README tells the agent to say when the image is not enough, instead of claiming a perfect match.
  • Python gates the build. The README says model tokens are spent on visual judgment and code, not on the checks.

Cons

  • One photo does not reveal the back of an object. The README says hidden sides are inferred by mirroring and may be approximate, stylized or low-poly.
  • Characters are stylized. A projection path for likeness is opt-in and still asks for more views when confidence is low.
  • Roadmap items such as Unity and Unreal exporters, auto-rigging and a web UI are not in the current quick start.
  • You bring the coding agent and its model. The skill does not include one.

Setup

  1. Install Node.js 18 or newer, Git, and Python 3.10 or newer, and use Claude Code, Codex, OpenCode or Hermes.
  2. Run npx --yes img2threejs@latest install, then npx --yes img2threejs@latest doctor. The README says managed means the agent has the skill.
  3. Hermes also needs the symlink in the README into the active profile's skills directory. Restart the agent after installing.
  4. Install only the plugins you need. Give the agent one reference image. Read the honesty section before you expect a photoreal person.
