Claude Code Templates is an open catalog and CLI of more than 1,980 Claude Code components (skills, subagents, slash commands, hooks, MCP servers and settings) at aitmpl.com, where you preview each file and combine components into one npx install that merges with your existing configuration. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-11-09.

What is Claude Code Templates?

Claude Code Templates is an MIT-licensed catalog and CLI of Claude Code components. The README says the catalog at aitmpl.com holds more than 1,980 components and that you can preview every file a component writes before you install it. The CLI merges into the configuration you already have instead of replacing it. A table in the README breaks the catalog down as 918 skills, 422 agents, 288 commands, 119 MCPs, 80 settings, 63 hooks, 50 mods, 18 loops, 14 templates, 11 sandboxes and 1 plugin, and points at dashboard/public/counts.json for live counts.

npx claude-code-templates@latest browses and installs with no global install. One command can pass --skill, --agent, --command and --mcp together. --yes skips the confirmation. Three local tools are documented: --analytics on localhost:3333, --chats on localhost:9876, and --health-check. The README says the two dashboards listen on 127.0.0.1 only because they serve conversation history. A list of flags removed in 1.31.0 is in the README.

Sources: github.com/davila7/claude-code-templates, github.com/davila7/claude-code-templates/blob/main/README.md, aitmpl.com, docs.aitmpl.com and our directory listing, checked 2026-11-09.

Who is Claude Code Templates for?

Claude Code users who want to preview and install skills, agents, hooks, MCP servers or settings from one catalog, without hand-copying each file.

Pros and cons

Pros

  • The CLI merges existing configuration. The README says it does not overwrite it.
  • Every component page shows the install command, and --search finds one from the terminal.
  • Pull requests are checked by Claude Code's plugin validator and scanned by NVIDIA SkillSpector, according to the README.

Cons

  • The dashboards read your conversation history. They are bound to localhost. Reaching --chats from another machine means an SSH port forward you set up yourself.
  • The README's component counts are a snapshot. It says live counts are in dashboard/public/counts.json, so the table can go stale.
  • Mods need Claude Code 2.1.287 or later, and the plugin example needs 2.1.288 or later.
  • Flags removed in 1.31.0 still print a replacement when you run them. They no longer do the old job.

Setup

  1. Run npx claude-code-templates@latest to browse, or add --skill, --agent, --command or --mcp and the component id from the catalog.
  2. Add --yes only when you already know the component. The default asks you to confirm.
  3. Open docs.aitmpl.com for the CLI reference. Use --health-check to diagnose the local Claude Code install.
  4. Leave --analytics and --chats on localhost. The README's SSH example is ssh -L 9876:localhost:9876 if you need the chat browser from another device.
