    What is LTX-2?

    LTX-2 is Lightricks' open-weights audio-video foundation model, a diffusion transformer that generates synchronized video and sound in one model. The repository is the official Python inference package and LoRA trainer, with pipelines for the LTX-2.5 checkpoints published on Hugging Face.

    It offers several speed and quality modes, latent upscaling and distilled variants. The full model download is large (around 66 GB for the main set), so it is aimed at people with serious GPUs; Lightricks also offers API access.

    Sources: the official README and our directory listing, checked 2026-10-20. Official site: github.com/Lightricks/LTX-2.

    Who is LTX-2 for?

    Developers and studios who want to run or fine-tune an open audio-video generation model on their own hardware.
