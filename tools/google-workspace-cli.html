About Google Workspace CLI

Google Workspace CLI is listed in our MCP & infra category and is aimed at builders. Official Google Workspace command-line tool for Drive, Gmail, Calendar, Docs and more, usable by agents. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

What is Google Workspace CLI?

Google Workspace CLI (gws) is one CLI for all of Google Workspace, built for humans and AI agents: Drive, Gmail, Calendar and every Workspace API, with structured JSON output and 40+ agent skills.

It reads Google's Discovery Service at runtime to build its commands dynamically. Its README states it is not an officially supported Google product.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: developers.google.com/workspace.

Who is Google Workspace CLI for?

Developers and agents that need to automate Google Workspace from the command line.
