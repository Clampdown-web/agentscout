About CocoIndex

CocoIndex is listed in our MCP & infra category and is aimed at builders. Incremental data engine for keeping agent context and indexes fresh. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

What is CocoIndex?

CocoIndex is an incremental data engine that turns codebases, meeting notes, inboxes, Slack, PDFs and videos into live, continuously fresh context for AI agents and LLM apps.

It processes only what changed, runs in parallel by default and is declarative in Python.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: cocoindex.io.

Who is CocoIndex for?

Teams whose agents need context that stays current as source data changes.
