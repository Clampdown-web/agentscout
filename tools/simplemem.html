      SimpleMem alternatives

      Other memory & RAG tools in our directory. See all memory & RAG tools →

      Hindsight

      Agent memory system that stores experiences and learns from them so agents improve over time.

      Activeloop

      Deep Lake, a multimodal database for AI that stores vectors, images, text and video so agents and RAG apps can search and retrieve them.

      Honcho

      Memory library and service for building stateful agents that remember users.

      Qdrant MCP Server

      Official Qdrant MCP server that lets agents store and retrieve memories and documents in the Qdrant vector database.

      Headroom

      Library, proxy and MCP server that compresses tool outputs, logs, files and RAG chunks locally before they reach the LLM, cutting tokens for coding agents.

      Mem0

      Mem0 is an open-source memory layer for AI agents that extracts facts from conversations in a single add-only pass, links entities across memories and retrieves them in later sessions, with an Apache-2.0 SDK and a managed platform.
