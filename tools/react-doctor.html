What is React Doctor?

React Doctor, from Million Software, runs deterministic checks on React code written by you or your coding agent and reports issues in state and effects, performance, architecture, security, accessibility and maintainability. It supports projects built with Next.js, Vite, Astro, TanStack, React Native and Expo.

You run a scan with npx react-doctor@latest, install it as a skill so Claude Code, Cursor, Codex or OpenCode can find and fix issues, or add it to CI to report issues each pull request introduces and block merges at a chosen severity. It can also record Chrome DevTools performance traces while you use a running app.

Sources: the official README and our directory listing, checked 2026-10-19. Official site: react.doctor.

Does React Doctor collect data?

The CLI collects crash reports and anonymous usage data; opt out with npx react-doctor@latest --no-telemetry.
