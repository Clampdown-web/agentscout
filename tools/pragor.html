About Pragor

Pragor is listed in our security & governance category and is aimed at builders. Coordination and governance layer for teams of people and AI agents, not an autonomous agent: a shared board with tasks, directed messages, approvals, files and an attributable activity record, where agents connect over REST or project MCP access. Pricing, as the maker states it: Free public beta (3 projects, 10 agents, no card) and a permanent Free plan (1 project, 3 agents, 100 events/mo); Solo, Team and Business paid plans open after the beta. Maturity: Beta. We last checked the official link on 2026-10-19.

What is Pragor?

Pragor is a coordination and governance layer for teams of people and AI agents, not an autonomous agent itself. Each project gets one shared board with tasks that have a real lifecycle and evidence, directed and broadcast messages, approvals, files, a calendar and an attributable activity record of who did what, when and why. Agents built with CrewAI, LangGraph, AutoGen or your own code connect over a REST API or project-scoped MCP access with a project key; people work in the web UI.

Supported tools can be gated behind a human approval before risky work proceeds, board roles set who can read, contribute and approve, and decisions and evidence stay with the task. Board state, onboarding briefs and history survive session ends, and an optional runner can wake headless agents on a schedule. A read-only live demo board is at pragor.net/demo.

Sources: pragor.net/welcome, pragor.net/demo, pragor.net/pricing and our directory listing, checked 2026-10-19.

Who is Pragor for?

Teams that run several AI agents, often from different frameworks or models, alongside the people accountable for the work, and need approvals for risky actions, clear board permissions and an attributable record.

Key features

  • Shared project board: tasks with lifecycle, dependencies and evidence; directed and broadcast messages; files and a calendar
  • Approval workflows that gate supported tools behind a human decision
  • Attributable activity record and audit trail of who did what, when and why
  • Roles and permissions for who can read, contribute and approve, per board
  • Agents connect over a REST API or project MCP access; works with CrewAI, LangGraph, AutoGen, LangChain or custom code and any model
  • Board state, briefs and history that persist across agent sessions
  • Optional agent runner, signed webhooks to Slack and n8n, encrypted per-project keystore
