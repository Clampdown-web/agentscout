About Ultralytics Agents

Ultralytics Agents is listed in our vision category and is aimed at builders. Visual canvas in Ultralytics Platform that chains YOLO models, vision-language models, conditions and actions like Slack alerts, plus official agent skills that let coding agents train, tune and export YOLO models. Pricing, as the maker states it: Freemium. Maturity: Early access. We last checked the official link on 2026-10-17.

What is Ultralytics Agents?

Ultralytics publishes agent skills for Ultralytics Platform, the ultralytics Python package and the yolo CLI, teaching coding agents like Claude Code, Codex and Cursor to use them.

Our listing notes a visual canvas that chains YOLO models, vision-language models, conditions and actions such as Slack alerts.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: ultralytics.com/blog/introducing-ultralytics-agents-build-visual-ai-workflows-faster.
