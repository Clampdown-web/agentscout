What is Mobilerun?

Mobilerun is an open-source framework for controlling Android and iOS devices with LLM agents.

It gives agents mobile-native tools to inspect UI state, understand screenshots, tap, swipe, type and plan multi-step workflows, through a CLI or Python API.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: mobilerun.ai/framework.
