Pricing, as the maker states it: Open source (MIT). Maturity: Active. We last checked the official link on 2026-10-18.

What is skills.sh?

skills is Vercel Labs' open-source command-line tool for the open agent skills ecosystem: npx skills add owner/repo installs reusable skills (instructions plus supporting files) into coding agents such as OpenCode, Claude Code, Codex, Cursor and 75 more.

It can pull skills from GitHub, GitLab, Azure Repos, any git URL or a local folder, install them globally or per project, and npx skills use generates a prompt for a single skill without installing it. The companion site skills.sh is a directory of skills with an install leaderboard.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: skills.sh.

Who is skills.sh for?

Developers who use one or more coding agents and want to install, share and update the same skills across all of them, including from private repositories.
