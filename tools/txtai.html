    What is txtai?

    txtai is an all-in-one open-source Python framework from NeuML for semantic search, LLM orchestration and language-model workflows. Its core is an embeddings database that combines sparse and dense vector indexes, graph networks and relational storage, so it works both as a vector search engine and as a knowledge source for RAG.

    On top of that it offers LLM pipelines (prompts, question answering, labeling, transcription, translation, summarization), workflows that chain them, and agents that connect embeddings, pipelines and workflows to solve problems on their own. It exposes web and Model Context Protocol (MCP) APIs, with bindings for JavaScript, Java, Rust and Go, and runs locally or scales out in containers.

    Sources: the official README and our directory listing, checked 2026-10-20. Official site: neuml.github.io/txtai.
