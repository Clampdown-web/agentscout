    About NVIDIA OpenShell

    NVIDIA OpenShell is listed in our sandboxes & code execution category and is aimed at builders. Sandboxed runtime for autonomous agents with declarative YAML policies on file, network and credential access. Pricing, as the maker states it: Open source (Apache 2.0). Maturity: Active; part of newly announced Open Agent Safety Platform. We last checked the official link on 2026-10-14.

    What is NVIDIA OpenShell?

    NVIDIA OpenShell is a safe, private runtime for fleets of autonomous AI agents. It lets agents read files, install packages, call APIs and use credentials without unrestricted access to your data, secrets or network.

    Policies are declared in YAML for file, network and credential access. Version 0.1.x brought a stable release cadence, new isolation primitives and new APIs. It is Apache 2.0 licensed.

    Sources: the official README and our directory listing, checked 2026-10-18. Official site: docs.nvidia.com/openshell/latest.
