GAL FAQ

What is GAL?

GAL (General Agent Loop & Executor) is a self-contained agent runtime shipped as a single binary for Linux, macOS and Windows that you drive from a CLI, desktop app, browser, chat apps or HTTP, with a kernel-enforced sandbox and scoped one-time authorizations so every agent step is contained and auditable without Docker, Python or Node.

How much does GAL cost?

GAL's pricing, as the maker states it: Open source. Open-source tools are free to use, though you may still pay for model API usage or a hosted plan. Check the official site for current plans.
