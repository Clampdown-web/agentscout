What is Verdent?

Verdent is an agentic coding suite with parallel agents, Plan Mode, bring-your-own-key and Eco Mode. It combines AI code review with agent orchestration.

It is available for VS Code, JetBrains, Mac and Windows.

Sources: the official site and our directory listing, checked 2026-10-18. Official site: verdent.ai.
