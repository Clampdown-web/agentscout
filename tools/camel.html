What is CAMEL?

CAMEL is one of the first multi-agent frameworks, for building role-playing agents and large agent societies. It is run by an open-source community dedicated to finding the scaling laws of agents by studying them at large scale.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: docs.camel-ai.org/get_started/introduction.
