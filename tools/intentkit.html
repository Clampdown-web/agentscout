IntentKit is listed in our frameworks category and is aimed at builders. Self-hosted cloud cluster for running a team of collaborating AI agents. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

What is IntentKit?

IntentKit is an open-source, self-hosted cloud agent cluster that manages a collaborating team of AI agents for you.

It takes the cloud-native path rather than local-first: agents run in the cloud with minimal local resources and little maintenance.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: intentcat.com/docs.

Who is IntentKit for?

Teams who want a team of agents running on their own cloud infrastructure rather than on a laptop.
