About Apify MCP Server

Apify MCP Server is listed in our MCP & infra category and is aimed at builders. Apify's MCP server giving agents access to thousands of scrapers for social media, search and maps. Pricing, as the maker states it: Open source + cloud. Maturity: Mature. We last checked the official link on 2026-10-16.

What is Apify MCP Server?

The Apify MCP Server, at mcp.apify.com, lets AI agents extract data from social media, search engines, maps, e-commerce sites and other websites using thousands of ready-made scrapers, crawlers and automation tools from Apify Store.

It supports OAuth, so you can connect from clients like Claude.ai or VS Code with just the URL.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: github.com/apify/apify-mcp-server.

Who is Apify MCP Server for?

Developers who want agents to collect web data without writing scrapers.
