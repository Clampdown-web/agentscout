    TypeSafe Jev

    Jev is TypeSafe's System One decision model, built for the small decisions inside software and agents. You send a state and typed questions (choice, score and more) and get typed answers with probabilities back instead of free-form text, so code can branch on them directly to route, classify, score or rank options. Agents can use it to settle narrow calls cheaply and save the larger LLM for open-ended work. Available through TypeSafe's API, Python and JavaScript SDKs, an agent skill, and OpenRouter.

    Tura

    Tura is an open-source agent runtime focused on cutting LLM spending. It manages the context an agent sends to the model so tasks use far fewer tokens, while keeping the finished results, execution evidence and benchmark scores auditable, which makes it aimed at teams running agents at scale.

    Grok Bot Jev Router

    Grok Bot Jev Router is an open-source Python reference router that puts TypeSafe Jev in front of Grok Bot as a cheap decision layer. Before expensive research, browser, retry or subagent work, Jev classifies the request and returns an explicit action such as reuse a cached result, stop a failing retry, cap research, run a deterministic step, or ask a human. It starts in shadow mode that only logs decisions, has an active mode for a Grok Bot skill that honors them, and includes a kill switch. It never sends, pays or deletes anything itself.

    CocoIndex

    Incremental data engine for keeping agent context and indexes fresh.

    Manifest

    Open-source LLM gateway that routes each request from agents and apps to the right model across API keys, subscriptions and local models, with spend tracking.

    Nango

    Integration platform that connects products and AI agents to 1,000+ APIs with managed auth, syncs and tool calls.
