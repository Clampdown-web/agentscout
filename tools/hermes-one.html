    What is Hermes One?

    Hermes One is a community-maintained, open-source desktop app for installing, configuring and chatting with Hermes Agent, Nous Research's self-improving AI assistant. Instead of managing the command line, it walks you through install (using the official Hermes install script), provider setup and daily use, and can also connect to a remote Hermes API server.

    It adds a streaming chat UI with token and cost tracking, 22 slash commands, searchable session history, separate profiles, a memory and persona editor, 14 toolsets, scheduled tasks with a cron builder, and messaging gateways, with providers from OpenRouter, Anthropic, OpenAI, Gemini, xAI and Nous Portal to local Ollama, LM Studio, vLLM and llama.cpp. The maker notes it is in active development.

    Sources: the official README and our directory listing, checked 2026-10-20. Official site: hermesone.org.

    Is Hermes One free?

    Hermes One's pricing, as the maker states it: Free and open source (MIT). Check the official site for current plans.

    Is Hermes One open source?

    Yes. Hermes One is released under the MIT License, according to its GitHub repository.

    Is Hermes One official?

    No. It is a community-maintained app that uses the official Hermes Agent install script; Hermes Agent itself is made by Nous Research.

    How do I install Hermes One?

    Download the desktop app from hermesone.org or GitHub Releases; the Windows installer is not code-signed, so SmartScreen warns on first launch.
