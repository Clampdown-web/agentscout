What is Google ADK?

Google's Agent Development Kit (ADK) is an open-source, code-first Python framework for building, evaluating and deploying AI agents. It applies software-development principles to agent creation, from simple tasks to complex systems.

ADK is optimized for Gemini but is model-agnostic, deployment-agnostic and compatible with other frameworks. It includes a graph-based workflow runtime for complex agent workflows.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: adk.dev.

Who is Google ADK for?

Python developers building agents, particularly on Google Cloud or with Gemini, who want a structured, code-first framework.
