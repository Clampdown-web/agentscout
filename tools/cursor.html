About Cursor

Cursor is listed in our coding category and is aimed at people who want a ready-to-use product. AI code editor with an agent mode and background agents. Pricing, as the maker states it: Free tier + paid plans. Maturity: Mature. We last checked the official link on 2026-10-14.

What is Cursor?

Cursor is an AI code editor built around coding agents. You can hand off tasks to its agents, and our listing notes an agent mode and background agents.

Its pricing page now sells Cursor together with X and Grok subscriptions: the $8 Plus plan uses only Grok models, while Premium and higher add cloud agents and automations, code hosting with AI code reviews, and third-party models at API list price.

Sources: the official site and our directory listing, checked 2026-10-18. Official site: cursor.com.

Who is Cursor for?

Developers who want an AI-first code editor with built-in agents rather than a terminal tool.

Key features

  • AI code editor with coding agents
  • Agent and Chat requests (limited on the Free plan)
  • Cloud agents and automations (Premium and up)
  • Code hosting and AI code reviews (Premium and up)
  • Third-party models at API list price, billed separately by usage
  • Teams plans with usage analytics, team-wide privacy settings and SCIM seat management (Enterprise)

Cursor pricing

  • Free: $0/mo · limited agent and Chat requests
  • Plus: $8/mo · shared AI usage pool; only Grok models
  • Premium: $30/mo · 4x Plus usage, latest Grok models, cloud agents, AI code reviews, third-party models at API list price
  • Super: $100/mo · 15x Plus usage, priority model access
  • Ultra: $200/mo · 50x Plus usage
  • Teams: $30+/user/mo
  • Enterprise: Custom

Cursor's plans are now combined with X/Grok subscriptions. Third-party model usage in Cursor is billed separately by usage.

Source: official pricing page, checked Oct 18, 2026. Prices change; check the source before buying.
