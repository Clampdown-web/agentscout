What is code-review-graph?

code-review-graph builds a local knowledge graph of your codebase with Tree-sitter, keeps it updated incrementally, and serves compact review context to AI coding tools over MCP, so the assistant reads only the files a change touches.

Its install command detects your AI coding tools and writes an MCP server entry for each, with support for Codex, Claude Code, Cursor, Windsurf, Zed, Continue, OpenCode, Gemini CLI, Copilot and others. It requires Python 3.10 or later and also ships a GitHub Action.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: code-review-graph.com.

Developers using AI coding assistants on large codebases who want more precise, cheaper code reviews.
