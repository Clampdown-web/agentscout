About BrowserTools MCP

BrowserTools MCP is listed in our MCP servers category and is aimed at builders. MCP server that lets Cursor and other agents read browser console logs and network activity. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

What is BrowserTools MCP?

BrowserTools MCP gives AI coding agents eyes on the browser. It streams console output, network activity, screenshots and Lighthouse audits from your real Chrome session to MCP clients such as Cursor, Claude Code, Windsurf, Cline, Zed and Gemini CLI.

Version 2.0 is a rewrite that runs as one process.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: agentdesk.ai.

Who is BrowserTools MCP for?

Web developers who want their coding agent to see browser errors and network calls while debugging.
