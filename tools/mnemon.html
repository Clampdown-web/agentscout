    Self-hosted AI gateway that puts hundreds of model providers behind one endpoint for Claude Code, Codex, Cursor and others, with quota-aware fallback and MCP/A2A support.

    opencodex

    A local provider proxy that lets OpenAI Codex (CLI, app and SDK) and Claude Code run on other model providers such as Claude, Gemini, Grok, DeepSeek or local Ollama models.

    Weave Router

    An open-source LLM router for Claude Code, Codex and other coding agents that sends each request to the cheapest model that still meets your quality bar, cutting model spend.

    Dataagent

    DataFoundry is an open-source AI workbench for data analysis, unifying data sources, knowledge, tools, and agent runtime into a governed workspace for interactive analytics

    Artil

    Artil gives each AI agent its own identity: a real email inbox on Artil's domain or yours, a dedicated US or UK SMS number on the Pro plan, and credential storage for API keys, tokens and 2FA codes it can save from a QR code. Agents use the artil CLI or MCP server to send and read email and texts, sign up for services, handle verification codes and message teammates and other agents on Slack, Telegram and email from one team directory, and Claude Code sessions can be woken by incoming messages. Works with ChatGPT, Claude, Claude Code, Codex, Hermes, OpenClaw and any MCP client; free to start.
