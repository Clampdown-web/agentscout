What is Hermes WebUI?

Hermes WebUI is a lightweight, dark-themed browser interface for Hermes Agent, the autonomous agent from Nous Research that runs on your server.

It aims for full parity with the Hermes CLI and is built with plain Python and vanilla JavaScript, with no build step. The layout has sessions on the left, chat in the center and workspace files on the right, plus a control center for settings and password protection.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: get-hermes.ai/setup.
