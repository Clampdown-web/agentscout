What is Open SWE?

Open SWE is LangChain's open-source asynchronous coding agent, built on Deep Agents. It investigates a codebase, implements changes, validates them and delivers a pull request, and it can review PRs, monitor CI and respond to feedback.

Its README says it is under active development with breaking changes, is not accepting issues or contributions, and that deploying it as is requires access to the Managed Deep Agents private beta; otherwise LangChain suggests forking and adapting it.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: github.com/langchain-ai/open-swe.

Teams experimenting with background coding agents that take work from issues and return pull requests, and who are comfortable adapting early-stage code.
