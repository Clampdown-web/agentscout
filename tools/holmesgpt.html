What is HolmesGPT?

HolmesGPT is an open-source AI agent for investigating production incidents and finding root causes. It works with Kubernetes, VMs, cloud providers, databases and SaaS platforms, and is a Cloud Native Computing Foundation sandbox project, originally created by Robusta.Dev with major contributions from Microsoft.

A newer Operator Mode runs it in the background around the clock to spot problems before customers notice and message you in Slack with the fix; with the GitHub integration it can also open pull requests.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: holmesgpt.dev.
