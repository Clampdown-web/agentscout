What is NeverApply?

NeverApply is an AI job-search platform and hosted remote MCP server (neverapply.co/mcp) that connects your live job hunt directly to Claude, ChatGPT, Codex, Cursor, VS Code, Gemini CLI, Kiro, Grok and other MCP-compatible assistants. Rather than answering career questions from generic guesses, a connected assistant reads your live NeverApply shortlist, resume fit scores, profile facts and application tracker across an index of 919,000+ open roles from 37,000+ companies across 69 countries.

Authentication uses OAuth 2.1 with PKCE and dynamic client registration—no personal API keys or bearer tokens in config files—with granular permission scopes for reading (mcp:read), profile and document preparation (mcp:write), and submitting applications (mcp:apply). When you ask your assistant to apply to a role, NeverApply enforces explicit human approval for each named job and company, handles employer screening questions without guessing personal facts, and dispatches the application through its browser agent.

Sources: neverapply.co/features/mcp, neverapply.co/pricing, github.com/kasovy/neverapply-mcp and our directory listing, checked 2026-11-04.

Who is NeverApply for?

Job seekers and builders who want Claude, ChatGPT, Cursor, Codex, Gemini CLI or Grok to search live job matches, track quiet applications, tailor resumes, build interview prep and submit approved applications via MCP.

Pros and cons

Pros

  • The hosted MCP endpoint is https://neverapply.co/mcp, with OAuth 2.1 and PKCE, so the client config does not hold a personal API key.
  • Applying requires the mcp:apply scope, credits, and an explicit confirmation of the job title and company. Screening answers are not guessed.
  • The Free tier is $0: 10 lifetime auto-applies, a 5-matches-a-day preview, and 50 MCP reads a day per client.

Cons

  • Those free caps are the whole free plan. Pro is $29 a month (150 apply credits) and Max is $49 a month (450).
  • The job index is the maker's figure (919,000+ roles on the listing). It is not a count we re-crawled.
  • An assistant can prepare a resume and a cart of roles, but it cannot submit a named application until you confirm that job.

Setup

  1. Add https://neverapply.co/mcp as a remote Streamable HTTP MCP server in Claude, Cursor, Codex, ChatGPT, VS Code, Gemini CLI, Kiro, or Grok.
  2. Complete the browser OAuth sign-in and grant mcp:read, mcp:write, or mcp:apply.
  3. Or install the MIT-licensed plugin and skills from the kasovy/neverapply-mcp repository.
  4. Confirm the plan's apply credits on neverapply.co/pricing before you expect submissions.

Key features

  • Hosted Streamable HTTP MCP server (https://neverapply.co/mcp) with OAuth 2.1 + PKCE sign-in and granular read, edit and apply permission scopes.
  • 15 MCP tools spanning job search and match scoring, application pipeline tracking, profile updates, background resume tailoring, interview prep and human-approved job applications.
  • Live job index covering 919,000+ verified open roles across 37,000+ hiring companies and 69 countries, with 30-day expiry and dead-link pruning.
  • MIT-licensed plugin and skill repository (kasovy/neverapply-mcp) providing ready-made manifests and guided skills (find-jobs, apply-to-jobs, track-applications) for Claude Code, Codex, Cursor, Gemini CLI, Kiro and Grok.

NeverApply MCP server

  • Endpoint: https://neverapply.co/mcp
  • Transport: Streamable HTTP (remote)
  • Authentication: OAuth 2.1 with PKCE and dynamic client registration (scopes: mcp:read, mcp:write, mcp:apply; no API key needed)

Tools

  • search_jobs: Search open roles by title, location, remote scope, salary floor or recency (up to 20 results per call).
  • get_matches: Retrieve your daily curated job matches with match tiers and profile-to-listing fit reasons.
  • get_job: Read the full details and requirements for a specific job listing by listing_id.
  • get_profile: Read your candidate profile, completeness status, preferences and daily MCP budget allowance.
  • list_applications: List your tracked job applications filtered by stage or status (such as needs_answer, ready_to_send, stale, interview or offer).
  • get_application: Inspect a single application or browser run by application_id or run_id, including pending screening questions.
  • update_profile: Update your target roles, locations and career profile details.
  • upload_resume: Upload or update your resume in your NeverApply account.
  • save_answer: Save stated candidate facts and reusable answers for future applications.
  • tailor_resume: Generate a job-specific tailored resume variant in the background for a target listing_id (paid plan feature).
  • prepare_interview: Generate a role-specific interview preparation pack for an application_id or listing_id (paid plan feature).
  • send_feedback: Send user-stated feedback or issue reports directly to NeverApply.
  • apply_to_job: Queue or hold an application for a specific listing_id after explicit user confirmation of the job title, company and resume variant.
  • answer_screening_question: Submit user-chosen answers to employer screening questions on a held application run.
  • approve_application: Send or dismiss a held application run after explicit user confirmation.

Client config (Cursor, VS Code, Claude Code and other config-file clients):

{"mcpServers": {"neverapply": {"url": "https://neverapply.co/mcp"}}}
