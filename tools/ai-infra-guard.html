What is AI-Infra-Guard?

AI-Infra-Guard (A.I.G) is an AI red-teaming platform from Tencent Zhuque Lab.

It combines agent scanning, AI infrastructure vulnerability scanning, MCP server and agent-skill scanning, and jailbreak evaluation.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: tencent.github.io/AI-Infra-Guard.
