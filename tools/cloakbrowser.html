What is CloakBrowser?

CloakBrowser is a stealth Chromium build for browser automation. Instead of patching config or injecting JavaScript, it modifies fingerprints in Chromium's C++ source, so anti-bot systems see an ordinary browser.

It works as a drop-in replacement for Playwright and Puppeteer in Python and JavaScript, installs with pip or npm, and has a humanize option for human-like mouse, keyboard and scrolling. A free binary is available, with a paid Pro tier.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: cloakbrowser.dev.

Who is CloakBrowser for?

Developers whose scrapers or browser agents get blocked by bot detection and who already use Playwright or Puppeteer.
