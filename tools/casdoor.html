About Casdoor

Casdoor is listed in our MCP & infra category and is aimed at builders. Agent-first identity and access management with an MCP and agent gateway. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

What is Casdoor?

Casdoor is an open-source, self-hosted identity and access management platform: a single sign-on and authentication server with a web console. Our listing describes it as agent-first, with an MCP and agent gateway.

It speaks OAuth 2.0, OIDC, SAML 2.0, CAS, LDAP, SCIM 2.0, WebAuthn, TOTP/MFA and MCP, and connects to identity providers such as Google Workspace, Microsoft Entra ID and GitHub.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: casdoor.ai.

Who is Casdoor for?

Teams that need self-hosted SSO and access control for users and agents.
