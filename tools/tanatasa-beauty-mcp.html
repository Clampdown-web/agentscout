What is Tanatasa Beauty MCP?

Tanatasa Beauty MCP is a hosted Streamable HTTP Model Context Protocol server (tanatasa-shopping 1.0.0 at https://tanatasa.sg/mcp), public REST API (https://tanatasa.sg/agent/v1) and MIT-licensed CLI (@tanatasa/cli) for Tanatasa, a Singapore online retailer specializing in authentic Korean and Japanese skincare and beauty products. AI assistants can connect immediately with no API key or sign-in to search the live catalog, read product descriptions, ingredient lists and usage guides, and verify real-time stock and Singapore Dollar (SGD) pricing.

For shopping workflows, the server exposes ten MCP tools covering catalog discovery, guest or signed-in cart management, promo code quoting and checkout handoff, plus a read-only endpoint at https://tanatasa.sg/mcp/catalog with just search_products and get_product. Calling create_cart issues a private guest_token, and create_checkout locks the cart and returns a 1-hour checkout link on tanatasa.sg where the buyer enters a Singapore delivery address and completes payment via Stripe (with optional OAuth + PKCE scopes catalog:read, cart:write and orders:read for linked customer accounts).

Sources: tanatasa.sg/ai-agent-docs, github.com/tanatasa-beauty/tanatasa, tanatasa.sg/agent/v1/openapi.json and our directory listing, checked 2026-10-25.

Tanatasa Beauty MCP MCP server

  • Endpoint: https://tanatasa.sg/mcp
  • Transport: Streamable HTTP (remote; read-only catalog endpoint at https://tanatasa.sg/mcp/catalog)
  • Authentication: No API key required for catalog search, guest carts (X-Guest-Token / guest_token) and checkout links; optional OAuth 2.0 with PKCE for customer accounts (scopes: catalog:read, cart:write, orders:read)

Tools

  • search_products: Search the live Tanatasa skincare and beauty catalog by keyword, category, brand, availability or SGD price ceiling.
  • get_product: Fetch full product details by slug or UUID, including description, usage steps, ingredients, images, stock and SGD price.
  • create_cart: Create a new shopping cart and receive a private guest_token for subsequent cart and checkout calls.
  • get_cart: Read the current cart contents, line items, quantities and subtotal using a guest_token or OAuth bearer token.
  • set_cart_item: Add, update or remove a product quantity in the active cart (quantity 0 removes the item).
  • set_cart_coupon: Apply or clear a promotional coupon code on the active cart.
  • quote_cart: Calculate the itemized cart quote including subtotal, coupon discount, free Singapore shipping and total in SGD cents.
  • create_checkout: Lock the cart (with an Idempotency-Key) and generate a 1-hour checkout review URL on tanatasa.sg for human delivery and payment.
  • get_order: Retrieve order status and summary by order ID (for guest orders with guest_token or signed-in customer orders).
  • checkout_session: Create a Stripe payment session for an active locked checkout.

Client config (Cursor, VS Code, Claude Code and other config-file clients):

{"mcpServers": {"tanatasa": {"url": "https://tanatasa.sg/mcp"}}}

How do I connect Tanatasa Beauty MCP to Claude, Cursor or another MCP client?
