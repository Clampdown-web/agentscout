Pricing, as the maker states it: Open source + paid cloud. Maturity: Archived (discontinued, end of life Aug 31, 2026). We last checked the official link on 2026-10-14.

    What is Flowise?

    Flowise is discontinued. The team announced on July 29, 2026 that it was winding the project down and froze the code. The GitHub repository was archived on August 13, 2026, and npm packages and Docker images were marked deprecated. End of life was August 31, 2026, when the core team stopped taking part on Discord and GitHub.

    Flowise was an open-source platform for building agents visually. It offered Agentflow for multi-agent systems, Chatflow for single-agent chatbots with tool calling and RAG, human-in-the-loop review, and execution traces. The Apache 2.0 code stays on GitHub, and the team encourages people to fork it.

    Sources: github.com/FlowiseAI/Flowise, github.com/FlowiseAI/Flowise/discussions/6727 and our directory listing, checked 2026-10-18.
