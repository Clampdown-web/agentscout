About Langflow

Langflow is listed in our no-code builders category and is aimed at builders. Visual drag-and-drop builder for AI agents and workflows that you can run locally, deploy as an API or expose as an MCP server. Pricing, as the maker states it: Open source + cloud. Maturity: Mature. We last checked the official link on 2026-10-16.

What is Langflow?

Langflow is a platform for building and deploying AI agents and workflows, with a visual authoring experience plus built-in API and MCP servers.

You can run flows locally, deploy them as an API or expose them as MCP servers.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: github.com/langflow-ai/langflow.

Developers prototyping and shipping agent workflows.
