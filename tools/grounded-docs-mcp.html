Maturity: Active. We last checked the official link on 2026-10-18.

What is Grounded Docs MCP?

Grounded Docs is a self-hosted MCP server that gives coding assistants a documentation index matching the library versions you actually use. It fetches docs from websites, GitHub repositories, npm, PyPI, local folders and archives, reads HTML, Markdown, PDF, Office, EPUB, notebooks and source code, and stores each library version separately.

Search combines full text with optional vector search through OpenAI, Ollama, Gemini, Vertex AI, Bedrock, Azure or any OpenAI-compatible server, with the index kept in local SQLite. It serves MCP over stdio or Streamable HTTP plus a CLI and web UI, and positions itself as an open-source alternative to Context7. Telemetry is on by default and can be turned off. MIT.

Sources: the official README and our directory listing, checked 2026-10-31. Official site: grounded.tools.
