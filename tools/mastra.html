About Mastra

Mastra is listed in our frameworks category and is aimed at builders. TypeScript framework for agents, workflows and RAG. Pricing, as the maker states it: Open source. Maturity: Active. We last checked the official link on 2026-10-14.

What is Mastra?

Mastra is a TypeScript framework for building AI-powered applications and agents, from prototypes to production. It includes agents, workflows and RAG.

It integrates with React, Next.js and Node, or deploys anywhere as a standalone server.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: mastra.ai.

TypeScript developers building agents and AI features into web apps.
