About MCPHub

MCPHub is listed in our MCP & infra category and is aimed at builders. Self-hosted MCP gateway for managing many servers. Pricing, as the maker states it: Open source. Maturity: Active. We last checked the official link on 2026-10-16.

What is MCPHub?

MCPHub is an open-source, self-hosted MCP gateway and control plane for connecting, controlling and operating MCP servers.

You connect local and remote servers once, organize and route their capabilities through stable endpoints, and control access with authentication.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: mcphub.app.
