Pricing, as the maker states it: Free and open source (Apache-2.0); research preview. Maturity: Early (research preview). We last checked the official link on 2026-10-20.

    What is OpenGCUA?

    OpenGCUA (Open Generalist CUA) is an ongoing open project from the MAI-UI team at Tongyi Lab to build the full stack for generalist computer-use agents: systems that complete computer tasks by deciding for themselves whether to look at a screenshot or an accessibility tree, and whether to click, call an API, run a shell command or write a small program that combines them.

    The first research preview (October 2026) releases an OSWorld integration example with reference screenshot-action and code-action agents, evaluation trajectories for eight frontier models, a preliminary macOS real-device harness (a menu-bar app that runs the agent on your own Mac) and a Cross-Device SDK with one programming interface for computers, browsers and phones. On the OSWorld-v2 offline set the team reports the design raised the mean partial score of the eight models from 45.3 to 64.9 and cut steps per task by 53% on average. A model release is listed as next on the roadmap.

    Sources: the official README and our directory listing, checked 2026-10-20. Official site: tongyi-mai.github.io/OpenGCUA.

    What is OpenGCUA?

    Who is OpenGCUA for?

    Is OpenGCUA free?

    OpenGCUA's pricing, as the maker states it: Free and open source (Apache-2.0); research preview. Check the official site for current plans.

    Is OpenGCUA open source?

    Yes. OpenGCUA is released under the Apache License 2.0, according to its GitHub repository.

    What does OpenGCUA need to run?

    The macOS real-device harness needs macOS 14 or later; Python 3.12 is recommended, and prebuilt SDK wheels do not need Rust. The project calls the harness and SDK preliminary.

    Is there an OpenGCUA model?

    Not yet. The roadmap lists a GCUA model for computer and browser use as the next release; this preview opens the harness, SDK, OSWorld example and trajectories.
