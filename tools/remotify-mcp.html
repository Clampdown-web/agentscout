About remotify-mcp

remotify-mcp is listed in our MCP servers category and is aimed at builders. remotify-mcp is a free, open-source (Apache-2.0) local stdio MCP server (npx remotify-mcp) that gives Claude Code, Cursor, Codex, OpenCode, Gemini CLI and other MCP hosts a remote_exec tool for running shell commands on a remote computer through an HTTP relay. The remote machine needs only curl and bash (no SSH port or installed agent), and each command can wait for human approval or run automatically. Pricing, as the maker states it: Free and open source (Apache-2.0); the public relay at relay.remotify.run is free, or self-host it with Docker. Maturity: Active.
