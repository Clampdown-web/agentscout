About Manifest

Manifest is listed in our agent infra category and is aimed at builders. Open-source LLM gateway that routes each request from agents and apps to the right model across API keys, subscriptions and local models, with spend tracking. Pricing, as the maker states it: Self-hosted free (MIT); Manifest Cloud Free plan until Nov 1, 2026, then Cloud $19/month (Pro). Maturity: Mature. We last checked the official link on 2026-10-21.

What is Manifest?

Manifest LLM Gateway is an open-source gateway for AI agents and apps. You connect API keys, subscriptions and local models once, and everything goes through one OpenAI-compatible endpoint; send model 'auto' and Manifest picks the model for each request, so you are not locked to one provider.

It connects to 300+ models through 35 built-in provider connections plus any OpenAI- or Anthropic-compatible endpoint, and can reuse 18 subscription flows. It logs full request and error bodies, tracks spend with budget alerts and limits, and falls back to other models when a query fails. You can use Manifest Cloud or self-host the Docker image on Railway, Render, AWS, GCP, Fly.io and other platforms.

Sources: the official README and our directory listing, checked 2026-10-21. Official site: manifest.build.

Developers and teams running agents across several model providers who want routing, fallbacks and cost tracking in one place.

    Free, open-source menu bar app and local gateway that lets any coding agent (Claude Code, Codex, Gemini CLI, OpenCode and 60+ more) use any model provider or subscription, with failover when a quota runs out.

    Portkey AI Gateway

    Fast open-source AI gateway that routes requests to hundreds of LLMs through one API with fallbacks, load balancing and built-in guardrails.

    Weave Router

    An open-source LLM router for Claude Code, Codex and other coding agents that sends each request to the cheapest model that still meets your quality bar, cutting model spend.

    System One API

    System One API is the hosted decision API behind TypeSafe Jev, with an open-source TypeScript SDK for AI agents. Where the TypeSafe Jev listing covers the decision model itself, this listing covers the developer API and console: send text or app context and get back a typed choice, a score or a yes/no probability for routing tools, ranking results and checking conditions, with API keys, call logs and credit use managed in one place.

    Tura

    Tura is an open-source agent runtime focused on cutting LLM spending. It manages the context an agent sends to the model so tasks use far fewer tokens, while keeping the finished results, execution evidence and benchmark scores auditable, which makes it aimed at teams running agents at scale.

    Cloud-native API and AI gateway supporting REST, GraphQL, gRPC and MCP, with rate limiting, auth and analytics.
