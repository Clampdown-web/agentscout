    What is Agent Lightning?

    Agent Lightning is Microsoft's lightweight framework (about 3,500 lines) for training existing agents with reinforcement learning using their real harnesses, without rewriting the agent's tools or control flow. It is MIT-licensed and was refactored in v1.0.

    Its README reports a 2026 example where pure RL improved Qwen3.5-35B-A3B on SWE-bench Verified from 47.8% to 61.6% with 1.8K training examples, and an Agent Lightning Skill that helps one coding agent improve another.

    Sources: the official README and our directory listing, checked 2026-10-18. Official site: microsoft.github.io/agent-lightning.
