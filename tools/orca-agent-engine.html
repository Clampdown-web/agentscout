    What is Orca Agent Engine?

    Orca Agent Engine is an open, Apache-2.0, self-hosted implementation of the managed-agents API. You define agents, run them in sessions and stream each session's events.

    It follows Anthropic's Managed Agents beta closely enough that the official Anthropic SDKs can use it by changing their base URL, while agents, sessions, files, memory and credentials stay in your infrastructure. Our listing notes a choice of harness (Claude Agent SDK, Codex, Pi) and a Developer Preview released Oct 6, 2026.

    Sources: the official README and our directory listing, checked 2026-10-18. Official site: runorca.ai.
