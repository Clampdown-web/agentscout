What is OpenAI Agents SDK (Python)?

The OpenAI Agents SDK is a lightweight framework for building multi-agent workflows in Python. It is provider-agnostic, supporting the OpenAI Responses and Chat Completions APIs plus 100+ other LLMs.

Its building blocks include agents configured with instructions, tools, guardrails and handoffs, sandbox agents that work in a container over long time horizons, realtime agents and voice pipelines. A JavaScript/TypeScript version is also available.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: openai.github.io/openai-agents-python.

Who is OpenAI Agents SDK (Python) for?

Python developers building multi-agent or voice workflows who want an official, lightweight SDK that also works with other providers.
