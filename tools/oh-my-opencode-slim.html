What is Oh My OpenCode Slim?

Oh My OpenCode Slim is an agent orchestration plugin for OpenCode. It includes a built-in team of specialized agents that can scout a codebase, look up fresh documentation, review architecture, handle UI work and carry out well-scoped implementation tasks.

An orchestrator plans the work, dispatches specialists as background tasks and reconciles their results, routing each part of the job to the best-suited agent to balance quality, speed and cost. You can mix any models.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: ohmyopencodeslim.com.
