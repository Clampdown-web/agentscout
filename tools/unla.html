Unla is listed in our MCP servers category and is aimed at builders. Lightweight MCP gateway that turns existing MCP servers and APIs into MCP endpoints without code changes, with a management UI. Pricing, as the maker states it: Open source. Maturity: Active. We last checked the official link on 2026-10-18.

What is Unla?

Unla is a lightweight, highly available MCP gateway written in Go that turns existing REST APIs and MCP servers into MCP-compliant endpoints through YAML configuration, without changing application code. It runs on bare metal, VMs, ECS or Kubernetes without modifying existing infrastructure.

A built-in web management UI simplifies setup and operations. The project warns that it is under rapid development, so backward compatibility is not fully guaranteed between versions. MIT.

Sources: the official README and our directory listing, checked 2026-10-29. Official site: github.com/AmoyLab/Unla.
