About Radar

Radar is listed in our MCP & infra category and is aimed at builders. Open-source Kubernetes UI with a built-in MCP server for agents. Pricing, as the maker states it: Open source. Maturity: Active. We last checked the official link on 2026-10-16.

What is Radar?

Radar is an open-source Kubernetes UI with a built-in MCP server for AI agents. It is a single binary that needs no account and is free, and it can run from your laptop or in-cluster.

Views include topology, resources, Helm, GitOps, traffic, cost, audit, RBAC and upgrade impact, with nothing to install on the cluster.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: radarhq.io.

Who is Radar for?

Kubernetes users who want a visual UI plus cluster context for their AI agents.
