    MailVeri MCP is listed in our MCP servers category and is aimed at builders.     What is MailVeri MCP?

    MailVeri MCP is the official, MIT-licensed Model Context Protocol server for MailVeri, an email verification service. It lets AI assistants such as Claude Desktop, Claude Code, Codex, Cursor, Windsurf and VS Code (Cline) check whether an address is deliverable straight from chat: syntax, MX and SMTP checks, mailbox existence, catch-all domains, disposable providers, role accounts and full inboxes.

    Agents can also queue bulk lists for background verification, follow batch progress, download filtered results and check the remaining credit balance before a large outreach run. It runs locally over stdio (or SSE) via uvx from GitHub with a MailVeri API key; verification uses pay-as-you-go credits.

    Sources: the official site and our directory listing, checked 2026-10-19. Official site: mailveri.com/docs/mcp.

    Who is MailVeri MCP for?

    Developers, growth and sales teams who clean lead and contact lists, and builders of outreach agents who want their AI assistant to verify emails before sending.

    Key features

    • Single-email verification: syntax, MX, SMTP, catch-all, disposable, role-account and full-inbox detection
    • Bulk list verification as background batches, with progress and filtered CSV or ZIP results
    • Credit balance check before large runs
    • Six MCP tools (verify_email, verify_batch, get_batch_status, download_batch_result, delete_batch, get_balance)
    • Configs for Claude Desktop, Claude Code, Codex, Cursor, Windsurf, VS Code (Cline) and more; stdio or SSE transport
    • MIT-licensed server, launched with uvx from GitHub
