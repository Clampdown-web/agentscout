What is Genkit?

Genkit is Google's open-source framework for building full-stack AI-powered applications, built and used in production by Firebase.

SDKs cover JavaScript/TypeScript and Go (production-ready), Python (beta) and Dart (preview), with a unified interface across models.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: genkit.dev.

Who is Genkit for?

App developers, especially on Firebase or Google Cloud, adding AI and agent features in JS, Go, Python or Dart.
