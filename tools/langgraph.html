About LangGraph

LangGraph is listed in our frameworks category and is aimed at builders. Framework for stateful, graph-based agent workflows. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-14.

What is LangGraph?

LangGraph is a low-level orchestration framework from LangChain for building, managing and deploying long-running, stateful agents. Its README names Klarna, Replit and Elastic among companies using it.

It provides infrastructure such as durable execution for any long-running, stateful workflow or agent. A JS/TS version is available, and LangChain points to Deep Agents, built on LangGraph, if you want to build agents more quickly.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: langchain.com/langgraph.

Who is LangGraph for?

Developers who need fine-grained control over stateful, long-running agent workflows in Python or JavaScript.
