About Agent Skills (Addy Osmani)

Agent Skills (Addy Osmani) is listed in our coding category and is aimed at builders. Agent Skills by Addy Osmani packages senior-engineer workflows and quality gates as skills for AI coding agents, with nine slash commands such as /spec, /plan, /build, /test, /review and /ship that walk an agent from idea to production with tests and review at each step. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-11-09.

What is Agent Skills (Addy Osmani)?

Agent Skills by Addy Osmani is an MIT-licensed pack of workflow skills for coding agents. The README maps nine slash commands onto a lifecycle: /spec, /plan, /build, /test, /constraints, /review, /webperf, /code-simplify and /ship. It says the repository holds 25 skills, and that skills also turn on from the work in front of the agent, such as API design or UI.

/build auto generates a plan and implements every task in one approved pass. The README says each task stays test-driven and is committed on its own, and that the run pauses on failures or risky steps. A one-skill npx install copies only that skill's folder, not the repo-level references/ checklists. The lifecycle slash commands are Claude Code plugin commands. The README says GitHub Copilot does not get those commands and that you invoke the skill names instead.

Sources: github.com/addyosmani/agent-skills, github.com/addyosmani/agent-skills/blob/main/README.md, skills.addy.ie and our directory listing, checked 2026-11-09.

Who is Agent Skills (Addy Osmani) for?

Engineers who want a coding agent to follow a spec, plan, test and review sequence instead of jumping straight to a patch.

Pros and cons

Pros

  • The commands are tied to a written sequence: spec before code, tests as proof, review before merge.
  • You can install all 25 skills or name one skill. The skills CLI is documented for many agents.
  • The README says automatic activation still applies when you are designing an API or building UI, without typing a command.

Cons

  • A per-skill npx install does not copy references/. Shared checklists are missing until you clone the repo or copy them. The README tracks that gap in issue 361.
  • Where Claude Code already has /review, the README says to use /agent-skills:review.
  • The lifecycle slash commands do not appear in GitHub Copilot. Copilot uses the skill names.
  • The Claude Code marketplace clones over SSH. The README documents an HTTPS URL and a git-insteadOf rewrite when you have no SSH key.

Setup

  1. For any agent, run npx skills add addyosmani/agent-skills to install all 25 skills, or add --skill and a skill name for one.
  2. In Claude Code, run /plugin marketplace add addyosmani/agent-skills and /plugin install agent-skills@addy-agent-skills. If SSH fails, the README says to add the https://github.com/addyosmani/agent-skills.git URL instead.
  3. In Cursor, copy workflow skills into .cursor/skills/ and short policies into .cursor/rules. The README says this repo does not ship a .cursor folder, and points to docs/cursor-setup.md.
  4. If you installed a single skill and a checklist path is missing, clone the repository or copy the references/ files into the installed skill.
