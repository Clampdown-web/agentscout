What is Jupyter AI?

Jupyter AI is the official open-source extension that connects AI agents to computational notebooks in JupyterLab. It provides a native chat UI where you work with agents such as Claude, Codex, GitHub Copilot, Gemini, Goose, Kiro, Mistral Vibe and OpenCode, all through the Agent Client Protocol (ACP).

Agents are detected automatically when their dependencies are installed. They can read and write files, run terminal commands and work with notebooks through a built-in Jupyter MCP server, and a permission system gives you guardrails over what they do.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: jupyter-ai.readthedocs.io/en/stable.

Data scientists and researchers who work in JupyterLab and want agents to help inside their notebooks.
