What is Lyzr?

Lyzr is an enterprise agent studio and framework for building secure AI agents, listed with freemium pricing.

Its open-source Lyzr Automata is a low-code multi-agent framework for process automation; the makers note it began as an experiment and is being improved for stability.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: lyzr.ai.

Who is Lyzr for?

Enterprises building secure agents, and developers who want a low-code multi-agent automation framework.
