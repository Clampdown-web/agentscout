About A2UI

A2UI is listed in our frameworks category and is aimed at builders. A2UI is an open-source agent-to-UI protocol and toolkit for rendering interactive agent interfaces so products can show structured agent output beyond plain chat bubbles. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-11-06.

What is A2UI?

A2UI is an Apache-2.0 format and set of renderers for agent-generated interfaces. An agent sends a declarative JSON description of components and data. The client renders that JSON with its own catalog of widgets, such as Flutter, Angular, Lit, React, SwiftUI or Jetpack Compose. The README says the agent can only ask for components the client has already approved, so the payload is data rather than executable code.

The README recommends A2UI when the agent is remote or across a trust boundary, or when one agent should drive more than one client platform. It says a React-only chat that renders tool results as your own components may not need it. Renderers include @a2ui/react, @a2ui/angular and @a2ui/lit, plus a2ui_flutter. The quickstart is a restaurant-finder demo that needs Node.js 18 or newer, uv, and a Gemini API key.

Sources: github.com/a2ui-project/a2ui, github.com/a2ui-project/a2ui/blob/main/README.md, a2ui.org and our directory listing, checked 2026-11-09.

Who is A2UI for?

Developers whose agents must show forms, cards or dashboards inside an app they control, without letting the model send executable UI code.

Pros and cons

Pros

  • The client decides which components exist. A model cannot ship a new executable widget.
  • The same JSON can be rendered by different frameworks.
  • You can try the composer and the theater without cloning the repo.

Cons

  • You still build and trust the catalog. A2UI does not review a widget you registered yourself.
  • The restaurant-finder quickstart needs a Gemini API key and the uv package manager.
  • A single-platform React chat may not need the format. The README says so.
  • Host frameworks in the dependencies section are listed as web or Flutter today. Other platforms depend on the renderer you add.

Setup

  1. For a client you already have, npm install the renderer (@a2ui/react, @a2ui/angular or @a2ui/lit) and follow the client setup guide on a2ui.org.
  2. For Flutter, the README's command is flutter pub add a2ui_flutter a2ui_core.
  3. For the full demo, clone a2ui-project/a2ui, install Node.js 18 or newer and uv, set GEMINI_API_KEY, and follow the quickstart linked from the README.
  4. Register only components you trust. The agent can request those components and no others.
