What is MCP Inspector?

MCP Inspector is the official developer tool from the Model Context Protocol project for testing and debugging MCP servers. One npm package, @modelcontextprotocol/inspector, gives you four ways in: a web app, a scriptable CLI for automation and CI, an interactive terminal UI, and an experimental connection CLI (mcpdo) that keeps a named connection open across many commands.

You point it at a server over stdio or HTTP, then list and call its tools, read resources, try prompts and watch the raw protocol messages. It handles OAuth flows and stores tokens and secrets in the OS keychain where one is available, so it is the usual first stop when an MCP server misbehaves in Claude, Cursor or another client.

Sources: the official README and our directory listing, checked 2026-10-20. Official site: modelcontextprotocol.io/docs/2026-07-28/tools/inspector.
