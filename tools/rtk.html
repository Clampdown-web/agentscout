About rtk

rtk is listed in our coding category and is aimed at builders. A CLI proxy that sits between coding agents and your shell and trims noisy command output before it reaches the model, cutting token use on everyday commands like tests, builds and git. Free and open source, with an RTK Pro tier for teams. Pricing, as the maker states it: Free and open source (Apache-2.0); RTK Pro adds team features.. Maturity: Mature.     Kilo Code

    Open-source AI coding agent for VS Code, JetBrains, the CLI and the cloud that works with 500+ models at no markup.

    ANUS

    A free coding agent in your terminal. It runs on the smartest free model that is up today

    OmniRush

    OmniRush is a desktop coding agent for Windows, macOS and Linux, with a terminal CLI as well. It works through the files of your own projects, reading code, making edits and running commands, and gives free access to frontier models from a model picker, with GPT 6 Astra as the default. Builds for each platform are published on its releases page.

    Paritok

    Paritok is a compression gateway that sits between a coding agent and its LLM. Using its own open-source 4B code-aware model, it shrinks tool output, files and conversation history on the fly without losing what the agent needs, which cuts token bills and lets agent sessions run longer before they hit context limits.

    Agent Skills (Addy Osmani)

    Agent Skills by Addy Osmani packages senior-engineer workflows and quality gates as skills for AI coding agents, with nine slash commands such as /spec, /plan, /build, /test, /review and /ship that walk an agent from idea to production with tests and review at each step.

    Claude Code Templates

    Claude Code Templates is an open catalog and CLI of more than 1,980 Claude Code components (skills, subagents, slash commands, hooks, MCP servers and settings) at aitmpl.com, where you preview each file and combine components into one npx install that merges with your existing configuration.
