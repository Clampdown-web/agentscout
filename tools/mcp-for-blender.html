What is MCP for Blender?

MCP for Blender (formerly blender-mcp) connects Blender to any LLM through the Model Context Protocol, for prompt-assisted 3D modeling, scene creation and manipulation. It is a third-party integration, not made by Blender.

One setup command installs the Blender add-on and configures MCP clients it finds on your machine, such as Claude Desktop, Claude Code, Codex, Cursor, VS Code, Windsurf and OpenCode. The PyPI package is now mcp-for-blender, and existing blender-mcp setups keep working.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: mcp-for-blender.com.
