About Windmill

Windmill is listed in our agent infra category and is aimed at builders. Windmill is an open-source developer platform that turns scripts in Python, TypeScript, Go, SQL and other languages into webhooks, workflows and internal UIs. Its flows include AI agent steps that call an LLM with your scripts as tools, support nested agents and MCP, and run on a fast self-hostable workflow engine. It positions itself as an open-source alternative to Retool and Temporal. Pricing, as the maker states it: Free and open-source Community Edition from $0/mo (self-hosted, unlimited executions, up to 10 SSO users); Enterprise from $120/mo; cloud and self-hosted paid plans (windmill.dev/pricing, checked Oct 22 2026). Core is AGPLv3, some enterprise features proprietary.. Maturity: Mature. We last checked the official link on 2026-10-22.

What is Windmill?

Windmill is a platform for scripts, flows, internal apps and AI agents. The README says you write a Python, TypeScript, Go or Bash script, Windmill turns the arguments into a form and an HTTP endpoint, and you chain scripts into a flow or build a UI on top. Schedules, webhooks, HTTP routes, Kafka, WebSockets and email can start a run. AI sessions build scripts, flows and apps in a workspace fork, with a diff to review before deploy.

The source you compile without the enterprise flag is AGPLv3. API clients and the OpenAPI spec are Apache-2.0. Community Edition images also include proprietary code. Using that edition internally or through its APIs is free inside the quotas in the software. Selling it as a managed service, wrapping it, or re-exposing it to your users needs a commercial licence, with iframed public apps excepted. The pricing page on 9 Nov 2026 lists the free self-hosted tier at $0 a month and Enterprise from $120 a month.

Sources: github.com/windmill-labs/windmill, github.com/windmill-labs/windmill/blob/main/README.md, windmill.dev/pricing, windmill.dev/docs/advanced/self_host and our directory listing, checked 2026-11-09.

Who is Windmill for?

Teams who want to self-host scripts and flows, let an AI session draft them, and still require a person to review before production.

Pros and cons

Pros

  • The free self-hosted tier lists unlimited executions. The pricing page caps SSO at 10 users on that tier.
  • AI output is an ordinary script, flow or app and goes through the same review as handwritten code.
  • You can develop in the browser or sync a Git repo with the CLI and the VS Code extension.

Cons

  • Community Edition binaries are not pure AGPL. They include proprietary code. Reselling them as a managed service needs a commercial licence.
  • The project is not seeking outside features. The README says small, trivially verified pull requests are still accepted.
  • Enterprise SSO above the free cap, audit logs and SAML are paid features on the pricing page.
  • The Docker Compose quick start publishes a default login. Change it before anyone else can reach the instance.

Setup

  1. For Docker Compose, download docker-compose.yml, Caddyfile and .env from the repository paths in the README, then run docker compose up -d.
  2. Open http://localhost. The README's default login is admin@windmill.dev with password changeme. Change that password.
  3. For Kubernetes, add the helm repo windmill-labs.github.io/windmill-helm-charts and install the chart. Set DATABASE_URL if you use an external Postgres.
  4. Read the pricing page before you enable Enterprise features. The free tier is $0 a month. Enterprise starts at $120 a month, as listed on 9 Nov 2026.

    System One API is the hosted decision API behind TypeSafe Jev, with an open-source TypeScript SDK for AI agents. Where the TypeSafe Jev listing covers the decision model itself, this listing covers the developer API and console: send text or app context and get back a typed choice, a score or a yes/no probability for routing tools, ranking results and checking conditions, with API keys, call logs and credit use managed in one place.

    Inngest

    Inngest is a durable workflow orchestration platform for running stateful step functions and AI workflows on serverless, servers or the edge. You write functions in TypeScript, Python or Go with automatic retries, queues, throttling and human-in-the-loop waits, and its AgentKit and AI inference steps let you build durable, long-running AI agents with tracing and evals. The server is source-available (SSPL, converting to Apache 2.0 later) and can be self-hosted, or you can use Inngest Cloud.
