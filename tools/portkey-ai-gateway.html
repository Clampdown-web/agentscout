About Portkey AI Gateway

Portkey AI Gateway is listed in our agent infra category and is aimed at builders. Fast open-source AI gateway that routes requests to hundreds of LLMs through one API with fallbacks, load balancing and built-in guardrails. Pricing, as the maker states it: Open-source gateway free to self-host; hosted Developer plan free (10k logs/mo), Production $49/mo, Enterprise custom. Maturity: Mature. We last checked the official link on 2026-10-20.

What is Portkey AI Gateway?

Portkey's AI Gateway is a fast, lightweight open-source gateway that puts hundreds of LLMs behind one API (Portkey cites 250+ LLMs and 1,600+ language, vision, audio and image models). You can integrate a new model in minutes and add reliability without changing app code.

It handles automatic retries and fallbacks, load balancing and conditional routing, guardrails, multimodal requests and agent-framework integrations, and Portkey's MCP Gateway adds enterprise auth and observability for MCP servers. You can self-host the open-source gateway or use Portkey's hosted platform, which adds observability, prompt management and caching; a Gateway 2.0 pre-release is merging Portkey's enterprise gateway into the open-source project.

Sources: the official README and our directory listing, checked 2026-10-20. Official site: portkey.ai/features/ai-gateway.

Who is Portkey AI Gateway for?

Teams running LLM apps or agents in production who want one API across providers, with fallbacks, budgets and logs.

    Jev API returns fast, typed decisions for software: you send state and the possible outcomes, and it answers with a choice, a yes/no or a score plus probabilities, so apps and agents can make routine judgments without a full LLM call; a free jev-1.13 tier is available and paid access runs through BeatAPI.

    Jev is TypeSafe's System One decision model, built for the small decisions inside software and agents. Agents can use it to settle narrow calls cheaply and save the larger LLM for open-ended work. Available through TypeSafe's API, Python and JavaScript SDKs, an agent skill, and OpenRouter.
