What is A2A?

A2A (Agent2Agent) is an open protocol for communication and interoperability between agentic applications. It lets agents built on different frameworks, by different companies and running on separate servers, collaborate as agents, not just as tools.

The protocol covers things like negotiating interaction modalities (text, forms, media) and collaborating securely, aiming to give agents a common language.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: a2a-protocol.org.

Who is A2A for?

Developers and companies building agents that need to talk to agents built elsewhere.
