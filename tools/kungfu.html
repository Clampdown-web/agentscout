About Kungfu

Kungfu is listed in our coding category and is aimed at builders. Workspace that keeps the same task moving across Codex, Claude, OpenCode and other agents without re-explaining context at each handoff. Pricing, as the maker states it: Free and open source (Apache-2.0). Maturity: Active. We last checked the official link on 2026-10-23.

What is Kungfu?

Kungfu is a workspace that keeps one piece of work moving across different coding agents, so you don't have to copy context and re-explain decisions every time you switch. You can use a strong agent when it matters and a cheaper one when it doesn't, across Codex, Claude, OpenCode, Amp or your own execution surface.

It tracks each piece of work through attempts, so a task can survive a disconnect or crash and recover. It is in alpha, installs on macOS or Linux with a per-user script that needs no sudo, and includes a mock agent to test recovery without provider credentials.

Sources: the official README and our directory listing, checked 2026-10-23. Official site: kungfu.tech.

Who is Kungfu for?

Developers who switch between coding agents and want the task and its context to carry over.
