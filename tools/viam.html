About Viam

Viam is listed in our frameworks category and is aimed at builders. Software platform for building and operating robots and smart machines. Pricing, as the maker states it: Open source + cloud. Maturity: Active. We last checked the official link on 2026-10-16.

What is Viam?

Viam is a software platform for building and operating robots and smart machines. Its open-source robot architecture exposes robotics functionality through simple APIs.

The core server (RDK) is written in Go, and a cloud platform is offered alongside it.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: viam.com.

Who is Viam for?

Robotics and hardware teams building and running robots and smart machines.
