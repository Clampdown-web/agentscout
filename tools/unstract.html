About Unstract

Unstract is listed in our no-code builders category and is aimed at builders. LLM-powered platform for extracting structured data from documents via APIs and ETL pipelines. Pricing, as the maker states it: Open source + cloud. Maturity: Mature. We last checked the official link on 2026-10-16.

What is Unstract?

Unstract uses LLMs to turn unstructured documents (PDFs, images, scans) into structured JSON.

You define what to extract in natural language, then run it via APIs or ETL pipelines.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: unstract.com.
