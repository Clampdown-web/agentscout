What is TrueForge?

TrueForge, from TrueFoundry, is an open-source agent harness: the runtime layer that turns an LLM into a working agent. It runs the execution loop, including model calls, MCP tools, skills, sandboxing, approvals, context management and session state.

It exposes the agent three ways: a chat UI, an HTTP API with a TypeScript SDK, and an embeddable UI SDK.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: trueforge.dev/introduction.

Who is TrueForge for?

Developers who want streaming, persistence, tool servers, sandboxing and approvals without building the runtime themselves.
