About optillm

optillm is listed in our agent infra category and is aimed at builders. Inference proxy that applies reasoning techniques to improve LLM answers. Pricing, as the maker states it: Open source. Maturity: Active. We last checked the official link on 2026-10-16.

What is optillm?

optillm is an OpenAI API-compatible optimizing inference proxy that applies 20+ reasoning techniques to improve LLM accuracy on reasoning tasks without training or fine-tuning.

Its README claims 2-10x accuracy improvements on reasoning tasks.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: github.com/algorithmicsuperintelligence/optillm.

Who is optillm for?

Developers who want better reasoning from existing models by changing only the endpoint.

    LiteLLM

    Open-source AI gateway and Python SDK that calls 100+ LLM providers in the OpenAI format, with cost tracking, guardrails, load balancing and logging.

    Kong Gateway

    Cloud-native API, LLM and MCP gateway that adds routing, auth, multi-LLM support, semantic security and MCP traffic analytics through plugins.

    opencodex

    A local provider proxy that lets OpenAI Codex (CLI, app and SDK) and Claude Code run on other model providers such as Claude, Gemini, Grok, DeepSeek or local Ollama models.

    Inngest

    Inngest is a durable workflow orchestration platform for running stateful step functions and AI workflows on serverless, servers or the edge. You write functions in TypeScript, Python or Go with automatic retries, queues, throttling and human-in-the-loop waits, and its AgentKit and AI inference steps let you build durable, long-running AI agents with tracing and evals. The server is source-available (SSPL, converting to Apache 2.0 later) and can be self-hosted, or you can use Inngest Cloud.

    Kestra

    Kestra is an open-source, event-driven orchestration and scheduling platform where workflows are declared in YAML or built in a no-code editor. It includes an AI Agent task that gives flows an LLM with memory and tools, supports nested agents and the Agent-to-Agent (A2A) protocol, and can expose any flow as a tool to external AI agents through its MCP server. It runs in the cloud, on-prem or air-gapped and is Apache 2.0 licensed.

    TypeSafe Jev

    Jev is TypeSafe's System One decision model, built for the small decisions inside software and agents. You send a state and typed questions (choice, score and more) and get typed answers with probabilities back instead of free-form text, so code can branch on them directly to route, classify, score or rank options. Agents can use it to settle narrow calls cheaply and save the larger LLM for open-ended work. Available through TypeSafe's API, Python and JavaScript SDKs, an agent skill, and OpenRouter.
