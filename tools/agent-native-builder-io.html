About Agent-Native (Builder.io)

Agent-Native (Builder.io) is listed in our frameworks category and is aimed at builders. Open-source TypeScript framework for building agents that come with their own app UI; each action is shared by the UI, agent, API, CLI, MCP and A2A. Pricing, as the maker states it: Open-source framework; optional hosted building on Builder.io. Maturity: Beta, launched Oct 14. We last checked the official link on 2026-10-15.
