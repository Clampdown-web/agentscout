    Backlog.md is listed in our coding category and is aimed at builders. Markdown task board in your Git repo for coordinating work between people and AI agents. Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-16.

    What is Backlog.md?

    Backlog.md is a Markdown-native task manager and kanban visualizer for any Git repository. It turns a folder into a self-contained project board powered by plain Markdown files and a zero-config CLI.

    It structures agent work around review checkpoints: the agent first breaks your idea into tasks with descriptions, acceptance criteria and milestones, so you can review the specs before any code exists.

    Sources: the official README and our directory listing, checked 2026-10-18. Official site: github.com/MrLesk/Backlog.md.
