About Cube

Cube is listed in our data & analytics category and is aimed at builders. Cube is an open-source semantic layer that lets BI tools and AI agents query the same metrics Pricing, as the maker states it: Open source. Maturity: Mature. We last checked the official link on 2026-10-28.

What is Cube?

Cube Core is the open-source semantic layer in cube-js/cube. The README says you define metrics, dimensions, joins and access rules in code and expose them through SQL, REST and GraphQL to BI tools, applications or AI agents. It does not ship a UI. It works with SQL warehouses such as Snowflake, Databricks and BigQuery, engines such as Presto and Athena, and application databases such as Postgres, and it includes a relational cache.

The backend is Apache-2.0 and the client is MIT, according to the README. Cube, the commercial product, is a separate hosted analytics platform on the same model. Its pricing page on 9 Nov 2026 lists a free developer seat, Starter at $40 per developer a month, Premium at $80 per developer a month, and Enterprise as custom. A Premium viewer seat is $20 per user a month. Development mode on a self-hosted Cube Core turns off API authentication. The README says never to expose that mode to the internet.

Sources: github.com/cube-js/cube, github.com/cube-js/cube/blob/master/README.md, cube.dev/pricing, docs.cube.dev and our directory listing, checked 2026-11-09.

Who is Cube for?

Data teams who want one metric definition for BI tools and for agents, either by running Cube Core themselves or by using the hosted Cube product.

Pros and cons

Pros

  • A model built in Cube Core runs in the hosted product and the other way around, according to the README.
  • Agents and BI tools can share one definition instead of a copy in each tool.
  • The source licences for the client and the backend are OSI licences.

Cons

  • CUBEJS_DEV_MODE=true disables JWT checks on the REST and GraphQL APIs and serves the Playground with no authentication. The README says this is for a local machine only.
  • Cube Core has no workbook UI. Dashboards, Analytics Chat and managed deployment are the hosted Cube product.
  • Hosted seats are per developer. The pricing page bills self-serve customers monthly through Stripe.
  • The SQL API accepts any credentials when CUBEJS_SQL_PASSWORD is unset, which the README ties to development mode.

Setup

  1. Install Docker. In an empty project folder, run the README's docker run of cubejs/cube with ports 4000 and 15432, a volume on /cube/conf, and CUBEJS_DEV_MODE=true only on your machine.
  2. Open http://localhost:4000. Do not expose that development port. The README links the production configuration docs for a real deployment.
  3. Define the data model in code. Point BI tools or agents at the SQL, REST or GraphQL API.
  4. For the hosted product, read cube.dev/pricing. Starter is $40 per developer a month and Premium is $80, as listed on 9 Nov 2026. Cube Core itself stays the open-source repository.
