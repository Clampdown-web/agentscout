What is Acontext?

Acontext is an open-source skill memory layer for AI agents. It automatically captures learnings from agent runs and stores them as agent skill files you can read, edit and share across agents, LLMs and frameworks.

The aim is for agents to learn from mistakes and reuse what worked without opaque memory polluting the context.

Sources: the official README and our directory listing, checked 2026-10-18. Official site: acontext.io.

Who is Acontext for?

Developers who want agent learnings stored as readable, shareable skills.
