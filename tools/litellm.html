Pricing, as the maker states it: Open source + cloud. Maturity: Mature. We last checked the official link on 2026-10-18.

    What is LiteLLM?

    LiteLLM is an open-source AI gateway that gives you one interface to call 100+ LLM providers, including OpenAI, Anthropic, Gemini, Bedrock and Azure, using the OpenAI format.

    You can use it as a Python SDK inside your code or deploy the AI Gateway (proxy server) as a central service for a team, with virtual keys, spend tracking, guardrails, load balancing and an admin dashboard. A hosted proxy and an enterprise tier are also offered.

    Sources: the official README and our directory listing, checked 2026-10-18. Official site: litellm.ai.

    Who is LiteLLM for?

    Developers and platform teams who call several LLM providers and want one OpenAI-compatible API, plus central keys, budgets and spend tracking.

      Windmill is an open-source developer platform that turns scripts in Python, TypeScript, Go, SQL and other languages into webhooks, workflows and internal UIs.
