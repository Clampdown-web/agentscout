What this is

This page collects the 21 directory listings filed under games: agents and tools for making games, driving NPCs, generating game assets, or playing. The pricing mix is 9 open source, 6 free or freemium, 3 paid, usage-based or enterprise, 3 pricing on the maker's site.

It is not a review of games. It is a shelf of tools whose makers put them in this category. A card might be an engine plugin, a character model, or a finished app. The description on the card is the maker's line, and the category is how we grouped it.

Who it is for

9 listings are for builders who want something to embed or extend. 12 are ready-to-use products. Game developers who also need concept art, 3D, or voice should use the role page, which pulls those jobs in from other categories.

Pros and cons

Pros

  • Names with the most tracked stars on this page include AI Town, Universal Modder, Voyager, Mindcraft, Godot AI. The leader is AI Town. Stars recorded on that listing: 10,725.
  • 9 listings are open source or open source plus cloud, which matters if you need to ship the tool inside your own game.
  • The filters on this page (price, open source, stars, newest) are the same ones used across category pages, so you can narrow the shelf without leaving it.

Cons

  • 3 listings do not state a price here. Asset shops and hosted NPC services often do that. Check the official site.
  • A high star count can be a general model or a library that is only partly about games. Read the description before you treat the sort as a best-of list.
  • 0 listings are discontinued or archived. Leave those for history.

How to use it

  1. Skim the top of the grid for the job you actually have: an NPC runtime, an asset generator, or a player-facing app.
  2. If you will vendor the code, turn on Open source only and open the GitHub link from the listing.
  3. If you need art, models, or voices around the game, leave this page for the game-developers role, which adds those categories.
  4. Confirm the license and the price on the official site before you put the tool in a commercial build.

FAQ

Is this a ranking of the best AI games?

No. It is every listing in the games category, 21 tools, with filters and a star sort. We do not score gameplay or art direction.

Where do I look if I am building a game, not browsing toys?

Use the game-developers role page. It keeps concept art, 3D, and voice next to this category so you are not limited to tools that happen to be tagged games.

How do I tell a library from a finished product?

The card says For builders or Ready to use. On this page that split is 9 builder listings and 12 ready-to-use listings.

Co-op Anything

gamesOpen source

Co-op Anything lets you point your AI coding agent at a single-player game and have it build or revive a co-op mod, so you can play it with friends online or split-screen. The project gives the agent a step-by-step method for working out what has to be synced between players (the story, enemies, the world, items and players seeing each other) and testing it. Its website is a searchable directory of every co-op mod made this way, with player ratings, how much of each game works in co-op and how active each project is.

Aura Autopilot

gamesOpen source

Open-source, continually learning playtesting agent from Ramen, the team behind the Aura game-dev assistant. Installed as a plugin in Unreal Engine 5, Unity 6 or Godot 4 on Windows and macOS, it reads your project's source, writes a bespoke harness for a real-time decision model, then plays the game with real keyboard and mouse input to explore levels, test features, verify fixes or pursue goals such as 'kill 10 enemies', and files a report with what broke. Per-game memory makes it faster each run; works with an Aura plan, BYOK keys, or Claude Code and Codex via its skills and MCP server. Apache-2.0.
