BoardUI is a React design system for building agentic products and data-heavy dashboards, with 85 components and blocks (including chart cards), Tailwind CSS styling and fully editable source. The free set ships with a working AI chat app example, and Pro templates add ready-made layouts, so teams can put a polished interface on an agent quickly.

Massvai

Newapp buildersFreemium

Massvai is an AI full-stack app builder for Next.js, TypeScript, Tailwind CSS and Supabase. From a plain-language prompt or reference screenshot, its coding agent plans the architecture, writes exportable TypeScript code with a live HMR preview, wires Supabase authentication and database flows, syncs the repository to GitHub and deploys to Vercel.
