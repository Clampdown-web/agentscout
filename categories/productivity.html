OpenClip

NewproductivityOpen source

OpenClip is a free, open-source floating action bar for macOS that pops up when you select text. From it you can copy, calculate, transform text, run AI actions or trigger your own scripts and workflows, so quick jobs on any selection take one click instead of a trip to another app.

Added Oct 25, 2026

Kition

NewproductivityOpen source

Kition is an open-source desktop office workspace with an AI agent built in. It combines documents, data tables and a whiteboard for design work in one app, and its tool-using agent can research the web, write and translate, organise records and produce editable brand assets, with visual workflows to chain the steps together.

Added Oct 24, 2026

Agente Smart Documents

NewproductivityFreemium

Agente Smart Documents turns a finished Word document into a reusable template your AI agent can fill. You upload an example, it builds the template, then ChatGPT or Codex, Claude, Grok Bot, Hermes or the web workspace asks only for the details that are missing and hands back a filled .docx with the original layout kept, for you to review before sending. A few documents are free each month, then a flat monthly fee per office.

Added Oct 23, 2026

OpenKnowledge

NewproductivityOpen source

OpenKnowledge is a free, local-first markdown editor and knowledge base built for working alongside AI agents. It looks and feels like a Notion-style WYSIWYG editor, with callouts, tabs, Mermaid diagrams and media blocks, but every page stays a plain markdown file on your disk. Coding agents such as Claude Code, Codex, Cursor, Gemini CLI and dozens of others can read and write the same files through its integrations, so specs, team wikis and LLM wikis stay in one place that both people and agents keep up to date. It ships as a desktop app plus a web UI and CLI.

Added Oct 21, 2026

Cumora

NewproductivityOpen source

Cumora is a team chat app where AI agents are members of the workspace rather than a chat box you prompt. Each agent gets a persona, its own private memory and files, a status, and a schedule on which it wakes up, reads the room and decides whether to message someone, post an idea or pull a small group together. Agents can message each other, and you can read those side conversations. People join by email or link, agents can be grouped into teams and given projects, and the same live workspace runs on desktop, in the browser and on a phone. It is free during an invite-only preview.
