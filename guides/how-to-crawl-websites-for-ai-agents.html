How to crawl websites for AI agents (and pick an AI web crawler)

An AI web crawler fetches pages, renders JavaScript when needed, and returns clean Markdown or JSON a model can read. Pick by job: an open-source library like Crawl4AI for free local crawls, a hosted API like Firecrawl when you want reliability without running browsers, and a browser agent like Browser Use or Stagehand only for logged-in or interactive pages.

Steps

  1. Decide the output. Markdown for RAG or agent context, typed JSON for a database, or actions for a browser agent. The output decides the tool: a Markdown crawler will not give you a typed schema, and a browser agent is slow, expensive bulk crawling.
  2. Scope the crawl. List seed URLs or a sitemap, include-patterns, a depth cap, and a page cap. Then check robots.txt and the site's terms before you fetch anything.
  3. Pick the fetch layer. Plain HTTP is enough for static pages. Reach for a headless browser only when the content needs JavaScript to appear.
  4. Pick the tool. Use the table below. A hosted API fits when you want reliability without running browsers. A local library fits when the crawl is free and yours to run. A browser agent fits only for logged-in or interactive pages.
  5. Clean and chunk. Strip navigation, ads, and boilerplate. Chunk by headings. Keep the URL, the page title, the crawl date, and a content hash with every chunk, so you can trace an answer back to its source.
  6. Treat crawled text as untrusted input. Page text can carry prompt injection: instructions hidden in a page that try to make your agent act. Restrict the seeds you crawl, and never let page text trigger tool calls on its own.
  7. Give it to an agent. Expose the crawler through an MCP server: Firecrawl MCP, ScrapeGraph MCP, or Playwright MCP. Use a search API such as Tavily or Exa when the agent needs to find pages rather than crawl a known site.
  8. Recrawl incrementally and spot-check. Compare content hashes and re-embed only the pages that changed. Then spot-check five pages against their source: a clean-looking crawl can still drop a table or merge two sections.

Checklist

  • Output format chosen: Markdown, typed JSON, or actions.
  • Scope set: seed URLs or sitemap, include-patterns, depth and page caps.
  • robots.txt and the site's terms checked.
  • JavaScript rendering only where the content needs it.
  • Every chunk keeps its URL, title, crawl date, and content hash.
  • Crawled text treated as untrusted: no tool calls from page text.
  • Agent hookup chosen: an MCP server, or a search API for finding pages.
  • Recrawl plan set, and five pages spot-checked against their source.

FAQ

What is an AI web crawler?

An AI web crawler fetches pages, renders JavaScript when needed, and returns clean Markdown or JSON a model can read. It is the step between a website and an agent: the crawler turns pages into text the model can use as context or store for retrieval.

Is there a free or open-source AI web crawler?

Yes. Crawl4AI (Apache-2.0), ScrapeGraphAI (MIT), Scrapling (BSD-3-Clause), and Spider (MIT) are free to run on your own machine. Firecrawl's core is open source under AGPL-3.0 and self-hostable, and its hosted plan starts with 1,000 free credits a month.

Is Firecrawl free?

Firecrawl's hosted Free plan gives you 1,000 credits a month, about 1,000 pages, with no card required. Hobby is $19 a month for 5,000 credits and Standard is $99 a month for 100,000. A scrape or crawl costs 1 credit per page, and the JSON format adds 4 credits per page. Credits do not roll over below the Scale plan.

Firecrawl vs Crawl4AI: which should I use?

Use Firecrawl when you want a hosted API and do not want to run browsers yourself. Use Crawl4AI when you want a free local crawl under the permissive Apache-2.0 license and are happy running Python and Playwright. If you self-host Firecrawl's core and build a closed service on it, read the AGPL-3.0 copyleft terms first.

How do I scrape a website with AI?

Decide the output first: Markdown for reading, typed JSON for a database. Then scope the crawl, check robots.txt and the site's terms, and pick the tool from the table below. Clean and chunk the result, keep the source URL and crawl date, and treat the crawled text as untrusted input before you hand it to an agent.

Can an AI agent scrape websites through MCP?

Yes. Firecrawl MCP, ScrapeGraph MCP, and Playwright MCP expose scrape, crawl, and browser tools to any MCP client, so the agent can fetch a page without you writing the crawler. Use a search API such as Tavily or Exa instead when the agent needs to find pages it does not already know.

Is web scraping legal?

There is no single answer, and this is not legal advice. Scraping public data is the usual starting point, but you should respect robots.txt and the site's terms, and rules on personal data vary by country. When in doubt, check the rules where you operate or ask a lawyer.
