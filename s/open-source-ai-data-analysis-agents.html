  1. 1. Paperclip

    business agentsOpen source★ 108,842 GitHub stars

    Self-hosted app for running a team of AI agents like a small company, with org charts, goals, budgets and approval gates across Claude Code, Codex, OpenClaw and other harnesses.

    Pricing (as stated): Open source · Mature

  2. 2. RuView

    robotics & physical AIOpen source★ 104,343 GitHub stars

    RuView is an MIT-licensed sensing system that turns ordinary WiFi signals into spatial awareness without cameras or wearables: it detects people, tracks movement and estimates breathing and heart rate room by room, even through walls and in the dark. It runs on low-cost ESP32 hardware, exposes presence and vitals to Home Assistant, Apple Home, Google Home and Alexa through MQTT, HAP or Matter, and ships an AI toolkit and trained models for building your own sensing apps.

    Pricing (as stated): Open source · Mature

  3. 3. PPT Master

    productivityOpen source★ 71,178 GitHub stars

    PPT Master is an MIT-licensed tool that turns documents or topics into native, editable PowerPoint decks with real shapes, transitions and animations, data-backed charts and tables, audio narration from speaker notes, and support for your own .pptx templates. It can read PDFs, Word files and web pages, structure the narrative and write a .pptx you can keep editing in PowerPoint; v6.9.0 shipped Nov 8, 2026.

    Pricing (as stated): Free and open source (MIT). · Mature

  4. 4. CLI-Anything

    agent infraOpen source★ 57,786 GitHub stars

    CLI-Anything, from the HKU Data Science lab (HKUDS), is an Apache-2.0 project that turns existing desktop software, codebases and web APIs into agent-native command-line tools, so coding agents like Claude Code can drive programs such as Blender, GIMP, LibreOffice or CAD apps through structured commands with previews instead of screenshots. Its CLI-Hub (pip install cli-anything-hub) lets agents browse and install community-built CLIs, and contributors can add new harnesses by pull request.

    Pricing (as stated): Open source (Apache-2.0) · Active

  5. 5. PrivateGPT

    frameworksOpen source★ 57,620 GitHub stars

    PrivateGPT is an Apache-2.0 API layer that turns local models into private AI applications: it speaks a Claude-style messages API and adds file ingestion, retrieval with citations and agentic RAG, built-in tools (web search, web fetch, code execution), custom tools, MCP connectors and structured access such as text-to-SQL. It does not run models itself; it connects to any OpenAI-compatible inference server (Ollama, llama.cpp, vLLM and others) and ships a workbench UI at /ui for testing.

    Pricing (as stated): Free and open source (Apache-2.0). The same team also offers the commercial on-premise Zylon platform (no price listed in this update). · Mature

  6. 6. Scientific Agent Skills

    researchOpen source★ 56,830 GitHub stars

    Scientific Agent Skills, formerly Claude Scientific Skills, is K-Dense's MIT-licensed library of 177 validated Agent Skills plus connectors to more than 100 scientific databases for biology, chemistry, medicine and drug discovery; it works with Cursor, Claude Code, Codex and any agent that supports the open Agent Skills standard, and also powers K-Dense BYOK, a free desktop co-scientist that runs on your own API keys.

    Pricing (as stated): Open source · Mature

  7. 7. Goose

    codingOpen source★ 55,956 GitHub stars

    goose is an Apache-2.0, general-purpose AI agent that runs on your own machine as a desktop app (macOS, Linux, Windows), a CLI and an embeddable API, built in Rust. It installs, runs, edits and tests code, and also handles research, writing, automation and data analysis. It works with 15+ model providers including Anthropic, OpenAI, Google, Ollama, OpenRouter, Azure and Bedrock, can reuse existing Claude, ChatGPT or Gemini subscriptions through ACP, and connects to 70+ MCP extensions. goose is part of the Agentic AI Foundation at the Linux Foundation.

    Pricing (as stated): Open source · Mature

  8. 8. LlamaIndex

    frameworksOpen source + cloud★ 52,743 GitHub stars

    LlamaIndex is an MIT-licensed Python framework for building agents and RAG pipelines over your own documents and data, with connectors, indexes, query engines and agent workflows. The company now focuses on document parsing and extraction: LlamaParse is its hosted platform for agentic OCR, parsing, extraction and indexing, and LiteParse is a free, fast open-source parser.

    Pricing (as stated): Open source + paid cloud · Mature

  9. 9. DeepTutor

    education & tutoringOpen source★ 51,307 GitHub stars

    DeepTutor is an Apache-2.0 lifelong personalized tutoring agent from HKU DS that turns your study materials into guided explanations, practice, mastery tracking and long-term learning support. It offers a desktop app, a CLI for agent-native use, narrated video lessons, notebooks, Anki and calendar exports, and a skills community; v1.7.2 shipped Nov 6, 2026 with complete desktop downloads, selected-text speech, NVIDIA NIM embeddings and a Korean interface preview.

    Pricing (as stated): Free and open source (Apache-2.0). · Mature

  10. 10. OpenViking

    memory & RAGOpen source★ 41,191 GitHub stars

    OpenViking is an AGPL-3.0 context database for AI agents from ByteDance's Volcano Engine that keeps memory, knowledge and skills in one virtual filesystem under viking://. Agents navigate it with ls, tree, read, write and grep, every directory carries a generated summary so they can scan before reading, and people can open any folder to inspect or correct what an agent knows. It runs self-hosted or in the browser via OpenViking Studio, with retrieval tuned for long-running agents.

    Pricing (as stated): Open source · Mature

  11. 11. Marker

    data & analyticsOpen source + cloud★ 40,995 GitHub stars

    Marker is Datalab's Apache-2.0 converter that turns PDFs, scans, spreadsheets and slides into Markdown, HTML or JSON for people and for agents. GitHub listed 40,995 stars on datalab-to/marker on 20 Nov 2026. Datalab's site says new users get free credit and then pay per 1,000 pages; this listing does not repeat a dollar rate.

    Pricing (as stated): Open source + cloud · Mature

  12. 12. PDFMathTranslate

    researchOpen source★ 38,419 GitHub stars

    PDFMathTranslate (pdf2zh) translates scientific PDFs while keeping the original layout: formulas, charts, tables of contents and annotations stay in place and it outputs bilingual or translated-only files. It works with Google, DeepL, OpenAI, Ollama and other translation services, adds experimental OCR and an ultrafast mode for native-text PDFs, and runs as a CLI, a desktop or web GUI, Docker, an MCP server or a Zotero plugin. AGPL-3.0; an EMNLP 2025 demo paper.

    Pricing (as stated): Open source · Mature

  13. 13. Tabby

    codingOpen source + cloud★ 33,923 GitHub stars

    Self-hosted AI coding assistant that offers an on-premises alternative to GitHub Copilot with no database or cloud service required.

    Pricing (as stated): Open source + cloud · Mature

  14. 14. FinceptTerminal

    finance & accountingOpen source + cloud★ 33,795 GitHub stars

    Fincept Terminal is an AGPL-3.0 desktop finance terminal for market analytics, investment research and economic data, with multi-agent AI research, portfolio tools, backtesting and data from hundreds of sources in one interface. The open-source edition is free; a paid Enterprise edition adds real-time data, live broker and algorithmic execution and priority support from $15 per user a month.

    Pricing (as stated): Open source + cloud · Mature

  15. 15. Chroma

    memory & RAGOpen source + cloud★ 29,609 GitHub stars

    Open-source search and vector database widely used for agent memory and RAG.

    Pricing (as stated): Open source + cloud · Mature

  16. 16. Chat2DB

    data & analyticsOpen source★ 28,348 GitHub stars

    Chat2DB is a local-first database client where you ask questions in plain language and get SQL

    Pricing (as stated): Open source · Mature

  17. 17. Dbx

    MCP serversOpen source + cloudLocal only★ 28,251 GitHub stars

    25 MB lightweight cross-platform database client for 100+ databases, including MySQL, PostgreSQL, SQLite, Redis, MongoDB, DuckDB, SQL Server, and Dameng. Built-in AI, MCP Server, CLI, desktop and Docker.

    Pricing (as stated): Open-source (Apache-2.0); see site for any hosted plans · Mature

  18. 18. Opik

    evals & observabilityOpen source + cloud★ 23,035 GitHub stars

    Opik is Comet's Apache-2.0 platform for LLM observability and evaluation: it traces LLM calls, RAG pipelines and agent runs, scores them with built-in and custom metrics (including LLM-as-judge), runs experiments on datasets, manages prompts and monitors production traffic with dashboards. SDKs and integrations cover Python, TypeScript, OpenAI, LangChain, LlamaIndex and other frameworks. The full platform is free to self-host, or you can use Comet's hosted cloud.

    Pricing (as stated): Open source + cloud · Mature

  19. 19. Teable

    data & analyticsOpen source + cloud★ 21,938 GitHub stars

    AI spreadsheet and database for business with built-in agents.

    Pricing (as stated): Open source + cloud · Mature

  20. 20. Cube

    data & analyticsOpen source★ 21,133 GitHub stars

    Cube is an open-source semantic layer that lets BI tools and AI agents query the same metrics

    Pricing (as stated): Open source · Mature

  21. 21. Excelize

    frameworksOpen source + cloud★ 21,025 GitHub stars

    Go language library for reading and writing Microsoft Excel™ (XLAM / XLSM / XLSX / XLTM / XLTX) spreadsheets

    Pricing (as stated): Open-source (BSD-3-Clause); see site for any hosted plans · Mature

  22. 22. WrenAI

    data & analyticsOpen source + cloud★ 18,020 GitHub stars

    Generative BI for agents: governed text-to-SQL with a semantic context layer.

    Pricing (as stated): Open source + cloud · Mature

  23. 23. Memori

    memory & RAGOpen source + cloud★ 17,231 GitHub stars

    An LLM-, database- and framework-agnostic memory layer that turns what agents do and say into structured, persistent state they can recall in later runs. Open source to self-host, or use Memori Cloud with an API key.

    Pricing (as stated): Open source to self-host; Memori Cloud has a free tier. · Mature

  24. 24. MCP Toolbox for Databases

    MCP serversOpen sourceNot yet checked★ 16,762 GitHub stars

    Pricing (as stated): Open source · Mature
