  1. 1. Open Code Review

    codingOpen source★ 49,071 GitHub stars

    Alibaba's AI code review CLI that combines deterministic pipelines with an LLM agent to post line-level comments on Git diffs, using OpenAI or Anthropic models.

    Pricing (as stated): Open source · Mature

  2. 2. GitHub MCP Server

    MCP serversOpen source★ 34,082 GitHub stars

    GitHub's official MCP server for letting agents work with repositories, issues, pull requests and Actions.

    Pricing (as stated): Open source · Mature

  3. 3. Open SWE

    codingOpen source★ 11,146 GitHub stars

    LangChain's asynchronous coding agent that takes work from GitHub issues, Slack or Linear, implements it in an isolated sandbox and opens a pull request.

    Pricing (as stated): Open source · Mature

  4. 4. Emdash

    codingOpen source★ 6,120 GitHub stars

    A free, open-source agentic development environment (YC W26) for running Claude Code, Codex and other coding agents in parallel, each in its own worktree, then reviewing diffs, PRs and CI in one place.

    Pricing (as stated): Free and open source (Apache-2.0). · Mature

  5. 5. Redamon

    MCP serversOpen source + cloud★ 3,246 GitHub stars

    Open-source, self-hosted AI penetration testing framework: maps your attack surface into a graph, autonomously exploits it from a Kali sandbox with human approval gates, and opens PRs that fix what.

    Pricing (as stated): Open source + cloud · Active

  6. 6. Shippie

    QA & testingOpen source★ 2,514 GitHub stars

    Extendable code review and QA agent that reads your diff, explores the codebase and posts focused review comments.

    Pricing (as stated): Open source · Active

  7. 7. PR Lens

    codingOpen source★ 2,298 GitHub stars

    PR Lens helps people review code that agents wrote. For each pull request it draws animated architecture and data-flow diagrams inside the PR, showing which parts of the app were added, changed or removed, what else depends on the change and how a request now moves through the system. It also flags likely bugs, security holes and design problems in the same review comment, with a ready prompt to hand each fix to your coding agent or an autofix. The open-source core runs locally and installs as an agent skill.

    Pricing (as stated): Open-source core (MIT), runs locally; installs as an agent skill · Active

  8. 8. Kodus

    codingOpen source + cloud★ 1,548 GitHub stars

    Self-hostable AI code reviewer for GitHub, GitLab, Bitbucket and Azure DevOps pull requests that works with the model you choose.

    Pricing (as stated): Open source + cloud · Active

  9. 9. Superlog

    evals & observabilityOpen source + cloud★ 1,476 GitHub stars

    Superlog runs AI agents on routine engineering work around production. You set up automations with triggers and connectors, for example rating each new Sentry issue, posting a plain-language summary to Slack and opening a pull request with the fix, comparing error rates and latency against their normal range every hour, adding missing logs and spans to hard-to-debug code paths, or answering community questions from your code and docs. You choose the model and agent harness and bring your own tokens or subscriptions. The core is open source (Apache-2.0) with a hosted version.

    Pricing (as stated): Open source (Apache-2.0) to self-host; hosted plans and enterprise on the pricing page; bring your own model tokens or subscriptions · Active

  10. 10. Tracely

    evals & observabilityOpen source + cloud★ 1,209 GitHub stars

    Tracely is open-source, trace-native CI/CD for AI agents: it grades every production trace with evaluators, clusters failures into issues, freezes bad runs into replayable test cases and blocks pull requests that would reintroduce them.

    Pricing (as stated): Self-host free (MIT); hosted Free $0 (20k traces/month), Team $49/mo; LLM judges run on your own OpenRouter key · Active

  11. 11. OpenQodex

    codingOpen source★ 1,067 GitHub stars

    Code review that runs inside your coding agent before you push, combining security and quality scanners with a separate AI reviewer.

    Pricing (as stated): Open source · Active

  12. 12. Aletheore

    security & governanceOpen source + cloud★ 659 GitHub stars

    Aletheore audits code repositories and backs every finding with evidence. Its deterministic scanner looks for leaked secrets, vulnerable dependencies and dead code, it can watch live endpoints and draw architecture maps, and it reviews pull requests automatically through a GitHub Action. A built-in MCP server lets coding agents run the same audits.

    Pricing (as stated): Open source + cloud · Active

  13. 13. CodeAF

    codingOpen source★ 596 GitHub stars

    CodeAF is an open-source software factory from AgentField built to run on open models. It ships ready-made specialist agents you call with slash commands, one to build features like a senior developer, one to audit code for security issues and one to review GitHub pull requests, and spreads the work across a pool of models to balance cost and quality.

    Pricing (as stated): Open source · Active

  14. 14. Muxin

    codingOpen source★ 377 GitHub stars

    Muxin is a free, open-source desktop app that puts all your Macs, Linux, Windows and cloud machines in one window, so you can run Claude Code, Codex and other agent CLIs on any of them, see their screens and logs, and take changes to a pull request.

    Pricing (as stated): Free and open source (Apache-2.0) · Active

  15. 15. Orbi

    codingOpen source + cloud★ 239 GitHub stars

    Orbi is an open-source (AGPL-3.0) software factory for GitHub repositories. When you label a GitHub Issue ai-ready, Orbi implements it in an isolated worktree, opens and reviews pull requests in a separate AI review session that checks acceptance criteria and repairs failing tests, merges the exact reviewed commit SHA, and cuts a tagged GitHub Release when a human applies the ai-release label.

    Pricing (as stated): Self-hosted: free and open source (AGPL-3.0 or Sustainable Use License, bring your own model); Cloud: 3 free merged deliveries (no card), Solo $24/month (400M tokens, 1 repo), Pro $66/month (1.2B tokens, 5 repos) · Active

  16. 16. Diffinery

    codingOpen source★ 72 GitHub stars

    Open source, agent-first GitHub alternative on your own Cloudflare account: git hosting, pull requests, Actions-compatible CI, and agents with their own accounts.

    Pricing (as stated): Apache-2.0, free to self-host on your own Cloudflare account; hosted early access · Active
