  1. 1. REA

    MCP serversOpen source★ 410,375 GitHub stars

    MCP server and CLI that lets coding agents reverse engineer native binaries, Electron and JavaScript apps, .NET assemblies and live websites, using Ghidra, Hopper or IDA under the hood.

    Pricing (as stated): Open source · Mature

  2. 2. ECC

    frameworksOpen source + cloud★ 293,059 GitHub stars

    The agent harness performance optimization system. Skills, instincts, memory, security, and research-first development for Claude Code, Codex, Opencode, Cursor and beyond

    Pricing (as stated): Open source + cloud · Mature

  3. 3. Hermes Agent (Nous Research)

    frameworksOpen source★ 258,708 GitHub stars

    Hermes Agent is Nous Research's MIT-licensed, self-improving agent with a built-in learning loop: it writes skills from completed tasks, refines them in use, keeps agent-curated memory and searches its own past conversations. It runs on anything from a $5 VPS to serverless infrastructure, offers a full terminal UI, and one gateway serves Telegram, Discord, Slack, WhatsApp, Signal and the CLI, with any model via Nous Portal, OpenRouter, OpenAI or your own endpoint.

    Pricing (as stated): Free and open source (MIT); model usage billed by your chosen provider. · Active, frequent releases

  4. 4. Firecrawl

    researchOpen source + cloud★ 196,925 GitHub stars

    Pricing (as stated): Open source + paid cloud · Mature

  5. 5. Taste Skill

    codingOpen source★ 112,355 GitHub stars

    Taste Skill is an MIT Agent Skill that pushes coding agents to build polished company websites instead of generic landing pages, enforcing one design system, plain copy, real photos and brand icons, restrained motion, and a browser-based checker and finish gate that verify the rules before a page is done.

    Pricing (as stated): Open source · Mature

  6. 6. Agent-Reach

    researchOpen source★ 106,606 GitHub stars

    Agent Reach is an MIT-licensed CLI that gives an AI agent read and search access to sites it usually cannot reach well, including X, Reddit, YouTube, GitHub, Bilibili and XiaoHongShu, through one tool and without paid platform APIs. It is meant to be installed alongside agents such as Claude Code or OpenClaw so they can pull posts, threads, transcripts and repository data straight into a task; the project and its docs are mainly in Chinese.

    Pricing (as stated): Free and open source (MIT); no API fees, though some platforms may need your own logged-in cookies or a proxy. · Mature

  7. 7. Claude-Mem

    memory & RAGOpen source★ 105,394 GitHub stars

    Claude-Mem is an Apache-2.0 memory plugin for coding agents that records what the agent does during a session, compresses those observations with AI, and feeds the relevant context back into later sessions, so the agent does not start from zero each time. It works with Claude Code, Codex, Gemini CLI, Copilot, OpenCode, OpenClaw, Hermes and others, stores memory locally, and includes search tools for looking back through past work.

    Pricing (as stated): Free and open source (Apache-2.0). · Mature

  8. 8. Crawl4AI

    browser/computer useOpen source★ 86,582 GitHub stars

    Crawl4AI is an Apache-2.0 web crawler that turns pages into clean, LLM-ready Markdown, extracts structured JSON and handles browser automation for RAG pipelines and agents, runnable yourself with Python or Docker. Crawl4AI Cloud offers the same capabilities as a hosted scrape, extract and search API with managed browsers and proxies, plus setup for Claude Code, Cursor and Codex.

    Pricing (as stated): Open source to self-host; Crawl4AI Cloud includes 1,000 free credits a month. · Mature

  9. 9. Deer Flow

    researchOpen source★ 84,715 GitHub stars

    DeerFlow 2.0 is ByteDance's MIT-licensed super-agent harness for long tasks that can take minutes to hours, such as research reports, coding jobs and content creation. It coordinates sub-agents, long-term memory, sandboxed code execution, tools and extensible skills, and can take requests through a message gateway; version 2.0 is a ground-up rewrite, with the original Deep Research framework kept on a separate branch.

    Pricing (as stated): Free and open source (MIT); you supply your own model API keys. · Mature

  10. 10. Career Ops

It fills in the forms but you press Submit yourself.

    Pricing (as stated): Free and open source (MIT); you use your own AI CLI subscription. · Mature
