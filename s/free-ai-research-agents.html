  1. 1. REA

    MCP serversOpen sourceNot yet checked★ 410,375 GitHub stars

    MCP server and CLI that lets coding agents reverse engineer native binaries, Electron and JavaScript apps, .NET assemblies and live websites, using Ghidra, Hopper or IDA under the hood.

    Pricing (as stated): Open source · Mature

  2. 2. ECC

    frameworksOpen source + cloud★ 293,059 GitHub stars

    The agent harness performance optimization system. Skills, instincts, memory, security, and research-first development for Claude Code, Codex, Opencode, Cursor and beyond

    Pricing (as stated): Open source + cloud · Mature

  3. 3. Hermes Agent (Nous Research)

    frameworksOpen source★ 258,708 GitHub stars

    Hermes Agent is Nous Research's MIT-licensed, self-improving agent with a built-in learning loop: it writes skills from completed tasks, refines them in use, keeps agent-curated memory and searches its own past conversations. It runs on anything from a $5 VPS to serverless infrastructure, offers a full terminal UI, and one gateway serves Telegram, Discord, Slack, WhatsApp, Signal and the CLI, with any model via Nous Portal, OpenRouter, OpenAI or your own endpoint.

    Pricing (as stated): Free and open source (MIT); model usage billed by your chosen provider. · Active, frequent releases

  4. 4. Firecrawl

    researchOpen source + cloud★ 196,925 GitHub stars

    Turns websites into clean, LLM-ready data for agents.

    Pricing (as stated): Open source + paid cloud · Mature

  5. 5. Taste Skill

    codingOpen source★ 112,355 GitHub stars

    Taste Skill is an MIT Agent Skill that pushes coding agents to build polished company websites instead of generic landing pages, enforcing one design system, plain copy, real photos and brand icons, restrained motion, and a browser-based checker and finish gate that verify the rules before a page is done.

    Pricing (as stated): Open source · Mature

  6. 6. Agent-Reach

    researchOpen source★ 106,606 GitHub stars

    Agent Reach is an MIT-licensed CLI that gives an AI agent read and search access to sites it usually cannot reach well, including X, Reddit, YouTube, GitHub, Bilibili and XiaoHongShu, through one tool and without paid platform APIs. It is meant to be installed alongside agents such as Claude Code or OpenClaw so they can pull posts, threads, transcripts and repository data straight into a task; the project and its docs are mainly in Chinese.

    Pricing (as stated): Free and open source (MIT); no API fees, though some platforms may need your own logged-in cookies or a proxy. · Mature

  7. 7. Claude-Mem

    memory & RAGOpen source★ 105,394 GitHub stars

    Claude-Mem is an Apache-2.0 memory plugin for coding agents that records what the agent does during a session, compresses those observations with AI, and feeds the relevant context back into later sessions, so the agent does not start from zero each time. It works with Claude Code, Codex, Gemini CLI, Copilot, OpenCode, OpenClaw, Hermes and others, stores memory locally, and includes search tools for looking back through past work.

    Pricing (as stated): Free and open source (Apache-2.0). · Mature

  8. 8. Crawl4AI

    browser/computer useOpen source★ 86,582 GitHub stars

    Crawl4AI is an Apache-2.0 web crawler that turns pages into clean, LLM-ready Markdown, extracts structured JSON and handles browser automation for RAG pipelines and agents, runnable yourself with Python or Docker. Crawl4AI Cloud offers the same capabilities as a hosted scrape, extract and search API with managed browsers and proxies, plus setup for Claude Code, Cursor and Codex.

    Pricing (as stated): Open source to self-host; Crawl4AI Cloud includes 1,000 free credits a month. · Mature

  9. 9. Deer Flow

    researchOpen source★ 84,715 GitHub stars

    DeerFlow 2.0 is ByteDance's MIT-licensed super-agent harness for long tasks that can take minutes to hours, such as research reports, coding jobs and content creation. It coordinates sub-agents, long-term memory, sandboxed code execution, tools and extensible skills, and can take requests through a message gateway; version 2.0 is a ground-up rewrite, with the original Deep Research framework kept on a separate branch.

    Pricing (as stated): Free and open source (MIT); you supply your own model API keys. · Mature

  10. 10. Career Ops

    personal agentsOpen source★ 78,796 GitHub stars

    Career-Ops is an MIT-licensed job-search agent that runs on your machine inside Claude Code, Codex, OpenCode or another AI CLI. You paste a job or let it scan job boards; it checks whether the posting is still open, scores the fit from 1 to 5 against your CV, tailors an ATS-friendly resume and cover letter, drafts application answers, preps you for interviews and tracks every application. It fills in the forms but you press Submit yourself.

    Pricing (as stated): Free and open source (MIT); you use your own AI CLI subscription. · Mature

  11. 11. TrendRadar

    researchOpen source★ 63,563 GitHub stars

    TrendRadar is a GPL-3.0 trending-news assistant that you can deploy in minutes with Docker, locally or on Cloudflare; it gathers hot lists and RSS feeds from many platforms, filters them by your keywords or with AI, adds AI analysis and translation, and pushes alerts to WeChat Work, Feishu, Telegram, Slack, ntfy, Bark or email, with an MCP server so AI clients can query the news. Its main docs are in Chinese.

    Pricing (as stated): Open source · Mature

  12. 12. MemPalace

    memory & RAGOpen source★ 60,133 GitHub stars

    MemPalace is an MIT-licensed, local-first memory system for AI agents that stores conversation history as verbatim text (it does not summarize or paraphrase) and retrieves it with semantic search. People and projects are organised as wings, topics as rooms and original content in drawers so searches can be scoped, and the retrieval backend is pluggable (ChromaDB by default) with no API calls required. Official docs are at mempalaceofficial.com; v3.11.0 shipped Oct 14, 2026.

    Pricing (as stated): Free and open source (MIT). · Mature

  13. 13. PrivateGPT

    frameworksOpen source★ 57,620 GitHub stars

    PrivateGPT is an Apache-2.0 API layer that turns local models into private AI applications: it speaks a Claude-style messages API and adds file ingestion, retrieval with citations and agentic RAG, built-in tools (web search, web fetch, code execution), custom tools, MCP connectors and structured access such as text-to-SQL. It does not run models itself; it connects to any OpenAI-compatible inference server (Ollama, llama.cpp, vLLM and others) and ships a workbench UI at /ui for testing.

    Pricing (as stated): Free and open source (Apache-2.0). The same team also offers the commercial on-premise Zylon platform (no price listed in this update). · Mature

  14. 14. Scientific Agent Skills

    researchOpen source★ 56,830 GitHub stars

    Scientific Agent Skills, formerly Claude Scientific Skills, is K-Dense's MIT-licensed library of 177 validated Agent Skills plus connectors to more than 100 scientific databases for biology, chemistry, medicine and drug discovery; it works with Cursor, Claude Code, Codex and any agent that supports the open Agent Skills standard, and also powers K-Dense BYOK, a free desktop co-scientist that runs on your own API keys.

    Pricing (as stated): Open source · Mature

  15. 15. Goose

    codingOpen source★ 55,956 GitHub stars

    goose is an Apache-2.0, general-purpose AI agent that runs on your own machine as a desktop app (macOS, Linux, Windows), a CLI and an embeddable API, built in Rust. It installs, runs, edits and tests code, and also handles research, writing, automation and data analysis. It works with 15+ model providers including Anthropic, OpenAI, Google, Ollama, OpenRouter, Azure and Bedrock, can reuse existing Claude, ChatGPT or Gemini subscriptions through ACP, and connects to 70+ MCP extensions. goose is part of the Agentic AI Foundation at the Linux Foundation.

    Pricing (as stated): Open source · Mature

  16. 16. Agentic Awesome Skills

    codingOpen source★ 49,467 GitHub stars

    Agentic Awesome Skills, formerly Antigravity Awesome Skills, is a library of more than 2,900 installable SKILL.md playbooks for Claude Code, Codex, Cursor, Gemini CLI and other coding agents, with AAS Core, a tool that lets Codex or Claude search the full local catalog, record the skills it picks and preview a plan before changing your project; the code is MIT and imported skills keep their own licences.

    Pricing (as stated): Open source · Mature

  17. 17. Open Code Review

    codingOpen source★ 49,071 GitHub stars

    Open Code Review is Alibaba's Apache-2.0 AI code review CLI (ocr), used internally by tens of thousands of Alibaba developers before it was open-sourced. It reads Git diffs and sends changed files to an agent that can read whole files, search the codebase and inspect related changes, then posts structured line-level comments; deterministic pipelines and a built-in multi-language ruleset catch issues like null-pointer risks, thread safety, XSS and SQL injection, and ocr scan reviews whole files or folders without a diff. It works with any OpenAI- or Anthropic-compatible model endpoint.

    Pricing (as stated): Open source · Mature

  18. 18. LibreChat

    personal agentsOpen source★ 46,482 GitHub stars

    LibreChat is an MIT-licensed, self-hosted multi-user AI chat platform that puts OpenAI, Anthropic, Google Gemini, AWS Bedrock, Azure, Mistral, OpenRouter and other providers behind one ChatGPT-style interface. It includes agents with MCP tools and skills, a code interpreter, artifacts, message search, presets and secure multi-user auth; v0.8.8 added a beta Agent Management API with OpenAPI docs, per-agent workspaces and Ask/Allow/Deny approval controls for file writes and commands.

    Pricing (as stated): Open source · Mature

  19. 19. MindsHub

    productivityOpen source + cloud★ 39,831 GitHub stars

    MindsDB's agent workspace for research, analysis, documents and coding, with a model router, a scoped vault for connected data and swappable open-source agent harnesses.

    Pricing (as stated): Open source + cloud · Mature

  20. 20. Vane

    researchOpen source★ 37,844 GitHub stars

    Open-source AI answering engine that searches the web and replies with sources, self-hostable.

    Pricing (as stated): Open source · Mature

  21. 21. Vibe-Trading

    cryptoOpen source★ 37,194 GitHub stars

    Open-source personal trading agent for researching markets and testing strategies in natural language.

    Pricing (as stated): Open source · Mature

  22. 22. ScrapeGraphAI

    browser/computer useOpen source + cloud★ 32,368 GitHub stars

    Python library that uses LLMs and graph logic to build scraping pipelines: describe the data you want and it extracts it from websites or documents.

    Pricing (as stated): Open source + cloud · Mature

  23. 23. STORM

    researchOpen source★ 31,749 GitHub stars

    Stanford system that writes Wikipedia-style articles from web research.

    Pricing (as stated): Open source · Research project; no recent updates (last commit Sep 2025)

  24. 24. OpenCLI

    Pricing (as stated): Open source · Mature
