  1. 1. opencode

    codingOpen source★ 223,180 GitHub stars

    OpenCode is an MIT-licensed open-source AI coding agent for the terminal, with a beta desktop app, that works with many model providers instead of locking you to one. Install it with a one-line script, npm, Homebrew, pacman, mise or Nix, then let it read your repository, edit files and run commands from a keyboard-driven TUI.

    Pricing (as stated): Free and open source (MIT); bring your own model provider. · Active

  2. 2. OpenAI Codex CLI

    codingOpen source★ 131,661 GitHub stars

    Codex CLI is OpenAI's Apache-2.0 coding agent that runs locally in your terminal, reading your repository, editing files and running commands, with standalone installers for macOS, Linux and Windows plus npm and Homebrew. The same agent is available as IDE extensions for VS Code, Cursor and Windsurf, a desktop app via codex app, and the cloud-based Codex Web in ChatGPT.

    Pricing (as stated): Open source CLI; usage through a ChatGPT plan or OpenAI API key. · Mature

  3. 3. Orca

    codingOpen source★ 110,696 GitHub stars

    Orca is an MIT-licensed desktop app for running a fleet of coding agents such as Claude Code and Codex in parallel on your own subscriptions, each in its own git worktree, with diffs, a built-in browser and a CLI in one place. You can drive an agent in a chat view or its raw terminal and switch between them without losing context, hand a big task to one agent that splits it across worker agents, and keep agents running on a remote Orca server, any SSH host or a cloud VM after you close your laptop; there are mobile apps too.

    Pricing (as stated): Free and open source (MIT); you use your own Claude, Codex or other agent subscriptions. · Mature

  4. 4. Cline

    codingOpen source★ 71,064 GitHub stars

    Cline is an Apache-2.0 open-source coding agent that runs as a VS Code extension, a JetBrains plugin, a macOS and Windows desktop app, a CLI (npm i -g cline, interactive or headless for CI) and an SDK for building your own agents. It creates and edits files, runs commands, browses the web and uses MCP tools with human-in-the-loop approval for each step, and works with the model provider of your choice.

    Pricing (as stated): Open source · Mature

  5. 5. Daily Stock Analysis

    finance & accountingOpen source★ 69,916 GitHub stars

    Daily Stock Analysis is an MIT-licensed, LLM-driven system that analyses a personal watchlist across A-shares, Hong Kong, US, Japanese, Korean and Taiwanese stocks and ETFs, pulling quotes, technical indicators, news and filings, then pushes a daily decision dashboard with scores, levels, risk alerts and a checklist to WeCom, Feishu, Telegram, Discord, Slack or email. It runs free on GitHub Actions, Docker or locally, has a web and desktop workbench with backtests, and an agent mode for follow-up questions using 15 built-in strategies. It is not financial advice.

    Pricing (as stated): Open source · Mature

  6. 6. AnythingLLM

    personal agentsOpen source + cloud★ 67,747 GitHub stars

    Local-first desktop and server app for chatting with your documents, running agents and connecting any LLM.

    Pricing (as stated): Open source + cloud · Mature

  7. 7. Warp

    codingOpen source + cloud★ 65,787 GitHub stars

    Warp is an agentic development environment born out of the terminal, and the project is now open source under AGPL-3.0. You can use Warp's built-in coding agent or bring your own CLI agent such as Claude Code, Codex or Gemini CLI, and the repo also describes Warp Factories, infrastructure for teams to run cloud software factories defined in code. The desktop app is available from warp.dev.

    Pricing (as stated): The source repository is free and open source (AGPL-3.0); Warp also offers a hosted product at warp.dev (no price listed in this update). · Mature

  8. 8. T3 Code

    codingOpen source★ 57,908 GitHub stars

    T3 Code is an MIT-licensed control plane for coding agents from the T3 team: it runs Claude Code, Codex, Cursor, OpenCode, Grok Build, Kiro and any ACP agent on your own machine and gives them one interface on desktop, web, iOS and Android. It drives the subscriptions you already have rather than reselling tokens, lets you switch models or hand a task from one agent to another mid-thread, and supports remote machines over your LAN or Tailscale.

    Pricing (as stated): Open source · Mature

  9. 9. Scientific Agent Skills

    researchOpen source★ 56,830 GitHub stars

    Scientific Agent Skills, formerly Claude Scientific Skills, is K-Dense's MIT-licensed library of 177 validated Agent Skills plus connectors to more than 100 scientific databases for biology, chemistry, medicine and drug discovery; it works with Cursor, Claude Code, Codex and any agent that supports the open Agent Skills standard, and also powers K-Dense BYOK, a free desktop co-scientist that runs on your own API keys.

    Pricing (as stated): Open source · Mature

  10. 10. Goose

    codingOpen source★ 55,956 GitHub stars

    goose is an Apache-2.0, general-purpose AI agent that runs on your own machine as a desktop app (macOS, Linux, Windows), a CLI and an embeddable API, built in Rust. It installs, runs, edits and tests code, and also handles research, writing, automation and data analysis. It works with 15+ model providers including Anthropic, OpenAI, Google, Ollama, OpenRouter, Azure and Bedrock, can reuse existing Claude, ChatGPT or Gemini subscriptions through ACP, and connects to 70+ MCP extensions. goose is part of the Agentic AI Foundation at the Linux Foundation.

    Pricing (as stated): Open source · Mature

  11. 11. Cherry Studio

    personal agentsOpen source★ 53,099 GitHub stars

    Cherry Studio is an AGPL-3.0 desktop AI workstation for Windows, macOS and Linux that lets you chat with many cloud and local model providers side by side, run agents, build knowledge bases, generate images and automate everyday tasks from one app. It ships hundreds of ready-made assistants, supports MCP tools, and now has iOS and Android companion apps; a commercial licence is offered for teams that cannot use AGPL.

    Pricing (as stated): Open source · Mature

  12. 12. DeepTutor

    education & tutoringOpen source★ 51,307 GitHub stars

    DeepTutor is an Apache-2.0 lifelong personalized tutoring agent from HKU DS that turns your study materials into guided explanations, practice, mastery tracking and long-term learning support. It offers a desktop app, a CLI for agent-native use, narrated video lessons, notebooks, Anki and calendar exports, and a skills community; v1.7.2 shipped Nov 6, 2026 with complete desktop downloads, selected-text speech, NVIDIA NIM embeddings and a Korean interface preview.

    Pricing (as stated): Free and open source (Apache-2.0). · Mature
