  1. 1. Freebuff

    codingOpen source★ 14,336 GitHub stars

    Freebuff is an Apache-2.0 coding agent from Codebuff. The README says there is no subscription, no credits and no API key, and that text ads pay for the included models. It names four products: a desktop app that runs agents locally, a CLI, a web builder for full-stack apps, and a cloud runner for GitHub repositories. GitHub CodebuffAI/freebuff showed 14,336 stars and 1,551 forks on 27 Nov 2026.

    Pricing (as stated): Apache-2.0. The README says access is free and funded by text ads. No subscription price was listed. Checked 27 Nov 2026. · Mature

  2. 2. Bindu

    agent infraOpen source★ 10,022 GitHub stars

    Identity, communication and payments layer that lets AI agents talk to and pay each other.

    Pricing (as stated): Open source · Mature

  3. 3. x402

    cryptoOpen standard★ 6,772 GitHub stars

    Open HTTP payment standard so agents can pay for APIs per request in stablecoins.

    Pricing (as stated): Open standard · Active

  4. 4. ClawRouter

    cryptoOpen source★ 6,645 GitHub stars

    The agent-native LLM router for autonomous agents. Every frontier model behind one wallet, <1ms local routing, USDC payments on Base & Solana via x402

    Pricing (as stated): Open source · Mature

  5. 5. Sphere SDK

    cryptoOpen source★ 5,387 GitHub stars

    TypeScript SDK that gives autonomous agents an identity and wallet on the Unicity network to find, negotiate and settle payments with other agents.

    Pricing (as stated): Free and open source (MIT) · Mature

  6. 6. vAPI Network

    cryptoOpen source★ 3,876 GitHub stars

    vapi-network is an Apache-2.0, non-custodial TypeScript client from vAPI Network for finding and paying x402 APIs in USDC on Base from a terminal, an MCP client or your own code; keys stay encrypted on your device, a spend policy is checked before each payment is signed, payments go straight to the provider with no vAPI fee, and each call leaves a local receipt. It is not related to the voice company Vapi.ai.

    Pricing (as stated): Open source · Active

  7. 7. MonoCode

    codingOpen source★ 3,489 GitHub stars

    MonoCode is a desktop app that puts the coding agents you already pay for behind one interface. It drives Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity, Pi, Hermes Agent, Devin and others, using the subscriptions and logins already on your machine, so you never buy tokens through it. Each tab is an agent session and one composer sends work to whichever agent you pick, so several sessions can run side by side. It runs on macOS, Windows and Linux, with an iOS app in public beta.

    Pricing (as stated): Free and open source (MIT); uses your existing agent subscriptions, sells no tokens · Active

  8. 8. AnyModelBot

    personal agentsOpen source★ 2,741 GitHub stars

    Pricing (as stated): Open source · Active
