    agent infraOpen source★ 10,032 GitHub stars

    Identity, communication and payments layer that lets AI agents talk to and pay each other.

    Pricing (as stated): Open source · Mature

  2. 2. x402

    cryptoOpen standard★ 6,760 GitHub stars

    Open HTTP payment standard so agents can pay for APIs per request in stablecoins.

    Pricing (as stated): Open standard · Active

  3. 3. Sphere SDK

    cryptoOpen source★ 5,387 GitHub stars

    TypeScript SDK that gives autonomous agents an identity and wallet on the Unicity network to find, negotiate and settle payments with other agents.

    Pricing (as stated): Free and open source (MIT) · Mature

  4. 4. MonoCode

    codingOpen source★ 3,374 GitHub stars

    MonoCode is a desktop app that puts the coding agents you already pay for behind one interface. It drives Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity, Pi, Hermes Agent, Devin and others, using the subscriptions and logins already on your machine, so you never buy tokens through it. Each tab is an agent session and one composer sends work to whichever agent you pick, so several sessions can run side by side. It runs on macOS, Windows and Linux, with an iOS app in public beta.

    Pricing (as stated): Free and open source (MIT); uses your existing agent subscriptions, sells no tokens · Active

  5. 5. Stripe Agent Toolkit

    MCP serversOpen source★ 1,967 GitHub stars

    Stripe's agent toolkit and MCP server for customers, payments and billing.

    Pricing (as stated): Open source · Active

  6. 6. Decionis

    security & governanceOpen source + cloud★ 671 GitHub stars

    Decionis is an approval gateway for actions taken by AI agents. It sits in front of consequential API calls such as payments, price changes and orders, checks each one against your policy before it runs, and only lets it through with a single-use permit, keeping a signed record of every decision for audit.

    Pricing (as stated): Open source + cloud · Active

  14. 14. Sundae

    personal agentsFreemium

    Sundae is a personal AI assistant you text from iMessage or Android RCS, with no app or account needed. It works on a computer of its own: it books tables, finds flights at current prices, compares shops, reads letters and photos you send, sets reminders, watches prices and builds simple web pages, then texts back with a screenshot so you can check. It remembers what you tell it, asks before spending money, sending, deleting or opening accounts, and stops at checkout for you to pay. It is free to start with a daily limit, with a paid Plus plan, and is in limited beta.

    Pricing (as stated): Free to start with a daily limit; paid Plus plan raises it; limited beta · Active

  15. 15. Wren Pre-sign Check

    security & governancePaid

    Wren Pre-sign Check is a pay-per-call x402 API that an AI agent calls before it signs anything with its wallet. Send a transaction (to + data), an EIP-712 typed-data payload or untrusted text, and it returns block, review or allow, the decoded call in plain words and every finding: unlimited approvals, Permit and Permit2 signatures, setApprovalForAll, EIP-7702 delegation, contract deployment and injected instructions. With an optional wren-guard policy (allowlist, spenders, caps) it also blocks unknown recipients, over-cap amounts and lookalike addresses. It is a static check and stores nothing you send; free demos show real output.

    Pricing (as stated): Paid: $0.01 in USDC on Base per check over x402 (EIP-3009 payment authorisation, no approvals); free demo endpoints with fixed examples · Active

  16. 16. Wren x402 Doctor

    cryptoFreemium

    Wren x402 Doctor helps sellers of x402 pay-per-call endpoints, the payment standard AI agents use to pay for APIs in USDC, get listed in the Coinbase CDP Bazaar and stay listed. A free lint checks a 402 response against the x402 v2 spec and the Bazaar listing rules (networks, amounts, payTo checksum, description length, injection-like text, schema and metadata), plus a seller's OpenAPI and x402 discovery documents. Paid endpoints include a Bazaar health check ($0.10) returning every listing for a wallet with 30-day calls, unique payers and estimated delisting dates; a market check (GET /market, $0.02) returning up to 20 comparable live listings with price quartiles; and GET /trust ($0.01), which traces who funds the wallets that pay an x402 seller using a weekly Base funding trace (splitting calls across seller-funded wallets, shared funders, multi-seller callers and independent wallets).

    Pricing (as stated): Freemium: free lint of any 402 response and discovery documents; Bazaar health check $0.10, market check (GET /market) $0.02, and payer funding trace (GET /trust) $0.01 in USDC on Base per report over x402 · Active

  17. 17. Self Agent Vault

    agent infraFreemium

    Payment and login layer for AI agents: agents check out and sign in using mock tokens, while real card numbers and passwords are swapped in out of the agent's view, with spending caps, merchant allowlists and a kill switch.

    Pricing (as stated): Free, Plus and Enterprise tiers; first 1,000 sign-ups get Plus free for three months · Live; launched Oct 15, 2026 by Self Labs
