  1. 1. MarkItDown

    memory & RAGOpen source★ 192,990 GitHub stars

    MarkItDown is Microsoft's MIT-licensed Python tool that converts PDFs, Word, PowerPoint and Excel files, images, audio, HTML, CSV, JSON, ZIP archives and more into clean Markdown that LLMs and agents can read, keeping headings, lists, tables and links. You can call it from the command line or Python, add optional plugins such as Azure Document Intelligence for harder documents, and expose it to Claude Desktop and other agents through the companion markitdown-mcp server.

    Pricing (as stated): Free and open source (MIT). · Mature

  2. 2. HyperFrames

    film & TV productionOpen source★ 75,783 GitHub stars

    HyperFrames is HeyGen's Apache-2.0 framework for turning HTML, CSS, media and seekable animations into deterministic MP4 videos, so a coding agent can write a web page and render it as a video. You can use it from the CLI, from Claude Code, Codex or Cursor after installing its skills with one command, or in the free HyperFrames Studio desktop app, whose Pro plan adds HeyGen's video, image, voice and music models.

    Pricing (as stated): Free and open source (Apache-2.0); the Studio app is free, with an optional paid Pro plan. · Mature

  3. 3. Front-End Checklist

    MCP serversOpen source★ 74,686 GitHub stars

    Front-End Checklist is an MCP server agents call to review frontend code and live pages against 386 quality-gated web development rules.

    Pricing (as stated): Open source · Mature

  4. 4. LiteLLM

    agent infraOpen source + cloud★ 62,372 GitHub stars

    Open-source AI gateway and Python SDK that calls 100+ LLM providers in the OpenAI format, with cost tracking, guardrails, load balancing and logging.

    Pricing (as stated): Open source + cloud · Mature

  5. 5. DeepTutor

    education & tutoringOpen source★ 51,307 GitHub stars

    DeepTutor is an Apache-2.0 lifelong personalized tutoring agent from HKU DS that turns your study materials into guided explanations, practice, mastery tracking and long-term learning support. It offers a desktop app, a CLI for agent-native use, narrated video lessons, notebooks, Anki and calendar exports, and a skills community; v1.7.2 shipped Nov 6, 2026 with complete desktop downloads, selected-text speech, NVIDIA NIM embeddings and a Korean interface preview.

    Pricing (as stated): Free and open source (Apache-2.0). · Mature

  6. 6. LocalAI

    models & local runtimesOpen source★ 50,071 GitHub stars

    Pricing (as stated): Open source · Mature

  7. 7. Fish Audio

    voiceFreemium★ 33,488 GitHub stars

    Fish Audio is a voice AI platform for text to speech, voice cloning and speech to text, with a real-time API for voice agents. Its Drama 3 and S2 models take inline emotion and delivery tags such as whispering, laughing or pauses, it can clone a voice from a few seconds of audio, and its library has more than two million community voices for narration, characters, audiobooks and support agents. The Fish Speech models behind it are published on GitHub and Hugging Face.

    Pricing (as stated): Free tier (8,000 credits a month); Plus $11/mo and Pro $75/mo billed yearly ($15 and $100 monthly); Max $749/mo yearly; API billed by usage · Mature
