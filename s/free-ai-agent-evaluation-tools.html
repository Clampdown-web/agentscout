  1. 1. Firecrawl

    researchOpen source + cloud★ 196,925 GitHub stars

    Firecrawl is an AGPL-3.0 web data API for AI agents, open source and available as a hosted service: Search returns full page content for web results, Scrape turns any URL into clean Markdown, HTML, screenshots or structured JSON, Crawl and Map cover whole sites, Interact clicks, scrolls and types before extracting, and Parse converts PDFs and DOCX files. It handles proxies, rate limits and JavaScript-heavy pages for you, and connects to any agent or MCP client with a single command.

    Pricing (as stated): Open source + paid cloud · Mature

  2. 2. RuView

    robotics & physical AIOpen source★ 104,343 GitHub stars

    RuView is an MIT-licensed sensing system that turns ordinary WiFi signals into spatial awareness without cameras or wearables: it detects people, tracks movement and estimates breathing and heart rate room by room, even through walls and in the dark. It runs on low-cost ESP32 hardware, exposes presence and vitals to Home Assistant, Apple Home, Google Home and Alexa through MQTT, HAP or Matter, and ships an AI toolkit and trained models for building your own sensing apps.

    Pricing (as stated): Open source · Mature

  3. 3. Worldmonitor

    frameworksOpen source + cloud★ 89,781 GitHub stars

    Real-time global intelligence dashboard. AI-powered news aggregation, geopolitical monitoring, and infrastructure tracking in a unified situational awareness interface

    Pricing (as stated): Open source + cloud · Mature

  4. 4. Netdata

    MCP serversOpen sourceNot yet checked★ 81,332 GitHub stars

    Netdata is an MCP server that gives agents a way to handle infrastructure monitoring with metrics, logs, alerts, and ML-based anomaly detection.

    Pricing (as stated): Open source · Mature

  5. 5. Career Ops

    personal agentsOpen source★ 78,796 GitHub stars

    Career-Ops is an MIT-licensed job-search agent that runs on your machine inside Claude Code, Codex, OpenCode or another AI CLI. You paste a job or let it scan job boards; it checks whether the posting is still open, scores the fit from 1 to 5 against your CV, tailors an ATS-friendly resume and cover letter, drafts application answers, preps you for interviews and tracks every application. It fills in the forms but you press Submit yourself.

    Pricing (as stated): Free and open source (MIT); you use your own AI CLI subscription. · Mature

  6. 6. LiteLLM

    agent infraOpen source + cloud★ 62,372 GitHub stars

    Open-source AI gateway and Python SDK that calls 100+ LLM providers in the OpenAI format, with cost tracking, guardrails, load balancing and logging.

    Pricing (as stated): Open source + cloud · Mature

  7. 7. LlamaIndex

    frameworksOpen source + cloud★ 52,743 GitHub stars

    LlamaIndex is an MIT-licensed Python framework for building agents and RAG pipelines over your own documents and data, with connectors, indexes, query engines and agent workflows. The company now focuses on document parsing and extraction: LlamaParse is its hosted platform for agentic OCR, parsing, extraction and indexing, and LiteParse is a free, fast open-source parser.

    Pricing (as stated): Open source + paid cloud · Mature

  8. 8. DeepTutor

    education & tutoringOpen source★ 51,307 GitHub stars

    DeepTutor is an Apache-2.0 lifelong personalized tutoring agent from HKU DS that turns your study materials into guided explanations, practice, mastery tracking and long-term learning support. It offers a desktop app, a CLI for agent-native use, narrated video lessons, notebooks, Anki and calendar exports, and a skills community; v1.7.2 shipped Nov 6, 2026 with complete desktop downloads, selected-text speech, NVIDIA NIM embeddings and a Korean interface preview.

    Pricing (as stated): Free and open source (Apache-2.0). · Mature

  9. 9. Langfuse

    evals & observabilityOpen source + cloud★ 36,753 GitHub stars

    Open-source LLM observability, tracing and evals.

    Pricing (as stated): Open source + paid cloud · Mature

  10. 10. LangChain Deep Agents

    frameworksOpen source★ 30,785 GitHub stars

    Deep Agents is LangChain's MIT-licensed, batteries-included agent harness for long-horizon, multi-step work: an opinionated agent that runs out of the box and lets you override or replace any piece. It provides sub-agents with isolated context windows, a pluggable filesystem (local, sandboxed or remote), context summarisation and offloading, shell access in your sandbox, persistent memory and human-in-the-loop approvals. It is model-agnostic for any tool-calling LLM and builds on LangGraph, with tracing, evals and deployment through LangSmith.

    Pricing (as stated): Open source · Active

  11. 11. MLflow

    evals & observabilityOpen source + cloud★ 28,599 GitHub stars

    Open-source platform for tracing, evaluating and managing agents, LLM apps and ML models.

    Pricing (as stated): Open source + cloud · Mature

  12. 12. Beads

    codingOpen source★ 28,303 GitHub stars

    Issue-tracking memory for coding agents so they can keep track of long-running work.

    Pricing (as stated): Open source · Mature

  13. 13. Open SEO

    sales & marketingOpen source★ 26,592 GitHub stars

    Open SEO is an open-source SEO toolkit for AI agents that audits sites, tracks opportunities and helps agents ship search improvements without a closed SaaS lock-in.

    Pricing (as stated): Open-source (MIT); see site for any hosted plans · Mature

  14. 14. Opik

    evals & observabilityOpen source + cloud★ 23,035 GitHub stars

    Opik is Comet's Apache-2.0 platform for LLM observability and evaluation: it traces LLM calls, RAG pipelines and agent runs, scores them with built-in and custom metrics (including LLM-as-judge), runs experiments on datasets, manages prompts and monitors production traffic with dashboards. SDKs and integrations cover Python, TypeScript, OpenAI, LangChain, LlamaIndex and other frameworks. The full platform is free to self-host, or you can use Comet's hosted cloud.

    Pricing (as stated): Open source + cloud · Mature

  15. 15. Moli

    browser/computer useOpen source★ 21,676 GitHub stars

    Lightweight Rust headless browser for AI agents that fetches pages, searches and extracts content, usable via CLI, CDP or WebDriver.

    Pricing (as stated): Open source · Mature

  16. 16. WeClone

    personal agentsOpen source★ 18,405 GitHub stars

    WeClone distills your identity, goals, preferences and current situation from your chat history and other digital records into a reviewable life portrait organized by domains such as work, family and health, where every fact traces back to its source. That portrait serves as long-term memory for your personal assistants and can power a clone that writes in your own style. Extraction runs through Codex or any OpenAI-compatible API. AGPL-3.0.

    Pricing (as stated): Open source · Mature

  17. 17. CVAT AI Agents

    visionFreemium★ 17,038 GitHub stars

    CVAT feature that runs your own detection, segmentation or tracking model as an agent on your infrastructure and feeds its auto-annotations back into CVAT tasks.

    Pricing (as stated): Freemium · Active

    Pricing (as stated): Open source + cloud · Mature

  20. 20. Oumi

    models & local runtimesOpen source★ 9,419 GitHub stars

    Open platform for fine-tuning, evaluating and deploying open agentic LLMs and VLMs.

    Pricing (as stated): Open source · Mature

  21. 21. Oh Story

    codingOpen source★ 8,731 GitHub stars

    Oh Story is an MIT-licensed pack of 14 agent skills for writing Chinese web novels inside a coding agent such as Claude Code, Codex CLI, Google Antigravity, OpenCode, ZCode, OpenClaw or Reasonix. It covers the whole workflow: scanning charts for trending genres, breaking down hit books, outlines, long-form setting and foreshadowing tracking, short-story twists, a de-AI editing pass and cover images. It uses the files on disk as memory, so long books survive new sessions, and needs no GPU or extra model.

    Pricing (as stated): Open source · Mature

  22. 22. CCPM

    codingOpen source★ 8,454 GitHub stars

    CCPM is an MIT-licensed project-management agent skill from Automaze for spec-driven development: it turns an idea into a PRD, the PRD into an epic, the epic into GitHub Issues, and the issues into code, with traceability at each step. Work runs in parallel across Git worktrees with several agents at once. It installs as an Agent Skill in any compatible harness, including Claude Code, Codex, OpenCode, Factory, Amp and Cursor.

    Pricing (as stated): Open source · Mature

  23. 23. Open SEO MCP Skills

    sales & marketingOpen source★ 8,043 GitHub stars

    Free SEO MCP server plus MIT-licensed SEO and GEO skills for Claude: keyword research, rank tracking, audits, and AI visibility on your own Search Console data.

    Pricing (as stated): Free; MIT skills, hosted Ryze MCP connector with Google sign-in, DataForSEO billed at cost · Mature

  24. 24. Tick Stock Panel (TSP)

    finance & accountingOpen source★ 7,830 GitHub stars

    TSP (Tick Stock Panel) is a self-hosted, MIT-licensed quant workbench for China A-shares that runs in a single Docker container with no external database. You write or customize strategies with help from an LLM assistant, scan the whole market in milliseconds with a Polars engine, run backtests and factor mining, and monitor positions in a React dashboard, with data sources as plugins and every capability exposed as an API. The author stresses it is a research tool, not investment advice or a stock-picking app.

    Pricing (as stated): Open source · Mature

  25. 25. GEPA

    evals & observabilityOpen source★ 7,513 GitHub stars

    GEPA is an MIT library for optimizing text you can score, including prompts, code and agent architectures, by letting a model reflect on what failed and searching for better variants. The docs site is the project homepage. GitHub listed 7,513 stars on gepa-ai/gepa on 20 Nov 2026.

    Pricing (as stated): Open source · Mature
